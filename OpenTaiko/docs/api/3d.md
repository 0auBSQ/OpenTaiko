# 3D engine: rasterizer world <span class="badge-exp">Experimental</span>

Scenes, models, lights, cameras, physics, colliders, pathfinding, particles, render targets and terrain heightmaps.

The 3D engine is experimental. The plan is to drop the experimental label with version 1.0.

<div class="callout">
Every global and every method on this page can change between releases without a deprecation period. If your skin relies on it, test again after each update and state which game version you target.
</div>

Conventions used on this page:

- Positions and sizes are world units; +Y is up. Object, texture, sprite, material and primitive ids are integers.
- Angles are degrees unless a row says radians (physics vehicle heading and tilt, wheel spin, grass sway phase).
- `Clear`, `FillRect`, `DrawLine`, `SetFog`, `ObjSetPass`, `PsEmit` and `PsBurst` take 0-255 colours. Lights, the sun, ambient, materials, tints and `ObjSetColor` take linear 0-1 colours.
- Three renderers share the same scene data: the GPU rasterizer (default when GLES 3.1 compute shaders are available), the CPU rasterizer (fallback, or forced with `SetMode("raster_cpu")`) and the path tracer (`SetMode("raytrace")`). The other renderers ignore rows marked *GPU rasterizer only* or *path tracer only*.

The raytracer and the physics world have their own pages: [raytracer world](3d-raytrace.md) and [physics](3d-physics.md).

## Scenes

### SCENE3D

<span class="badge-exp">Experimental</span>

Factory for 3D scenes. A scene is a render target that owns a camera, retained objects, textures, sprites, lights and particle systems; you draw it like a 2D texture.

| Method | Description |
| --- | --- |
| `SCENE3D:CreateScene(width, height)  -> scene` | Create a scene with the given logical size in pixels and return its handle. The game disposes the scene when it tears down the script's stage. |

### Scene handle

<span class="badge-exp">Experimental</span>

<div class="callout warn">
Per-frame flow: draw the background (FillRect or ClearTransparent), update the camera and any per-frame geometry, call Render, then Upload, then Draw. Render does not clear the colour buffer, so draw the sky or backdrop first.
</div>

```lua
local scene, floor

function onStart()
    scene = SCENE3D:CreateScene(1280, 720)
    scene:SetLighting(true)
    scene:SetAmbient(0.4, 0.4, 0.46)
    scene:SetSun(0.3, 0.8, 0.5, 0.85, 0.82, 0.72)

    scene:RegisterTexture(1, pixels, 16, 16)          -- pixels: 1-based array of 0xRRGGBB ints
    floor = scene:NewObject()
    scene:ObjAddQuadTex(floor, 0,0,0,  0,0,8,  8,0,8,  8,0,0,  1, 8, 8, 1.0)
    scene:ObjSetBounds(floor, 0, 0, 0, 8, 0, 8)
end

function draw()
    scene:SetCameraPosition(4, 3, -6)
    scene:SetCameraAngles(0, -20)
    scene:FillRect(0, 0, 1280, 720, 90, 140, 220, 255)
    scene:Render()
    scene:Upload()
    scene:Draw(0, 0)
end

function onDestroy()
    scene:Dispose()
end
```

#### Renderer

| Method | Description |
| --- | --- |
| `scene:SetMode(mode)  -> nil` | Choose the renderer: `"raster"` (default; GPU when available, otherwise CPU), `"raster_cpu"`, `"raytrace"` or `"rt"` (GPU path tracer with CPU fallback), `"raytrace_cpu"` or `"rt_cpu"`. Switching drops cached and accumulated state. |
| `scene:GetMode()  -> string` | Active renderer: `"raster"`, `"raster_cpu"` or `"raytrace"`. |

| `scene:SetRenderDistance(d)  -> nil` | Skip objects whose bounds (see ObjSetBounds) lie entirely beyond this distance from the camera; 0 = unlimited. Rasterizers only. |
| `scene:SetAntialias(on)  -> nil` | Enable post-process edge smoothing on the final colour buffer (off by default). |
| `scene:GetSampleCount()  -> number` | Path tracer samples accumulated per pixel since the last camera or scene change; 0 in raster modes. |
| `scene:GetMemoryStats()  -> texCount, texBytes, spriteCount, objCount, grassBlades, liveParticles` | Resource counts for debug overlays. |
| `scene:GetRendererStats()  -> string` | Renderer-side cache counts on the GPU rasterizer, or `"cpu"`. |

| `scene:Dispose()  -> nil` | Free the scene immediately; otherwise it lives until the stage teardown. |

If the GPU renderer fails while rendering (for example a shader the driver rejects), the scene switches to the CPU rasterizer for the rest of its lifetime and the stage keeps running.

#### Textures and sprites

A texture is an opaque RGB image that quads and triangles sample by UV. A sprite is an ARGB image that billboard sprites, sprite quads, particles, grass blades and terrain splat weights use. Texture ids and sprite ids are separate namespaces, and registering an id that already exists replaces its pixels.

| Method | Description |
| --- | --- |
| `scene:RegisterTexture(id, pixels, w, h)  -> nil` | Register a texture from a 1-based Lua array of packed `0xRRGGBB` integers (row-major, top-left origin). A negative value marks a transparent (cutout) texel. The scene ignores images above 4,194,304 pixels. |
| `scene:RegisterTextureFromImage(id, tex)  -> nil` | Register a texture by reading back the pixels of a loaded texture handle. The read-back drops alpha and touches the GPU once per call, which is too slow for per-frame use. |
| `scene:SetTextureFilter(id, mode)  -> nil` | Sampling filter for a texture: `"nearest"` (default), `"linear"` or `"mipmap"`. GPU rasterizer only. |
| `scene:UnregisterTexture(id)  -> nil` | Forget a texture, including its GPU upload and any render-to-texture target bound to the id. |
| `scene:SetSpriteRGBA(spriteId, pixels, w, h)  -> nil` | Register a sprite from a 1-based Lua array of ARGB integers (`a << 24 | r << 16 | g << 8 | b`, row-major, top-left origin). |
| `scene:RegisterSpriteFromTexture(spriteId, tex)  -> nil` | Register a sprite by reading back the pixels of a loaded texture handle. The read-back touches the GPU once per call, which is too slow for per-frame use. |
| `scene:MakeSoftCircle(spriteId, res, edge)  -> nil` | Generate a white round sprite of `res` x `res` pixels, opaque at the centre and fading to zero at the edge; `edge` shapes the falloff (1 is linear, 2-3 a soft glow). |
| `scene:MakeCrystal(spriteId, res)  -> nil` | Generate a six-armed white-blue snowflake sprite of `res` x `res` pixels. |
| `scene:SetSpriteFilter(spriteId, mode)  -> nil` | Sampling filter for a sprite: `"nearest"` (default) or `"linear"`. Call right after registering. GPU rasterizer only. |
| `scene:UnregisterSprite(spriteId)  -> nil` | Forget a sprite, including its GPU upload. |

A model's Register call registers its materials as textures with ids from 4000 upward (glTF) and 6000 upward (OBJ), so keep your own texture ids below 4000 when a scene also draws models.

#### Objects

An object is a retained group of primitives. All primitives in one object must be of the same kind (textured quads, flat quads, textured triangles, billboard sprites or sprite quads); call ObjBegin before refilling an object with a different kind. Object ids start at 1.

| Method | Description |
| --- | --- |
| `scene:NewObject()  -> id` | Create an empty, visible object in the opaque pass. |
| `scene:DeleteObject(id)  -> nil` | Remove an object and its geometry. |
| `scene:ClearObjects()  -> nil` | Remove every object and every particle system and drop the render caches. Textures, sprites, lights and the camera survive; object ids restart at 1. |
| `scene:ObjBegin(id)  -> nil` | Clear an object's primitives so you can refill it. |
| `scene:ObjAddQuadTex(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, texId, uMax, vMax, shade)  -> nil` | Append a textured quad. Corners map to UVs (0, vMax), (uMax, vMax), (uMax, 0), (0, 0); `shade` (0-1) multiplies the texel and gates the sun when lighting is on. |
| `scene:ObjAddQuadFlat(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3)  -> nil` | Append a flat-coloured quad; the colour and alpha come from ObjSetPass. |
| `scene:ObjAddTriTex(id, x0, y0, z0, u0, v0, x1, y1, z1, u1, v1, x2, y2, z2, u2, v2, texId, shade)  -> nil` | Append a textured triangle with explicit UVs. Model handles fill objects with this primitive. |
| `scene:ObjAddSprite(id, x, y, z, w, h, spriteId, billboard, cutout)  -> nil` | Append a sprite quad of world size `w` x `h` whose bottom centre is at (x, y, z). `billboard`: 0 fixed XY plane, 1 faces the camera but stays upright, 2 always faces the camera, 3 lies flat on the ground stretched along the SetGroundSpriteLight direction. `cutout` non-zero alpha-tests and writes depth (opaque pass); 0 alpha-blends (put the object in the transparent pass). |
| `scene:ObjAddSpriteQuad(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, spriteId, cutout)  -> nil` | Append a sprite on an explicit world quad (corners map to UVs (0, 1), (1, 1), (1, 0), (0, 0)); not billboarded. |
| `scene:ObjSetTransform(id, m)  -> nil` | Set the object's model matrix from a Lua table of 16 row-major numbers (translation in m[4], m[8], m[12]); nil restores the identity. |
| `scene:ObjSetTransform16(id, m0, m1, m2, m3, m4, m5, m6, m7, m8, m9, m10, m11, m12, m13, m14, m15)  -> nil` | Same as ObjSetTransform with 16 plain arguments; use this for per-frame updates. |
| `scene:ObjClearTransform(id)  -> nil` | Restore the identity model matrix. |
| `scene:ObjSetBounds(id, minX, minY, minZ, maxX, maxY, maxZ)  -> nil` | World-space bounds for behind-camera culling, SetRenderDistance and ObjSetNormal. |
| `scene:ObjSetNormal(id, nx, ny, nz)  -> nil` | Treat the object as a planar group facing (nx, ny, nz) and skip it when the camera is behind that plane (needs ObjSetBounds); 0, 0, 0 disables. |
| `scene:ObjSetVisible(id, v)  -> nil` | Show or hide an object. |
| `scene:ObjSetPass(id, pass, r, g, b, a)  -> nil` | Render pass (0 opaque, drawn front to back; 1 transparent, drawn back to front) plus the flat-quad colour (0-255) and the alpha (0-255) applied to flat quads and sprites. |
| `scene:ObjSetTint(id, r, g, b)  -> nil` | Per-channel colour multiply (0-1) for textured surfaces and sprites; 1, 1, 1 = none. |
| `scene:ObjSetColor(id, r, g, b)  -> nil` | Flat albedo override (0-1) that replaces the texture or material colour before lighting; r < 0 clears it. GPU rasterizer only. |
| `scene:ObjSetEmissive(id, r, g, b)  -> nil` | Emissive add (colour += base x rgb); values above 1 feed the SetDiorama bloom. 0, 0, 0 = off. GPU rasterizer only. |
| `scene:ObjSetLit(id, lit)  -> nil` | Whether forward lighting applies to the object (default true); false renders it at its baked shade only. |
| `scene:ObjSetCastShadow(id, on)  -> nil` | Whether the object's sprites cast into the sun shadow map (default true). GPU rasterizer only. |
| `scene:ObjSetDepthBias(id, bias)  -> nil` | Polygon-offset depth bias: negative pulls the object toward the camera (decals on a coplanar surface), positive pushes it away; 0 = off. GPU rasterizer only. |
| `scene:ObjSetOverlay(id, on)  -> nil` | Draw the object last over a cleared depth buffer so it always appears on top (first-person view models). |
| `scene:ObjSetXray(id, alpha)  -> nil` | Redraw the object's sprites as a ghost at this alpha (0-1) where world geometry occludes them; 0 = off. GPU rasterizer only. |
| `scene:ObjSetMaterial(id, matId)  -> nil` | Material the path tracer uses for this object (-1 = default). Path tracer only. |
| `scene:ObjSetTerrainSplat(id, splatSpriteId, tex1, tex2, tex3, tex4, worldW, worldH, uvScale)  -> nil` | Blend four layer textures per pixel by an ARGB weight sprite (see the Splatmap handle); `worldW`/`worldH` are the splat's world coverage, `uvScale` the texture repeats per world unit. `splatSpriteId` < 0 disables. GPU rasterizer only. |

#### Lights and shadows

Forward lighting is off by default. Once you enable it, the ambient term, the sun and the point lights light each face.

| Method | Description |
| --- | --- |
| `scene:SetLighting(on)  -> nil` | Enable forward lighting on the rasterizers. |
| `scene:SetAmbient(r, g, b)  -> nil` | Ambient light added to every lit face. |
| `scene:SetSun(dx, dy, dz, r, g, b)  -> nil` | Directional sun: (dx, dy, dz) is the direction toward the sun (normalised automatically); (r, g, b) is the colour times brightness, so values above 1 work. A zero colour disables it. |
| `scene:AddLight(x, y, z, r, g, b, intensity)  -> nil` | Add a point light with inverse-square falloff; colour times intensity. |
| `scene:AddLightRanged(x, y, z, r, g, b, intensity, range)  -> nil` | Add a point light whose falloff reaches zero at `range` on the rasterizers; the path tracer ignores the range. |
| `scene:ClearLights()  -> nil` | Remove all point lights. |
| `scene:SetShadows(on)  -> nil` | Enable sun shadow mapping. Needs SetLighting and a non-zero SetSun. GPU rasterizer only. |
| `scene:SetShadowFocus(x, y, z)  -> nil` | Centre the sun shadow map on this world point (normally the player) each frame. GPU rasterizer only. |
| `scene:SetShadowArea(half)  -> nil` | Half-extent in world units of the shadow map box around the focus (default 60, minimum 4). GPU rasterizer only. |
| `scene:SetGroundSpriteLight(dx, dz, lenScale)  -> nil` | Horizontal direction and length scale for billboard mode 3 sprites (ground-flat cast shadows). |

#### Grass

Grass blades are camera-facing cutout quads with wind sway, batched into one buffer. GPU rasterizer only.

| Method | Description |
| --- | --- |
| `scene:GrassSprite(spriteId)  -> nil` | Sprite used as the blade texture. |
| `scene:GrassAdd(x, y, z, h, phase, shade)  -> nil` | Plant one blade with its foot at (x, y, z), world height `h`, sway phase in radians and shade 0-1. |
| `scene:GrassRemoveRect(x0, z0, x1, z1)  -> nil` | Remove the blades whose foot lies inside the XZ rectangle (roads, pools, building pads). |

| `scene:GrassCount()  -> number` | Current blade count. |

#### Particles

A particle system is a pool of camera-facing billboards. Emit into it, call PsUpdate each frame, and the rasterizers draw the live particles in the transparent pass. System ids start at 0; ClearObjects invalidates them.

| Method | Description |
| --- | --- |
| `scene:NewParticleSystem()  -> id` | Create a particle system and return its id. |
| `scene:PsUpdate(id, dt)  -> nil` | Advance the system by `dt` seconds (ageing, gravity, drag, motion). |
| `scene:PsEmit(id, x, y, z, vx, vy, vz, r, g, b, a0, size0, size1, life, gravity, drag, additive)  -> nil` | Emit one particle: colour 0-255, start opacity `a0` 0-1, billboard size `size0` to `size1` (world units) over `life` seconds, downward gravity, drag per second; `additive` non-zero blends the particle additively onto the frame, 0 alpha-blends it. |
| `scene:PsBurst(id, x, y, z, count, dirX, dirY, dirZ, spread, speed, r, g, b, colorJitter, a0, size0, size1, life, lifeVar, gravity, drag, additive)  -> nil` | Emit `count` particles in random directions biased toward (dirX, dirY, dirZ) by `spread` (0 = exactly along the direction, 1 = fully random), with speeds up to `speed`, colour jitter, and per-particle life variation `lifeVar` (fraction of `life`). |
| `scene:PsSetSprite(id, spriteId)  -> nil` | Sprite stamped onto particles emitted next (-1 = flat square). |
| `scene:PsSetNextRotation(id, rotDeg, rotVelDegPerSec)  -> nil` | Billboard spin for particles emitted next: start angle in degrees (negative = random per particle) and spin rate in degrees per second (each particle gets a random magnitude and sign). 0, 0 = off. |
| `scene:PsSetNextCurves(id, sizeCurve, fadeCurve)  -> nil` | Curves for particles emitted next. Size: 0 linear, 1 ease-out, 2 grow then shrink. Fade: 0 linear, 1 smooth in and out, 2 bright flash with a long tail. |
| `scene:PsSetCap(id, cap)  -> nil` | Maximum live particles (default 4000); the system drops emits beyond the cap. |
| `scene:PsCount(id)  -> number` | Live particle count. |
| `scene:PsClear(id)  -> nil` | Remove every live particle from the system. |

#### Render-to-texture views

These re-render the scene from another camera into a registered texture, which a quad then samples by screen position (ObjSetScreenTex) to show mirrors, water reflections, portals and monitors. The re-render skips objects flagged ObjSetScreenTex or ObjSetOverlay so reflections do not recurse.

| Method | Description |
| --- | --- |
| `scene:SetReflectionScale(shift)  -> nil` | Resolution of re-renders relative to the main view: 0 full, 1 half (default), 2 quarter, 3 eighth. |
| `scene:SetReflectionGpu(on)  -> nil` | Route RenderView and RenderViewReflect through a GPU off-screen pass. Off by default, in which case the CPU rasterizer renders the views; if the GPU pass fails, the scene falls back to the CPU path. |
| `scene:RenderView(texId, cx, cy, cz, yawDeg, pitchDeg, fovDeg, clr, clg, clb, flipX)  -> nil` | Render the scene from the given camera into texture `texId`, clearing it to (clr, clg, clb) (0-255) first. `flipX` non-zero mirrors the image (planar mirrors). |
| `scene:RenderViewReflect(texId, px, py, pz, nx, ny, nz, clr, clg, clb)  -> nil` | Render the planar reflection about the plane through (px, py, pz) with normal (nx, ny, nz) into texture `texId`. The GPU path clips geometry below the plane. |
| `scene:ObjSetScreenTex(id, on)  -> nil` | Switch the object's texture sampling from UV to screen position, so a quad textured with a RenderView result shows that view aligned to the screen. |
| `scene:ObjSetScreenTexRipple(id, amp, freq, speed)  -> nil` | Animated distortion of a screen-textured surface: `amp` in render-target pixels (0 = off), world-space wave frequency and animation speed (driven by SetTime). GPU rasterizer only. |
| `scene:ObjSetFresnel(id, f0)  -> nil` | Per-pixel Schlick fresnel reflectivity for a screen-textured surface (about 0.04 for water); negative disables. GPU rasterizer only. |
| `scene:ObjSetWaterColors(id, dr, dg, db)  -> nil` | Deep-water colour (0-1) for a screen-textured surface; the per-vertex shade lerps from the object's base colour (shallow) to this colour (deep). GPU rasterizer only. |
| `scene:ObjSetSurfaceShader(id, fragSrc)  -> nil` | Attach a custom GLSL ES 3.00 fragment shader to a screen-textured surface, replacing the built-in ripple and fresnel look. Complete source or a `main()` body; the prelude provides `vUV`, `vShade`, `vCamZ`, `vWorld`, `vNormal`, `uTex` (the reflection), `uRsh`, `uRttFlip`, `uCam`, `uTint`, `uFlat`, `uTime`, `uAlpha`, `uUser[4]` and `out vec4 frag`. nil or "" detaches; a compile failure falls back to the built-in shader. GPU rasterizer only. |
| `scene:SetSurfaceUniform(slot, x, y, z, w)  -> nil` | Set `uUser[slot]` (0..3) shared by every custom surface shader. |

## Models

### MODEL

<span class="badge-exp">Experimental</span>

Loads glTF/GLB (skinned, animated) and OBJ (static) files into poseable model handles.

<div class="callout warn">
Paths are relative to the script directory; the loader also accepts absolute paths. The loader parses each glTF file once per process and shares it between scenes and stages, so part routing set with SetPartObject persists until ClearPartObjects or PurgeCache. glTF support covers indexed triangle primitives with positions, one UV set, optional joints and weights, one skin, node hierarchies, linear TRS animations, material base colours and embedded base-colour textures (downscaled to 512 pixels on the long side). OBJ support covers positions, texture coordinates, polygon faces and diffuse colours from the .mtl file; the loader skips image textures.
</div>

| Method | Description |
| --- | --- |
| `MODEL:Load(path)  -> model` | Load a .glb, .gltf or .obj file and return a model handle, or nil on failure. |
| `MODEL:PurgeCache()  -> nil` | Drop the process-wide glTF cache (stage exit). Reload any model still in use afterwards. |

### Model handle

<span class="badge-exp">Experimental</span>

<div class="callout warn">
Call Register once per scene, then Pose each frame to write the placed (and, for glTF, skinned) triangles into a scene object. Animation indices are 0-based; -1 poses the bind pose. Pose clamps animation time to the clip, so loop it yourself with Duration. The methods below Duration are glTF-only; OBJ handles expose Register, Pose, AnimCount (0), AnimName and Duration.
</div>

```lua
local model, obj
local clip = 0

function onStart()
    model = MODEL:Load("models/lantern.glb")
    if model then
        model:Register(scene)
        obj = scene:NewObject()
    end
end

function draw()
    if model then
        local t = elapsed % model:Duration(clip)
        model:Pose(scene, obj, clip, t, x, y, z, yawDeg, 1.0)
    end
end

function onDestroy()
    MODEL:PurgeCache()
end
```

| Method | Description |
| --- | --- |
| `model:Register(scene)  -> nil` | Register the model's materials and textures into a scene (once per scene). |
| `model:Pose(scene, objId, anim, time, x, y, z, yawDeg, scale)  -> nil` | Clear object `objId` and fill it with the model's triangles at animation `anim` and `time` seconds, translated to (x, y, z), rotated about Y by `yawDeg` and uniformly scaled. |
| `model:AnimCount()  -> number` | Number of animation clips (0 for OBJ). |
| `model:AnimName(i)  -> string` | Name of clip `i`, or "" when out of range. |
| `model:Duration(i)  -> number` | Duration in seconds of clip `i`, or 0 when out of range. |
| `model:PartCount()  -> number` | Number of parts (primitive instances). |
| `model:PartMaterial(part)  -> number` | Material index of a part (0-based), or -1 when out of range. |
| `model:MaterialCount()  -> number` | Number of glTF materials. |
| `model:MaterialName(mat)  -> string` | Name of a glTF material, or "" when out of range. |
| `model:MaterialEmissive(mat)  -> r, g, b` | The material's glTF `emissiveFactor`, or 0, 0, 0 when none. |
| `model:SetPartObject(part, objId)  -> nil` | Route a part's triangles into their own scene object on Pose, so that part can carry its own transparency, emissive or mirror flags; -1 clears the routing for that part. |
| `model:ClearPartObjects()  -> nil` | Drop all part routing. Call it on world unload, since the model instance is shared and object ids restart after ClearObjects. |
| `model:GetBounds()  -> minX, minY, minZ, maxX, maxY, maxZ` | Model-space bind-pose bounds. |
| `model:BuildCollider(mc, x, y, z, yawDeg, scale)  -> nil` | Append the bind-pose triangles, placed with the given transform, to a MeshCollider. A negative scale acts as its magnitude. |

## Heightmaps

### HEIGHTMAP

<span class="badge-exp">Experimental</span>

Loads raw 16-bit heightfields and RGBA splat images for terrain, and builds a whole terrain in one call.

<div class="callout warn">
Paths are relative to the script directory. A heightfield file holds w x h little-endian unsigned 16-bit samples in row-major order; a splat image is an RGBA PNG whose channels R, G, B, A are the weights of layers 1 to 4. On a read error, both loaders return a flat fallback.
</div>

| Method | Description |
| --- | --- |
| `HEIGHTMAP:Load(path, w, h)  -> heightfield` | Load a heightfield of w x h samples; returns a flat zero field on error. |
| `HEIGHTMAP:LoadSplat(path)  -> splatmap` | Load a splat image; returns an all-layer-1 map on error. A fully opaque alpha channel means the map has no layer 4. |
| `HEIGHTMAP:BuildTerrain(scene, floorObj, world, hf, splat, w, h, minY, maxY, cellSize, tex1, tex2, tex3, tex4, grassDensity, grassClump)  -> number` | Emit the terrain in one call: one textured quad per cell into `floorObj` (sample (ix, iz) sits at world x = ix x cellSize, z = iz x cellSize, y = minY + sample x (maxY - minY); each layer texture repeats once per cell), matching collision quads plus invisible border walls into `world` (call it between BeginStatic and EndStatic), and grass blades on layer-1 ground away from steep slopes and the map edge when `grassDensity` > 0 (`grassClump` > 0 groups them into patches). Without a splat, steep cells use `tex2` and the rest `tex1`. Returns the number of grass blades planted. |

### Heightfield handle

<span class="badge-exp">Experimental</span>

The loader normalises samples to 0..1; world height = minY + sample x (maxY - minY).

| Method | Description |
| --- | --- |
| `heightfield:W()  -> number` | Width in samples. |
| `heightfield:H()  -> number` | Height in samples. |
| `heightfield:At(ix, iz)  -> number` | Sample at integer grid coordinates, clamped to the edges. |
| `heightfield:Sample(fx, fz)  -> number` | Bilinear sample at fractional grid coordinates. |
| `heightfield:Release()  -> nil` | Drop the sample buffer now (map unload); At and Sample return 0 afterwards. |

### Splatmap handle

<span class="badge-exp">Experimental</span>

Layers are numbered 1 to 4 (image channels R, G, B, A).

| Method | Description |
| --- | --- |
| `splat:W()  -> number` | Width in texels. |
| `splat:H()  -> number` | Height in texels. |
| `splat:At(ix, iz)  -> number` | Dominant layer at integer texel coordinates (1 when the map is empty). |
| `splat:Weight(layer, fx, fz)  -> number` | Bilinear weight (0-1, normalised against the texel's channel sum) of a layer at fractional texel coordinates. |
| `splat:RegisterSprite(scene, spriteId)  -> nil` | Register the channel weights as a linear-filtered ARGB sprite for scene:ObjSetTerrainSplat. |
| `splat:Release()  -> nil` | Drop the buffers now (map unload); At returns 1 afterwards. |
