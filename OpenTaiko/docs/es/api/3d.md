# Motor 3D: mundo del rasterizador <span class="badge-exp">Experimental</span>

Escenas, modelos, luces, cámaras, físicas, colliders, búsqueda de rutas, partículas, destinos de renderizado y mapas de alturas de terreno.

El motor 3D es experimental. El plan es retirar la etiqueta de experimental con la versión 1.0.

<div class="callout">
Todas las globales y todos los métodos de esta página pueden cambiar entre versiones sin periodo de obsolescencia. Si tu skin depende de ellos, pruébalo de nuevo tras cada actualización e indica a qué versión del juego se dirige.
</div>

Convenciones usadas en esta página:

- Las posiciones y tamaños están en unidades del mundo; +Y es arriba. Los ids de objeto, textura, sprite, material y primitiva son enteros.
- Los ángulos están en grados salvo que una fila indique radianes (rumbo e inclinación del vehículo físico, giro de rueda, fase de balanceo de la hierba).
- `Clear`, `FillRect`, `DrawLine`, `SetFog`, `ObjSetPass`, `PsEmit` y `PsBurst` reciben colores 0-255. Las luces, el sol, el ambiental, los materiales, los tintes y `ObjSetColor` reciben colores lineales 0-1.
- Tres renderizadores comparten los mismos datos de escena: el rasterizador GPU (por defecto cuando hay shaders de cómputo GLES 3.1 disponibles), el rasterizador CPU (alternativa, o forzado con `SetMode("raster_cpu")`) y el trazador de rutas (`SetMode("raytrace")`). Los demás renderizadores ignoran las filas marcadas *solo rasterizador GPU* o *solo trazador de rutas*.

El trazador de rutas y el mundo de físicas tienen sus propias páginas: [mundo del trazador de rutas](3d-raytrace.md) y [físicas](3d-physics.md).

## Escenas

### SCENE3D

<span class="badge-exp">Experimental</span>

Fábrica de escenas 3D. Una escena es un destino de renderizado que posee una cámara, objetos retenidos, texturas, sprites, luces y sistemas de partículas; la dibujas como una textura 2D.

| Método | Descripción |
| --- | --- |
| `SCENE3D:CreateScene(width, height)  -> scene` | Crea una escena con el tamaño lógico indicado en píxeles y devuelve su handle. El juego libera la escena cuando desmonta el stage del script. |

### Handle de escena

<span class="badge-exp">Experimental</span>

<div class="callout warn">
Flujo por fotograma: dibuja el fondo (FillRect o ClearTransparent), actualiza la cámara y cualquier geometría por fotograma, llama a Render, luego a Upload y luego a Draw. Render no borra el búfer de color, así que dibuja primero el cielo o el telón de fondo.
</div>

```lua
local scene, floor

function onStart()
    scene = SCENE3D:CreateScene(1280, 720)
    scene:SetLighting(true)
    scene:SetAmbient(0.4, 0.4, 0.46)
    scene:SetSun(0.3, 0.8, 0.5, 0.85, 0.82, 0.72)

    scene:RegisterTexture(1, pixels, 16, 16)          -- pixels: array indexado desde 1 de enteros 0xRRGGBB
    floor = scene:NewObject()
    scene:ObjAddQuadTex(floor, 0,0,0,  0,0,8,  8,0,8,  8,0,0,  1, 8, 8, 1.0)
    scene:ObjSetBounds(floor, 0, 0, 0, 8, 0, 8)
end

function draw()
    scene:SetCameraPosition(4, 3, -6)
    scene:SetCameraAngles(0, -20)
    scene:FillRect(0, 0, 1280, 720, 90, 140, 220, 255)
    scene:Render()
    scene:Upload()
    scene:Draw(0, 0)
end

function onDestroy()
    scene:Dispose()
end
```

#### Renderizador

| Método | Descripción |
| --- | --- |
| `scene:SetMode(mode)  -> nil` | Elige el renderizador: `"raster"` (por defecto; GPU cuando está disponible, si no CPU), `"raster_cpu"`, `"raytrace"` o `"rt"` (trazador de rutas GPU con alternativa CPU), `"raytrace_cpu"` o `"rt_cpu"`. Cambiar descarta el estado en caché y acumulado. |
| `scene:GetMode()  -> string` | Renderizador activo: `"raster"`, `"raster_cpu"` o `"raytrace"`. |
| `scene:SetThreads(n)  -> nil` | Número de hilos para el rasterizador CPU, que divide la pantalla en ese número de bandas de filas (1 por defecto). |
| `scene:SetRenderDistance(d)  -> nil` | Omite los objetos cuyos límites (consulta ObjSetBounds) quedan por completo más allá de esta distancia de la cámara; 0 = sin límite. Solo rasterizadores. |
| `scene:SetAntialias(on)  -> nil` | Activa el suavizado de bordes de posprocesado sobre el búfer de color final (desactivado por defecto). |
| `scene:GetSampleCount()  -> number` | Muestras por píxel acumuladas por el trazador de rutas desde el último cambio de cámara o de escena; 0 en los modos raster. |
| `scene:GetMemoryStats()  -> texCount, texBytes, spriteCount, objCount, grassBlades, liveParticles` | Recuentos de recursos para superposiciones de depuración. |
| `scene:GetRendererStats()  -> string` | Recuentos de caché del lado del renderizador en el rasterizador GPU, o `"cpu"`. |
| `scene:ClearRenderCaches()  -> nil` | Descarta las cachés de renderizado reconstruibles (destinos de render a textura, búferes de vértices por objeto, búferes estáticos fusionados). Las texturas y sprites registrados sobreviven; llámalo al descargar un mapa. |
| `scene:Dispose()  -> nil` | Libera la escena de inmediato; de lo contrario vive hasta el desmontaje del stage. |

Si el renderizador GPU falla durante el renderizado (por ejemplo un shader que el controlador rechaza), la escena cambia al rasterizador CPU durante el resto de su vida y el stage sigue ejecutándose.

#### Texturas y sprites

Una textura es una imagen RGB opaca que los quads y triángulos muestrean por UV. Un sprite es una imagen ARGB que usan los sprites billboard, los quads de sprite, las partículas, las briznas de hierba y los pesos de splat de terreno. Los ids de textura y los ids de sprite son espacios de nombres separados, y registrar un id que ya existe reemplaza sus píxeles.

| Método | Descripción |
| --- | --- |
| `scene:RegisterTexture(id, pixels, w, h)  -> nil` | Registra una textura a partir de un array Lua indexado desde 1 de enteros empaquetados `0xRRGGBB` (por filas, origen arriba a la izquierda). Un valor negativo marca un téxel transparente (recorte). La escena ignora las imágenes de más de 4,194,304 píxeles. |
| `scene:RegisterTextureFromImage(id, tex)  -> nil` | Registra una textura leyendo de vuelta los píxeles de un handle de textura cargado. La lectura descarta el alfa y accede a la GPU una vez por llamada, lo que es demasiado lento para usarlo por fotograma. |
| `scene:SetTextureFilter(id, mode)  -> nil` | Filtro de muestreo de una textura: `"nearest"` (por defecto), `"linear"` o `"mipmap"`. Solo rasterizador GPU. |
| `scene:UnregisterTexture(id)  -> nil` | Olvida una textura, incluida su subida a la GPU y cualquier destino de render a textura vinculado al id. |
| `scene:SetSpriteRGBA(spriteId, pixels, w, h)  -> nil` | Registra un sprite a partir de un array Lua indexado desde 1 de enteros ARGB (`a << 24 | r << 16 | g << 8 | b`, por filas, origen arriba a la izquierda). |
| `scene:RegisterSpriteFromTexture(spriteId, tex)  -> nil` | Registra un sprite leyendo de vuelta los píxeles de un handle de textura cargado. La lectura accede a la GPU una vez por llamada, lo que es demasiado lento para usarlo por fotograma. |
| `scene:MakeSoftCircle(spriteId, res, edge)  -> nil` | Genera un sprite redondo blanco de `res` x `res` píxeles, opaco en el centro y desvaneciéndose a cero en el borde; `edge` da forma a la caída (1 es lineal, 2-3 un brillo suave). |
| `scene:MakeCrystal(spriteId, res)  -> nil` | Genera un sprite de copo de nieve blanco-azul de seis brazos de `res` x `res` píxeles. |
| `scene:SetSpriteFilter(spriteId, mode)  -> nil` | Filtro de muestreo de un sprite: `"nearest"` (por defecto) o `"linear"`. Llámalo justo después de registrar. Solo rasterizador GPU. |
| `scene:UnregisterSprite(spriteId)  -> nil` | Olvida un sprite, incluida su subida a la GPU. |

La llamada a Register de un modelo registra sus materiales como texturas con ids a partir de 4000 (glTF) y de 6000 (OBJ), así que mantén tus propios ids de textura por debajo de 4000 cuando una escena también dibuje modelos.

#### Objetos

Un objeto es un grupo retenido de primitivas. Todas las primitivas de un objeto deben ser del mismo tipo (quads texturizados, quads planos, triángulos texturizados, sprites billboard o quads de sprite); llama a ObjBegin antes de rellenar un objeto con un tipo distinto. Los ids de objeto empiezan en 1.

| Método | Descripción |
| --- | --- |
| `scene:NewObject()  -> id` | Crea un objeto vacío y visible en la pasada opaca. |
| `scene:DeleteObject(id)  -> nil` | Elimina un objeto y su geometría. |
| `scene:ClearObjects()  -> nil` | Elimina todos los objetos y todos los sistemas de partículas y descarta las cachés de renderizado. Las texturas, sprites, luces y la cámara sobreviven; los ids de objeto vuelven a empezar en 1. |
| `scene:ObjBegin(id)  -> nil` | Borra las primitivas de un objeto para que puedas rellenarlo. |
| `scene:ObjAddQuadTex(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, texId, uMax, vMax, shade)  -> nil` | Añade un quad texturizado. Las esquinas se asignan a las UV (0, vMax), (uMax, vMax), (uMax, 0), (0, 0); `shade` (0-1) multiplica el téxel y regula el sol cuando la iluminación está activada. |
| `scene:ObjAddQuadFlat(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3)  -> nil` | Añade un quad de color plano; el color y el alfa provienen de ObjSetPass. |
| `scene:ObjAddTriTex(id, x0, y0, z0, u0, v0, x1, y1, z1, u1, v1, x2, y2, z2, u2, v2, texId, shade)  -> nil` | Añade un triángulo texturizado con UV explícitas. Los handles de modelo rellenan los objetos con esta primitiva. |
| `scene:ObjAddSprite(id, x, y, z, w, h, spriteId, billboard, cutout)  -> nil` | Añade un quad de sprite de tamaño en el mundo `w` x `h` cuyo centro inferior está en (x, y, z). `billboard`: 0 plano XY fijo, 1 mira a la cámara pero se mantiene vertical, 2 siempre mira a la cámara, 3 yace plano sobre el suelo estirado a lo largo de la dirección de SetGroundSpriteLight. `cutout` distinto de cero aplica prueba alfa y escribe profundidad (pasada opaca); 0 mezcla por alfa (pon el objeto en la pasada transparente). |
| `scene:ObjAddSpriteQuad(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, spriteId, cutout)  -> nil` | Añade un sprite sobre un quad explícito del mundo (las esquinas se asignan a las UV (0, 1), (1, 1), (1, 0), (0, 0)); sin billboard. |
| `scene:ObjSetTransform(id, m)  -> nil` | Establece la matriz de modelo del objeto a partir de una tabla Lua de 16 números por filas (traslación en m[4], m[8], m[12]); nil restaura la identidad. |
| `scene:ObjSetTransform16(id, m0, m1, m2, m3, m4, m5, m6, m7, m8, m9, m10, m11, m12, m13, m14, m15)  -> nil` | Igual que ObjSetTransform con 16 argumentos simples; úsalo para las actualizaciones por fotograma. |
| `scene:ObjClearTransform(id)  -> nil` | Restaura la matriz de modelo identidad. |
| `scene:ObjSetBounds(id, minX, minY, minZ, maxX, maxY, maxZ)  -> nil` | Límites en el espacio del mundo para el descarte detrás de la cámara, SetRenderDistance y ObjSetNormal. |
| `scene:ObjSetNormal(id, nx, ny, nz)  -> nil` | Trata el objeto como un grupo plano orientado hacia (nx, ny, nz) y lo omite cuando la cámara está detrás de ese plano (necesita ObjSetBounds); 0, 0, 0 lo desactiva. |
| `scene:ObjSetVisible(id, v)  -> nil` | Muestra u oculta un objeto. |
| `scene:ObjSetPass(id, pass, r, g, b, a)  -> nil` | Pasada de renderizado (0 opaca, dibujada de delante hacia atrás; 1 transparente, dibujada de atrás hacia delante) más el color de quad plano (0-255) y el alfa (0-255) aplicados a quads planos y sprites. |
| `scene:ObjSetTint(id, r, g, b)  -> nil` | Multiplicación de color por canal (0-1) para superficies texturizadas y sprites; 1, 1, 1 = ninguna. |
| `scene:ObjSetColor(id, r, g, b)  -> nil` | Sustitución de albedo plano (0-1) que reemplaza el color de textura o material antes de la iluminación; r < 0 la elimina. Solo rasterizador GPU. |
| `scene:ObjSetEmissive(id, r, g, b)  -> nil` | Adición emisiva (color += base x rgb); los valores por encima de 1 alimentan el bloom de SetDiorama. 0, 0, 0 = desactivado. Solo rasterizador GPU. |
| `scene:ObjSetLit(id, lit)  -> nil` | Si la iluminación directa se aplica al objeto (true por defecto); false lo renderiza solo con su sombreado horneado. |
| `scene:ObjSetCastShadow(id, on)  -> nil` | Si los sprites del objeto proyectan en el mapa de sombras del sol (true por defecto). Solo rasterizador GPU. |
| `scene:ObjSetDepthBias(id, bias)  -> nil` | Sesgo de profundidad por desplazamiento de polígono: negativo acerca el objeto a la cámara (calcomanías sobre una superficie coplanar), positivo lo aleja; 0 = desactivado. Solo rasterizador GPU. |
| `scene:ObjSetOverlay(id, on)  -> nil` | Dibuja el objeto al final sobre un búfer de profundidad borrado para que siempre aparezca encima (modelos de vista en primera persona). |
| `scene:ObjSetXray(id, alpha)  -> nil` | Vuelve a dibujar los sprites del objeto como un fantasma con este alfa (0-1) donde la geometría del mundo los oculta; 0 = desactivado. Solo rasterizador GPU. |
| `scene:ObjSetMaterial(id, matId)  -> nil` | Material que el trazador de rutas usa para este objeto (-1 = por defecto). Solo trazador de rutas. |
| `scene:ObjSetTerrainSplat(id, splatSpriteId, tex1, tex2, tex3, tex4, worldW, worldH, uvScale)  -> nil` | Mezcla cuatro texturas de capa por píxel según un sprite de pesos ARGB (consulta el handle de splatmap); `worldW`/`worldH` son la cobertura del splat en el mundo, `uvScale` las repeticiones de textura por unidad del mundo. `splatSpriteId` < 0 lo desactiva. Solo rasterizador GPU. |

#### Luces y sombras

La iluminación directa está desactivada por defecto. Una vez que la activas, el término ambiental, el sol y las luces puntuales iluminan cada cara.

| Método | Descripción |
| --- | --- |
| `scene:SetLighting(on)  -> nil` | Activa la iluminación directa en los rasterizadores. |
| `scene:SetAmbient(r, g, b)  -> nil` | Luz ambiental añadida a cada cara iluminada. |
| `scene:SetSun(dx, dy, dz, r, g, b)  -> nil` | Sol direccional: (dx, dy, dz) es la dirección hacia el sol (normalizada automáticamente); (r, g, b) es el color por el brillo, así que los valores por encima de 1 funcionan. Un color cero lo desactiva. |
| `scene:AddLight(x, y, z, r, g, b, intensity)  -> nil` | Añade una luz puntual con caída inversa al cuadrado; color por intensidad. |
| `scene:AddLightRanged(x, y, z, r, g, b, intensity, range)  -> nil` | Añade una luz puntual cuya caída llega a cero en `range` en los rasterizadores; el trazador de rutas ignora el alcance. |
| `scene:ClearLights()  -> nil` | Elimina todas las luces puntuales. |
| `scene:SetShadows(on)  -> nil` | Activa el mapeado de sombras del sol. Necesita SetLighting y un SetSun distinto de cero. Solo rasterizador GPU. |
| `scene:SetShadowFocus(x, y, z)  -> nil` | Centra el mapa de sombras del sol en este punto del mundo (normalmente el jugador) cada fotograma. Solo rasterizador GPU. |
| `scene:SetShadowArea(half)  -> nil` | Semiextensión en unidades del mundo de la caja del mapa de sombras alrededor del foco (60 por defecto, mínimo 4). Solo rasterizador GPU. |
| `scene:SetGroundSpriteLight(dx, dz, lenScale)  -> nil` | Dirección horizontal y escala de longitud para los sprites en modo billboard 3 (sombras proyectadas planas sobre el suelo). |

#### Niebla, cielo y posprocesado

| Método | Descripción |
| --- | --- |
| `scene:SetFog(on, r, g, b, start, end)  -> nil` | Niebla por distancia: los píxeles se desvanecen a (r, g, b) (0-255) entre las profundidades de cámara `start` y `end`. Solo rasterizadores. |
| `scene:SetDiorama(on, tilt, sat, vig, bloom)  -> nil` | Gradación de posprocesado: desenfoque tilt-shift en píxeles (0 = ninguno), saturación (1 = ninguna), intensidad de viñeta e intensidad de bloom (0 = desactivado). Solo rasterizador GPU. |
| `scene:SetColorGrade(exposure, r, g, b)  -> nil` | Multiplicación de exposición y tinte por canal aplicados por la pasada de SetDiorama; 1, 1, 1, 1 es neutro. Solo rasterizador GPU. |

| `scene:SetOutline(r, g, b, thicknessPx)  -> nil` | Contorno de silueta del color (0-255) y grosor en píxeles indicados alrededor de las formas renderizadas; 0 lo desactiva. |
| `scene:ApplyOutline(r, g, b, thickness)  -> nil` | Ejecuta la pasada de contorno directamente sobre el búfer de color CPU. Render ya lo hace en el rasterizador CPU cuando SetOutline está establecido. |
| `scene:SetTime(t)  -> nil` | Reloj de shader en segundos (`uTime`) para los shaders de ondulación, cielo, superficie y posprocesado; aliméntalo una vez por fotograma. |
| `scene:SetSkyShader(fragSrc)  -> nil` | Adjunta un shader de fragmentos GLSL ES 3.00 a pantalla completa que el renderizador dibuja antes de la pasada 3D. Pasa el código completo, o solo un cuerpo de `main()` y la escena antepone el preludio (`uRes`, `uTime`, `uUser[8]`, `out vec4 frag`). nil o "" lo desvincula. Solo rasterizador GPU. |

Mismas reglas de código que SetSkyShader; el preludio proporciona `uTex` (el fotograma renderizado), `uRes`, `uTime`, `uUser[4]` y `out vec4 frag`. nil o "" lo desvincula. Solo rasterizador GPU. |

| `scene:SetDistanceBlur(on, near, far)  -> nil` | Operación nula obsoleta que se conserva para que los scripts antiguos sigan funcionando; usa SetDiorama. |

#### Hierba

Las briznas de hierba son quads recortados orientados a la cámara con balanceo por viento, agrupados en un único búfer. Solo rasterizador GPU.

| Método | Descripción |
| --- | --- |
| `scene:GrassSprite(spriteId)  -> nil` | Sprite usado como textura de las briznas. |
| `scene:GrassAdd(x, y, z, h, phase, shade)  -> nil` | Planta una brizna con su pie en (x, y, z), altura en el mundo `h`, fase de balanceo en radianes y sombreado 0-1. |
| `scene:GrassRemoveRect(x0, z0, x1, z1)  -> nil` | Elimina las briznas cuyo pie está dentro del rectángulo XZ (carreteras, estanques, solares de edificios). |
| `scene:GrassFade(start, end)  -> nil` | Las briznas se desvanecen y encogen entre estas dos distancias de cámara. |
| `scene:GrassCount()  -> number` | Número actual de briznas. |
| `scene:GrassClear()  -> nil` | Elimina todas las briznas y libera el búfer (descarga de mapa). |

#### Partículas

Un sistema de partículas es una reserva de billboards orientados a la cámara. Emite en él, llama a PsUpdate cada fotograma, y los rasterizadores dibujan las partículas vivas en la pasada transparente. Los ids de sistema empiezan en 0; ClearObjects los invalida.

| Método | Descripción |
| --- | --- |
| `scene:NewParticleSystem()  -> id` | Crea un sistema de partículas y devuelve su id. |
| `scene:PsUpdate(id, dt)  -> nil` | Avanza el sistema `dt` segundos (envejecimiento, gravedad, arrastre, movimiento). |

## Modelos

### MODEL

<span class="badge-exp">Experimental</span>

Carga archivos glTF/GLB (con skinning, animados) y OBJ (estáticos) en handles de modelo posables.

<div class="callout warn">
Las rutas son relativas al directorio del script; el cargador también acepta rutas absolutas. El cargador analiza cada archivo glTF una vez por proceso y lo comparte entre escenas y stages, así que el enrutamiento de partes establecido con SetPartObject persiste hasta ClearPartObjects o PurgeCache. La compatibilidad con glTF cubre primitivas de triángulos indexados con posiciones, un conjunto de UV, articulaciones y pesos opcionales, un skin, jerarquías de nodos, animaciones TRS lineales, colores base de material y texturas de color base incrustadas (reducidas a 512 píxeles en el lado largo). La compatibilidad con OBJ cubre posiciones, coordenadas de textura, caras poligonales y colores difusos del archivo .mtl; el cargador omite las texturas de imagen.
</div>

| Método | Descripción |
| --- | --- |
| `MODEL:Load(path)  -> model` | Carga un archivo .glb, .gltf u .obj y devuelve un handle de modelo, o nil en caso de fallo. |
| `MODEL:PurgeCache()  -> nil` | Descarta la caché glTF de todo el proceso (salida del stage). Recarga después cualquier modelo todavía en uso. |

### Handle de modelo

<span class="badge-exp">Experimental</span>

<div class="callout warn">
Llama a Register una vez por escena, y luego a Pose cada fotograma para escribir los triángulos colocados (y, para glTF, con skinning) en un objeto de escena. Los índices de animación empiezan en 0; -1 posa la pose de enlace (bind pose). Pose limita el tiempo de animación al clip, así que repítelo tú mismo con Duration. Los métodos por debajo de Duration son solo para glTF; los handles OBJ exponen Register, Pose, AnimCount (0), AnimName y Duration.
</div>

```lua
local model, obj
local clip = 0

function onStart()
    model = MODEL:Load("models/lantern.glb")
    if model then
        model:Register(scene)
        obj = scene:NewObject()
    end
end

function draw()
    if model then
        local t = elapsed % model:Duration(clip)
        model:Pose(scene, obj, clip, t, x, y, z, yawDeg, 1.0)
    end
end

function onDestroy()
    MODEL:PurgeCache()
end
```

| Método | Descripción |
| --- | --- |
| `model:Register(scene)  -> nil` | Registra los materiales y texturas del modelo en una escena (una vez por escena). |
| `model:Pose(scene, objId, anim, time, x, y, z, yawDeg, scale)  -> nil` | Borra el objeto `objId` y lo rellena con los triángulos del modelo en la animación `anim` y el instante `time` en segundos, trasladados a (x, y, z), rotados alrededor de Y por `yawDeg` y escalados uniformemente. |
| `model:AnimCount()  -> number` | Número de clips de animación (0 para OBJ). |
| `model:AnimName(i)  -> string` | Nombre del clip `i`, o "" cuando está fuera de rango. |
| `model:Duration(i)  -> number` | Duración en segundos del clip `i`, o 0 cuando está fuera de rango. |
| `model:PartCount()  -> number` | Número de partes (instancias de primitiva). |
| `model:PartMaterial(part)  -> number` | Índice de material de una parte (desde 0), o -1 cuando está fuera de rango. |
| `model:MaterialCount()  -> number` | Número de materiales glTF. |
| `model:MaterialName(mat)  -> string` | Nombre de un material glTF, o "" cuando está fuera de rango. |
| `model:MaterialEmissive(mat)  -> r, g, b` | El `emissiveFactor` glTF del material, o 0, 0, 0 cuando no hay ninguno. |
| `model:SetPartObject(part, objId)  -> nil` | Dirige los triángulos de una parte a su propio objeto de escena en Pose, para que esa parte pueda llevar sus propios indicadores de transparencia, emisivo o espejo; -1 elimina el enrutamiento de esa parte. |
| `model:ClearPartObjects()  -> nil` | Descarta todo el enrutamiento de partes. Llámalo al descargar el mundo, ya que la instancia del modelo es compartida y los ids de objeto vuelven a empezar tras ClearObjects. |
| `model:GetBounds()  -> minX, minY, minZ, maxX, maxY, maxZ` | Límites de la pose de enlace en el espacio del modelo. |
| `model:BuildCollider(mc, x, y, z, yawDeg, scale)  -> nil` | Añade a un MeshCollider los triángulos de la pose de enlace, colocados con la transformación indicada. Una escala negativa actúa como su magnitud. |

## Mapas de alturas

### HEIGHTMAP

<span class="badge-exp">Experimental</span>

Carga campos de alturas de 16 bits en bruto e imágenes de splat RGBA para el terreno, y construye un terreno completo en una sola llamada.

<div class="callout warn">
Las rutas son relativas al directorio del script. Un archivo de campo de alturas contiene w x h muestras de 16 bits sin signo little-endian en orden por filas; una imagen de splat es un PNG RGBA cuyos canales R, G, B, A son los pesos de las capas 1 a 4. Ante un error de lectura, ambos cargadores devuelven una alternativa plana.
</div>

| Método | Descripción |
| --- | --- |
| `HEIGHTMAP:Load(path, w, h)  -> heightfield` | Carga un campo de alturas de w x h muestras; devuelve un campo plano de ceros en caso de error. |
| `HEIGHTMAP:LoadSplat(path)  -> splatmap` | Carga una imagen de splat; devuelve un mapa todo capa 1 en caso de error. Un canal alfa completamente opaco significa que el mapa no tiene capa 4. |
| `HEIGHTMAP:BuildTerrain(scene, floorObj, world, hf, splat, w, h, minY, maxY, cellSize, tex1, tex2, tex3, tex4, grassDensity, grassClump)  -> number` | Emite el terreno en una sola llamada: un quad texturizado por celda en `floorObj` (la muestra (ix, iz) queda en el mundo en x = ix x cellSize, z = iz x cellSize, y = minY + muestra x (maxY - minY); cada textura de capa se repite una vez por celda), los quads de colisión correspondientes más paredes de borde invisibles en `world` (llámalo entre BeginStatic y EndStatic), y briznas de hierba sobre el suelo de capa 1 lejos de pendientes pronunciadas y del borde del mapa cuando `grassDensity` > 0 (`grassClump` > 0 las agrupa en manchas). Sin splat, las celdas empinadas usan `tex2` y el resto `tex1`. Devuelve el número de briznas de hierba plantadas. |

### Handle de campo de alturas

<span class="badge-exp">Experimental</span>

El cargador normaliza las muestras a 0..1; altura en el mundo = minY + muestra x (maxY - minY).

| Método | Descripción |
| --- | --- |
| `heightfield:W()  -> number` | Anchura en muestras. |
| `heightfield:H()  -> number` | Altura en muestras. |
| `heightfield:At(ix, iz)  -> number` | Muestra en coordenadas de cuadrícula enteras, limitadas a los bordes. |
| `heightfield:Sample(fx, fz)  -> number` | Muestra bilineal en coordenadas de cuadrícula fraccionarias. |
| `heightfield:Release()  -> nil` | Descarta ahora el búfer de muestras (descarga de mapa); At y Sample devuelven 0 después. |
