# Moteur 3D : monde du rastériseur <span class="badge-exp">Expérimental</span>

Scènes, modèles, lumières, caméras, physique, colliders, recherche de chemin, particules, cibles de rendu et cartes de hauteurs de terrain.

Le moteur 3D est expérimental. Le plan est d'abandonner l'étiquette expérimentale avec la version 1.0.

<div class="callout">
Chaque globale et chaque méthode de cette page peut changer d'une version à l'autre sans période de dépréciation. Si votre skin en dépend, testez-le de nouveau après chaque mise à jour et indiquez la version du jeu que vous visez.
</div>

Conventions utilisées sur cette page :

- Les positions et tailles sont en unités monde ; +Y est vers le haut. Les identifiants d'objet, de texture, de sprite, de matériau et de primitive sont des entiers.
- Les angles sont en degrés sauf quand une ligne indique des radians (cap et inclinaison des véhicules physiques, rotation des roues, phase de balancement de l'herbe).
- `Clear`, `FillRect`, `DrawLine`, `SetFog`, `ObjSetPass`, `PsEmit` et `PsBurst` prennent des couleurs de 0 à 255. Les lumières, le soleil, l'ambiance, les matériaux, les teintes et `ObjSetColor` prennent des couleurs linéaires de 0 à 1.
- Trois moteurs de rendu partagent les mêmes données de scène : le rastériseur GPU (par défaut quand les shaders de calcul GLES 3.1 sont disponibles), le rastériseur CPU (solution de repli, ou forcé avec `SetMode("raster_cpu")`) et le path tracer (`SetMode("raytrace")`). Les autres moteurs de rendu ignorent les lignes marquées *rastériseur GPU uniquement* ou *path tracer uniquement*.

Le path tracer et le monde physique ont leurs propres pages : [monde du path tracer](3d-raytrace.md) et [physique](3d-physics.md).

## Scènes

### SCENE3D

<span class="badge-exp">Expérimental</span>

Fabrique de scènes 3D. Une scène est une cible de rendu qui possède une caméra, des objets retenus, des textures, des sprites, des lumières et des systèmes de particules ; vous la dessinez comme une texture 2D.

| Méthode | Description |
| --- | --- |
| `SCENE3D:CreateScene(width, height)  -> scene` | Crée une scène de la taille logique donnée en pixels et renvoie son handle. Le jeu libère la scène quand il démonte le stage du script. |

### Handle de scène

<span class="badge-exp">Expérimental</span>

<div class="callout warn">
Déroulement par frame : dessinez l'arrière-plan (FillRect ou ClearTransparent), mettez à jour la caméra et toute géométrie par frame, appelez Render, puis Upload, puis Draw. Render n'efface pas le tampon de couleur ; dessinez donc le ciel ou le fond d'abord.
</div>

```lua
local scene, floor

function onStart()
    scene = SCENE3D:CreateScene(1280, 720)
    scene:SetLighting(true)
    scene:SetAmbient(0.4, 0.4, 0.46)
    scene:SetSun(0.3, 0.8, 0.5, 0.85, 0.82, 0.72)

    scene:RegisterTexture(1, pixels, 16, 16)          -- pixels : tableau indexé à partir de 1 d'entiers 0xRRGGBB
    floor = scene:NewObject()
    scene:ObjAddQuadTex(floor, 0,0,0,  0,0,8,  8,0,8,  8,0,0,  1, 8, 8, 1.0)
    scene:ObjSetBounds(floor, 0, 0, 0, 8, 0, 8)
end

function draw()
    scene:SetCameraPosition(4, 3, -6)
    scene:SetCameraAngles(0, -20)
    scene:FillRect(0, 0, 1280, 720, 90, 140, 220, 255)
    scene:Render()
    scene:Upload()
    scene:Draw(0, 0)
end

function onDestroy()
    scene:Dispose()
end
```

#### Moteur de rendu

| Méthode | Description |
| --- | --- |
| `scene:SetMode(mode)  -> nil` | Choisit le moteur de rendu : `"raster"` (par défaut ; GPU si disponible, sinon CPU), `"raster_cpu"`, `"raytrace"` ou `"rt"` (path tracer GPU avec repli CPU), `"raytrace_cpu"` ou `"rt_cpu"`. Changer abandonne l'état mis en cache et accumulé. |
| `scene:GetMode()  -> string` | Moteur de rendu actif : `"raster"`, `"raster_cpu"` ou `"raytrace"`. |
| `scene:SetThreads(n)  -> nil` | Nombre de threads pour le rastériseur CPU, qui découpe l'écran en autant de bandes de lignes (1 par défaut). |
| `scene:SetRenderDistance(d)  -> nil` | Ignore les objets dont les limites (voir ObjSetBounds) se trouvent entièrement au-delà de cette distance de la caméra ; 0 = illimité. Rastériseurs uniquement. |
| `scene:SetAntialias(on)  -> nil` | Active le lissage des bords en post-traitement sur le tampon de couleur final (désactivé par défaut). |
| `scene:GetSampleCount()  -> number` | Échantillons du path tracer accumulés par pixel depuis le dernier changement de caméra ou de scène ; 0 en modes raster. |
| `scene:GetMemoryStats()  -> texCount, texBytes, spriteCount, objCount, grassBlades, liveParticles` | Comptes de ressources pour les superpositions de débogage. |
| `scene:GetRendererStats()  -> string` | Comptes de caches côté moteur de rendu sur le rastériseur GPU, ou `"cpu"`. |
| `scene:ClearRenderCaches()  -> nil` | Abandonne les caches de rendu reconstructibles (cibles de rendu vers texture, tampons de sommets par objet, tampons statiques fusionnés). Les textures et sprites enregistrés survivent ; appelez-la au déchargement d'une carte. |
| `scene:Dispose()  -> nil` | Libère la scène immédiatement ; sinon elle vit jusqu'au démontage du stage. |

Si le moteur de rendu GPU échoue pendant le rendu (par exemple un shader rejeté par le pilote), la scène bascule vers le rastériseur CPU pour le reste de sa vie et le stage continue de s'exécuter.

#### Textures et sprites

Une texture est une image RGB opaque que les quads et les triangles échantillonnent par UV. Un sprite est une image ARGB que les sprites billboard, les quads de sprite, les particules, les brins d'herbe et les poids de splat de terrain utilisent. Les identifiants de texture et de sprite sont des espaces de noms distincts, et enregistrer un identifiant déjà existant remplace ses pixels.

| Méthode | Description |
| --- | --- |
| `scene:RegisterTexture(id, pixels, w, h)  -> nil` | Enregistre une texture à partir d'un tableau Lua indexé à partir de 1 d'entiers `0xRRGGBB` compactés (ligne par ligne, origine en haut à gauche). Une valeur négative marque un texel transparent (découpe). La scène ignore les images de plus de 4 194 304 pixels. |
| `scene:RegisterTextureFromImage(id, tex)  -> nil` | Enregistre une texture en relisant les pixels d'un handle de texture chargé. La relecture abandonne l'alpha et sollicite le GPU une fois par appel, ce qui est trop lent pour un usage à chaque frame. |
| `scene:SetTextureFilter(id, mode)  -> nil` | Filtre d'échantillonnage d'une texture : `"nearest"` (par défaut), `"linear"` ou `"mipmap"`. Rastériseur GPU uniquement. |
| `scene:UnregisterTexture(id)  -> nil` | Oublie une texture, y compris son envoi GPU et toute cible de rendu vers texture liée à l'identifiant. |
| `scene:SetSpriteRGBA(spriteId, pixels, w, h)  -> nil` | Enregistre un sprite à partir d'un tableau Lua indexé à partir de 1 d'entiers ARGB (`a << 24 | r << 16 | g << 8 | b`, ligne par ligne, origine en haut à gauche). |
| `scene:RegisterSpriteFromTexture(spriteId, tex)  -> nil` | Enregistre un sprite en relisant les pixels d'un handle de texture chargé. La relecture sollicite le GPU une fois par appel, ce qui est trop lent pour un usage à chaque frame. |
| `scene:MakeSoftCircle(spriteId, res, edge)  -> nil` | Génère un sprite rond blanc de `res` x `res` pixels, opaque au centre et s'estompant jusqu'à zéro au bord ; `edge` façonne l'atténuation (1 est linéaire, 2-3 une lueur douce). |
| `scene:MakeCrystal(spriteId, res)  -> nil` | Génère un sprite de flocon de neige blanc-bleu à six branches de `res` x `res` pixels. |
| `scene:SetSpriteFilter(spriteId, mode)  -> nil` | Filtre d'échantillonnage d'un sprite : `"nearest"` (par défaut) ou `"linear"`. À appeler juste après l'enregistrement. Rastériseur GPU uniquement. |
| `scene:UnregisterSprite(spriteId)  -> nil` | Oublie un sprite, y compris son envoi GPU. |

L'appel Register d'un modèle enregistre ses matériaux comme textures avec des identifiants à partir de 4000 (glTF) et de 6000 (OBJ) ; gardez donc vos propres identifiants de texture sous 4000 quand une scène dessine aussi des modèles.

#### Objets

Un objet est un groupe retenu de primitives. Toutes les primitives d'un objet doivent être du même type (quads texturés, quads plats, triangles texturés, sprites billboard ou quads de sprite) ; appelez ObjBegin avant de remplir de nouveau un objet avec un type différent. Les identifiants d'objet commencent à 1.

| Méthode | Description |
| --- | --- |
| `scene:NewObject()  -> id` | Crée un objet vide et visible dans la passe opaque. |
| `scene:DeleteObject(id)  -> nil` | Retire un objet et sa géométrie. |
| `scene:ClearObjects()  -> nil` | Retire chaque objet et chaque système de particules et abandonne les caches de rendu. Les textures, sprites, lumières et la caméra survivent ; les identifiants d'objet repartent à 1. |
| `scene:ObjBegin(id)  -> nil` | Efface les primitives d'un objet pour que vous puissiez le remplir de nouveau. |
| `scene:ObjAddQuadTex(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, texId, uMax, vMax, shade)  -> nil` | Ajoute un quad texturé. Les coins correspondent aux UV (0, vMax), (uMax, vMax), (uMax, 0), (0, 0) ; `shade` (0-1) multiplie le texel et module le soleil quand l'éclairage est activé. |
| `scene:ObjAddQuadFlat(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3)  -> nil` | Ajoute un quad de couleur unie ; la couleur et l'alpha viennent d'ObjSetPass. |
| `scene:ObjAddTriTex(id, x0, y0, z0, u0, v0, x1, y1, z1, u1, v1, x2, y2, z2, u2, v2, texId, shade)  -> nil` | Ajoute un triangle texturé avec des UV explicites. Les handles de modèle remplissent les objets avec cette primitive. |
| `scene:ObjAddSprite(id, x, y, z, w, h, spriteId, billboard, cutout)  -> nil` | Ajoute un quad de sprite de taille monde `w` x `h` dont le centre bas est en (x, y, z). `billboard` : 0 plan XY fixe, 1 fait face à la caméra mais reste droit, 2 fait toujours face à la caméra, 3 repose à plat sur le sol, étiré le long de la direction SetGroundSpriteLight. `cutout` non nul effectue un test alpha et écrit la profondeur (passe opaque) ; 0 fusionne en alpha (placez l'objet dans la passe transparente). |
| `scene:ObjAddSpriteQuad(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, spriteId, cutout)  -> nil` | Ajoute un sprite sur un quad monde explicite (les coins correspondent aux UV (0, 1), (1, 1), (1, 0), (0, 0)) ; pas de billboard. |
| `scene:ObjSetTransform(id, m)  -> nil` | Définit la matrice modèle de l'objet à partir d'une table Lua de 16 nombres en ordre ligne-majeur (translation en m[4], m[8], m[12]) ; nil restaure l'identité. |
| `scene:ObjSetTransform16(id, m0, m1, m2, m3, m4, m5, m6, m7, m8, m9, m10, m11, m12, m13, m14, m15)  -> nil` | Identique à ObjSetTransform avec 16 arguments simples ; utilisez-la pour les mises à jour par frame. |
| `scene:ObjClearTransform(id)  -> nil` | Restaure la matrice modèle identité. |
| `scene:ObjSetBounds(id, minX, minY, minZ, maxX, maxY, maxZ)  -> nil` | Limites en espace monde pour l'élimination derrière la caméra, SetRenderDistance et ObjSetNormal. |
| `scene:ObjSetNormal(id, nx, ny, nz)  -> nil` | Traite l'objet comme un groupe planaire orienté vers (nx, ny, nz) et l'ignore quand la caméra est derrière ce plan (nécessite ObjSetBounds) ; 0, 0, 0 désactive. |
| `scene:ObjSetVisible(id, v)  -> nil` | Affiche ou masque un objet. |
| `scene:ObjSetPass(id, pass, r, g, b, a)  -> nil` | Passe de rendu (0 opaque, dessinée d'avant en arrière ; 1 transparente, dessinée d'arrière en avant) plus la couleur des quads plats (0-255) et l'alpha (0-255) appliqué aux quads plats et aux sprites. |
| `scene:ObjSetTint(id, r, g, b)  -> nil` | Multiplication de couleur par canal (0-1) pour les surfaces texturées et les sprites ; 1, 1, 1 = aucune. |
| `scene:ObjSetColor(id, r, g, b)  -> nil` | Substitution d'albédo uni (0-1) qui remplace la couleur de texture ou de matériau avant l'éclairage ; r < 0 l'efface. Rastériseur GPU uniquement. |
| `scene:ObjSetEmissive(id, r, g, b)  -> nil` | Ajout émissif (couleur += base x rgb) ; les valeurs supérieures à 1 alimentent le bloom de SetDiorama. 0, 0, 0 = désactivé. Rastériseur GPU uniquement. |
| `scene:ObjSetLit(id, lit)  -> nil` | Si l'éclairage direct s'applique à l'objet (true par défaut) ; false le rend uniquement avec son ombrage précalculé. |
| `scene:ObjSetCastShadow(id, on)  -> nil` | Si les sprites de l'objet projettent dans la carte d'ombres du soleil (true par défaut). Rastériseur GPU uniquement. |
| `scene:ObjSetDepthBias(id, bias)  -> nil` | Biais de profondeur par décalage de polygone : négatif tire l'objet vers la caméra (décalcomanies sur une surface coplanaire), positif l'éloigne ; 0 = désactivé. Rastériseur GPU uniquement. |
| `scene:ObjSetOverlay(id, on)  -> nil` | Dessine l'objet en dernier par-dessus un tampon de profondeur effacé pour qu'il apparaisse toujours au-dessus (modèles de vue à la première personne). |
| `scene:ObjSetXray(id, alpha)  -> nil` | Redessine les sprites de l'objet comme un fantôme à cet alpha (0-1) là où la géométrie du monde les occulte ; 0 = désactivé. Rastériseur GPU uniquement. |
| `scene:ObjSetMaterial(id, matId)  -> nil` | Matériau que le path tracer utilise pour cet objet (-1 = par défaut). Path tracer uniquement. |
| `scene:ObjSetTerrainSplat(id, splatSpriteId, tex1, tex2, tex3, tex4, worldW, worldH, uvScale)  -> nil` | Mélange quatre textures de couche par pixel selon un sprite de poids ARGB (voir le handle de splatmap) ; `worldW`/`worldH` sont la couverture monde du splat, `uvScale` le nombre de répétitions de texture par unité monde. `splatSpriteId` < 0 désactive. Rastériseur GPU uniquement. |

#### Lumières et ombres

L'éclairage direct est désactivé par défaut. Une fois que vous l'activez, le terme ambiant, le soleil et les lumières ponctuelles éclairent chaque face.

| Méthode | Description |
| --- | --- |
| `scene:SetLighting(on)  -> nil` | Active l'éclairage direct sur les rastériseurs. |
| `scene:SetAmbient(r, g, b)  -> nil` | Lumière ambiante ajoutée à chaque face éclairée. |
| `scene:SetSun(dx, dy, dz, r, g, b)  -> nil` | Soleil directionnel : (dx, dy, dz) est la direction vers le soleil (normalisée automatiquement) ; (r, g, b) est la couleur multipliée par la luminosité, les valeurs supérieures à 1 fonctionnent donc. Une couleur nulle le désactive. |
| `scene:AddLight(x, y, z, r, g, b, intensity)  -> nil` | Ajoute une lumière ponctuelle à atténuation en inverse du carré ; couleur multipliée par l'intensité. |
| `scene:AddLightRanged(x, y, z, r, g, b, intensity, range)  -> nil` | Ajoute une lumière ponctuelle dont l'atténuation atteint zéro à `range` sur les rastériseurs ; le path tracer ignore la portée. |
| `scene:ClearLights()  -> nil` | Retire toutes les lumières ponctuelles. |
| `scene:SetShadows(on)  -> nil` | Active la carte d'ombres du soleil. Nécessite SetLighting et un SetSun non nul. Rastériseur GPU uniquement. |
| `scene:SetShadowFocus(x, y, z)  -> nil` | Centre la carte d'ombres du soleil sur ce point monde (normalement le joueur) à chaque frame. Rastériseur GPU uniquement. |
| `scene:SetShadowArea(half)  -> nil` | Demi-étendue en unités monde de la boîte de la carte d'ombres autour du point de focalisation (60 par défaut, minimum 4). Rastériseur GPU uniquement. |
| `scene:SetGroundSpriteLight(dx, dz, lenScale)  -> nil` | Direction horizontale et échelle de longueur pour les sprites en mode billboard 3 (ombres projetées à plat sur le sol). |

#### Brouillard, ciel et post-traitement

| Méthode | Description |
| --- | --- |
| `scene:SetFog(on, r, g, b, start, end)  -> nil` | Brouillard de distance : les pixels s'estompent vers (r, g, b) (0-255) entre les profondeurs caméra `start` et `end`. Rastériseurs uniquement. |
| `scene:SetDiorama(on, tilt, sat, vig, bloom)  -> nil` | Étalonnage en post-traitement : flou tilt-shift en pixels (0 = aucun), saturation (1 = aucune), intensité du vignettage et intensité du bloom (0 = désactivé). Rastériseur GPU uniquement. |

| `scene:SetOutline(r, g, b, thicknessPx)  -> nil` | Contour de silhouette de la couleur (0-255) et de l'épaisseur en pixels données autour des formes rendues ; 0 désactive. |

| `scene:SetTime(t)  -> nil` | Horloge des shaders en secondes (`uTime`) pour les shaders d'ondulation, de ciel, de surface et de post-traitement ; alimentez-la une fois par frame. |

#### Herbe

Les brins d'herbe sont des quads découpés faisant face à la caméra avec un balancement de vent, regroupés dans un seul tampon. Rastériseur GPU uniquement.

| Méthode | Description |
| --- | --- |
| `scene:GrassSprite(spriteId)  -> nil` | Sprite utilisé comme texture de brin. |
| `scene:GrassAdd(x, y, z, h, phase, shade)  -> nil` | Plante un brin avec son pied en (x, y, z), une hauteur monde `h`, une phase de balancement en radians et un ombrage 0-1. |
| `scene:GrassRemoveRect(x0, z0, x1, z1)  -> nil` | Retire les brins dont le pied se trouve dans le rectangle XZ (routes, bassins, emprises de bâtiments). |
| `scene:GrassFade(start, end)  -> nil` | Les brins s'estompent et rétrécissent entre ces deux distances à la caméra. |
| `scene:GrassCount()  -> number` | Nombre de brins courant. |
| `scene:GrassClear()  -> nil` | Retire chaque brin et libère le tampon (déchargement de carte). |

#### Particules

Un système de particules est un réservoir de billboards faisant face à la caméra. Émettez dedans, appelez PsUpdate à chaque frame, et les rastériseurs dessinent les particules vivantes dans la passe transparente. Les identifiants de système commencent à 0 ; ClearObjects les invalide.

| Méthode | Description |
| --- | --- |
| `scene:NewParticleSystem()  -> id` | Crée un système de particules et renvoie son identifiant. |
| `scene:PsUpdate(id, dt)  -> nil` | Fait avancer le système de `dt` secondes (vieillissement, gravité, traînée, mouvement). |
| `scene:PsEmit(id, x, y, z, vx, vy, vz, r, g, b, a0, size0, size1, life, gravity, drag, additive)  -> nil` | Émet une particule : couleur 0-255, opacité initiale `a0` 0-1, taille de billboard de `size0` à `size1` (unités monde) sur `life` secondes, gravité vers le bas, traînée par seconde ; `additive` non nul fusionne la particule de façon additive sur la frame, 0 la fusionne en alpha. |
| `scene:PsBurst(id, x, y, z, count, dirX, dirY, dirZ, spread, speed, r, g, b, colorJitter, a0, size0, size1, life, lifeVar, gravity, drag, additive)  -> nil` | Émet `count` particules dans des directions aléatoires orientées vers (dirX, dirY, dirZ) selon `spread` (0 = exactement le long de la direction, 1 = totalement aléatoire), avec des vitesses jusqu'à `speed`, une variation de couleur, et une variation de durée de vie par particule `lifeVar` (fraction de `life`). |
| `scene:PsSetSprite(id, spriteId)  -> nil` | Sprite appliqué aux particules émises ensuite (-1 = carré plat). |
| `scene:PsSetNextRotation(id, rotDeg, rotVelDegPerSec)  -> nil` | Rotation de billboard pour les particules émises ensuite : angle initial en degrés (négatif = aléatoire par particule) et vitesse de rotation en degrés par seconde (chaque particule reçoit une amplitude et un signe aléatoires). 0, 0 = désactivé. |
| `scene:PsSetNextCurves(id, sizeCurve, fadeCurve)  -> nil` | Courbes pour les particules émises ensuite. Taille : 0 linéaire, 1 sortie en douceur, 2 croissance puis rétrécissement. Fondu : 0 linéaire, 1 entrée et sortie douces, 2 éclair vif avec une longue traîne. |
| `scene:PsSetCap(id, cap)  -> nil` | Nombre maximum de particules vivantes (4000 par défaut) ; le système abandonne les émissions au-delà du plafond. |
| `scene:PsCount(id)  -> number` | Nombre de particules vivantes. |
| `scene:PsClear(id)  -> nil` | Retire chaque particule vivante du système. |

#### Vues de rendu vers texture

Ces méthodes rendent de nouveau la scène depuis une autre caméra dans une texture enregistrée, qu'un quad échantillonne ensuite par position d'écran (ObjSetScreenTex) pour afficher miroirs, reflets d'eau, portails et moniteurs. Le nouveau rendu ignore les objets marqués ObjSetScreenTex ou ObjSetOverlay pour que les reflets ne se répètent pas récursivement.

| Méthode | Description |
| --- | --- |
| `scene:SetReflectionScale(shift)  -> nil` | Résolution des nouveaux rendus par rapport à la vue principale : 0 entière, 1 moitié (par défaut), 2 quart, 3 huitième. |
| `scene:SetReflectionGpu(on)  -> nil` | Fait passer RenderView et RenderViewReflect par une passe hors écran GPU. Désactivé par défaut, auquel cas le rastériseur CPU rend les vues ; si la passe GPU échoue, la scène retombe sur le chemin CPU. |
| `scene:RenderView(texId, cx, cy, cz, yawDeg, pitchDeg, fovDeg, clr, clg, clb, flipX)  -> nil` | Rend la scène depuis la caméra donnée dans la texture `texId`, en l'effaçant d'abord à (clr, clg, clb) (0-255). `flipX` non nul inverse l'image (miroirs plans). |
| `scene:RenderViewReflect(texId, px, py, pz, nx, ny, nz, clr, clg, clb)  -> nil` | Rend le reflet planaire par rapport au plan passant par (px, py, pz) de normale (nx, ny, nz) dans la texture `texId`. Le chemin GPU découpe la géométrie sous le plan. |
| `scene:ObjSetScreenTex(id, on)  -> nil` | Fait passer l'échantillonnage de la texture de l'objet des UV à la position d'écran, pour qu'un quad texturé avec un résultat de RenderView affiche cette vue alignée sur l'écran. |
| `scene:ObjSetScreenTexRipple(id, amp, freq, speed)  -> nil` | Distorsion animée d'une surface texturée par écran : `amp` en pixels de cible de rendu (0 = désactivé), fréquence d'onde en espace monde et vitesse d'animation (pilotée par SetTime). Rastériseur GPU uniquement. |
| `scene:ObjSetFresnel(id, f0)  -> nil` | Réflectivité de Fresnel de Schlick par pixel pour une surface texturée par écran (environ 0.04 pour l'eau) ; négatif désactive. Rastériseur GPU uniquement. |
| `scene:ObjSetWaterColors(id, dr, dg, db)  -> nil` | Couleur d'eau profonde (0-1) pour une surface texturée par écran ; l'ombrage par sommet interpole de la couleur de base de l'objet (peu profond) vers cette couleur (profond). Rastériseur GPU uniquement. |
| `scene:ObjSetSurfaceShader(id, fragSrc)  -> nil` | Attache un shader de fragment GLSL ES 3.00 personnalisé à une surface texturée par écran, remplaçant le rendu intégré d'ondulation et de Fresnel. Source complète ou corps de `main()` ; le prélude fournit `vUV`, `vShade`, `vCamZ`, `vWorld`, `vNormal`, `uTex` (le reflet), `uRsh`, `uRttFlip`, `uCam`, `uTint`, `uFlat`, `uTime`, `uAlpha`, `uUser[4]` et `out vec4 frag`. nil ou "" détache ; un échec de compilation retombe sur le shader intégré. Rastériseur GPU uniquement. |
| `scene:SetSurfaceUniform(slot, x, y, z, w)  -> nil` | Définit `uUser[slot]` (0..3) partagé par chaque shader de surface personnalisé. |

## Modèles

### MODEL

<span class="badge-exp">Expérimental</span>

Charge des fichiers glTF/GLB (skinnés, animés) et OBJ (statiques) dans des handles de modèle posables.

<div class="callout warn">
Les chemins sont relatifs au répertoire du script ; le chargeur accepte aussi les chemins absolus. Le chargeur analyse chaque fichier glTF une fois par processus et le partage entre scènes et stages, si bien que le routage de parties défini avec SetPartObject persiste jusqu'à ClearPartObjects ou PurgeCache. La prise en charge glTF couvre les primitives triangulaires indexées avec positions, un jeu d'UV, joints et poids facultatifs, un skin, les hiérarchies de nœuds, les animations TRS linéaires, les couleurs de base des matériaux et les textures de couleur de base embarquées (réduites à 512 pixels sur le grand côté). La prise en charge OBJ couvre les positions, les coordonnées de texture, les faces polygonales et les couleurs diffuses du fichier .mtl ; le chargeur saute les textures image.
</div>

| Méthode | Description |
| --- | --- |
| `MODEL:Load(path)  -> model` | Charge un fichier .glb, .gltf ou .obj et renvoie un handle de modèle, ou nil en cas d'échec. |
| `MODEL:PurgeCache()  -> nil` | Abandonne le cache glTF à l'échelle du processus (sortie de stage). Rechargez ensuite tout modèle encore utilisé. |

### Handle de modèle

<span class="badge-exp">Expérimental</span>

<div class="callout warn">
Appelez Register une fois par scène, puis Pose à chaque frame pour écrire les triangles placés (et, pour glTF, skinnés) dans un objet de scène. Les indices d'animation commencent à 0 ; -1 pose la pose de repos. Pose borne le temps d'animation au clip ; bouclez-le vous-même avec Duration. Les méthodes sous Duration sont réservées à glTF ; les handles OBJ exposent Register, Pose, AnimCount (0), AnimName et Duration.
</div>

```lua
local model, obj
local clip = 0

function onStart()
    model = MODEL:Load("models/lantern.glb")
    if model then
        model:Register(scene)
        obj = scene:NewObject()
    end
end

function draw()
    if model then
        local t = elapsed % model:Duration(clip)
        model:Pose(scene, obj, clip, t, x, y, z, yawDeg, 1.0)
    end
end

function onDestroy()
    MODEL:PurgeCache()
end
```

| Méthode | Description |
| --- | --- |
| `model:Register(scene)  -> nil` | Enregistre les matériaux et textures du modèle dans une scène (une fois par scène). |
| `model:Pose(scene, objId, anim, time, x, y, z, yawDeg, scale)  -> nil` | Efface l'objet `objId` et le remplit avec les triangles du modèle à l'animation `anim` et au temps `time` en secondes, translatés en (x, y, z), pivotés autour de Y de `yawDeg` et mis à l'échelle uniformément. |
| `model:AnimCount()  -> number` | Nombre de clips d'animation (0 pour OBJ). |
| `model:AnimName(i)  -> string` | Nom du clip `i`, ou "" hors limites. |
| `model:Duration(i)  -> number` | Durée en secondes du clip `i`, ou 0 hors limites. |
| `model:PartCount()  -> number` | Nombre de parties (instances de primitive). |
| `model:PartMaterial(part)  -> number` | Indice de matériau d'une partie (à partir de 0), ou -1 hors limites. |
| `model:MaterialCount()  -> number` | Nombre de matériaux glTF. |
| `model:MaterialName(mat)  -> string` | Nom d'un matériau glTF, ou "" hors limites. |
| `model:MaterialEmissive(mat)  -> r, g, b` | L'`emissiveFactor` glTF du matériau, ou 0, 0, 0 s'il n'y en a pas. |
| `model:SetPartObject(part, objId)  -> nil` | Route les triangles d'une partie vers leur propre objet de scène lors de Pose, pour que cette partie puisse porter ses propres drapeaux de transparence, d'émission ou de miroir ; -1 efface le routage de cette partie. |
| `model:ClearPartObjects()  -> nil` | Abandonne tout le routage de parties. Appelez-la au déchargement du monde, car l'instance de modèle est partagée et les identifiants d'objet repartent après ClearObjects. |
| `model:GetBounds()  -> minX, minY, minZ, maxX, maxY, maxZ` | Limites de la pose de repos en espace modèle. |
| `model:BuildCollider(mc, x, y, z, yawDeg, scale)  -> nil` | Ajoute à un MeshCollider les triangles de la pose de repos, placés avec la transformation donnée. Une échelle négative agit par sa valeur absolue. |

## Cartes de hauteurs

### HEIGHTMAP

<span class="badge-exp">Expérimental</span>

Charge des champs de hauteurs bruts 16 bits et des images de splat RGBA pour le terrain, et construit un terrain complet en un seul appel.

<div class="callout warn">
Les chemins sont relatifs au répertoire du script. Un fichier de champ de hauteurs contient w x h échantillons 16 bits non signés petit-boutiste en ordre ligne par ligne ; une image de splat est un PNG RGBA dont les canaux R, G, B, A sont les poids des couches 1 à 4. En cas d'erreur de lecture, les deux chargeurs renvoient une solution de repli plate.
</div>

| Méthode | Description |
| --- | --- |
| `HEIGHTMAP:Load(path, w, h)  -> heightfield` | Charge un champ de hauteurs de w x h échantillons ; renvoie un champ plat nul en cas d'erreur. |
| `HEIGHTMAP:LoadSplat(path)  -> splatmap` | Charge une image de splat ; renvoie une carte entièrement couche 1 en cas d'erreur. Un canal alpha entièrement opaque signifie que la carte n'a pas de couche 4. |
| `HEIGHTMAP:BuildTerrain(scene, floorObj, world, hf, splat, w, h, minY, maxY, cellSize, tex1, tex2, tex3, tex4, grassDensity, grassClump)  -> number` | Émet le terrain en un seul appel : un quad texturé par cellule dans `floorObj` (l'échantillon (ix, iz) se trouve en x monde = ix x cellSize, z = iz x cellSize, y = minY + échantillon x (maxY - minY) ; chaque texture de couche se répète une fois par cellule), les quads de collision correspondants plus des murs de bordure invisibles dans `world` (appelez-la entre BeginStatic et EndStatic), et des brins d'herbe sur le sol de couche 1 loin des pentes raides et du bord de la carte quand `grassDensity` > 0 (`grassClump` > 0 les regroupe en touffes). Sans splat, les cellules raides utilisent `tex2` et les autres `tex1`. Renvoie le nombre de brins d'herbe plantés. |

### Handle de champ de hauteurs

<span class="badge-exp">Expérimental</span>

Le chargeur normalise les échantillons de 0 à 1 ; hauteur monde = minY + échantillon x (maxY - minY).

| Méthode | Description |
| --- | --- |
| `heightfield:W()  -> number` | Largeur en échantillons. |
| `heightfield:H()  -> number` | Hauteur en échantillons. |
| `heightfield:At(ix, iz)  -> number` | Échantillon aux coordonnées de grille entières, bornées aux bords. |
| `heightfield:Sample(fx, fz)  -> number` | Échantillon bilinéaire aux coordonnées de grille fractionnaires. |
| `heightfield:Release()  -> nil` | Abandonne maintenant le tampon d'échantillons (déchargement de carte) ; At et Sample renvoient 0 ensuite. |

### Handle de splatmap

<span class="badge-exp">Expérimental</span>

Les couches sont numérotées de 1 à 4 (canaux d'image R, G, B, A).

| Méthode | Description |

| `splat:W()  -> number` | Largeur en texels. |
