# OpenTaiko ドキュメント

<span class="badge-new">ゲームバージョン 0.6.1</span>

<div class="callout warn">このドキュメントは現在レビュー中で、リリースまでに変更される可能性があります。</div>

OpenTaiko は、コアのゲームプレイ以外のほぼすべての画面を、スキンに同梱された Lua スクリプトで描画しています。メニュー、選曲画面、部屋画面やストーリーシーン、背景、リザルト画面などです。このサイトでは、それらのスクリプトが使う Lua API を解説し、スキン作者がよく行う作業を順を追って説明します。

## どこから始めるか

- モジュールをまだ書いたことがなければ、[モジュールの仕組み](getting-started.md)をお読みください。スキンのフォルダ構成、モジュールの種類、スクリプトが受け取るライフサイクルコールバックを説明しています。
- 関数を調べるには、[API リファレンス](api/)を開き、サイドバーからカテゴリを選んでください。
- 具体的な目的があるなら、ガイドが[キャラクター](guides/characters.md)、[ぷちキャラ](guides/puchicharas.md)、[スキンとテーマ](guides/skins.md)、[譜面のアンロック要素](guides/unlockables.md)を手順ごとに解説しています。

## 作成できるもの

| 分野 | 置き場所 | 内容 |
| --- | --- | --- |
| モジュール | スキンの `Modules/` フォルダ | ステージ (入力、描画、状態を独自に持つ完全な画面。選曲画面、部屋画面、ストーリーシーンなど)、アクティビティ (ダイアログやネームプレートなどのサブ画面とオーバーレイ)、トランジション (ステージ間のフェードとローディング画面)。 |
| バックグラウンド | スキンの `Graphics/` フォルダ | 画面を装飾するスクリプト。起動画面、部屋画面、ゲームプレイの背景とモブ、リザルト画面など。 |
| スキンとテーマ | ゲーム本体の隣の `System/` | プレイヤーがインストールして切り替える完全なビジュアルパッケージと、それがオプション画面に公開するテーマ設定。 |
| キャラクターとぷちキャラ | すべてのスキンが共有する `Global/Characters/` と `Global/PuchiChara/` | プレイ中に反応する踊り手と小さなマスコット。 |
| 譜面のアンロック要素 | 譜面の隣の楽曲フォルダ | プレイヤーが条件を達成するまで楽曲をロックしておく `Unlock.json`。 |

## 実験的な節

一部のページには、サイドバーに <span class="badge-exp">実験的</span> バッジが付いています。それらが説明する機能は現在のリリースで動作しますが、その API は非推奨期間なしにリリース間で変更される可能性があります。それらに依存するスキンは対象とするゲームバージョンを明記し、更新のたびに再テストしてください。

## 言語

このドキュメントは OpenTaiko が対応するすべての言語で存在します。サイドバー上部の言語セレクタで言語を選んでください。翻訳ができるまで、サイトはそのページを英語で表示します。
