# 3D エンジン: ラスタライザーの世界 <span class="badge-exp">実験的</span>

シーン、モデル、ライト、カメラ、物理、コライダー、経路探索、パーティクル、レンダーターゲット、地形のハイトマップ。

3D エンジンは実験的です。バージョン 1.0 で実験的の表記を外す予定です。

<div class="callout">
このページのすべてのグローバルとすべてのメソッドは、非推奨期間なしにリリース間で変更される可能性があります。スキンがこれに依存する場合は、更新のたびに再テストし、対象とするゲームバージョンを明記してください。
</div>

このページで使う規約:

- 位置とサイズはワールド単位で、+Y が上です。オブジェクト、テクスチャ、スプライト、マテリアル、プリミティブの id は整数です。
- 角度は、行がラジアンと明記していない限り度です (物理の車両の向きと傾き、ホイールの回転、草の揺れの位相)。
- `Clear`、`FillRect`、`DrawLine`、`SetFog`、`ObjSetPass`、`PsEmit`、`PsBurst` は 0-255 の色を取ります。ライト、太陽、環境光、マテリアル、ティント、`ObjSetColor` はリニアの 0-1 の色を取ります。
- 3 つのレンダラーが同じシーンデータを共有します: GPU ラスタライザ (GLES 3.1 コンピュートシェーダが利用可能なときの既定)、CPU ラスタライザ (フォールバック、または `SetMode("raster_cpu")` で強制)、パストレーサー (`SetMode("raytrace")`)。*GPU ラスタライザのみ* または *パストレーサーのみ* と記された行は、他のレンダラーが無視します。

レイトレーサーと物理ワールドには専用のページがあります: [レイトレーサーの世界](3d-raytrace.md) と [物理](3d-physics.md)。

## シーン

### SCENE3D

<span class="badge-exp">実験的</span>

3D シーンのファクトリです。シーンは、カメラ、保持されるオブジェクト、テクスチャ、スプライト、ライト、パーティクルシステムを所有するレンダーターゲットで、2D テクスチャと同じように描画します。

| メソッド | 説明 |
| --- | --- |
| `SCENE3D:CreateScene(width, height)  -> scene` | 指定した論理ピクセルサイズでシーンを作成し、そのハンドルを返します。ゲームはスクリプトのステージを破棄するときにシーンを破棄します。 |

### シーンハンドル

<span class="badge-exp">実験的</span>

<div class="callout warn">
フレームごとの流れ: 背景を描き (FillRect または ClearTransparent)、カメラとフレームごとのジオメトリを更新し、Render、次に Upload、次に Draw を呼びます。Render はカラーバッファをクリアしないため、空や背景を先に描いてください。
</div>

```lua
local scene, floor

function onStart()
    scene = SCENE3D:CreateScene(1280, 720)
    scene:SetLighting(true)
    scene:SetAmbient(0.4, 0.4, 0.46)
    scene:SetSun(0.3, 0.8, 0.5, 0.85, 0.82, 0.72)

    scene:RegisterTexture(1, pixels, 16, 16)          -- pixels: 1-based array of 0xRRGGBB ints
    floor = scene:NewObject()
    scene:ObjAddQuadTex(floor, 0,0,0,  0,0,8,  8,0,8,  8,0,0,  1, 8, 8, 1.0)
    scene:ObjSetBounds(floor, 0, 0, 0, 8, 0, 8)
end

function draw()
    scene:SetCameraPosition(4, 3, -6)
    scene:SetCameraAngles(0, -20)
    scene:FillRect(0, 0, 1280, 720, 90, 140, 220, 255)
    scene:Render()
    scene:Upload()
    scene:Draw(0, 0)
end

function onDestroy()
    scene:Dispose()
end
```

#### レンダラー

| メソッド | 説明 |
| --- | --- |
| `scene:SetMode(mode)  -> nil` | レンダラーを選びます: `"raster"` (既定。利用可能なら GPU、そうでなければ CPU)、`"raster_cpu"`、`"raytrace"` または `"rt"` (CPU フォールバック付きの GPU パストレーサー)、`"raytrace_cpu"` または `"rt_cpu"`。切り替えるとキャッシュと蓄積された状態が破棄されます。 |
| `scene:GetMode()  -> string` | アクティブなレンダラー: `"raster"`、`"raster_cpu"`、`"raytrace"`。 |
| `scene:SetThreads(n)  -> nil` | CPU ラスタライザのスレッド数。ラスタライザは画面をその数の行帯に分割します (既定 1)。 |
| `scene:SetRenderDistance(d)  -> nil` | 境界 (ObjSetBounds を参照) がカメラからこの距離より完全に遠いオブジェクトをスキップします。0 = 無制限。ラスタライザのみ。 |
| `scene:SetAntialias(on)  -> nil` | 最終カラーバッファに対するポストプロセスのエッジ平滑化を有効にします (既定はオフ)。 |
| `scene:GetSampleCount()  -> number` | 最後のカメラまたはシーンの変更以降にパストレーサーがピクセルごとに蓄積したサンプル数。ラスタモードでは 0。 |
| `scene:GetMemoryStats()  -> texCount, texBytes, spriteCount, objCount, grassBlades, liveParticles` | デバッグオーバーレイ用のリソース数。 |
| `scene:GetRendererStats()  -> string` | GPU ラスタライザのレンダラー側キャッシュ数、または `"cpu"`。 |
| `scene:ClearRenderCaches()  -> nil` | 再構築可能なレンダーキャッシュ (レンダーテクスチャのターゲット、オブジェクトごとの頂点バッファ、マージされた静的バッファ) を破棄します。登録されたテクスチャとスプライトは残ります。マップのアンロード時に呼んでください。 |
| `scene:Dispose()  -> nil` | シーンを直ちに解放します。呼ばなければシーンはステージの破棄まで生存します。 |

レンダリング中に GPU レンダラーが失敗した場合 (例えばドライバがシェーダを拒否した場合)、シーンは残りの生存期間を CPU ラスタライザに切り替え、ステージは動き続けます。

#### テクスチャとスプライト

テクスチャは、クワッドと三角形が UV によってサンプリングする不透明な RGB 画像です。スプライトは、ビルボードスプライト、スプライトクワッド、パーティクル、草の葉、地形のスプラット重みが使う ARGB 画像です。テクスチャ id とスプライト id は別々の名前空間で、すでに存在する id を登録するとそのピクセルが置き換わります。

| メソッド | 説明 |
| --- | --- |
| `scene:RegisterTexture(id, pixels, w, h)  -> nil` | パックされた `0xRRGGBB` 整数の 1 始まりの Lua 配列 (行優先、左上原点) からテクスチャを登録します。負の値は透明 (カットアウト) のテクセルを示します。4,194,304 ピクセルを超える画像はシーンが無視します。 |
| `scene:RegisterTextureFromImage(id, tex)  -> nil` | 読み込み済みのテクスチャハンドルのピクセルを読み戻してテクスチャを登録します。読み戻しはアルファを破棄し、呼び出しごとに GPU に 1 回アクセスするため、フレームごとの使用には遅すぎます。 |
| `scene:SetTextureFilter(id, mode)  -> nil` | テクスチャのサンプリングフィルタ: `"nearest"` (既定)、`"linear"`、`"mipmap"`。GPU ラスタライザのみ。 |
| `scene:UnregisterTexture(id)  -> nil` | テクスチャを、その GPU アップロードと id に紐づくレンダーテクスチャのターゲットを含めて破棄します。 |
| `scene:SetSpriteRGBA(spriteId, pixels, w, h)  -> nil` | ARGB 整数 (`a << 24 | r << 16 | g << 8 | b`、行優先、左上原点) の 1 始まりの Lua 配列からスプライトを登録します。 |
| `scene:RegisterSpriteFromTexture(spriteId, tex)  -> nil` | 読み込み済みのテクスチャハンドルのピクセルを読み戻してスプライトを登録します。読み戻しは呼び出しごとに GPU に 1 回アクセスするため、フレームごとの使用には遅すぎます。 |
| `scene:MakeSoftCircle(spriteId, res, edge)  -> nil` | 中心が不透明で端に向かって 0 に減衰する、`res` x `res` ピクセルの白い丸のスプライトを生成します。`edge` は減衰の形を決めます (1 は線形、2-3 は柔らかい光)。 |
| `scene:MakeCrystal(spriteId, res)  -> nil` | `res` x `res` ピクセルの、6 本の腕を持つ白青の雪の結晶のスプライトを生成します。 |
| `scene:SetSpriteFilter(spriteId, mode)  -> nil` | スプライトのサンプリングフィルタ: `"nearest"` (既定) または `"linear"`。登録の直後に呼んでください。GPU ラスタライザのみ。 |
| `scene:UnregisterSprite(spriteId)  -> nil` | スプライトを、その GPU アップロードを含めて破棄します。 |

モデルの Register 呼び出しは、そのマテリアルを 4000 以降 (glTF) と 6000 以降 (OBJ) の id を持つテクスチャとして登録するため、シーンがモデルも描画する場合は、自分のテクスチャ id を 4000 未満に収めてください。

#### オブジェクト

オブジェクトは保持されるプリミティブのグループです。1 つのオブジェクト内のすべてのプリミティブは同じ種類 (テクスチャ付きクワッド、単色クワッド、テクスチャ付き三角形、ビルボードスプライト、スプライトクワッド) でなければなりません。別の種類でオブジェクトを埋め直す前に ObjBegin を呼んでください。オブジェクト id は 1 から始まります。

| メソッド | 説明 |
| --- | --- |
| `scene:NewObject()  -> id` | 不透明パスに空の可視オブジェクトを作成します。 |
| `scene:DeleteObject(id)  -> nil` | オブジェクトとそのジオメトリを取り除きます。 |
| `scene:ClearObjects()  -> nil` | すべてのオブジェクトとすべてのパーティクルシステムを取り除き、レンダーキャッシュを破棄します。テクスチャ、スプライト、ライト、カメラは残ります。オブジェクト id は 1 から再開します。 |
| `scene:ObjBegin(id)  -> nil` | 埋め直せるようにオブジェクトのプリミティブをクリアします。 |
| `scene:ObjAddQuadTex(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, texId, uMax, vMax, shade)  -> nil` | テクスチャ付きクワッドを追加します。頂点は UV (0, vMax)、(uMax, vMax)、(uMax, 0)、(0, 0) に対応します。`shade` (0-1) はテクセルに乗算され、ライティングが有効なときは太陽光を制御します。 |
| `scene:ObjAddQuadFlat(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3)  -> nil` | 単色のクワッドを追加します。色とアルファは ObjSetPass から取られます。 |
| `scene:ObjAddTriTex(id, x0, y0, z0, u0, v0, x1, y1, z1, u1, v1, x2, y2, z2, u2, v2, texId, shade)  -> nil` | 明示的な UV を持つテクスチャ付き三角形を追加します。モデルハンドルはこのプリミティブでオブジェクトを埋めます。 |
| `scene:ObjAddSprite(id, x, y, z, w, h, spriteId, billboard, cutout)  -> nil` | 底辺の中心が (x, y, z) にある、ワールドサイズ `w` x `h` のスプライトクワッドを追加します。`billboard`: 0 固定の XY 平面、1 カメラを向くが直立を保つ、2 常にカメラを向く、3 SetGroundSpriteLight の方向に引き伸ばされて地面に平らに置かれる。`cutout` が 0 以外ならアルファテストして深度を書き込みます (不透明パス)。0 ならアルファブレンドします (オブジェクトを透明パスに置いてください)。 |
| `scene:ObjAddSpriteQuad(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, spriteId, cutout)  -> nil` | 明示的なワールドクワッド上にスプライトを追加します (頂点は UV (0, 1)、(1, 1)、(1, 0)、(0, 0) に対応)。ビルボードにはなりません。 |
| `scene:ObjSetTransform(id, m)  -> nil` | 行優先の 16 個の数値の Lua テーブル (平行移動は m[4]、m[8]、m[12]) からオブジェクトのモデル行列を設定します。nil は単位行列に戻します。 |
| `scene:ObjSetTransform16(id, m0, m1, m2, m3, m4, m5, m6, m7, m8, m9, m10, m11, m12, m13, m14, m15)  -> nil` | 16 個の通常の引数を取る ObjSetTransform。フレームごとの更新にはこちらを使ってください。 |
| `scene:ObjClearTransform(id)  -> nil` | 単位のモデル行列に戻します。 |
| `scene:ObjSetBounds(id, minX, minY, minZ, maxX, maxY, maxZ)  -> nil` | カメラ背後のカリング、SetRenderDistance、ObjSetNormal のためのワールド空間の境界。 |
| `scene:ObjSetNormal(id, nx, ny, nz)  -> nil` | オブジェクトを (nx, ny, nz) を向く平面グループとして扱い、カメラがその平面の後ろにあるときスキップします (ObjSetBounds が必要)。0, 0, 0 で無効。 |
| `scene:ObjSetVisible(id, v)  -> nil` | オブジェクトを表示または非表示にします。 |
| `scene:ObjSetPass(id, pass, r, g, b, a)  -> nil` | レンダーパス (0 不透明、手前から奥へ描画。1 透明、奥から手前へ描画) と、単色クワッドとスプライトに適用される単色クワッドの色 (0-255) とアルファ (0-255)。 |
| `scene:ObjSetTint(id, r, g, b)  -> nil` | テクスチャ付きサーフェスとスプライトのチャンネルごとの色の乗算 (0-1)。1, 1, 1 = なし。 |
| `scene:ObjSetColor(id, r, g, b)  -> nil` | ライティング前にテクスチャまたはマテリアルの色を置き換える単色のアルベド上書き (0-1)。r < 0 でクリア。GPU ラスタライザのみ。 |
| `scene:ObjSetEmissive(id, r, g, b)  -> nil` | エミッシブの加算 (色 += ベース x rgb)。1 を超える値は SetDiorama のブルームに寄与します。0, 0, 0 = オフ。GPU ラスタライザのみ。 |
| `scene:ObjSetLit(id, lit)  -> nil` | オブジェクトにフォワードライティングを適用するかどうか (既定 true)。false ならベイクされたシェードのみで描画します。 |
| `scene:ObjSetCastShadow(id, on)  -> nil` | オブジェクトのスプライトが太陽のシャドウマップに影を落とすかどうか (既定 true)。GPU ラスタライザのみ。 |
| `scene:ObjSetDepthBias(id, bias)  -> nil` | ポリゴンオフセットの深度バイアス: 負はオブジェクトをカメラ側に引き寄せ (同一平面上のデカール)、正は遠ざけます。0 = オフ。GPU ラスタライザのみ。 |
| `scene:ObjSetOverlay(id, on)  -> nil` | クリアした深度バッファの上にオブジェクトを最後に描き、常に最前面に表示します (一人称視点のモデル)。 |
| `scene:ObjSetXray(id, alpha)  -> nil` | ワールドジオメトリに遮られる部分で、オブジェクトのスプライトをこのアルファ (0-1) のゴーストとして再描画します。0 = オフ。GPU ラスタライザのみ。 |
| `scene:ObjSetMaterial(id, matId)  -> nil` | パストレーサーがこのオブジェクトに使うマテリアル (-1 = 既定)。パストレーサーのみ。 |
| `scene:ObjSetTerrainSplat(id, splatSpriteId, tex1, tex2, tex3, tex4, worldW, worldH, uvScale)  -> nil` | ARGB の重みスプライト (スプラットマップハンドルを参照) によって 4 つのレイヤーテクスチャをピクセルごとにブレンドします。`worldW`/`worldH` はスプラットのワールド上の範囲、`uvScale` はワールド単位あたりのテクスチャの繰り返し数です。`splatSpriteId` < 0 で無効。GPU ラスタライザのみ。 |

#### ライトと影

フォワードライティングは既定でオフです。有効にすると、環境光の項、太陽、ポイントライトが各面を照らします。

| メソッド | 説明 |
| --- | --- |
| `scene:SetLighting(on)  -> nil` | ラスタライザでフォワードライティングを有効にします。 |
| `scene:SetAmbient(r, g, b)  -> nil` | すべての照らされる面に加えられる環境光。 |
| `scene:SetSun(dx, dy, dz, r, g, b)  -> nil` | 方向性の太陽: (dx, dy, dz) は太陽へ向かう方向 (自動的に正規化されます)。(r, g, b) は色に明るさを掛けたもので、1 を超える値も動作します。ゼロの色で無効になります。 |
| `scene:AddLight(x, y, z, r, g, b, intensity)  -> nil` | 逆 2 乗の減衰を持つポイントライトを追加します。色に強度を掛けます。 |
| `scene:AddLightRanged(x, y, z, r, g, b, intensity, range)  -> nil` | ラスタライザで `range` で減衰が 0 に達するポイントライトを追加します。パストレーサーは範囲を無視します。 |
| `scene:ClearLights()  -> nil` | すべてのポイントライトを取り除きます。 |
| `scene:SetShadows(on)  -> nil` | 太陽のシャドウマッピングを有効にします。SetLighting とゼロでない SetSun が必要です。GPU ラスタライザのみ。 |
| `scene:SetShadowFocus(x, y, z)  -> nil` | 毎フレーム、太陽のシャドウマップの中心をこのワールド上の点 (通常はプレイヤー) に合わせます。GPU ラスタライザのみ。 |
| `scene:SetShadowArea(half)  -> nil` | 焦点の周りのシャドウマップボックスの、ワールド単位での半幅 (既定 60、最小 4)。GPU ラスタライザのみ。 |

## モデル

### MODEL

<span class="badge-exp">実験的</span>

glTF/GLB (スキン付き、アニメーション付き) と OBJ (静的) ファイルを、ポーズ可能なモデルハンドルに読み込みます。

<div class="callout warn">
パスはスクリプトのディレクトリからの相対パスです。ローダーは絶対パスも受け付けます。ローダーは各 glTF ファイルをプロセスごとに 1 回だけ解析し、シーンとステージの間で共有するため、SetPartObject で設定したパートのルーティングは ClearPartObjects または PurgeCache まで持続します。glTF の対応範囲は、位置、1 つの UV セット、任意のジョイントとウェイト、1 つのスキン、ノード階層、線形の TRS アニメーション、マテリアルのベース色、埋め込まれたベース色テクスチャ (長辺 512 ピクセルに縮小) を持つインデックス付き三角形プリミティブです。OBJ の対応範囲は、位置、テクスチャ座標、多角形の面、.mtl ファイルの拡散反射色です。ローダーは画像テクスチャをスキップします。
</div>

| メソッド | 説明 |
| --- | --- |
| `MODEL:Load(path)  -> model` | .glb、.gltf、.obj ファイルを読み込み、モデルハンドルを返します。失敗時は nil。 |
| `MODEL:PurgeCache()  -> nil` | プロセス全体の glTF キャッシュを破棄します (ステージ終了時)。まだ使用中のモデルは、その後再読み込みしてください。 |

### モデルハンドル

<span class="badge-exp">実験的</span>

<div class="callout warn">
シーンごとに 1 回 Register を呼び、その後毎フレーム Pose を呼んで、配置された (glTF ではスキニングされた) 三角形をシーンオブジェクトに書き込みます。アニメーションインデックスは 0 始まりで、-1 はバインドポーズをポーズします。Pose はアニメーション時間をクリップの範囲に制限するため、Duration を使って自分でループしてください。Duration より下のメソッドは glTF 専用です。OBJ ハンドルは Register、Pose、AnimCount (0)、AnimName、Duration を公開します。
</div>

```lua
local model, obj
local clip = 0

function onStart()
    model = MODEL:Load("models/lantern.glb")
    if model then
        model:Register(scene)
        obj = scene:NewObject()
    end
end

function draw()
    if model then
        local t = elapsed % model:Duration(clip)
        model:Pose(scene, obj, clip, t, x, y, z, yawDeg, 1.0)
    end
end

function onDestroy()
    MODEL:PurgeCache()
end
```

| メソッド | 説明 |
| --- | --- |
| `model:Register(scene)  -> nil` | モデルのマテリアルとテクスチャをシーンに登録します (シーンごとに 1 回)。 |
| `model:Pose(scene, objId, anim, time, x, y, z, yawDeg, scale)  -> nil` | オブジェクト `objId` をクリアし、アニメーション `anim` の `time` 秒時点のモデルの三角形を、(x, y, z) に移動し、Y の周りに `yawDeg` 回転し、一様にスケールして埋めます。 |
| `model:AnimCount()  -> number` | アニメーションクリップの数 (OBJ では 0)。 |
| `model:AnimName(i)  -> string` | クリップ `i` の名前。範囲外なら ""。 |
| `model:Duration(i)  -> number` | クリップ `i` の長さ (秒)。範囲外なら 0。 |
| `model:PartCount()  -> number` | パート (プリミティブインスタンス) の数。 |
| `model:PartMaterial(part)  -> number` | パートのマテリアルインデックス (0 始まり)。範囲外なら -1。 |
| `model:MaterialCount()  -> number` | glTF マテリアルの数。 |
| `model:MaterialName(mat)  -> string` | glTF マテリアルの名前。範囲外なら ""。 |
| `model:MaterialEmissive(mat)  -> r, g, b` | マテリアルの glTF `emissiveFactor`。なければ 0, 0, 0。 |
| `model:SetPartObject(part, objId)  -> nil` | Pose の際にパートの三角形を独自のシーンオブジェクトへ振り分け、そのパートが独自の透明度、エミッシブ、鏡のフラグを持てるようにします。-1 でそのパートのルーティングをクリアします。 |
| `model:ClearPartObjects()  -> nil` | すべてのパートのルーティングを破棄します。モデルインスタンスは共有されており、ClearObjects の後にオブジェクト id が再開するため、ワールドのアンロード時に呼んでください。 |
| `model:GetBounds()  -> minX, minY, minZ, maxX, maxY, maxZ` | モデル空間でのバインドポーズの境界。 |
| `model:BuildCollider(mc, x, y, z, yawDeg, scale)  -> nil` | 指定した変換で配置したバインドポーズの三角形を MeshCollider に追加します。負のスケールはその絶対値として働きます。 |

## ハイトマップ

### HEIGHTMAP

<span class="badge-exp">実験的</span>

地形用の生の 16 ビットハイトフィールドと RGBA のスプラット画像を読み込み、地形全体を 1 回の呼び出しで構築します。

<div class="callout warn">
パスはスクリプトのディレクトリからの相対パスです。ハイトフィールドファイルは、行優先で並んだ w x h 個のリトルエンディアンの符号なし 16 ビットサンプルを持ちます。スプラット画像は、チャンネル R、G、B、A がレイヤー 1 から 4 の重みである RGBA の PNG です。読み込みエラー時、どちらのローダーも平坦なフォールバックを返します。
</div>

| メソッド | 説明 |
| --- | --- |
| `HEIGHTMAP:Load(path, w, h)  -> heightfield` | w x h サンプルのハイトフィールドを読み込みます。エラー時は平坦なゼロのフィールドを返します。 |
| `HEIGHTMAP:LoadSplat(path)  -> splatmap` | スプラット画像を読み込みます。エラー時はすべてレイヤー 1 のマップを返します。完全に不透明なアルファチャンネルは、マップにレイヤー 4 がないことを意味します。 |
| `HEIGHTMAP:BuildTerrain(scene, floorObj, world, hf, splat, w, h, minY, maxY, cellSize, tex1, tex2, tex3, tex4, grassDensity, grassClump)  -> number` | 地形を 1 回の呼び出しで出力します: セルごとに 1 つのテクスチャ付きクワッドを `floorObj` に (サンプル (ix, iz) はワールドの x = ix x cellSize、z = iz x cellSize、y = minY + サンプル x (maxY - minY) に置かれ、各レイヤーテクスチャはセルごとに 1 回繰り返されます)、対応する衝突クワッドと不可視の境界壁を `world` に (BeginStatic と EndStatic の間で呼んでください)、そして `grassDensity` > 0 のとき、急斜面とマップの端から離れたレイヤー 1 の地面に草の葉を植えます (`grassClump` > 0 で群生にまとめます)。スプラットがない場合、急なセルは `tex2`、それ以外は `tex1` を使います。植えられた草の葉の数を返します。 |

### ハイトフィールドハンドル

<span class="badge-exp">実験的</span>

| `heightfield:W()  -> number` | サンプル単位の幅。 |
| `heightfield:H()  -> number` | サンプル単位の高さ。 |
| `heightfield:At(ix, iz)  -> number` | 整数のグリッド座標でのサンプル。端に制限されます。 |
| `heightfield:Sample(fx, fz)  -> number` | 小数のグリッド座標でのバイリニアサンプル。 |
| `heightfield:Release()  -> nil` | サンプルバッファを今すぐ破棄します (マップのアンロード)。以降 At と Sample は 0 を返します。 |

### スプラットマップハンドル

| `splat:At(ix, iz)  -> number` | 整数のテクセル座標での支配的なレイヤー (マップが空なら 1)。 |
| `splat:Weight(layer, fx, fz)  -> number` | 小数のテクセル座標でのレイヤーのバイリニアの重み (0-1。テクセルのチャンネル合計で正規化)。 |
| `splat:RegisterSprite(scene, spriteId)  -> nil` | scene:ObjSetTerrainSplat 用に、チャンネルの重みを線形フィルタの ARGB スプライトとして登録します。 |
| `splat:Release()  -> nil` | バッファを今すぐ破棄します (マップのアンロード)。以降 At は 1 を返します。 |
