# API リファレンス

<span class="badge-new">ゲームバージョン 0.6.1</span>

OpenTaiko の Lua ランタイムがスキンに公開しているすべてのグローバルのリファレンスです。サイドバーからカテゴリを選ぶか、まだモジュールを書いたことがなければ[モジュールとライフサイクル](activities.md)から始めてください。

## シグネチャの読み方

各項目は、関数を Lua から呼び出すときの形で示しています。

- コロンは、その関数を値に対して呼び出し、Lua がその値を暗黙の `self` として渡すことを意味します。`tex:Draw(x, y)` は、先に読み込んだテクスチャに対して呼び出します。
- ドット、または名前だけのものは通常の呼び出しです。例: `GetSaveFile(0)`。
- 矢印の後ろの型は呼び出しの戻り値です。`TEXTURE:CreateTexture(path) -> texture` は、保持しておいて後で描画するハンドルを返します。

グローバルの名前は大文字です (`TEXTURE`、`SOUND`、`INPUT`)。ランタイムがすべてのモジュールスクリプト内でこれらを提供し、自分で作成することはありません。

## 「実験的」バッジ

<span class="badge-exp">実験的</span> と表記された関数は現在動作しますが、非推奨期間なしにリリース間で変更される可能性があります。3D エンジンとオンラインネットワークが現在このバッジを持ち、3D エンジンはバージョン 1.0 で実験的の扱いから外れる予定です。スキンが実験的な関数に依存する場合は、更新のたびに再テストし、対象とするゲームバージョンを明記してください。
