# ぷちキャラの追加

ぷちキャラは、プレイ中にゲージの隣で跳ねる小さな相棒です。各ぷちキャラは、ゲームのインストールフォルダの `Global/PuchiChara/` の下にある 1 つのフォルダで、2 フレームのスプライトシートといくつかの任意の JSON ファイルを持ちます。コードを書く必要はありません。正しいファイル名でフォルダを作成すれば、ゲームは次回の起動時にそれを取り込みます。

互換性：OpenTaiko 0.6.1 は 0.6.0 向けに作られたぷちキャラを引き続き変更なしで読み込みます。

## 始める前に

- OpenTaiko 0.6.1 がインストールされていること。ゲームはぷちキャラをゲームの実行ファイルの隣の `Global/PuchiChara/` から読み込み、すべてのスキンがこのフォルダを共有します。
- 透明度付きの PNG を書き出せる画像エディタ。
- JSON ファイル用のテキストエディタ。
- 任意: `Welcome.ogg` 用の短い `.ogg` クリップ。

## ステップ 1: フォルダを作成する

ゲームは起動時に `Global/PuchiChara/` のサブフォルダを列挙し、それぞれをぷちキャラとして扱います。フォルダ名が識別子です。プレイヤーがぷちキャラを選択するとゲームはそれをセーブファイルに書き込み、アンロックもその名前の下に記録します。安定した名前を選んでください。名前を変えると、既存の選択は最初のフォルダにフォールバックし、記録されたアンロックは一致しなくなります。同梱のフォルダは `00 - None`、`01a - OpenTaiko-Kun`、`02 - Bol` のようにソート用の接頭辞を使っています。ゲームはリストをソートしないため、接頭辞がファイルシステムの順序を予測可能にしています。最初のフォルダは、セーブがもう存在しないフォルダを参照しているときのフォールバックなので、`00 - None` を先頭に置いたままにしてください。

```
Global/PuchiChara/
    00 - None/
    01a - OpenTaiko-Kun/
    02 - Bol/
    99 - MyMascot/          <-- your new folder
```

## ステップ 2: スプライトシート (Chara.png) を描く

ゲームは相棒を横並びのスプライトシート `Chara.png` から描画します。フレームのレイアウトはスキンの値 `Game_PuchiChara` で決まり、既定は `256,256,2` (フレーム幅、フレーム高さ、フレーム数) なので、同梱のシートは 512x256 ピクセル、つまり 256x256 のフレーム 2 つを横に並べ、フレーム 0 が左です。プレイ中、ゲームはフレームを順に切り替え、垂直の跳ね (メニューでは待機の跳ね、ゲーム中は拍に同期した跳ね) を加えるため、2 つのフレームは同じキャラクターの 2 つのポーズにしてください。背景は透明にします。`Chara.png` がない場合でもエントリは読み込まれますが、何も描画しません。

同梱のフォルダには `Chara.xcf` (GIMP のソース) と `PuchiConfig.txt` も入っています。ゲームはどちらも読み取りません。

```ini
Chara.png : 512 x 256 PNG, transparency
  +-----------------+-----------------+
  |    frame 0      |    frame 1      |
  |   256 x 256     |   256 x 256     |
  +-----------------+-----------------+
```

## ステップ 3: Metadata.json を書く

次のフィールドを持つ `Metadata.json` を作成します。

- `name`、`author`、`description`: それぞれプレーンな文字列か、ローカライズオブジェクト `{ "strings": { "default": "...", "ja": "...", ... } }`。`default` がフォールバックで、他のキーはゲームの言語コードです。
- `rarity`: `Poor`、`Common`、`Uncommon`、`Rare`、`Epic`、`Legendary`、`Mythical` のいずれか。レアリティは色とアンロック通知の段階を決めます。すべてのレアリティでコイン倍率は 1 なので、獲得量は変わりません。不明な値は `Common` として振る舞います。

ファイルがない場合、エントリは名前 `(None)`、レアリティ `Common`、作者 `(None)` で読み込まれます。

```json
{
    "name": {
        "strings": {
            "default": "MyMascot",
            "ja": "マイマスコット"
        }
    },
    "rarity": "Rare",
    "description": {
        "strings": {
            "default": "A friendly companion.\nWaves during play."
        }
    },
    "author": "YourName"
}
```

## ステップ 4 (任意): Effects.json を追加する

`Effects.json` はぷちキャラにゲームプレイ効果を与えます。ファイルがない場合、すべてのフィールドは既定でオフです。

- `allpurple` (bool): 大きなドンとカッの音符が、どちらの太鼓でも受け付ける紫の音符になります。
- `autoroll` (int): 連打と風船に対する毎秒の自動ヒット数。0 より大きい値はコイン倍率を 0 にします。
- `showadlib` (bool): 隠された ADLIB 音符を表示します。コインを 0.9 倍にします。
- `splitlane` (bool): ドンとカッの音符を別々のレーンに描画します。

純粋に見た目だけの相棒にはこのファイルを置かないでください。

```json
{
    "allpurple": false,
    "autoroll": 0,
    "showadlib": false,
    "splitlane": false
}
```

## ステップ 5 (任意): Welcome.ogg と Render.png を追加する

- `Welcome.ogg`: ゲームがボイス音量グループで読み込むボイスクリップ。ゲーム組み込みの部屋画面は、プレイヤーがぷちキャラを選択したときにこれを再生します。Lua ステージからは到達できないため、独自の部屋画面を持つスキンでは再生されません。
- `Render.png`: Lua ステージがポートレートとして描画できるフルサイズの静止画 (`PUCHICHARALIST` エントリの `render` テクスチャ)。任意のサイズの 1 枚の画像です。同梱のぷちキャラにはどれにも含まれていません。

どちらのファイルも任意です。

```
MyMascot/
    Chara.png       (required, the animated sprite sheet)
    Metadata.json   (name, rarity, author, description)
    Effects.json    (optional gameplay effects)
    Unlock.json     (optional unlock condition)
    Welcome.ogg     (optional voice clip)
    Render.png      (optional portrait)
```

## ステップ 6 (任意): アンロック条件 (Unlock.json) を追加する

`Unlock.json` がなければ、ぷちキャラは直ちに利用可能です。ロックするには、`condition`、`type`、`values`、`references` のフィールドを持つ `Unlock.json` を追加します。形式と条件 id は楽曲やキャラクターと同じです (アンロック要素のガイドを参照)。以下の例はプレイヤーが合計 500 コインを獲得するとアンロックされます。同梱の例: OpenTaiko-Kun は 100 コイン (`"condition": "ch"`)、Bol は譜面作者 `bol` の譜面を 20 曲クリア (`"condition": "sc"`)、Tinyfox はジャンル `Project Outfox Serenity` の楽曲を 1 曲プレイ (`"condition": "sg"`) が必要です。

コイン条件はプレイヤーが部屋画面で購入します。他の条件はゲームが各プレイ後のリザルト画面で確認します。プレイヤーが条件を満たすと、ゲームはぷちキャラをセーブファイルのアンロック済みリストに追加し、通知を表示します。

```json
{
    "condition": "ce",
    "type": "me",
    "values": [
        500
    ]
}
```

## ステップ 7: 再起動して選択する

ゲームがリストを再構築するよう、ゲームを再起動します (または設定からスキンを再読み込みします)。部屋画面を開き、ぷちキャラのリストから新しいエントリを選びます。選択すると、プレイ中にゲージの隣に現れます。プレイ中に相棒が現れない場合は、システム設定の `Draw PuchiChara` オプションが有効になっているか確認してください。

## トラブルシューティングと注意点

- ファイル名は厳密です: `Chara.png`、`Metadata.json`、`Effects.json`、`Unlock.json`、`Welcome.ogg`、`Render.png`。ゲームは名前を間違えたファイルを無視し、既定値を適用します。
- セーブファイルとアンロック記録はフォルダ名をそのまま保存します。フォルダの名前を変えると、既存の選択は最初のフォルダにフォールバックします。
- ゲームはスプライトシートをスキンの `Game_PuchiChara` のフレームサイズ (既定 `256,256,2`) で切り出します。異なるサイズのシートも同じ数値で切り出すため、フレームが切れたりずれたりします。スキンが `Game_PuchiChara` を上書きしている場合は、その値に合わせてください。同梱のスキンは上書きしていません。
- 0 より大きい `autoroll` はコイン獲得を 0 にし、`showadlib` は 0.9 倍に減らすため、どちらかを設定した見た目だけの相棒は、そのプレイヤーの獲得コインを減らします。
- 同梱の JSON ファイルには末尾のカンマが含まれています。ゲームの JSON パーサーはこれを受け付けます。厳密なバリデータは拒否します。
- ゲームはリストを起動時とスキンの再読み込み時に 1 回構築します。ゲームの実行中に追加したフォルダは、次の起動またはスキンの再読み込み後に現れます。
