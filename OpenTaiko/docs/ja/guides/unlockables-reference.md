# アンロック要素リファレンス

楽曲、キャラクター、ぷちキャラ、ネームプレートは共通のアンロック条件の形式を使います。楽曲、キャラクター、ぷちキャラはそれを `Unlock.json` ファイルに、ネームプレートは `Nameplates.json` の各エントリの `unlock` オブジェクトに保持します。各ファイルの置き場所は、[譜面のアンロック要素](unlockables.md)、[キャラクターの追加](characters.md)、[ぷちキャラの追加](puchicharas.md)、[ネームプレートの追加](nameplates.md)の各ガイドが説明しています。このページでは、フィールド、条件 id、およびそれらが使う数値を一覧にしています。

## 条件のフィールド

| フィールド | 型 | 意味 |
| --- | --- | --- |
| `condition` | string | 条件 id (「条件 id」の節を参照)。 |
| `values` | int 配列 | 条件の数値パラメータ。 |
| `type` | string | 値に基づく条件が使う比較 (「比較の種類」の節を参照)。 |
| `references` | string 配列 | 条件に応じて、楽曲 id、ジャンル名、譜面作者名、フラグ名。 |

楽曲の `Unlock.json` には独自のフィールド (`hidden_index`、`rarity`、`custom_unlock_text`) が加わります。これらは[譜面のアンロック要素](unlockables.md)ガイドで説明しています。

## 条件 id

| Id | 意味 | `values` | `references` |
|----|---------|----------|--------------|
| `ch`、`cs`、`cm` | コインでの購入。ゲームは 3 つの id を同じように評価します (コインでの価格、`type` は `me` に強制、自動的には付与されない)。`cm` は楽曲向けの id です。スキンスクリプトはこの id を読み取り、購入をどこで提示するかの判断に使えます。 | `[price]` | 未使用 |
| `ce` | セーブファイルの作成以降に獲得したコインの合計 | `[coins]` | 未使用 |
| `tp` | 合計プレイ回数 | `[plays]` | 未使用 |
| `ap` | AI バトルのプレイ回数 | `[plays]` | 未使用 |
| `aw` | AI バトルの勝利数 | `[wins]` | 未使用 |
| `sd` | クリア状態に達した異なる譜面の数 | `[chart count, clear status]` | 未使用 |
| `dp` | クリア状態に達した、ある難易度の譜面の数 | `[difficulty, clear status, chart count]` | 未使用 |
| `lp` | クリア状態に達した、ある星の数のレベルの譜面の数 | `[level, clear status, chart count]` | 未使用 |
| `sp` | クリア状態に達した特定の楽曲 | 楽曲ごとに `[difficulty, clear status]` (`-1` = 任意の難易度) | 組ごとに楽曲 id 1 つ |
| `sg` | クリア状態に達した、指定したジャンル内の楽曲 | ジャンルごとに `[song count, clear status]` | 組ごとにジャンル名 1 つ |
| `sc` | クリア状態に達した、指定した譜面作者の譜面 | 譜面作者ごとに `[chart count, clear status]` | 組ごとに譜面作者名 1 つ |
| `gt` | グローバルトリガー (スクリプトが設定するセーブファイル内の名前付きオン/オフフラグ) | ON なら `[1]`、OFF なら `[0]` | `[trigger name]` |
| `gc` | グローバルカウンター (スクリプトが設定するセーブファイル内の名前付き数値) | `[value]`。`type` で比較 | `[counter name]` |
| `ig` | 入手不可能: 決してアンロックされない | なし | なし |
| `andcomb` | プレイヤーがすべての子条件を満たす必要がある ([譜面のアンロック要素](unlockables.md)ガイドの組み合わせの例を参照) | `[]` | エントリごとに JSON 文字列としての子条件 1 つ |
| `orcomb` | プレイヤーが少なくとも 1 つの子条件を満たす必要がある ([譜面のアンロック要素](unlockables.md)ガイドの組み合わせの例を参照) | `[]` | エントリごとに JSON 文字列としての子条件 1 つ |

ゲームは値の個数を検査します: `ch`/`cs`/`cm`/`ce`/`tp`/`ap`/`aw`/`gt`/`gc` はちょうど 1 つ、`sd` はちょうど 2 つ、`dp`/`lp` はちょうど 3 つの値が必要で、`sp`/`sg`/`sc` は参照ごとに 2 つの値と、組の数と同じ数の参照が必要です。個数が違うと条件は失敗し、ゲーム内にエラーメッセージが表示されます。

コイン条件をアンロックするのは、それを提示する画面での明示的な購入だけです。それ以外のすべての条件はゲームが各プレイ後のリザルト画面で確認します。プレイヤーが条件を満たすと、ゲームはアイテムをアンロックし、通知を表示します。

## 比較の種類

| `type` | 比較 |
| --- | --- |
| `l` | 未満 |
| `le` | 以下 |
| `e` | 等しい |
| `me` | 以上 (既定) |
| `m` | より大きい |
| `d` | 異なる |

コイン条件は、`type` の指定にかかわらず常に `me` を使います。

## クリア状態の値

状態の要件は「この状態以上」を意味します。

| 値 | クリア状態 |
| --- | --- |
| 0 | プレイ済み |
| 1 | アシストクリア |
| 2 | クリア |
| 3 | フルコンボ |
| 4 | 全良 |

## 難易度の値

| 値 | 難易度 |
| --- | --- |
| 0 | Easy |
| 1 | Normal |
| 2 | Hard |
| 3 | Extreme |
| 4 | Extra Extreme |

`dp` では難易度 3 に Extra Extreme の譜面も含まれます。`dp` と `lp` は通常の譜面だけを数え、Dan と Tower の譜面はスキップします。`sp` は任意の難易度を意味する `-1` を受け付けます。

## プレイ Mod の値

セーブファイルは、プレイヤーのベストプレイを譜面、難易度、プレイ Mod ごとに保存します。プレイ Mod の値は 1 回のプレイの Mod を最下位バイトから順に 8 バイトにパックします。Mod なしのプレイは 8925478921 になります。

| バイト | Mod | 値 |
| --- | --- | --- |
| 1 (最下位) | スクロール速度 | 0 から 99: 9 が 1.0x で、1 ステップは 0.1x |
| 2 | ステルス | 0 Off、1 Doron、2 Stealth、3 Hidden、4 Flashlight |
| 3 | ランダム | 0 Off、1 Random、2 Mirror、3 SuperRandom、4 MirrorRandom |
| 4 | 曲速度 | 2 から 200: 20 が 1.0x で、1 ステップは 0.05x |
| 5 | 判定幅 | 0 Loose、1 Lenient、2 Normal、3 Strict、4 Rigorous |
| 6 | 判定 Mod | 0 オフ、1 Just、2 Safe |
| 7 | 未使用 | 0 |
| 8 (最上位) | Fun Mod | 0 None、1 Avalanche、2 Minesweeper、3 Dynamic Beat |

スペシャル Mod (Flawless、Timed) はこの値に含まれません。
