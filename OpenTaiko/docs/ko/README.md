# OpenTaiko 문서

<span class="badge-new">게임 버전 0.6.1</span>

<div class="callout warn">이 문서는 아직 검토 중이며 출시 전까지 변경될 수 있습니다.</div>

OpenTaiko는 핵심 게임플레이를 제외한 거의 모든 화면(메뉴, 곡 선택, 방과 스토리 장면, 배경, 결과 화면)을 스킨에 포함된 Lua 스크립트로 그립니다. 이 사이트는 그 스크립트가 사용하는 Lua API를 문서화하고, 스킨 제작자가 가장 자주 하고 싶어 하는 작업을 단계별로 안내합니다.

## 어디서부터 시작할까

- 아직 모듈을 작성해 본 적이 없다면 [모듈의 동작 방식](getting-started.md)을 읽어 보십시오. 스킨의 폴더 구조, 모듈 종류, 스크립트가 받는 생명 주기 콜백을 설명합니다.
- 함수를 찾아보려면 [API 레퍼런스](api/)를 열고 사이드바에서 분류를 고르십시오.
- 구체적인 목표가 있다면 가이드가 [캐릭터](guides/characters.md), [푸치캬라](guides/puchicharas.md), [스킨과 테마](guides/skins.md), [채보 잠금 해제 요소](guides/unlockables.md)를 단계별로 안내합니다.

## 만들 수 있는 것

| 영역 | 위치 | 내용 |
| --- | --- | --- |
| 모듈 | 스킨의 `Modules/` 폴더 | 스테이지(입력, 그리기, 상태를 스스로 가지는 완전한 화면. 곡 선택, 방, 스토리 장면 등), 액티비티(대화 상자와 네임플레이트 같은 하위 화면과 오버레이), 트랜지션(스테이지 사이의 페이드와 로딩 화면). |
| 배경 | 스킨의 `Graphics/` 폴더 | 화면을 꾸미는 스크립트. 시작 화면, 방, 게임플레이 배경과 몹, 결과 화면. |
| 스킨과 테마 | 게임 옆의 `System/` | 플레이어가 설치하고 전환하는 완전한 비주얼 패키지와, 그것이 옵션 화면에 노출하는 테마 설정. |
| 캐릭터와 푸치캬라 | 모든 스킨이 공유하는 `Global/Characters/`와 `Global/PuchiChara/` | 플레이 중에 반응하는 댄서와 작은 마스코트. |
| 채보 잠금 해제 요소 | 곡 폴더의 채보 옆 | 플레이어가 조건을 달성할 때까지 곡을 잠가 두는 `Unlock.json`. |

## 실험적 절

일부 페이지는 사이드바에 <span class="badge-exp">실험적</span> 배지를 달고 있습니다. 그 페이지가 설명하는 기능은 현재 릴리스에서 동작하지만, API는 사용 중단 유예 기간 없이 릴리스 사이에 여전히 바뀔 수 있습니다. 이에 의존하는 스킨은 대상 게임 버전을 명시해야 하고, 업데이트마다 다시 테스트해야 합니다.

## 언어

이 문서는 OpenTaiko가 제공하는 모든 언어로 존재합니다. 사이드바 상단의 언어 선택기로 언어를 고르십시오. 사이트는 번역이 생길 때까지 페이지를 영어로 표시합니다.
