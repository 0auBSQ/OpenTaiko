# 3D 엔진: 래스터라이저 월드 <span class="badge-exp">실험적</span>

씬, 모델, 조명, 카메라, 물리, 콜라이더, 경로 탐색, 파티클, 렌더 타깃, 지형 하이트맵.

3D 엔진은 실험적입니다. 버전 1.0에서 실험적 표시를 떼어낼 계획입니다.

<div class="callout">
이 페이지의 모든 전역과 메서드는 사용 중단 유예 기간 없이 릴리스 사이에 바뀔 수 있습니다. 스킨이 이에 의존한다면 업데이트마다 다시 테스트하고 대상 게임 버전을 명시하십시오.
</div>

이 페이지에서 사용하는 규약:

- 위치와 크기는 월드 단위이며 +Y가 위입니다. 객체, 텍스처, 스프라이트, 재질, 프리미티브 id는 정수입니다.
- 각도는 행에 라디안이라고 적히지 않은 한 도 단위입니다(물리 차량의 헤딩과 기울기, 바퀴 회전, 풀 흔들림 위상).
- `Clear`, `FillRect`, `DrawLine`, `SetFog`, `ObjSetPass`, `PsEmit`, `PsBurst`는 0-255 색상을 받습니다. 조명, 태양, 앰비언트, 재질, 틴트, `ObjSetColor`는 선형 0-1 색상을 받습니다.
- 세 렌더러가 같은 씬 데이터를 공유합니다: GPU 래스터라이저(GLES 3.1 컴퓨트 셰이더를 사용할 수 있을 때 기본값), CPU 래스터라이저(대체용, 또는 `SetMode("raster_cpu")`로 강제), 패스 트레이서(`SetMode("raytrace")`). *GPU 래스터라이저 전용* 또는 *패스 트레이서 전용*으로 표시된 행은 다른 렌더러가 무시합니다.

레이트레이서와 물리 월드는 각자 페이지가 있습니다: [레이트레이서 월드](3d-raytrace.md), [물리](3d-physics.md).

## 씬

### SCENE3D

<span class="badge-exp">실험적</span>

3D 씬의 팩토리입니다. 씬은 카메라, 유지되는 객체, 텍스처, 스프라이트, 조명, 파티클 시스템을 소유하는 렌더 타깃이며, 2D 텍스처처럼 그립니다.

| 메서드 | 설명 |
| --- | --- |
| `SCENE3D:CreateScene(width, height)  -> scene` | 지정한 논리 픽셀 크기의 씬을 만들고 핸들을 반환합니다. 게임은 스크립트의 스테이지를 해체할 때 씬을 해제합니다. |

### 씬 핸들

<span class="badge-exp">실험적</span>

<div class="callout warn">
프레임별 흐름: 배경을 그리고(FillRect 또는 ClearTransparent), 카메라와 프레임별 지오메트리를 갱신하고, Render, 그다음 Upload, 그다음 Draw를 호출합니다. Render는 색 버퍼를 지우지 않으므로 하늘이나 배경을 먼저 그리십시오.
</div>

```lua
local scene, floor

function onStart()
    scene = SCENE3D:CreateScene(1280, 720)
    scene:SetLighting(true)
    scene:SetAmbient(0.4, 0.4, 0.46)
    scene:SetSun(0.3, 0.8, 0.5, 0.85, 0.82, 0.72)

    scene:RegisterTexture(1, pixels, 16, 16)          -- pixels: 0xRRGGBB 정수의 1부터 시작하는 배열
    floor = scene:NewObject()
    scene:ObjAddQuadTex(floor, 0,0,0,  0,0,8,  8,0,8,  8,0,0,  1, 8, 8, 1.0)
    scene:ObjSetBounds(floor, 0, 0, 0, 8, 0, 8)
end

function draw()
    scene:SetCameraPosition(4, 3, -6)
    scene:SetCameraAngles(0, -20)
    scene:FillRect(0, 0, 1280, 720, 90, 140, 220, 255)
    scene:Render()
    scene:Upload()
    scene:Draw(0, 0)
end

function onDestroy()
    scene:Dispose()
end
```

#### 크기와 2D 그리기

| 메서드 | 설명 |
| --- | --- |
| `scene.Width  -> number` | 읽기 전용 논리 픽셀 너비. |
| `scene.Height  -> number` | 읽기 전용 논리 픽셀 높이. |
| `scene:Clear(r, g, b, a)  -> nil` | 색 버퍼 전체를 RGBA 색(0-255)으로 현재 내용 위에 블렌딩하여 채웁니다. |
| `scene:ClearTransparent()  -> nil` | 렌더링된 프레임이 스테이지가 아래에 그린 것 위에 합성되도록 색 버퍼를 완전 투명으로 재설정합니다. |
| `scene:FillRect(x, y, w, h, r, g, b, a)  -> nil` | 2D 사각형(논리 픽셀 좌표)을 RGBA 색으로 채웁니다. |
| `scene:DrawLine(x0, y0, x1, y1, r, g, b)  -> nil` | 깊이 테스트 없이 색 버퍼 위에 2D 선을 그립니다. |
| `scene:ClearDepth()  -> nil` | 깊이 버퍼를 지웁니다. |

#### 카메라

| 메서드 | 설명 |
| --- | --- |
| `scene:SetCameraPosition(x, y, z)  -> nil` | 월드 공간의 시점 위치를 설정합니다. |
| `scene:SetCameraAngles(yawDeg, pitchDeg)  -> nil` | 시선 방향을 설정합니다. yaw는 +Y를 기준으로 돌며(yaw 0은 +Z를 봄), 양의 pitch는 위를 보고, 씬은 pitch를 +/-89.9로 제한합니다. |
| `scene:SetCameraFov(fovDeg)  -> nil` | 세로 시야각을 설정합니다. 1..179로 제한됩니다(기본값 70). |
| `scene:SetCameraNear(near)  -> nil` | 근접 클립 평면 거리를 설정합니다(기본값 0.06, 최소 0.0001). |
| `scene:GetCameraPosition()  -> x, y, z` | 현재 시점 위치. |
| `scene:GetCameraYaw()  -> number` | 현재 yaw(도). |
| `scene:GetCameraPitch()  -> number` | 현재 pitch(도). |
| `scene:GetCameraFov()  -> number` | 현재 세로 시야각(도). |
| `scene:GetCameraNear()  -> number` | 현재 근접 클립 평면 거리. |
| `scene:GetCameraForward()  -> fx, fy, fz` | 카메라 전방 기저 벡터. |
| `scene:GetCameraRight()  -> rx, ry, rz` | 카메라 우측 기저 벡터. |
| `scene:GetCameraUp()  -> ux, uy, uz` | 카메라 상방 기저 벡터. |
| `scene:WorldToScreen(wx, wy, wz)  -> x, y, depth` | 월드 점을 논리 픽셀 좌표와 카메라 공간 깊이로 투영합니다. 점이 근접 평면 위나 뒤에 있으면 `0, 0, -1`을 반환합니다. |
| `scene:Project(wx, wy, wz)  -> sx, sy, inFront` | 월드 점을 논리 픽셀 좌표로 투영합니다. 점이 근접 평면 뒤에 있으면 `inFront`가 false입니다. |

#### 렌더러

| 메서드 | 설명 |
| --- | --- |
| `scene:SetMode(mode)  -> nil` | 렌더러를 고릅니다: `"raster"`(기본값. 가능하면 GPU, 아니면 CPU), `"raster_cpu"`, `"raytrace"` 또는 `"rt"`(CPU 대체가 있는 GPU 패스 트레이서), `"raytrace_cpu"` 또는 `"rt_cpu"`. 전환하면 캐시되고 누적된 상태가 버려집니다. |
| `scene:GetMode()  -> string` | 활성 렌더러: `"raster"`, `"raster_cpu"`, `"raytrace"`. |
| `scene:SetThreads(n)  -> nil` | CPU 래스터라이저의 스레드 수. 래스터라이저는 화면을 그 수의 행 밴드로 나눕니다(기본값 1). |
| `scene:SetRenderDistance(d)  -> nil` | 경계(ObjSetBounds 참고)가 카메라로부터 이 거리를 완전히 넘어선 객체를 건너뜁니다. 0 = 무제한. 래스터라이저 전용. |
| `scene:SetAntialias(on)  -> nil` | 최종 색 버퍼에 후처리 가장자리 부드럽게 하기를 켭니다(기본값 꺼짐). |
| `scene:GetSampleCount()  -> number` | 마지막 카메라 또는 씬 변경 이후 픽셀당 누적된 패스 트레이서 샘플 수. 래스터 모드에서는 0. |
| `scene:GetMemoryStats()  -> texCount, texBytes, spriteCount, objCount, grassBlades, liveParticles` | 디버그 오버레이용 리소스 수. |
| `scene:GetRendererStats()  -> string` | GPU 래스터라이저의 렌더러 측 캐시 수, 또는 `"cpu"`. |
| `scene:ClearRenderCaches()  -> nil` | 다시 만들 수 있는 렌더 캐시(렌더 투 텍스처 타깃, 객체별 정점 버퍼, 병합된 정적 버퍼)를 버립니다. 등록된 텍스처와 스프라이트는 남습니다. 맵 언로드 시 호출하십시오. |
| `scene:Dispose()  -> nil` | 씬을 즉시 해제합니다. 호출하지 않으면 씬은 스테이지 해체까지 살아 있습니다. |

렌더링 중 GPU 렌더러가 실패하면(예: 드라이버가 거부하는 셰이더) 씬은 남은 수명 동안 CPU 래스터라이저로 전환되고 스테이지는 계속 실행됩니다.

#### 텍스처와 스프라이트

텍스처는 쿼드와 삼각형이 UV로 샘플링하는 불투명 RGB 이미지입니다. 스프라이트는 빌보드 스프라이트, 스프라이트 쿼드, 파티클, 풀잎, 지형 스플랫 가중치가 사용하는 ARGB 이미지입니다. 텍스처 id와 스프라이트 id는 별개의 네임스페이스이며, 이미 있는 id를 등록하면 그 픽셀이 교체됩니다.

| 메서드 | 설명 |
| --- | --- |
| `scene:RegisterTexture(id, pixels, w, h)  -> nil` | 패킹된 `0xRRGGBB` 정수의 1부터 시작하는 Lua 배열(행 우선, 왼쪽 위 원점)로 텍스처를 등록합니다. 음수 값은 투명(컷아웃) 텍셀을 표시합니다. 4,194,304픽셀을 넘는 이미지는 씬이 무시합니다. |
| `scene:RegisterTextureFromImage(id, tex)  -> nil` | 로드된 텍스처 핸들의 픽셀을 읽어 텍스처를 등록합니다. 읽기는 알파를 버리고 호출마다 GPU에 한 번 접근하므로 프레임마다 사용하기에는 너무 느립니다. |
| `scene:SetTextureFilter(id, mode)  -> nil` | 텍스처의 샘플링 필터: `"nearest"`(기본값), `"linear"`, `"mipmap"`. GPU 래스터라이저 전용. |
| `scene:UnregisterTexture(id)  -> nil` | GPU 업로드와 id에 바인딩된 렌더 투 텍스처 타깃을 포함해 텍스처를 잊습니다. |
| `scene:SetSpriteRGBA(spriteId, pixels, w, h)  -> nil` | ARGB 정수(`a << 24 | r << 16 | g << 8 | b`, 행 우선, 왼쪽 위 원점)의 1부터 시작하는 Lua 배열로 스프라이트를 등록합니다. |
| `scene:RegisterSpriteFromTexture(spriteId, tex)  -> nil` | 로드된 텍스처 핸들의 픽셀을 읽어 스프라이트를 등록합니다. 읽기는 호출마다 GPU에 한 번 접근하므로 프레임마다 사용하기에는 너무 느립니다. |
| `scene:MakeSoftCircle(spriteId, res, edge)  -> nil` | 중심은 불투명하고 가장자리로 갈수록 0으로 사라지는 `res` x `res` 픽셀의 흰 원형 스프라이트를 생성합니다. `edge`는 감쇠 형태입니다(1은 선형, 2-3은 부드러운 글로우). |
| `scene:MakeCrystal(spriteId, res)  -> nil` | `res` x `res` 픽셀의 여섯 갈래 흰색-파란색 눈송이 스프라이트를 생성합니다. |
| `scene:SetSpriteFilter(spriteId, mode)  -> nil` | 스프라이트의 샘플링 필터: `"nearest"`(기본값) 또는 `"linear"`. 등록 직후 호출하십시오. GPU 래스터라이저 전용. |
| `scene:UnregisterSprite(spriteId)  -> nil` | GPU 업로드를 포함해 스프라이트를 잊습니다. |

모델의 Register 호출은 재질을 4000부터(glTF)와 6000부터(OBJ)의 id로 텍스처로 등록하므로, 씬이 모델도 그린다면 자신의 텍스처 id는 4000 미만으로 유지하십시오.

#### 객체

객체는 유지되는 프리미티브 그룹입니다. 한 객체의 모든 프리미티브는 같은 종류(텍스처 쿼드, 플랫 쿼드, 텍스처 삼각형, 빌보드 스프라이트, 스프라이트 쿼드)여야 합니다. 객체를 다른 종류로 다시 채우기 전에 ObjBegin을 호출하십시오. 객체 id는 1부터 시작합니다.

| 메서드 | 설명 |
| --- | --- |
| `scene:NewObject()  -> id` | 불투명 패스에 비어 있는 보이는 객체를 만듭니다. |
| `scene:DeleteObject(id)  -> nil` | 객체와 그 지오메트리를 제거합니다. |
| `scene:ClearObjects()  -> nil` | 모든 객체와 모든 파티클 시스템을 제거하고 렌더 캐시를 버립니다. 텍스처, 스프라이트, 조명, 카메라는 남으며 객체 id는 1부터 다시 시작합니다. |
| `scene:ObjBegin(id)  -> nil` | 직접 다시 채울 수 있도록 객체의 프리미티브를 지웁니다. |
| `scene:ObjAddQuadTex(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, texId, uMax, vMax, shade)  -> nil` | 텍스처 쿼드를 덧붙입니다. 모서리는 UV (0, vMax), (uMax, vMax), (uMax, 0), (0, 0)에 대응됩니다. `shade`(0-1)는 텍셀에 곱해지며 조명이 켜져 있을 때 태양을 게이트합니다. |
| `scene:ObjAddQuadFlat(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3)  -> nil` | 단색 쿼드를 덧붙입니다. 색과 알파는 ObjSetPass에서 옵니다. |
| `scene:ObjAddTriTex(id, x0, y0, z0, u0, v0, x1, y1, z1, u1, v1, x2, y2, z2, u2, v2, texId, shade)  -> nil` | 명시적 UV를 가진 텍스처 삼각형을 덧붙입니다. 모델 핸들은 이 프리미티브로 객체를 채웁니다. |
| `scene:ObjAddSprite(id, x, y, z, w, h, spriteId, billboard, cutout)  -> nil` | 아래 중앙이 (x, y, z)에 있는 월드 크기 `w` x `h`의 스프라이트 쿼드를 덧붙입니다. `billboard`: 0 고정 XY 평면, 1 카메라를 향하되 똑바로 서 있음, 2 항상 카메라를 향함, 3 SetGroundSpriteLight 방향으로 늘어나 바닥에 눕힘. `cutout`이 0이 아니면 알파 테스트하고 깊이를 씁니다(불투명 패스). 0이면 알파 블렌딩합니다(객체를 투명 패스에 두십시오). |
| `scene:ObjAddSpriteQuad(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, spriteId, cutout)  -> nil` | 명시적 월드 쿼드에 스프라이트를 덧붙입니다(모서리는 UV (0, 1), (1, 1), (1, 0), (0, 0)에 대응). 빌보드가 아닙니다. |
| `scene:ObjSetTransform(id, m)  -> nil` | 16개의 행 우선 숫자로 된 Lua 테이블로 객체의 모델 행렬을 설정합니다(이동은 m[4], m[8], m[12]). nil은 단위 행렬을 복원합니다. |
| `scene:ObjSetTransform16(id, m0, m1, m2, m3, m4, m5, m6, m7, m8, m9, m10, m11, m12, m13, m14, m15)  -> nil` | 16개의 일반 인자를 받는 ObjSetTransform. 프레임별 갱신에는 이것을 사용하십시오. |
| `scene:ObjClearTransform(id)  -> nil` | 단위 모델 행렬을 복원합니다. |
| `scene:ObjSetBounds(id, minX, minY, minZ, maxX, maxY, maxZ)  -> nil` | 카메라 뒤 컬링, SetRenderDistance, ObjSetNormal을 위한 월드 공간 경계. |
| `scene:ObjSetNormal(id, nx, ny, nz)  -> nil` | 객체를 (nx, ny, nz)를 향하는 평면 그룹으로 취급하고 카메라가 그 평면 뒤에 있으면 건너뜁니다(ObjSetBounds 필요). 0, 0, 0은 끕니다. |
| `scene:ObjSetVisible(id, v)  -> nil` | 객체를 보이거나 숨깁니다. |

#### 파티클

파티클 시스템은 카메라를 향하는 빌보드의 풀입니다. 여기에 방출하고, 매 프레임 PsUpdate를 호출하면, 래스터라이저가 살아 있는 파티클을 투명 패스에서 그립니다. 시스템 id는 0부터 시작하며 ClearObjects가 이를 무효화합니다.

| 메서드 | 설명 |
| --- | --- |
| `scene:NewParticleSystem()  -> id` | 파티클 시스템을 만들고 id를 반환합니다. |
| `scene:PsUpdate(id, dt)  -> nil` | 시스템을 `dt`초만큼 전진시킵니다(노화, 중력, 항력, 이동). |
| `scene:PsEmit(id, x, y, z, vx, vy, vz, r, g, b, a0, size0, size1, life, gravity, drag, additive)  -> nil` | 파티클 하나를 방출합니다: 색 0-255, 시작 불투명도 `a0` 0-1, `life`초에 걸친 빌보드 크기 `size0`에서 `size1`(월드 단위), 아래 방향 중력, 초당 항력. `additive`가 0이 아니면 파티클을 프레임에 가산 블렌딩하고, 0이면 알파 블렌딩합니다. |
| `scene:PsBurst(id, x, y, z, count, dirX, dirY, dirZ, spread, speed, r, g, b, colorJitter, a0, size0, size1, life, lifeVar, gravity, drag, additive)  -> nil` | `spread`(0 = 정확히 방향을 따름, 1 = 완전 무작위)만큼 (dirX, dirY, dirZ)로 치우친 무작위 방향으로 `count`개의 파티클을 최대 `speed`의 속도, 색 지터, 파티클별 수명 변동 `lifeVar`(`life`의 비율)와 함께 방출합니다. |
| `scene:PsSetSprite(id, spriteId)  -> nil` | 다음에 방출되는 파티클에 찍을 스프라이트(-1 = 평평한 사각형). |

| `scene:PsSetNextCurves(id, sizeCurve, fadeCurve)  -> nil` | 다음에 방출되는 파티클의 곡선. 크기: 0 선형, 1 이즈아웃, 2 커졌다 작아짐. 페이드: 0 선형, 1 부드러운 인/아웃, 2 긴 꼬리가 있는 밝은 섬광. |
| `scene:PsSetCap(id, cap)  -> nil` | 최대 살아 있는 파티클 수(기본값 4000). 상한을 넘는 방출은 시스템이 버립니다. |

| `scene:ObjSetWaterColors(id, dr, dg, db)  -> nil` | 화면 텍스처 표면의 깊은 물 색(0-1). 정점별 shade가 객체의 기본 색(얕음)에서 이 색(깊음)으로 보간됩니다. GPU 래스터라이저 전용. |
| `scene:ObjSetSurfaceShader(id, fragSrc)  -> nil` | 화면 텍스처 표면에 내장 리플과 프레넬 외관을 대체하는 커스텀 GLSL ES 3.00 프래그먼트 셰이더를 연결합니다. 완전한 소스 또는 `main()` 본문. 프렐류드는 `vUV`, `vShade`, `vCamZ`, `vWorld`, `vNormal`, `uTex`(반사), `uRsh`, `uRttFlip`, `uCam`, `uTint`, `uFlat`, `uTime`, `uAlpha`, `uUser[4]`, `out vec4 frag`를 제공합니다. nil이나 ""는 분리하며, 컴파일 실패 시 내장 셰이더로 대체됩니다. GPU 래스터라이저 전용. |
| `scene:SetSurfaceUniform(slot, x, y, z, w)  -> nil` | 모든 커스텀 표면 셰이더가 공유하는 `uUser[slot]`(0..3)을 설정합니다. |

## 모델

### MODEL

<span class="badge-exp">실험적</span>

glTF/GLB(스킨, 애니메이션)와 OBJ(정적) 파일을 포즈 가능한 모델 핸들로 로드합니다.

<div class="callout warn">
경로는 스크립트 디렉터리 기준 상대 경로이며 로더는 절대 경로도 받습니다. 로더는 각 glTF 파일을 프로세스마다 한 번 파싱해 씬과 스테이지 사이에 공유하므로, SetPartObject로 설정한 파트 라우팅은 ClearPartObjects나 PurgeCache까지 유지됩니다. glTF 지원 범위는 위치, UV 세트 하나, 선택적 joints와 weights, 스킨 하나, 노드 계층, 선형 TRS 애니메이션, 재질 기본 색, 내장 기본 색 텍스처(긴 변 512픽셀로 축소)를 가진 인덱스 삼각형 프리미티브입니다. OBJ 지원 범위는 위치, 텍스처 좌표, 폴리곤 면, .mtl 파일의 디퓨즈 색입니다. 로더는 이미지 텍스처를 건너뜁니다.
</div>

| 메서드 | 설명 |
| --- | --- |
| `MODEL:Load(path)  -> model` | .glb, .gltf, .obj 파일을 로드하고 모델 핸들을 반환하며, 실패하면 nil. |
| `MODEL:PurgeCache()  -> nil` | 프로세스 전체 glTF 캐시를 버립니다(스테이지 종료). 아직 사용 중인 모델은 이후 다시 로드하십시오. |

### 모델 핸들

<span class="badge-exp">실험적</span>

<div class="callout warn">
씬마다 한 번 Register를 호출한 뒤, 매 프레임 Pose를 호출해 배치된(glTF는 스킨이 적용된) 삼각형을 씬 객체에 씁니다. 애니메이션 인덱스는 0부터 시작하며, -1은 바인드 포즈를 취합니다. Pose는 애니메이션 시간을 클립 안으로 제한하므로 Duration으로 직접 루프하십시오. Duration 아래의 메서드는 glTF 전용입니다. OBJ 핸들은 Register, Pose, AnimCount (0), AnimName, Duration을 노출합니다.
</div>

```lua
local model, obj
local clip = 0

function onStart()
    model = MODEL:Load("models/lantern.glb")
    if model then
        model:Register(scene)
        obj = scene:NewObject()
    end
end

function draw()
    if model then
        local t = elapsed % model:Duration(clip)
        model:Pose(scene, obj, clip, t, x, y, z, yawDeg, 1.0)
    end
end

function onDestroy()
    MODEL:PurgeCache()
end
```

| 메서드 | 설명 |
| --- | --- |
| `model:Register(scene)  -> nil` | 모델의 재질과 텍스처를 씬에 등록합니다(씬마다 한 번). |
| `model:Pose(scene, objId, anim, time, x, y, z, yawDeg, scale)  -> nil` | 객체 `objId`를 지우고 애니메이션 `anim`의 `time`초 시점 모델 삼각형으로 채웁니다. (x, y, z)로 이동하고 Y를 기준으로 `yawDeg`만큼 회전하며 균일하게 스케일합니다. |
| `model:AnimCount()  -> number` | 애니메이션 클립 수(OBJ는 0). |
| `model:AnimName(i)  -> string` | 클립 `i`의 이름. 범위를 벗어나면 "". |
| `model:Duration(i)  -> number` | 클립 `i`의 길이(초). 범위를 벗어나면 0. |
| `model:PartCount()  -> number` | 파트(프리미티브 인스턴스) 수. |
| `model:PartMaterial(part)  -> number` | 파트의 재질 인덱스(0부터 시작). 범위를 벗어나면 -1. |
| `model:MaterialCount()  -> number` | glTF 재질 수. |
| `model:MaterialName(mat)  -> string` | glTF 재질의 이름. 범위를 벗어나면 "". |
| `model:MaterialEmissive(mat)  -> r, g, b` | 재질의 glTF `emissiveFactor`. 없으면 0, 0, 0. |
| `model:SetPartObject(part, objId)  -> nil` | Pose 시 파트의 삼각형을 별도의 씬 객체로 라우팅해, 그 파트가 자체 투명도, 발광, 거울 플래그를 가질 수 있게 합니다. -1은 그 파트의 라우팅을 해제합니다. |
| `model:ClearPartObjects()  -> nil` | 모든 파트 라우팅을 버립니다. 모델 인스턴스가 공유되고 ClearObjects 뒤에 객체 id가 다시 시작하므로 월드 언로드 시 호출하십시오. |
| `model:GetBounds()  -> minX, minY, minZ, maxX, maxY, maxZ` | 모델 공간 바인드 포즈 경계. |
| `model:BuildCollider(mc, x, y, z, yawDeg, scale)  -> nil` | 지정한 변환으로 배치된 바인드 포즈 삼각형을 MeshCollider에 덧붙입니다. 음수 스케일은 절댓값으로 동작합니다. |

## 하이트맵

### HEIGHTMAP

<span class="badge-exp">실험적</span>

지형용 원시 16비트 하이트필드와 RGBA 스플랫 이미지를 로드하고, 한 번의 호출로 지형 전체를 만듭니다.

<div class="callout warn">
경로는 스크립트 디렉터리 기준 상대 경로입니다. 하이트필드 파일은 행 우선 순서의 w x h개 리틀 엔디언 부호 없는 16비트 샘플을 담습니다. 스플랫 이미지는 R, G, B, A 채널이 레이어 1에서 4의 가중치인 RGBA PNG입니다. 읽기 오류 시 두 로더 모두 평평한 대체값을 반환합니다.
</div>

| 메서드 | 설명 |
| --- | --- |
| `HEIGHTMAP:Load(path, w, h)  -> heightfield` | w x h 샘플의 하이트필드를 로드합니다. 오류 시 평평한 0 필드를 반환합니다. |
| `HEIGHTMAP:LoadSplat(path)  -> splatmap` | 스플랫 이미지를 로드합니다. 오류 시 전부 레이어 1인 맵을 반환합니다. 완전히 불투명한 알파 채널은 맵에 레이어 4가 없음을 뜻합니다. |
| `HEIGHTMAP:BuildTerrain(scene, floorObj, world, hf, splat, w, h, minY, maxY, cellSize, tex1, tex2, tex3, tex4, grassDensity, grassClump)  -> number` | 한 번의 호출로 지형을 생성합니다: `floorObj`에 셀당 텍스처 쿼드 하나(샘플 (ix, iz)는 월드 x = ix x cellSize, z = iz x cellSize, y = minY + sample x (maxY - minY)에 위치하며, 각 레이어 텍스처는 셀마다 한 번 반복), 그에 맞는 충돌 쿼드와 보이지 않는 경계 벽을 `world`에(BeginStatic과 EndStatic 사이에 호출), 그리고 `grassDensity` > 0이면 가파른 경사와 맵 가장자리에서 떨어진 레이어 1 지면에 풀잎(`grassClump` > 0이면 무리로 묶음). 스플랫이 없으면 가파른 셀은 `tex2`를, 나머지는 `tex1`을 사용합니다. 심은 풀잎 수를 반환합니다. |

### 하이트필드 핸들

<span class="badge-exp">실험적</span>

| 메서드 | 설명 |
| --- | --- |
| `heightfield:W()  -> number` | 샘플 단위 너비. |
| `heightfield:H()  -> number` | 샘플 단위 높이. |
| `heightfield:At(ix, iz)  -> number` | 정수 그리드 좌표의 샘플. 가장자리로 제한됩니다. |
