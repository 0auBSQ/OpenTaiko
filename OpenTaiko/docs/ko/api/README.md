# API 레퍼런스

<span class="badge-new">게임 버전 0.6.1</span>

OpenTaiko Lua 런타임이 스킨에 노출하는 모든 전역의 레퍼런스입니다. 사이드바에서 분류를 고르거나, 아직 모듈을 작성해 본 적이 없다면 [모듈과 생명 주기](activities.md)부터 시작하십시오.

## 시그니처 읽는 법

각 항목은 함수를 Lua에서 호출하는 형태 그대로 보여 줍니다.

- 콜론은 함수를 값에 대해 호출하며 Lua가 그 값을 숨은 `self`로 전달한다는 뜻입니다. `tex:Draw(x, y)`는 앞서 로드한 텍스처에 대해 호출합니다.
- 점이나 이름만 있는 것은 `GetSaveFile(0)`처럼 일반 호출입니다.
- 화살표 뒤의 타입은 호출이 반환하는 값입니다. `TEXTURE:CreateTexture(path) -> texture`는 보관했다가 나중에 그릴 핸들을 반환합니다.

전역 이름은 대문자입니다(`TEXTURE`, `SOUND`, `INPUT`). 런타임이 모든 모듈 스크립트 안에 이를 제공하며, 직접 만들 필요가 없습니다.

## 실험적 배지

<span class="badge-exp">실험적</span>으로 표시된 함수는 지금 동작하지만 사용 중단 유예 기간 없이 릴리스 사이에 바뀔 수 있습니다. 3D 엔진과 온라인 네트워킹이 현재 이 배지를 달고 있으며, 3D 엔진은 버전 1.0에서 실험적 상태를 벗어날 계획입니다. 스킨이 실험적 함수에 의존한다면 업데이트마다 다시 테스트하고 대상 게임 버전을 명시하십시오.
