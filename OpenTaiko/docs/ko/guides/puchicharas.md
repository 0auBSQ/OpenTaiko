# 푸치캬라 추가하기

푸치캬라는 플레이 중 게이지 옆에서 통통 튀는 작은 동반자입니다. 각 푸치캬라는 게임 설치 폴더의 `Global/PuchiChara/` 아래에 있는 폴더 하나로, 두 프레임 스프라이트 시트와 몇 개의 선택적 JSON 파일을 담습니다. 코드를 작성할 필요는 없습니다. 올바른 파일 이름으로 폴더를 만들면 게임이 다음 시작 시 인식합니다.

호환성: OpenTaiko 0.6.1은 0.6.0용으로 만든 푸치캬라를 여전히 변경 없이 로드합니다.

## 시작하기 전에

- OpenTaiko 0.6.1 설치. 게임은 푸치캬라를 게임 실행 파일 옆의 `Global/PuchiChara/`에서 읽으며, 이 폴더는 모든 스킨이 공유합니다.
- 투명도가 있는 PNG를 내보낼 수 있는 이미지 편집기.
- JSON 파일을 위한 텍스트 편집기.
- 선택 사항: `Welcome.ogg`용 짧은 `.ogg` 클립.

## 1단계: 폴더 만들기

게임은 부팅 시 `Global/PuchiChara/`의 하위 폴더를 나열하고 각각을 푸치캬라로 취급합니다. 폴더 이름이 식별자입니다. 플레이어가 푸치캬라를 선택하면 게임은 이를 세이브 파일에 기록하고 잠금 해제도 이 이름 아래에 기록합니다. 안정적인 이름을 고르십시오. 이름을 바꾸면 기존 선택은 첫 폴더로 대체되고 기록된 잠금 해제는 더 이상 일치하지 않습니다. 기본 제공 폴더는 정렬 접두어를 사용합니다. 예: `00 - None`, `01a - OpenTaiko-Kun`, `02 - Bol`. 게임은 목록을 정렬하지 않으므로, 접두어가 파일 시스템 순서를 예측 가능하게 합니다. 첫 폴더는 세이브가 더 이상 없는 폴더를 참조할 때의 대체이므로 `00 - None`을 첫 번째로 유지하십시오.

```
Global/PuchiChara/
    00 - None/
    01a - OpenTaiko-Kun/
    02 - Bol/
    99 - MyMascot/          <-- 새 폴더
```

## 2단계: 스프라이트 시트 그리기(Chara.png)

게임은 동반자를 가로 스프라이트 시트인 `Chara.png`에서 그립니다. 프레임 레이아웃은 스킨 값 `Game_PuchiChara`에서 오며, 기본값은 `256,256,2`(프레임 너비, 프레임 높이, 프레임 수)이므로 기본 제공 시트는 512x256픽셀입니다. 256x256 프레임 두 개가 나란히 있고 프레임 0이 왼쪽입니다. 플레이 중 게임은 프레임을 순환하며 세로 바운스(메뉴에서는 대기 바운스, 게임에서는 박자 동기 바운스)를 더하므로, 두 프레임은 같은 캐릭터의 두 포즈여야 합니다. 투명 배경을 사용하십시오. `Chara.png`가 없어도 항목은 로드되지만 아무것도 그리지 않습니다.

기본 제공 폴더에는 `Chara.xcf`(GIMP 소스)와 `PuchiConfig.txt`도 있습니다. 둘 다 게임이 읽지 않습니다.

```ini
Chara.png : 512 x 256 PNG, 투명 배경
  +-----------------+-----------------+
  |    프레임 0     |    프레임 1     |
  |   256 x 256     |   256 x 256     |
  +-----------------+-----------------+
```

## 3단계: Metadata.json 작성하기

다음 필드로 `Metadata.json`을 만듭니다.

- `name`, `author`, `description`: 각각 일반 문자열 또는 지역화 객체 `{ "strings": { "default": "...", "ja": "...", ... } }`. `default`가 대체값이고 다른 키는 게임 언어 코드입니다.
- `rarity`: `Poor`, `Common`, `Uncommon`, `Rare`, `Epic`, `Legendary`, `Mythical` 중 하나. 희귀도는 색상과 잠금 해제 알림 등급을 정합니다. 모든 희귀도의 코인 배율은 1이므로 획득량은 바뀌지 않습니다. 알 수 없는 값은 `Common`처럼 동작합니다.

파일이 없으면 항목은 이름 `(None)`, 희귀도 `Common`, 제작자 `(None)`으로 로드됩니다.

```json
{
    "name": {
        "strings": {
            "default": "MyMascot",
            "ja": "マイマスコット"
        }
    },
    "rarity": "Rare",
    "description": {
        "strings": {
            "default": "A friendly companion.\nWaves during play."
        }
    },
    "author": "YourName"
}
```

## 4단계(선택): Effects.json 추가하기

`Effects.json`은 푸치캬라에 게임플레이 효과를 줍니다. 파일이 없으면 모든 필드는 꺼짐이 기본값입니다.

- `allpurple`(bool): 큰 동과 카 노트가 어느 북이든 받는 보라색 노트가 됩니다.
- `autoroll`(int): 연타와 풍선에서 초당 자동 히트 수. 0보다 큰 값은 코인 배율을 0으로 만듭니다.
- `showadlib`(bool): 숨겨진 ADLIB 노트를 표시합니다. 코인에 0.9를 곱합니다.
- `splitlane`(bool): 동과 카 노트를 별도의 레인에 그립니다.

순수하게 외형만을 위한 동반자라면 파일을 두지 마십시오.

```json
{
    "allpurple": false,
    "autoroll": 0,
    "showadlib": false,
    "splitlane": false
}
```

## 5단계(선택): Welcome.ogg와 Render.png 추가하기

- `Welcome.ogg`: 게임이 음성 사운드 그룹에 로드하는 음성 클립. 게임 내장 방 화면이 플레이어가 푸치캬라를 선택할 때 재생합니다. Lua 스테이지는 이에 접근할 수 없으므로 자체 방 화면을 가진 스킨은 이를 재생하지 않습니다.
- `Render.png`: Lua 스테이지가 초상화로 그릴 수 있는 전체 크기 정지 이미지(`PUCHICHARALIST` 항목의 `render` 텍스처). 크기 제한이 없는 단일 이미지입니다. 기본 제공 푸치캬라 중 이를 포함한 것은 없습니다.

두 파일 모두 선택 사항입니다.

```
MyMascot/
    Chara.png       (필수, 애니메이션 스프라이트 시트)
    Metadata.json   (이름, 희귀도, 제작자, 설명)
    Effects.json    (선택적 게임플레이 효과)
    Unlock.json     (선택적 잠금 해제 조건)
    Welcome.ogg     (선택적 음성 클립)
    Render.png      (선택적 초상화)
```

## 6단계(선택): 잠금 해제 조건 추가하기(Unlock.json)

`Unlock.json`이 없으면 푸치캬라는 즉시 사용할 수 있습니다. 잠그려면 `condition`, `type`, `values`, `references` 필드를 가진 `Unlock.json`을 추가하십시오. 형식과 조건 id는 곡과 캐릭터와 같습니다(잠금 해제 요소 가이드 참고). 아래 예는 플레이어가 총 500코인을 획득하면 잠금 해제됩니다. 기본 제공 예: OpenTaiko-Kun은 100코인(`"condition": "ch"`), Bol은 채보 제작자 `bol`의 클리어한 채보 20개(`"condition": "sc"`), Tinyfox는 장르 `Project Outfox Serenity`의 곡 한 곡 플레이(`"condition": "sg"`)를 요구합니다.

코인 조건은 플레이어가 방 화면에서 구매합니다. 다른 조건은 게임이 플레이마다 결과 화면에서 검사합니다. 플레이어가 조건을 충족하면 게임은 푸치캬라를 세이브 파일의 잠금 해제 목록에 추가하고 알림을 표시합니다.

```json
{
    "condition": "ce",
    "type": "me",
    "values": [
        500
    ]
}
```

## 7단계: 재시작하고 선택하기

게임이 목록을 다시 만들도록 게임을 재시작하십시오(또는 설정에서 스킨을 다시 로드). 방 화면을 열고 푸치캬라 목록에서 새 항목을 고르십시오. 선택하면 플레이 중 게이지 옆에 나타납니다. 플레이 중 동반자가 나타나지 않으면 시스템 설정의 `Draw PuchiChara` 옵션이 켜져 있는지 확인하십시오.

## 문제 해결과 참고

- 파일 이름은 정확해야 합니다: `Chara.png`, `Metadata.json`, `Effects.json`, `Unlock.json`, `Welcome.ogg`, `Render.png`. 게임은 이름이 잘못된 파일을 무시하고 기본값을 적용합니다.
- 세이브 파일과 잠금 해제 기록은 폴더 이름을 그대로 저장합니다. 폴더 이름을 바꾸면 기존 선택이 첫 폴더로 대체됩니다.
- 게임은 스프라이트 시트를 스킨의 `Game_PuchiChara` 프레임 크기(기본값 `256,256,2`)로 자릅니다. 크기가 다른 시트도 같은 숫자로 자르므로 프레임이 잘리거나 어긋납니다. 스킨이 `Game_PuchiChara`를 덮어쓴다면 그 값에 맞추십시오. 기본 제공 스킨은 덮어쓰지 않습니다.
- 0보다 큰 `autoroll`은 코인 획득을 0으로 만들고 `showadlib`은 0.9로 줄이므로, 둘 중 하나라도 설정한 외형용 동반자는 플레이어의 수입을 줄입니다.
- 기본 제공 JSON 파일에는 후행 쉼표가 있습니다. 게임의 JSON 파서는 이를 허용하고, 엄격한 검사기는 거부합니다.
- 게임은 목록을 부팅 시와 스킨 리로드 시 한 번 만듭니다. 게임 실행 중에 추가한 폴더는 다음 부팅이나 스킨 리로드 후에 나타납니다.
