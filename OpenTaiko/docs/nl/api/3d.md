# 3D-engine: rasterizerwereld <span class="badge-exp">Experimenteel</span>

Scènes, modellen, lichten, camera's, fysica, colliders, pathfinding, deeltjes, rendertargets en terrein-heightmaps.

De 3D-engine is experimenteel. Het plan is om het experimentele label met versie 1.0 te laten vallen.

<div class="callout">
Elke global en elke methode op deze pagina kan tussen releases veranderen zonder afbouwperiode. Als je skin erop steunt, test dan na elke update opnieuw en vermeld op welke spelversie je je richt.
</div>

Conventies op deze pagina:

- Posities en afmetingen zijn in wereldeenheden; +Y is omhoog. Object-, textuur-, sprite-, materiaal- en primitief-id's zijn gehele getallen.
- Hoeken zijn in graden tenzij een rij radialen vermeldt (koers en helling van het fysicavoertuig, wielrotatie, zwaaifase van gras).
- `Clear`, `FillRect`, `DrawLine`, `SetFog`, `ObjSetPass`, `PsEmit` en `PsBurst` nemen kleuren 0-255. Lichten, de zon, het omgevingslicht, materialen, tinten en `ObjSetColor` nemen lineaire kleuren 0-1.
- Drie renderers delen dezelfde scènedata: de GPU-rasterizer (standaard wanneer GLES 3.1-computeshaders beschikbaar zijn), de CPU-rasterizer (terugval, of afgedwongen met `SetMode("raster_cpu")`) en de path tracer (`SetMode("raytrace")`). De andere renderers negeren rijen gemarkeerd als *alleen GPU-rasterizer* of *alleen path tracer*.

De raytracer en de fysicawereld hebben hun eigen pagina’s: [raytracerwereld](3d-raytrace.md) en [fysica](3d-physics.md).

## Scènes

### SCENE3D

<span class="badge-exp">Experimenteel</span>

Factory voor 3D-scènes. Een scène is een rendertarget dat een camera, bewaarde objecten, texturen, sprites, lichten en deeltjessystemen bezit; je tekent haar als een 2D-textuur.

| Methode | Beschrijving |
| --- | --- |
| `SCENE3D:CreateScene(width, height)  -> scene` | Maakt een scène met de gegeven logische grootte in pixels en geeft de handle terug. Het spel geeft de scène vrij wanneer het de stage van het script afbreekt. |

### Scène-handle

<span class="badge-exp">Experimenteel</span>

<div class="callout warn">
Verloop per frame: teken de achtergrond (FillRect of ClearTransparent), werk de camera en eventuele geometrie per frame bij, roep Render aan, dan Upload, dan Draw. Render wist de kleurbuffer niet, dus teken eerst de lucht of het decor.
</div>

```lua
local scene, floor

function onStart()
    scene = SCENE3D:CreateScene(1280, 720)
    scene:SetLighting(true)
    scene:SetAmbient(0.4, 0.4, 0.46)
    scene:SetSun(0.3, 0.8, 0.5, 0.85, 0.82, 0.72)

    scene:RegisterTexture(1, pixels, 16, 16)          -- pixels: 1-gebaseerde array van 0xRRGGBB-integers
    floor = scene:NewObject()
    scene:ObjAddQuadTex(floor, 0,0,0,  0,0,8,  8,0,8,  8,0,0,  1, 8, 8, 1.0)
    scene:ObjSetBounds(floor, 0, 0, 0, 8, 0, 8)
end

function draw()
    scene:SetCameraPosition(4, 3, -6)
    scene:SetCameraAngles(0, -20)
    scene:FillRect(0, 0, 1280, 720, 90, 140, 220, 255)
    scene:Render()
    scene:Upload()
    scene:Draw(0, 0)
end

function onDestroy()
    scene:Dispose()
end
```

#### Texturen en sprites

Een textuur is een ondoorzichtige RGB-afbeelding die quads en driehoeken via UV samplen. Een sprite is een ARGB-afbeelding die billboardsprites, spritequads, deeltjes, grassprieten en terrein-splatgewichten gebruiken. Textuur-id's en sprite-id's zijn afzonderlijke naamruimten, en een id registreren dat al bestaat, vervangt zijn pixels.

| Methode | Beschrijving |
| --- | --- |
| `scene:RegisterTexture(id, pixels, w, h)  -> nil` | Registreert een textuur uit een 1-gebaseerde Lua-array van gepackte `0xRRGGBB`-integers (rij-volgorde, oorsprong linksboven). Een negatieve waarde markeert een transparante (uitgesneden) texel. De scène negeert afbeeldingen boven 4.194.304 pixels. |
| `scene:RegisterTextureFromImage(id, tex)  -> nil` | Registreert een textuur door de pixels van een geladen textuur-handle terug te lezen. Het teruglezen laat alfa weg en raakt de GPU eenmaal per aanroep, wat te traag is voor gebruik per frame. |
| `scene:SetTextureFilter(id, mode)  -> nil` | Samplingfilter voor een textuur: `"nearest"` (standaard), `"linear"` of `"mipmap"`. Alleen GPU-rasterizer. |
| `scene:UnregisterTexture(id)  -> nil` | Vergeet een textuur, inclusief zijn GPU-upload en elk render-to-texture-target dat aan het id is gebonden. |
| `scene:SetSpriteRGBA(spriteId, pixels, w, h)  -> nil` | Registreert een sprite uit een 1-gebaseerde Lua-array van ARGB-integers (`a << 24 | r << 16 | g << 8 | b`, rij-volgorde, oorsprong linksboven). |
| `scene:RegisterSpriteFromTexture(spriteId, tex)  -> nil` | Registreert een sprite door de pixels van een geladen textuur-handle terug te lezen. Het teruglezen raakt de GPU eenmaal per aanroep, wat te traag is voor gebruik per frame. |
| `scene:MakeSoftCircle(spriteId, res, edge)  -> nil` | Genereert een witte ronde sprite van `res` x `res` pixels, ondoorzichtig in het midden en uitdovend naar nul aan de rand; `edge` vormt het verloop (1 is lineair, 2-3 een zachte gloed). |
| `scene:MakeCrystal(spriteId, res)  -> nil` | Genereert een zesarmige witblauwe sneeuwvloksprite van `res` x `res` pixels. |
| `scene:SetSpriteFilter(spriteId, mode)  -> nil` | Samplingfilter voor een sprite: `"nearest"` (standaard) of `"linear"`. Meteen na het registreren aanroepen. Alleen GPU-rasterizer. |
| `scene:UnregisterSprite(spriteId)  -> nil` | Vergeet een sprite, inclusief zijn GPU-upload. |

De Register-aanroep van een model registreert zijn materialen als texturen met id's vanaf 4000 (glTF) en vanaf 6000 (OBJ), dus houd je eigen textuur-id's onder 4000 wanneer een scène ook modellen tekent.

#### Objecten

Een object is een bewaarde groep primitieven. Alle primitieven in één object moeten van dezelfde soort zijn (getextureerde quads, vlakke quads, getextureerde driehoeken, billboardsprites of spritequads); roep ObjBegin aan voordat je een object met een andere soort opnieuw vult. Object-id's beginnen bij 1.

| --- | --- |
| `scene:NewObject()  -> id` | Maakt een leeg, zichtbaar object in de ondoorzichtige pass. |
| `scene:DeleteObject(id)  -> nil` | Verwijdert een object en zijn geometrie. |
| `scene:ClearObjects()  -> nil` | Verwijdert elk object en elk deeltjessysteem en laat de rendercaches vallen. Texturen, sprites, lichten en de camera blijven bestaan; object-id's beginnen opnieuw bij 1. |
| `scene:ObjBegin(id)  -> nil` | Wist de primitieven van een object zodat je het opnieuw kunt vullen. |

De hoeken worden afgebeeld op de UV's (0, vMax), (uMax, vMax), (uMax, 0), (0, 0); `shade` (0-1) vermenigvuldigt de texel en regelt de zon wanneer belichting aan staat. |
| `scene:ObjAddQuadFlat(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3)  -> nil` | Voegt een vlak gekleurde quad toe; de kleur en alfa komen uit ObjSetPass. |

| `scene:ObjSetBounds(id, minX, minY, minZ, maxX, maxY, maxZ)  -> nil` | Grenzen in wereldruimte voor culling achter de camera, SetRenderDistance en ObjSetNormal. |

| `scene:ObjSetVisible(id, v)  -> nil` | Toont of verbergt een object. |
| `scene:ObjSetPass(id, pass, r, g, b, a)  -> nil` | Renderpass (0 ondoorzichtig, van voor naar achter getekend; 1 transparant, van achter naar voor getekend) plus de kleur van vlakke quads (0-255) en de alfa (0-255) die op vlakke quads en sprites wordt toegepast. |

| `scene:ObjSetTerrainSplat(id, splatSpriteId, tex1, tex2, tex3, tex4, worldW, worldH, uvScale)  -> nil` | Blendt vier laagtexturen per pixel op basis van een ARGB-gewichtssprite (zie de Splatmap-handle); `worldW`/`worldH` zijn de werelddekking van de splat, `uvScale` het aantal textuurherhalingen per wereldeenheid. `splatSpriteId` < 0 schakelt uit. #### Deeltjes

Een deeltjessysteem is een pool van naar de camera gerichte billboards. Zend erin uit, roep elk frame PsUpdate aan, en de rasterizers tekenen de levende deeltjes in de transparante pass. Systeem-id's beginnen bij 0; ClearObjects maakt ze ongeldig.

| Methode | Beschrijving |
| --- | --- |

## Modellen

### MODEL

<span class="badge-exp">Experimenteel</span>

Laadt glTF/GLB-bestanden (geskind, geanimeerd) en OBJ-bestanden (statisch) in poseerbare model-handles.

<div class="callout warn">
Paden zijn relatief ten opzichte van de scriptmap; de loader accepteert ook absolute paden. De loader parseert elk glTF-bestand eenmaal per proces en deelt het tussen scènes en stages, dus de onderdeelroutering die met SetPartObject is ingesteld, blijft bestaan tot ClearPartObjects of PurgeCache. glTF-ondersteuning omvat geïndexeerde driehoeksprimitieven met posities, één UV-set, optionele joints en gewichten, één skin, node-hiërarchieën, lineaire TRS-animaties, basiskleuren van materialen en ingesloten basiskleurtexturen (verkleind tot 512 pixels aan de lange zijde). OBJ-ondersteuning omvat posities, textuurcoördinaten, polygoonvlakken en diffuse kleuren uit het .mtl-bestand; de loader slaat afbeeldingstexturen over.
</div>

| Methode | Beschrijving |
| --- | --- |
| `MODEL:Load(path)  -> model` | Laadt een .glb-, .gltf- of .obj-bestand en geeft een model-handle terug, of nil bij een fout. |
| `MODEL:PurgeCache()  -> nil` | Laat de procesbrede glTF-cache vallen (bij het verlaten van een stage). Laad daarna elk model dat nog in gebruik is opnieuw. |

### Model-handle

<span class="badge-exp">Experimenteel</span>

<div class="callout warn">
Roep Register eenmaal per scène aan, en daarna elk frame Pose om de geplaatste (en, voor glTF, geskinde) driehoeken in een scèneobject te schrijven. Animatie-indices beginnen bij 0; -1 poseert de bindpose. Pose begrenst de animatietijd op de clip, dus herhaal hem zelf met Duration. De methoden onder Duration zijn alleen voor glTF; OBJ-handles bieden Register, Pose, AnimCount (0), AnimName en Duration.
</div>

```lua
local model, obj
local clip = 0

function onStart()
    model = MODEL:Load("models/lantern.glb")
    if model then
        model:Register(scene)
        obj = scene:NewObject()
    end
end

function draw()
    if model then
        local t = elapsed % model:Duration(clip)
        model:Pose(scene, obj, clip, t, x, y, z, yawDeg, 1.0)
    end
end

function onDestroy()
    MODEL:PurgeCache()
end
```

| Methode | Beschrijving |
| --- | --- |
| `model:Register(scene)  -> nil` | Registreert de materialen en texturen van het model in een scène (eenmaal per scène). |
| `model:Pose(scene, objId, anim, time, x, y, z, yawDeg, scale)  -> nil` | Wist object `objId` en vult het met de driehoeken van het model op animatie `anim` en `time` seconden, verschoven naar (x, y, z), om Y geroteerd over `yawDeg` en uniform geschaald. |
| `model:AnimCount()  -> number` | Aantal animatieclips (0 voor OBJ). |
| `model:AnimName(i)  -> string` | Naam van clip `i`, of "" wanneer buiten bereik. |
| `model:Duration(i)  -> number` | Duur in seconden van clip `i`, of 0 wanneer buiten bereik. |
| `model:PartCount()  -> number` | Aantal onderdelen (primitiefinstanties). |
| `model:PartMaterial(part)  -> number` | Materiaalindex van een onderdeel (vanaf 0), of -1 wanneer buiten bereik. |
| `model:MaterialCount()  -> number` | Aantal glTF-materialen. |
| `model:MaterialName(mat)  -> string` | Naam van een glTF-materiaal, of "" wanneer buiten bereik. |
| `model:MaterialEmissive(mat)  -> r, g, b` | De glTF-`emissiveFactor` van het materiaal, of 0, 0, 0 wanneer er geen is. |
| `model:SetPartObject(part, objId)  -> nil` | Routeert de driehoeken van een onderdeel bij Pose naar een eigen scèneobject, zodat dat onderdeel eigen transparantie-, emissieve of spiegelvlaggen kan dragen; -1 wist de routering voor dat onderdeel. |
| `model:ClearPartObjects()  -> nil` | Laat alle onderdeelroutering vallen. Roep dit aan bij het ontladen van een wereld, omdat de modelinstantie gedeeld is en object-id's na ClearObjects opnieuw beginnen. |
| `model:GetBounds()  -> minX, minY, minZ, maxX, maxY, maxZ` | Grenzen van de bindpose in modelruimte. |
| `model:BuildCollider(mc, x, y, z, yawDeg, scale)  -> nil` | Voegt de driehoeken van de bindpose, geplaatst met de gegeven transformatie, toe aan een MeshCollider. Een negatieve schaal werkt als haar absolute waarde. |

## Heightmaps

### HEIGHTMAP

<span class="badge-exp">Experimenteel</span>

Laadt ruwe 16-bits heightfields en RGBA-splatafbeeldingen voor terrein, en bouwt een volledig terrein in één aanroep.

<div class="callout warn">
Paden zijn relatief ten opzichte van de scriptmap. Een heightfield-bestand bevat w x h little-endian unsigned 16-bits samples in rij-volgorde; een splatafbeelding is een RGBA-PNG waarvan de kanalen R, G, B, A de gewichten van de lagen 1 tot 4 zijn. Bij een leesfout geven beide loaders een vlakke terugval terug.
</div>

| Methode | Beschrijving |
| --- | --- |

| `HEIGHTMAP:LoadSplat(path)  -> splatmap` | Laadt een splatafbeelding; geeft bij een fout een map terug die volledig laag 1 is. Een volledig ondoorzichtig alfakanaal betekent dat de map geen laag 4 heeft. |
| `HEIGHTMAP:BuildTerrain(scene, floorObj, world, hf, splat, w, h, minY, maxY, cellSize, tex1, tex2, tex3, tex4, grassDensity, grassClump)  -> number` | Zendt het terrein in één aanroep uit: één getextureerde quad per cel in `floorObj` (sample (ix, iz) ligt op wereld-x = ix x cellSize, z = iz x cellSize, y = minY + sample x (maxY - minY); elke laagtextuur herhaalt zich eenmaal per cel), bijpassende botsingsquads plus onzichtbare randmuren in `world` (aanroepen tussen BeginStatic en EndStatic), en grassprieten op laag-1-grond, weg van steile hellingen en de kaartrand, wanneer `grassDensity` > 0 (`grassClump` > 0 groepeert ze in plukken).
