# 3D-движок: физика <span class="badge-exp">Экспериментально</span>

Твёрдые тела, персонажи и транспорт, статические столкновения, запросы к коллайдерам через лучи и навигационные графы. Позиции задаются в мировых единицах, +Y направлен вверх; раздел [3D-движок: мир растеризатора](3d.md) описывает общие соглашения.

## Физика

### PHYSICS

<span class="badge-exp">Экспериментально</span>

Фабрика физических миров: статический набор треугольников плюс динамические тела персонажей, твёрдые тела, ящики и транспорт.

| Метод | Описание |
| --- | --- |
| `PHYSICS:NewWorld()  -> world` | Создаёт физический мир и возвращает его дескриптор. |

### Дескриптор физического мира

<span class="badge-exp">Экспериментально</span>

<div class="callout warn">
Стройте статическую геометрию между BeginStatic и EndStatic, создавайте тела, задавайте их скорость каждый кадр и вызывайте Step. Тела сталкиваются со статическим набором треугольников методом collide-and-slide (сфера или ориентированный ящик против треугольников) и друг с другом как сферы или капсулы в горизонтальной плоскости, обмениваясь импульсом пропорционально массе.
</div>

```lua
local world = PHYSICS:NewWorld()
world:SetGravity(0, -32, 0)
world:BeginStatic()
world:AddQuad(-20, 0, -20,  -20, 0, 20,  20, 0, 20,  20, 0, -20)
world:EndStatic()

local body = world:NewCharacter(0.35)
body:SetGravityEnabled(true)
body:SetPos(0, 0.35, 0)

-- каждый кадр
body:SetVelocity(moveX, body:GetVy(), moveZ)
world:Step(dt)
local x, y, z = body:GetX(), body:GetY(), body:GetZ()
```

| Метод | Описание |
| --- | --- |
| `world:SetGravity(x, y, z)  -> nil` | Вектор гравитации (по умолчанию 0, -32, 0). |
| `world:SetFloorMaxAngleY(y)  -> nil` | Порог Y нормали контакта (по умолчанию 0.5): контакты выше него считаются полом, остальные — стеной. |
| `world:BeginStatic()  -> nil` | Начинает перестроение статического набора; очищает существующие треугольники и группы коллайдеров. |
| `world:AddTri(ax, ay, az, bx, by, bz, cx, cy, cz)  -> nil` | Добавляет статический треугольник. Его нормаль — (b - a) x (c - a); вырожденные треугольники мир пропускает. |
| `world:AddQuad(ax, ay, az, bx, by, bz, cx, cy, cz, dx, dy, dz)  -> nil` | Добавляет статический квад как два треугольника (a, b, c) и (a, c, d). |
| `world:AddMesh(mc)  -> nil` | Добавляет треугольники MeshCollider в набор. |
| `world:BeginGroup(id)  -> nil` | Помечает добавляемые далее треугольники группой коллайдеров (0 = по умолчанию), чтобы SetGroupEnabled мог переключать группу во время выполнения. |
| `world:EndStatic()  -> nil` | Завершает набор и строит сетку широкой фазы. |
| `world:SetGroupEnabled(id, on)  -> nil` | Делает группу коллайдеров твёрдой или проходимой без перестроения набора (двери, подгружаемые интерьеры). |
| `world:ClearStatic()  -> nil` | Освобождает статический набор и его хранилище сейчас (выгрузка карты); также сбрасывает группы коллайдеров. |
| `world:NewCharacter(radius)  -> body` | Кинематическое сферическое тело: вы задаёте его скорость, мир перемещает его методом collide-and-slide. |
| `world:NewRigid(radius, mass)  -> body` | Сферическое тело с включённой гравитацией, обменивающееся импульсом с другими телами. |
| `world:NewBox(hx, hy, hz, mass)  -> body` | Тело с гравитацией, сталкивающееся со статическим набором как ориентированный ящик с указанными полуразмерами (ориентируйте его через SetForward). |
| `world:NewVehicle(radius, mass)  -> vehicle` | Тело автомобильного типа: шасси-персонаж с гравитацией, прилипанием к земле и более крутым порогом пола, плюс колёса на рейкастах. |
| `world:NewMeshCollider()  -> mc` | Создаёт пустой MeshCollider. |
| `world:RemoveBody(body)  -> nil` | Удаляет тело из мира. |
| `world:Step(dt)  -> nil` | Продвигает симуляцию на `dt` секунд. Быстрые тела мир обрабатывает подшагами, чтобы они не проходили сквозь тонкие стены. |
| `world:Raycast(ox, oy, oz, dx, dy, dz, maxDist)  -> hit, dist, nx, ny, nz` | Пускает луч (единичное направление) против включённых статических треугольников; возвращает, попал ли луч во что-нибудь, расстояние до ближайшего попадания и нормаль этого треугольника. |
| `world:GroundYAt(x, startY, z, reach)  -> number` | Высота земли прямо под (x, startY, z) в пределах `reach` или NaN, если земли нет (проверяйте через `y ~= y`). |
| `world:StaticTriCount()  -> number` | Число треугольников в статическом наборе. |
| `world:StaticTriCapacity()  -> number` | Выделенная ёмкость списка треугольников. |

### Дескриптор физического тела

<span class="badge-exp">Экспериментально</span>

<div class="callout warn">
Этот дескриптор возвращают NewCharacter, NewRigid и NewBox. Позиции относятся к центру тела. Контакты тело-тело мир разрешает только в горизонтальной плоскости и пропускает их между телами, разнесёнными по Y более чем на 2 единицы.
</div>

| Метод | Описание |
| --- | --- |
| `body:SetPos(x, y, z)  -> nil` | Задаёт позицию центра. |
| `body:SetVelocity(x, y, z)  -> nil` | Задаёт скорость. |
| `body:AddVelocity(x, y, z)  -> nil` | Добавляет к скорости. |
| `body:SetRadius(r)  -> nil` | Радиус сферы и широкой фазы (минимум 0.01). |
| `body:SetCapsule(halfLen)  -> nil` | Использует горизонтальную капсулу этой полудлины вдоль оси «вперёд» для контактов тело-тело; статические столкновения по-прежнему используют радиус сферы. |
| `body:SetBox(hx, hy, hz)  -> nil` | Сталкивается со статическим набором как ориентированный ящик с полуразмерами (вправо, вверх, вперёд). |
| `body:SetForward(fx, fz)  -> nil` | Горизонтальная ось «вперёд» (нормализуется автоматически), ориентирующая капсулу или ящик. |
| `body:SetGravityEnabled(g)  -> nil` | Применяет к этому телу гравитацию мира. |
| `body:SetEnabled(e)  -> nil` | Отключённые тела Step пропускает. |
| `body:SetSnap(s)  -> nil` | Удерживает стоящее на земле тело прижатым к уходящей вниз поверхности в пределах небольшого зазора; без прилипания тело, бегущее под уклон, отрывается от земли и подпрыгивает. |
| `body:SetSmoothContacts(on)  -> nil` | Вариант решателя для персонажей: разрешает самый глубокий контакт за итерацию, сваривает швы пола, записывает нормали стен и спускается на проходимую поверхность. По умолчанию выключено. |
| `body:SetCollisionLayer(l)  -> nil` | Индекс слоя столкновений 0..30 для контактов тело-тело (по умолчанию 0). |
| `body:SetCollisionMask(m)  -> nil` | Битовая маска слоёв, с которыми сталкивается это тело (бит i = слой i); по умолчанию все, 0 = ни один. |
| `body:GetPos()  -> x, y, z` | Позиция центра. |
| `body:GetVelocity()  -> x, y, z` | Скорость. |
| `body:GetX()  -> number` | X центра. |
| `body:GetY()  -> number` | Y центра. |
| `body:GetZ()  -> number` | Z центра. |
| `body:GetVx()  -> number` | Скорость по X. |
| `body:GetVy()  -> number` | Скорость по Y. |
| `body:GetVz()  -> number` | Скорость по Z. |
| `body:Speed()  -> number` | Модуль скорости. |
| `body:IsOnFloor()  -> boolean` | Истина, если тело опиралось на пол во время последнего шага. |
| `body:HitWall()  -> boolean` | Истина, если тело коснулось стены во время последнего шага. |
| `body:GetWallNx()  -> number` | X нормали последнего контакта со стеной (задаётся при включённом SetSmoothContacts). |
| `body:GetWallNz()  -> number` | Z нормали последнего контакта со стеной (задаётся при включённом SetSmoothContacts). |
| `body:GetImpulseX()  -> number` | X суммарного изменения скорости от контактов тело-тело во время последнего шага. |
| `body:GetImpulseZ()  -> number` | Z суммарного изменения скорости от контактов тело-тело во время последнего шага. |

### Дескриптор транспортного тела

<span class="badge-exp">Экспериментально</span>

<div class="callout warn">
Этот дескриптор возвращает NewVehicle. Шасси — это тело персонажа, которое Step перемещает как обычно; каждый вызов UpdateWheels пускает колёса как лучи вниз от шасси, давая многоколёсный флаг контакта с землёй, сжатие подвески каждого колеса и тангаж и крен шасси, следующие за уклоном. Ваш код управления задаёт скорость шасси.
</div>

| Метод | Описание |
| --- | --- |
| `vehicle:AddWheel(lx, lz, radius, rest, steered, powered)  -> wheel` | Добавляет колесо со смещением в пространстве шасси (`lx` вправо, `lz` вперёд), указанным радиусом и длиной подвески в покое. Транспорт хранит `steered` и `powered` для вашего кода управления и сам их никогда не читает. |
| `vehicle:GetWheel(i)  -> wheel` | Колесо `i` (от 0) или nil. |
| `vehicle:WheelCount()  -> number` | Число колёс. |
| `vehicle:UpdateWheels(dt, speed)  -> nil` | Пускает лучи от колёс и обновляет контакт с землёй, сжатие, тангаж, крен и вращение колёс (`speed` в мировых единицах в секунду). Вызывайте один раз за кадр после Step. |
| `vehicle.Body  -> body` | Дескриптор тела шасси. |
| `vehicle:SetPos(x, y, z)  -> nil` | Задаёт позицию шасси. |
| `vehicle:SetVelocity(x, y, z)  -> nil` | Задаёт скорость шасси. |
| `vehicle:AddVelocity(x, y, z)  -> nil` | Добавляет к скорости шасси. |
| `vehicle:SetForward(fx, fz)  -> nil` | Задаёт ось «вперёд» и выводит из неё курс. |
| `vehicle:SetYaw(y)  -> nil` | Задаёт курс в радианах и выводит из него ось «вперёд». |
| `vehicle:SetGravityEnabled(g)  -> nil` | Применяет гравитацию к шасси. |
| `vehicle:SetEnabled(e)  -> nil` | Включает или отключает тело шасси. |
| `vehicle:SetCapsule(halfLen)  -> nil` | Полудлина капсулы для контактов шасси с телами. |
| `vehicle:SetRadius(r)  -> nil` | Радиус шасси. |
| `vehicle:GetX()  -> number` | X шасси. |
| `vehicle:GetY()  -> number` | Y шасси. |
| `vehicle:GetZ()  -> number` | Z шасси. |
| `vehicle:GetVx()  -> number` | Скорость шасси по X. |
| `vehicle:GetVy()  -> number` | Скорость шасси по Y. |
| `vehicle:GetVz()  -> number` | Скорость шасси по Z. |
| `vehicle:IsOnFloor()  -> boolean` | Истина, если хотя бы три колеса касаются земли или шасси опирается на пол. |
| `vehicle:HitWall()  -> boolean` | Истина, если шасси коснулось стены во время последнего шага. |
| `vehicle:GetImpulseX()  -> number` | X изменения скорости, полученного шасси от контактов тело-тело. |
| `vehicle:GetImpulseZ()  -> number` | Z изменения скорости, полученного шасси от контактов тело-тело. |
| `vehicle:GetPitch()  -> number` | Тангаж шасси в радианах, плавно следующий за контактами колёс. |
| `vehicle:GetRoll()  -> number` | Крен шасси в радианах, плавно следующий за контактами колёс. |

## Коллайдеры и рейкастинг

### COLLIDERS

<span class="badge-exp">Экспериментально</span>

Фабрика форм для запросов (сфера, ящик по осям, капсула) и лучей для проверок попадания, независимая от какого-либо физического мира.

| Метод | Описание |
| --- | --- |
| `COLLIDERS:Sphere(cx, cy, cz, r)  -> collider` | Сфера радиуса `r` с центром в (cx, cy, cz). |
| `COLLIDERS:Box(cx, cy, cz, hx, hy, hz)  -> collider` | Ящик по осям с полуразмерами (hx, hy, hz) и центром в (cx, cy, cz). |
| `COLLIDERS:Capsule(cx, cy, cz, hsx, hsy, hsz, r)  -> collider` | Капсула радиуса `r` вокруг отрезка от центр - (hsx, hsy, hsz) до центр + (hsx, hsy, hsz). |
| `COLLIDERS:CapsuleY(cx, cy, cz, halfHeight, r)  -> collider` | Вертикальная капсула с указанными полувысотой и радиусом. |
| `COLLIDERS:Ray(ox, oy, oz, dx, dy, dz, len)  -> ray` | Переиспользуемый луч с началом, направлением (нормализуется автоматически) и длиной. |

## Поиск пути

### PATHFIND

<span class="badge-exp">Экспериментально</span>

Фабрика взвешенных навигационных графов, по которым FindPath ищет путь алгоритмом A*.

| Метод | Описание |
| --- | --- |
| `PATHFIND:NewGraph()  -> graph` | Создаёт пустой граф и возвращает его дескриптор. |

### Дескриптор навигационного графа

<span class="badge-exp">Экспериментально</span>

<div class="callout warn">
Узлы несут мировую позицию; индексы начинаются с 1. Каждое ребро несёт вес и транзитную точку — позицию, через которую проходит движущийся объект при использовании этого ребра (например, середина дверного проёма). FindPath возвращает транзитные точки пройденных им рёбер, за которыми следует точка цели.
</div>

```lua
local g = PATHFIND:NewGraph()
local a = g:AddNode(0, 0, 0)
local b = g:AddNode(10, 0, 0)
g:Link(a, b, 10, 5, 0, 0)
local path = g:FindPath(g:NearestNode(1, 0, 0), g:NearestNode(9, 0, 0), 9, 0, 0)
if path then
    for i = 1, path:Count() do
        local x, z = path:X(i), path:Z(i)
    end
end
```

| Метод | Описание |
| --- | --- |
| `graph:AddNode(x, y, z)  -> number` | Добавляет узел и возвращает его индекс. |
| `graph:AddEdge(a, b, w, px, py, pz)  -> nil` | Добавляет направленное ребро от узла `a` к узлу `b` с весом `w` через транзитную точку (px, py, pz). |
| `graph:Link(a, b, w, px, py, pz)  -> nil` | Добавляет рёбра в обоих направлениях через одну общую транзитную точку. |
| `graph:NearestNode(x, y, z)  -> number` | Индекс узла, ближайшего к (x, y, z), или 0, если граф пуст. |
| `graph:FindPath(start, goal, goalX, goalY, goalZ)  -> path` | Выполняет A* от узла `start` к узлу `goal`; возвращает путь, заканчивающийся в (goalX, goalY, goalZ), или nil, если цель недостижима. |
| `graph:NodeCount()  -> number` | Число узлов. |
| `graph:Clear()  -> nil` | Удаляет все узлы и рёбра. |

### Дескриптор навигационного пути

<span class="badge-exp">Экспериментально</span>

Индексы путевых точек начинаются с 1.

| Метод | Описание |
| --- | --- |
| `path:Count()  -> number` | Число путевых точек. |
| `path:X(i)  -> number` | X путевой точки `i`. |
| `path:Y(i)  -> number` | Y путевой точки `i`. |
| `path:Z(i)  -> number` | Z путевой точки `i`. |
