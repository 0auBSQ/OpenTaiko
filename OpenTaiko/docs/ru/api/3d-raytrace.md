# 3D-движок: мир трассировщика лучей <span class="badge-exp">Экспериментально</span>

Трассировщик путей отрисовывает те же данные сцены, что и растеризатор, с материалами, аналитическими примитивами и градиентом неба. Переключите сцену на него вызовом `scene:SetMode("raytrace")`; раздел [3D-движок: мир растеризатора](3d.md) описывает сцены, объекты, текстуры и общие соглашения.

## Вызовы сцены, используемые трассировщиком путей

| Метод | Описание |
| --- | --- |
| `scene:GetRaytracerStatus()  -> string` | Сведения о бэкенде в режиме raytrace (тайминг GPU-вычислений, откат на CPU или CPU-трассировщик путей); пусто в растровых режимах. |
| `scene:RenderViewRT(texId, cx, cy, cz, yawDeg, pitchDeg, fovDeg, clr, clg, clb, flipX)  -> nil` | Как RenderView, но его рендерит CPU-трассировщик путей в четверти разрешения отражений. |

## Материалы и примитивы трассировщика путей

Материалы, аналитические примитивы и градиент неба использует только трассировщик путей. Трассировщик путей трассирует и хранимые объекты, используя материал, назначенный через ObjSetMaterial, или их текстуру и плоский цвет, если материал не задан. Идентификаторы материалов и примитивов начинаются с 0.

| Метод | Описание |
| --- | --- |
| `scene:SetSky(tr, tg, tb, br, bg, bb, strength)  -> nil` | Градиент неба (линейный 0-1) от верхнего цвета к нижнему, умноженный на `strength`; он освещает сцену, когда лучи уходят в пустоту. Сила 0 даёт чёрную студию. |
| `scene:NewMaterial()  -> id` | Создаёт материал (по умолчанию диффузный средне-серый) и возвращает его идентификатор. |
| `scene:MatSetType(id, type)  -> nil` | `"diffuse"`, `"metal"`, `"glass"` или `"emissive"`. |
| `scene:MatSetAlbedo(id, r, g, b)  -> nil` | Базовый цвет (линейный 0-1); для металла окрашивает отражение. |
| `scene:MatSetRoughness(id, rough)  -> nil` | 0 = идеальное зеркало или чистое стекло, 1 = полностью шероховатый. |
| `scene:MatSetIOR(id, ior)  -> nil` | Показатель преломления стекла (минимум 1). |
| `scene:MatSetEmission(id, r, g, b, strength)  -> nil` | Цвет излучения, умноженный на силу; излучающие поверхности освещают сцену. |
| `scene:MatSetTexture(id, texId)  -> nil` | Текстура альбедо (идентификатор зарегистрированной текстуры), выбираемая по UV; -1 = нет. |
| `scene:MatSetNormalMap(id, preset)  -> nil` | Процедурная карта нормалей: `"none"`, `"wood"`, `"perlin"` или `"waves"`. |
| `scene:MatSetNormalMapTexture(id, texId)  -> nil` | Текстура карты нормалей в касательном пространстве (нормаль, закодированная в RGB) для текстурированной геометрии; переопределяет пресет. -1 сбрасывает. |
| `scene:AddSphere(cx, cy, cz, r, mat)  -> id` | Примитив-сфера. |
| `scene:AddPlane(px, py, pz, nx, ny, nz, mat)  -> id` | Бесконечная плоскость через точку с указанной нормалью (нормализуется автоматически). |
| `scene:AddBox(minx, miny, minz, maxx, maxy, maxz, mat)  -> id` | Примитив-параллелепипед, выровненный по осям. |
| `scene:AddTorus(cx, cy, cz, R, r, axis, mat)  -> id` | Тор с большим радиусом `R`, малым радиусом `r`, ось 0 = X, 1 = Y, 2 = Z. |
| `scene:AddSDF(preset, cx, cy, cz, sx, sy, sz, mat)  -> id` | Фигура со знаковым полем расстояний, найденная маршированием лучей, с масштабом по осям: `"sphere"`, `"roundbox"`, `"torus"`, `"capsule"`, `"gyroid"`, `"octahedron"`, `"gem"` или `"diamond"`. |
| `scene:ClearPrimitives()  -> nil` | Удаляет все примитивы. |
| `scene:ClearRaytraceModel()  -> nil` | Удаляет все материалы, точечные источники и примитивы. |
