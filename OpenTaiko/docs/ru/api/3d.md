# 3D-движок: мир растеризатора <span class="badge-exp">Экспериментально</span>

Сцены, модели, источники света, камеры, физика, коллайдеры, поиск пути, частицы, цели рендеринга и карты высот местности.

3D-движок экспериментальный. По плану экспериментальная пометка будет снята в версии 1.0.

<div class="callout">
Каждый глобальный объект и каждый метод на этой странице может измениться между выпусками без периода устаревания. Если ваш скин на него полагается, проверяйте его заново после каждого обновления и указывайте, на какую версию игры он рассчитан.
</div>

Соглашения, принятые на этой странице:

- Позиции и размеры задаются в мировых единицах; +Y направлена вверх. Идентификаторы объектов, текстур, спрайтов, материалов и примитивов — целые числа.
- Углы задаются в градусах, если в строке не указаны радианы (курс и наклон физического транспорта, вращение колёс, фаза покачивания травы).
- `Clear`, `FillRect`, `DrawLine`, `SetFog`, `ObjSetPass`, `PsEmit` и `PsBurst` принимают цвета 0-255. Источники света, солнце, окружающий свет, материалы, оттенки и `ObjSetColor` принимают линейные цвета 0-1.
- Три рендерера используют одни и те же данные сцены: GPU-растеризатор (по умолчанию, когда доступны вычислительные шейдеры GLES 3.1), CPU-растеризатор (запасной вариант или принудительно через `SetMode("raster_cpu")`) и трассировщик путей (`SetMode("raytrace")`). Строки, помеченные *только GPU-растеризатор* или *только трассировщик путей*, остальные рендереры игнорируют.

У трассировщика лучей и физического мира есть отдельные страницы: [мир трассировщика лучей](3d-raytrace.md) и [физика](3d-physics.md).

## Сцены

### SCENE3D

<span class="badge-exp">Экспериментально</span>

Фабрика 3D-сцен. Сцена — это цель рендеринга, которая владеет камерой, хранимыми объектами, текстурами, спрайтами, источниками света и системами частиц; вы рисуете её как 2D-текстуру.

| Метод | Описание |
| --- | --- |
| `SCENE3D:CreateScene(width, height)  -> scene` | Создать сцену с указанным логическим размером в пикселях и вернуть её дескриптор. Игра освобождает сцену, когда завершает работу сцены Stage, которой принадлежит скрипт. |

### Дескриптор сцены

<span class="badge-exp">Экспериментально</span>

<div class="callout warn">
Порядок действий в каждом кадре: нарисуйте фон (FillRect или ClearTransparent), обновите камеру и покадровую геометрию, вызовите Render, затем Upload, затем Draw. Render не очищает цветовой буфер, поэтому небо или задник рисуйте заранее.
</div>

```lua
local scene, floor

function onStart()
    scene = SCENE3D:CreateScene(1280, 720)
    scene:SetLighting(true)
    scene:SetAmbient(0.4, 0.4, 0.46)
    scene:SetSun(0.3, 0.8, 0.5, 0.85, 0.82, 0.72)

    scene:RegisterTexture(1, pixels, 16, 16)          -- pixels: массив целых 0xRRGGBB с индексацией от 1
    floor = scene:NewObject()
    scene:ObjAddQuadTex(floor, 0,0,0,  0,0,8,  8,0,8,  8,0,0,  1, 8, 8, 1.0)
    scene:ObjSetBounds(floor, 0, 0, 0, 8, 0, 8)
end

function draw()
    scene:SetCameraPosition(4, 3, -6)
    scene:SetCameraAngles(0, -20)
    scene:FillRect(0, 0, 1280, 720, 90, 140, 220, 255)
    scene:Render()
    scene:Upload()
    scene:Draw(0, 0)
end

function onDestroy()
    scene:Dispose()
end
```

#### Размер и 2D-отрисовка

| Метод | Описание |
| --- | --- |
| `scene.Width  -> number` | Логическая ширина в пикселях, только чтение. |
| `scene.Height  -> number` | Логическая высота в пикселях, только чтение. |
| `scene:Clear(r, g, b, a)  -> nil` | Заливает весь цветовой буфер цветом RGBA (0-255), смешивая его с текущим содержимым. |
| `scene:ClearTransparent()  -> nil` | Сбрасывает цветовой буфер в полностью прозрачное состояние, чтобы отрисованный кадр накладывался на то, что сцена нарисовала под ним. |
| `scene:FillRect(x, y, w, h, r, g, b, a)  -> nil` | Заливает 2D-прямоугольник (логические пиксельные координаты) цветом RGBA. |
| `scene:DrawLine(x0, y0, x1, y1, r, g, b)  -> nil` | Рисует 2D-линию поверх цветового буфера без проверки глубины. |
| `scene:ClearDepth()  -> nil` | Очищает буфер глубины. |

| `scene:Project(wx, wy, wz)  -> sx, sy, inFront` | Проецирует мировую точку в логические пиксельные координаты; `inFront` ложно, если точка за ближней плоскостью. |

#### Рендерер

| Метод | Описание |
| --- | --- |
| `scene:SetMode(mode)  -> nil` | Выбирает рендерер: `"raster"` (по умолчанию; GPU при наличии, иначе CPU), `"raster_cpu"`, `"raytrace"` или `"rt"` (GPU-трассировщик путей с откатом на CPU), `"raytrace_cpu"` или `"rt_cpu"`. Переключение сбрасывает кэшированное и накопленное состояние. |
| `scene:GetMode()  -> string` | Активный рендерер: `"raster"`, `"raster_cpu"` или `"raytrace"`. |
| `scene:SetThreads(n)  -> nil` | Число потоков для CPU-растеризатора, который делит экран на столько горизонтальных полос (по умолчанию 1). |
| `scene:SetRenderDistance(d)  -> nil` | Пропускает объекты, границы которых (см. ObjSetBounds) целиком лежат дальше этого расстояния от камеры; 0 = без ограничения. Только растеризаторы. |
| `scene:SetAntialias(on)  -> nil` | Включает сглаживание краёв постобработкой в итоговом цветовом буфере (по умолчанию выключено). |
| `scene:GetSampleCount()  -> number` | Число выборок трассировщика путей, накопленных на пиксель с последнего изменения камеры или сцены; 0 в растровых режимах. |
| `scene:GetMemoryStats()  -> texCount, texBytes, spriteCount, objCount, grassBlades, liveParticles` | Счётчики ресурсов для отладочных наложений. |
| `scene:GetRendererStats()  -> string` | Счётчики кэшей на стороне рендерера у GPU-растеризатора или `"cpu"`. |
| `scene:ClearRenderCaches()  -> nil` | Сбрасывает перестраиваемые кэши рендеринга (цели рендеринга в текстуру, вершинные буферы объектов, объединённые статические буферы). Зарегистрированные текстуры и спрайты сохраняются; вызывайте при выгрузке карты. |
| `scene:Dispose()  -> nil` | Освобождает сцену немедленно; иначе она живёт до завершения работы сцены Stage. |

Если GPU-рендерер даёт сбой во время рендеринга (например, драйвер отклоняет шейдер), сцена переключается на CPU-растеризатор до конца своего существования, а сцена Stage продолжает работать.

#### Текстуры и спрайты

Текстура — это непрозрачное RGB-изображение, которое квады и треугольники выбирают по UV. Спрайт — это ARGB-изображение, которое используют билборд-спрайты, спрайт-квады, частицы, травинки и веса сплат-карты местности. Идентификаторы текстур и спрайтов — отдельные пространства имён, и регистрация уже существующего идентификатора заменяет его пиксели.

| Метод | Описание |
| --- | --- |
| `scene:RegisterTexture(id, pixels, w, h)  -> nil` | Регистрирует текстуру из Lua-массива с индексацией от 1 упакованных целых `0xRRGGBB` (построчно, начало в левом верхнем углу). Отрицательное значение помечает прозрачный (вырезаемый) тексель. Изображения больше 4 194 304 пикселей сцена игнорирует. |
| `scene:RegisterTextureFromImage(id, tex)  -> nil` | Регистрирует текстуру, считывая пиксели загруженного дескриптора текстуры. Считывание отбрасывает альфу и обращается к GPU один раз на вызов, что слишком медленно для использования каждый кадр. |
| `scene:SetTextureFilter(id, mode)  -> nil` | Фильтр выборки текстуры: `"nearest"` (по умолчанию), `"linear"` или `"mipmap"`. Только GPU-растеризатор. |
| `scene:UnregisterTexture(id)  -> nil` | Забывает текстуру, включая её загрузку на GPU и любую цель рендеринга в текстуру, привязанную к этому идентификатору. |
| `scene:SetSpriteRGBA(spriteId, pixels, w, h)  -> nil` | Регистрирует спрайт из Lua-массива с индексацией от 1 целых ARGB (`a << 24 | r << 16 | g << 8 | b`, построчно, начало в левом верхнем углу). |
| `scene:RegisterSpriteFromTexture(spriteId, tex)  -> nil` | Регистрирует спрайт, считывая пиксели загруженного дескриптора текстуры. Считывание обращается к GPU один раз на вызов, что слишком медленно для использования каждый кадр. |
| `scene:MakeSoftCircle(spriteId, res, edge)  -> nil` | Генерирует белый круглый спрайт размером `res` x `res` пикселей, непрозрачный в центре и затухающий до нуля к краю; `edge` задаёт форму спада (1 — линейный, 2-3 — мягкое свечение). |
| `scene:MakeCrystal(spriteId, res)  -> nil` | Генерирует шестилучевой бело-голубой спрайт снежинки размером `res` x `res` пикселей. |
| `scene:SetSpriteFilter(spriteId, mode)  -> nil` | Фильтр выборки спрайта: `"nearest"` (по умолчанию) или `"linear"`. Вызывайте сразу после регистрации. Только GPU-растеризатор. |
| `scene:UnregisterSprite(spriteId)  -> nil` | Забывает спрайт, включая его загрузку на GPU. |

Вызов Register модели регистрирует её материалы как текстуры с идентификаторами от 4000 (glTF) и от 6000 (OBJ), поэтому держите собственные идентификаторы текстур ниже 4000, если сцена также рисует модели.

#### Объекты

Объект — это хранимая группа примитивов. Все примитивы одного объекта должны быть одного вида (текстурированные квады, плоские квады, текстурированные треугольники, билборд-спрайты или спрайт-квады); вызовите ObjBegin перед заполнением объекта примитивами другого вида. Идентификаторы объектов начинаются с 1.

| Метод | Описание |
| --- | --- |
| `scene:NewObject()  -> id` | Создаёт пустой видимый объект в непрозрачном проходе. |
| `scene:DeleteObject(id)  -> nil` | Удаляет объект и его геометрию. |
| `scene:ClearObjects()  -> nil` | Удаляет все объекты и все системы частиц и сбрасывает кэши рендеринга. Текстуры, спрайты, источники света и камера сохраняются; идентификаторы объектов снова начинаются с 1. |
| `scene:ObjBegin(id)  -> nil` | Очищает примитивы объекта, чтобы вы могли заполнить его заново. |
| `scene:ObjAddQuadTex(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, texId, uMax, vMax, shade)  -> nil` | Добавляет текстурированный квад. Углы соответствуют UV (0, vMax), (uMax, vMax), (uMax, 0), (0, 0); `shade` (0-1) умножает тексель и ограничивает солнце при включённом освещении. |
| `scene:ObjAddQuadFlat(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3)  -> nil` | Добавляет одноцветный квад; цвет и альфа берутся из ObjSetPass. |
| `scene:ObjAddTriTex(id, x0, y0, z0, u0, v0, x1, y1, z1, u1, v1, x2, y2, z2, u2, v2, texId, shade)  -> nil` | Добавляет текстурированный треугольник с явными UV. Дескрипторы моделей заполняют объекты этим примитивом. |
| `scene:ObjAddSprite(id, x, y, z, w, h, spriteId, billboard, cutout)  -> nil` | Добавляет спрайт-квад мирового размера `w` x `h`, нижний центр которого находится в (x, y, z). `billboard`: 0 фиксированная плоскость XY, 1 поворачивается к камере, но остаётся вертикальным, 2 всегда обращён к камере, 3 лежит плоско на земле, растянутый вдоль направления SetGroundSpriteLight. `cutout` не ноль — альфа-тест и запись глубины (непрозрачный проход); 0 — альфа-смешивание (поместите объект в прозрачный проход). |
| `scene:ObjAddSpriteQuad(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, spriteId, cutout)  -> nil` | Добавляет спрайт на явно заданном мировом кваде (углы соответствуют UV (0, 1), (1, 1), (1, 0), (0, 0)); без билбординга. |
| `scene:ObjSetTransform(id, m)  -> nil` | Задаёт матрицу модели объекта из Lua-таблицы из 16 чисел в построчном порядке (перенос в m[4], m[8], m[12]); nil восстанавливает единичную матрицу. |
| `scene:ObjSetTransform16(id, m0, m1, m2, m3, m4, m5, m6, m7, m8, m9, m10, m11, m12, m13, m14, m15)  -> nil` | То же, что ObjSetTransform, с 16 обычными аргументами; используйте для покадровых обновлений. |
| `scene:ObjClearTransform(id)  -> nil` | Восстанавливает единичную матрицу модели. |
| `scene:ObjSetBounds(id, minX, minY, minZ, maxX, maxY, maxZ)  -> nil` | Границы в мировом пространстве для отсечения объектов позади камеры, SetRenderDistance и ObjSetNormal. |
| `scene:ObjSetNormal(id, nx, ny, nz)  -> nil` | Рассматривает объект как плоскую группу, обращённую в направлении (nx, ny, nz), и пропускает его, когда камера находится позади этой плоскости (требует ObjSetBounds); 0, 0, 0 отключает. |
| `scene:ObjSetVisible(id, v)  -> nil` | Показывает или скрывает объект. |
| `scene:ObjSetPass(id, pass, r, g, b, a)  -> nil` | Проход рендеринга (0 непрозрачный, рисуется спереди назад; 1 прозрачный, рисуется сзади вперёд), а также цвет плоских квадов (0-255) и альфа (0-255), применяемые к плоским квадам и спрайтам. |
| `scene:ObjSetTint(id, r, g, b)  -> nil` | Поканальное умножение цвета (0-1) для текстурированных поверхностей и спрайтов; 1, 1, 1 = без изменений. |
| `scene:ObjSetColor(id, r, g, b)  -> nil` | Переопределение плоского альбедо (0-1), заменяющее цвет текстуры или материала до освещения; r < 0 сбрасывает. Только GPU-растеризатор. |
| `scene:ObjSetEmissive(id, r, g, b)  -> nil` | Эмиссивная добавка (цвет += база x rgb); значения выше 1 питают блум SetDiorama. 0, 0, 0 = выключено. Только GPU-растеризатор. |
| `scene:ObjSetLit(id, lit)  -> nil` | Применяется ли к объекту прямое освещение (по умолчанию true); false рендерит его только с запечённым затенением. |
| `scene:ObjSetCastShadow(id, on)  -> nil` | Отбрасывают ли спрайты объекта тень в карту солнечных теней (по умолчанию true). Только GPU-растеризатор. |
| `scene:ObjSetDepthBias(id, bias)  -> nil` | Смещение глубины (polygon offset): отрицательное подтягивает объект к камере (декали на компланарной поверхности), положительное отодвигает; 0 = выключено. Только GPU-растеризатор. |
| `scene:ObjSetOverlay(id, on)  -> nil` | Рисует объект последним поверх очищенного буфера глубины, чтобы он всегда был сверху (модели вида от первого лица). |
| `scene:ObjSetXray(id, alpha)  -> nil` | Перерисовывает спрайты объекта как призрак с этой альфой (0-1) там, где их перекрывает геометрия мира; 0 = выключено. Только GPU-растеризатор. |
| `scene:ObjSetMaterial(id, matId)  -> nil` | Материал, который трассировщик путей использует для этого объекта (-1 = по умолчанию). Только трассировщик путей. |
| `scene:ObjSetTerrainSplat(id, splatSpriteId, tex1, tex2, tex3, tex4, worldW, worldH, uvScale)  -> nil` | Смешивает четыре текстуры слоёв попиксельно по ARGB-спрайту весов (см. «Дескриптор сплат-карты»); `worldW`/`worldH` — покрытие сплата в мировых единицах, `uvScale` — число повторов текстуры на мировую единицу. `splatSpriteId` < 0 отключает. Только GPU-растеризатор. |

#### Свет и тени

Прямое освещение по умолчанию выключено. Как только вы его включите, каждую грань освещают окружающий свет, солнце и точечные источники.

| Метод | Описание |
| --- | --- |
| `scene:SetLighting(on)  -> nil` | Включает прямое освещение на растеризаторах. |
| `scene:SetAmbient(r, g, b)  -> nil` | Окружающий свет, добавляемый к каждой освещённой грани. |
| `scene:SetSun(dx, dy, dz, r, g, b)  -> nil` | Направленное солнце: (dx, dy, dz) — направление на солнце (нормализуется автоматически); (r, g, b) — цвет, умноженный на яркость, поэтому значения выше 1 работают. Нулевой цвет отключает. |

## Модели

### MODEL

<span class="badge-exp">Экспериментально</span>

Загружает файлы glTF/GLB (со скиннингом, анимированные) и OBJ (статические) в дескрипторы моделей, которые можно позировать.

<div class="callout warn">
Пути задаются относительно каталога скрипта; загрузчик принимает и абсолютные пути. Загрузчик разбирает каждый файл glTF один раз на процесс и разделяет его между 3D-сценами и сценами Stage, поэтому маршрутизация частей, заданная SetPartObject, сохраняется до ClearPartObjects или PurgeCache. Поддержка glTF охватывает индексированные треугольные примитивы с позициями, одним набором UV, необязательными суставами и весами, одним скином, иерархией узлов, линейными TRS-анимациями, базовыми цветами материалов и встроенными текстурами базового цвета (уменьшаются до 512 пикселей по длинной стороне). Поддержка OBJ охватывает позиции, текстурные координаты, многоугольные грани и диффузные цвета из файла .mtl; текстуры-изображения загрузчик пропускает.
</div>

| Метод | Описание |
| --- | --- |
| `MODEL:Load(path)  -> model` | Загружает файл .glb, .gltf или .obj и возвращает дескриптор модели или nil при сбое. |
| `MODEL:PurgeCache()  -> nil` | Сбрасывает общепроцессный кэш glTF (выход из сцены Stage). После этого загрузите заново любую ещё используемую модель. |

### Дескриптор модели

<span class="badge-exp">Экспериментально</span>

<div class="callout warn">
Вызовите Register один раз на сцену, затем каждый кадр вызывайте Pose, чтобы записать размещённые (а для glTF — со скиннингом) треугольники в объект сцены. Индексы анимаций начинаются с 0; -1 позирует бинд-позу. Pose ограничивает время анимации длиной клипа, поэтому зацикливайте его сами через Duration. Методы ниже Duration относятся только к glTF; дескрипторы OBJ предоставляют Register, Pose, AnimCount (0), AnimName и Duration.
</div>

```lua
local model, obj
local clip = 0

function onStart()
    model = MODEL:Load("models/lantern.glb")
    if model then
        model:Register(scene)
        obj = scene:NewObject()
    end
end

function draw()
    if model then
        local t = elapsed % model:Duration(clip)
        model:Pose(scene, obj, clip, t, x, y, z, yawDeg, 1.0)
    end
end

function onDestroy()
    MODEL:PurgeCache()
end
```

| Метод | Описание |
| --- | --- |
| `model:Register(scene)  -> nil` | Регистрирует материалы и текстуры модели в сцене (один раз на сцену). |
| `model:Pose(scene, objId, anim, time, x, y, z, yawDeg, scale)  -> nil` | Очищает объект `objId` и заполняет его треугольниками модели для анимации `anim` в момент `time` секунд, перенесёнными в (x, y, z), повёрнутыми вокруг Y на `yawDeg` и равномерно масштабированными. |
| `model:AnimCount()  -> number` | Число клипов анимации (0 для OBJ). |
| `model:AnimName(i)  -> string` | Имя клипа `i` или "", если индекс вне диапазона. |
| `model:Duration(i)  -> number` | Длительность клипа `i` в секундах или 0, если индекс вне диапазона. |
| `model:PartCount()  -> number` | Число частей (экземпляров примитивов). |
| `model:PartMaterial(part)  -> number` | Индекс материала части (от 0) или -1, если индекс вне диапазона. |
| `model:MaterialCount()  -> number` | Число материалов glTF. |
| `model:MaterialName(mat)  -> string` | Имя материала glTF или "", если индекс вне диапазона. |
| `model:MaterialEmissive(mat)  -> r, g, b` | `emissiveFactor` материала из glTF или 0, 0, 0, если его нет. |
| `model:SetPartObject(part, objId)  -> nil` | Направляет треугольники части в отдельный объект сцены при Pose, чтобы эта часть могла нести собственные флаги прозрачности, свечения или зеркала; -1 сбрасывает маршрутизацию для этой части. |
| `model:ClearPartObjects()  -> nil` | Сбрасывает всю маршрутизацию частей. Вызывайте при выгрузке мира, поскольку экземпляр модели общий, а идентификаторы объектов после ClearObjects начинаются заново. |
| `model:GetBounds()  -> minX, minY, minZ, maxX, maxY, maxZ` | Границы бинд-позы в пространстве модели. |
| `model:BuildCollider(mc, x, y, z, yawDeg, scale)  -> nil` | Добавляет треугольники бинд-позы, размещённые с указанным преобразованием, в MeshCollider. Отрицательный масштаб действует как его модуль. |

## Карты высот

### HEIGHTMAP

<span class="badge-exp">Экспериментально</span>

Загружает сырые 16-битные поля высот и RGBA-изображения сплата для местности и строит всю местность одним вызовом.

<div class="callout warn">
Пути задаются относительно каталога скрипта. Файл поля высот содержит w x h беззнаковых 16-битных отсчётов с порядком байтов little-endian в построчном порядке; изображение сплата — RGBA PNG, каналы R, G, B, A которого являются весами слоёв с 1 по 4. При ошибке чтения оба загрузчика возвращают плоский запасной вариант.
</div>

| Метод | Описание |
| --- | --- |
| `HEIGHTMAP:Load(path, w, h)  -> heightfield` | Загружает поле высот из w x h отсчётов; при ошибке возвращает плоское нулевое поле. |
| `HEIGHTMAP:LoadSplat(path)  -> splatmap` | Загружает изображение сплата; при ошибке возвращает карту, целиком состоящую из слоя 1. Полностью непрозрачный альфа-канал означает, что у карты нет слоя 4. |
| `HEIGHTMAP:BuildTerrain(scene, floorObj, world, hf, splat, w, h, minY, maxY, cellSize, tex1, tex2, tex3, tex4, grassDensity, grassClump)  -> number` | Создаёт местность одним вызовом: по одному текстурированному кваду на ячейку в `floorObj` (отсчёт (ix, iz) располагается в мировых x = ix x cellSize, z = iz x cellSize, y = minY + отсчёт x (maxY - minY); каждая текстура слоя повторяется один раз на ячейку), соответствующие квады столкновений плюс невидимые пограничные стены в `world` (вызывайте между BeginStatic и EndStatic) и травинки на земле слоя 1 вдали от крутых склонов и края карты при `grassDensity` > 0 (`grassClump` > 0 группирует их в пятна). Без сплата крутые ячейки используют `tex2`, остальные — `tex1`. Возвращает число посаженных травинок. |

### Дескриптор поля высот

<span class="badge-exp">Экспериментально</span>

Загрузчик нормализует отсчёты к 0..1; мировая высота = minY + отсчёт x (maxY - minY).

| Метод | Описание |
| --- | --- |
| `heightfield:W()  -> number` | Ширина в отсчётах. |
| `heightfield:H()  -> number` | Высота в отсчётах. |
| `heightfield:At(ix, iz)  -> number` | Отсчёт в целочисленных координатах сетки, ограниченных краями. |
| `heightfield:Sample(fx, fz)  -> number` | Билинейная выборка в дробных координатах сетки. |
| `heightfield:Release()  -> nil` | Сбрасывает буфер отсчётов сейчас (выгрузка карты); после этого At и Sample возвращают 0. |

### Дескриптор сплат-карты

<span class="badge-exp">Экспериментально</span>

Слои нумеруются от 1 до 4 (каналы изображения R, G, B, A).

| Метод | Описание |
| --- | --- |
| `splat:W()  -> number` | Ширина в текселях. |
| `splat:H()  -> number` | Высота в текселях. |
| `splat:At(ix, iz)  -> number` | Преобладающий слой в целочисленных координатах текселя (1, если карта пуста). |
| `splat:Weight(layer, fx, fz)  -> number` | Билинейный вес (0-1, нормализованный относительно суммы каналов текселя) слоя в дробных координатах текселя. |
| `splat:RegisterSprite(scene, spriteId)  -> nil` | Регистрирует веса каналов как ARGB-спрайт с линейной фильтрацией для scene:ObjSetTerrainSplat. |
| `splat:Release()  -> nil` | Сбрасывает буферы сейчас (выгрузка карты); после этого At возвращает 1. |
