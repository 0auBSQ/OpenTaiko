# Справочник API

<span class="badge-new">Версия игры 0.6.1</span>

Справочник по всем глобальным объектам, которые среда выполнения Lua в OpenTaiko предоставляет скину. Выберите категорию в боковой панели или начните со страницы [Модули и жизненный цикл](activities.md), если вы ещё не писали модулей.

## Как читать сигнатуру

Каждая запись показывает функцию так, как вы вызываете её из Lua.

- Двоеточие означает, что вы вызываете функцию на значении, и Lua передаёт это значение как скрытый `self`: `tex:Draw(x, y)` вы вызываете на текстуре, которую загрузили раньше.
- Точка или голое имя означают обычный вызов, например `GetSaveFile(0)`.
- Тип после стрелки показывает, что возвращает вызов: `TEXTURE:CreateTexture(path) -> texture` возвращает дескриптор, который вы сохраняете и рисуете позже.

Имена глобальных объектов записываются в верхнем регистре (`TEXTURE`, `SOUND`, `INPUT`). Среда выполнения предоставляет их внутри каждого скрипта модуля; создавать их не нужно.

## Значок «Экспериментально»

Функции, помеченные как <span class="badge-exp">Экспериментально</span>, работают уже сейчас, но могут измениться между выпусками без периода устаревания. 3D-движок и сетевая игра сейчас несут этот значок; по плану 3D-движок выйдет из экспериментального статуса в версии 1.0. Если скин зависит от экспериментальных функций, проверяйте его заново после каждого обновления и указывайте, на какую версию игры он рассчитан.
