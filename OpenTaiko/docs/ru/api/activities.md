# Модули и жизненный цикл

Движок вызывает фиксированный набор обратных вызовов в Script.lua модуля. На этой странице они перечислены вместе с глобальными объектами, управляющими активностями, фонами и переходами, а также вспомогательными объектами счётчиков, камеры и диагностики, которые получает каждый модуль. Если вы ещё не писали модулей, сначала прочитайте [Как работают модули](../getting-started.md).

## Обратные вызовы жизненного цикла

Движок ищет глобальные функции верхнего уровня по имени в Script.lua каждого модуля и вызывает их в фиксированные моменты. Обратный вызов, который вы не определили, движок пропускает. Какие обратные вызовы вызывает движок, определяет вид модуля.

<div class="callout warn">
При загрузке скина движок создаёт и запускает модули в следующем порядке: Transitions, Stages, Activities, ROActivities. Внутри каждого вида движок сначала выполняет Script.lua каждого модуля (его код верхнего уровня), затем вызывает у каждого из них onStart. Поэтому, пока выполняется onStart сцены, Activity и ROActivity ещё не загружены, и поиск там возвращает nil: ищите их в activate. При смене скина или выходе onDestroy выполняется у Stages, затем у ROActivities и Activities, затем у Transitions.
</div>

### Сцены, Activity и ROActivity

| Метод | Описание |
| --- | --- |
| `onStart()` | Вызывается один раз после того, как движок создал модуль, что происходит при запуске и снова при каждой загрузке или перезагрузке скина движком. Выполняется как корутина (см. LOADING ниже); загружайте ресурсы здесь. |
| `activate(...)` | Сцена: вызывается при каждом входе движка в сцену, как корутина. Activity/ROActivity: хост вызывает его через `handle:Activate(...)` со своими аргументами; возвращаемые значения передаются хосту. Движок обновляет глобальные объекты CHARACTERLIST и PUCHICHARALIST непосредственно перед его запуском. |
| `update(timestamp)` | Вызывается каждый кадр перед draw; timestamp — игровые часы в миллисекундах. Сцена перестаёт получать update после вызова Exit; draw продолжает выполняться на протяжении затемнения. Activity/ROActivity: хост вызывает его через `handle:Update()`. |
| `draw(...)` | Вызывается каждый кадр. Activity/ROActivity: хост вызывает его через `handle:Draw(...)` со своими аргументами; возвращаемые значения передаются хосту. |
| `deactivate(...)` | Сцена: вызывается, когда движок покидает сцену. Activity/ROActivity: хост вызывает его через `handle:Deactivate(...)`, либо модуль вызывает его у самого себя через `DEACTIVATE()`; возвращаемые значения передаются хосту. |
| `afterSongEnum()` | Вызывается при каждом завершении перечисления песен, включая запуск и мягкую или полную перезагрузку песен, даже если модуль не активен. |
| `onDestroy()` | Вызывается перед тем, как движок выгрузит скин, чтобы модуль мог освободить то, что удерживает. |
| `reloadLanguage(lang)` | Вызывается у каждого загруженного модуля при смене языка игры; lang — новый код языка. |

### Фоны

Каждый экран размещает собственные фоны. Раздел «Фоны» ниже описывает аргумент state и обработчики событий.

| Метод | Описание |
| --- | --- |
| `onStart()` | Вызывается один раз, синхронно, при первой активации фона хостом. |
| `activate(state)` | Вызывается при каждой активации фона хостом; повторная активация не запускает onStart заново. |
| `update(timestamp, state)` | Вызывается каждый кадр (но не во время паузы игрового процесса); timestamp — это `state.timeStamp` в миллисекундах. |
| `draw(state)` | Вызывается каждый кадр. |
| `reloadLanguage(lang)` | Вызывается при смене языка игры. |

Движок не вызывает у фонов afterSongEnum и onDestroy; когда хост уничтожает фон, движок освобождает созданные им ресурсы.

### Переходы

| Метод | Описание |
| --- | --- |
| `onStart()` | Вызывается один раз при загрузке скина, до сцен и активностей, как корутина. |
| `fadeOut(t)` | Рисует затемнение поверх уходящей сцены; t идёт от 0 до 1. |
| `loading(progress, elapsed)` | Рисует экран загрузки; progress от 0 до 1, elapsed — время в секундах с начала загрузки. |
| `fadeIn(t)` | Рисует появление поверх новой сцены; t идёт от 0 до 1. |
| `onDestroy()` | Вызывается перед тем, как движок выгрузит скин, после сцен и активностей. |
| `reloadLanguage(lang)` | Вызывается при смене языка игры. |

### Exit

Функция, которую движок регистрирует только в скриптах сцен; её вызов просит движок покинуть сцену.

<div class="callout warn">
Доступна только в скриптах Modules/Stages; Activity и ROActivity управляет их хост, и они её не получают. Принимает от 0 до 3 аргументов и допускает nil в любой позиции. Сам вызов запрашивает выход; поставляемые сцены пишут `return Exit(...)` внутри update, чтобы в этом кадре больше ничего не выполнялось. target — это "title", "play", "stage" или "legacy"; nil или любое другое значение означает "title". Когда target равен "stage", name — это модуль Modules/Stages, к которому нужно перейти; когда target равен "legacy", name — одно из "heya", "config", "exit" или "onlinelounge" (любое другое значение ведёт на титульный экран). transition называет модуль Modules/Transitions; если вы его опустили или движок не может его найти, движок использует модуль с именем "default", а если у скина вообще нет переходов, проигрывается простое затемнение в чёрный.
</div>

| Метод | Описание |
| --- | --- |
| `Exit(target?, name?, transition?)  -> number` | Запрашивает выход из сцены к указанной цели, при необходимости называя целевой модуль и модуль перехода; возвращает 0. |

```lua
function update(timestamp)
    if INPUT:KeyboardPressed("S") then
        return Exit("stage", "demo2")          -- переход в Modules/Stages/demo2
    end
    if INPUT:Pressed("Cancel") then
        return Exit("title", nil, "nokon_curtain")   -- назад на титульный экран через именованный переход
    end
end
```

### LOADING

Вспомогательный объект полосы загрузки для обратных вызовов, выполняемых как корутины: onStart модуля любого вида и activate сцены.

<div class="callout warn">
Определён как глобальный объект LOADING в каждом модуле. Эти обратные вызовы выполняются в корутине, принадлежащей движку, которую движок возобновляет каждый кадр: движок автоматически уступает управление, как только возобновление исчерпало свой бюджет времени, а вы можете уступить его сами через coroutine.yield(progress) или LOADING:Tick(sub). Блоки, которые вы регистрируете через LOADING:Add, выполняются по порядку после возврата из тела обратного вызова, и полоса продвигается после каждого из них; вес блока — его доля полосы (по умолчанию 1). LOADING:Tick(sub) уступает один кадр изнутри блока и сообщает долю от 0 до 1 внутри этого блока. Вне обратного вызова-корутины (activate Activity или ROActivity, любой update или draw) LOADING:Tick возбуждает ошибку Lua, потому что уступать управление некому, а блоки, поставленные в очередь через LOADING:Add, никогда не выполняются.
</div>

| Метод | Описание |
| --- | --- |
| `LOADING:Add(fn)  -> nil` | Регистрирует блок загрузки, выполняемый после возврата из обратного вызова. |
| `LOADING:Add(label, fn)  -> nil` | Регистрирует блок загрузки с меткой. |
| `LOADING:Add(label, weight, fn)  -> nil` | Регистрирует блок загрузки с меткой и явным весом. |
| `LOADING:Tick(sub)  -> nil` | Уступает один кадр внутри блока, сообщая долю подпрогресса от 0 до 1 в текущем блоке. |

```lua
function onStart()
    LOADING:Add("textures", 3, function()
        for i, name in ipairs(names) do
            tx[name] = TEXTURE:CreateTexture(name)
            LOADING:Tick(i / #names)
        end
    end)
    LOADING:Add("sounds", 1, function()
        bgm = SOUND:CreateBGM("Sounds/BGM.ogg")
    end)
end
```

## Активности

### ACTIVITY

Глобальный объект для поиска загруженной Activity по имени.

<div class="callout warn">
Регистрируется как глобальный объект ACTIVITY в каждом модуле, кроме ROActivity и фонов, где он равен nil; эти модули используют ROACTIVITY. Движок загружает Activity из Modules/Activities/{name}. ACTIVITY также предоставляет GetROActivity, который ведёт себя как ROACTIVITY:GetROActivity.
</div>

| Метод | Описание |
| --- | --- |
| `ACTIVITY:GetActivity(name)  -> activity handle` | Возвращает дескриптор загруженной Activity с указанным именем папки или nil, если она не загружена. |
| `ACTIVITY:GetROActivity(name)  -> activity handle` | То же, что ROACTIVITY:GetROActivity. |

### ROACTIVITY

Глобальный объект для поиска загруженной Activity только для чтения (ROActivity) по имени.

<div class="callout warn">
Регистрируется как глобальный объект ROACTIVITY в каждом модуле. Движок загружает ROActivity из Modules/ROActivities/{name} и даёт им глобальные объекты CONFIG, DATABASE и GetSaveFile только для чтения, поэтому их скрипты не могут изменять состояние игры (см. раздел о модулях только для чтения на странице «Как работают модули»). Activity и ROActivity — синглтоны с ключом по имени: один экземпляр на папку, общий для всех хостов.
</div>

| Метод | Описание |
| --- | --- |
| `ROACTIVITY:GetROActivity(name)  -> activity handle` | Возвращает дескриптор загруженной ROActivity с указанным именем папки или nil, если она не загружена. |

### Дескриптор активности

Объект, который возвращают ACTIVITY:GetActivity и ROACTIVITY:GetROActivity. Хост использует его для управления обратными вызовами модуля.

<div class="callout warn">
Activate, Deactivate и Draw передают свои аргументы в обратные вызовы activate, deactivate и draw модуля. Update вызывает update с текущим игровым временем в миллисекундах. Каждый из них возвращает значения, возвращённые обратным вызовом, в виде массива с индексацией от 0, или nil, если обратный вызов ничего не вернул или не определён; первое значение читайте как `result[0]`. Call вызывает любую глобальную функцию, которую определяет скрипт модуля.
</div>

| Метод | Описание |
| --- | --- |
| `handle.IsActive  -> boolean` | Истина после выполнения Activate и до выполнения Deactivate (или собственного DEACTIVATE() модуля). |
| `handle:Activate(...)  -> array` | Вызывает обратный вызов activate модуля с указанными аргументами. |
| `handle:Deactivate(...)  -> array` | Вызывает обратный вызов deactivate модуля с указанными аргументами. |
| `handle:Update()  -> array` | Вызывает обратный вызов update модуля с текущим игровым временем в миллисекундах. |
| `handle:Draw(...)  -> array` | Вызывает обратный вызов draw модуля с указанными аргументами. |
| `handle:Call(functionName, ...)  -> array` | Вызывает именованную глобальную функцию скрипта модуля с указанными аргументами. |

```lua
local act = nil

function activate()
    if act == nil then act = ACTIVITY:GetActivity("song_select_core") end
    act:Activate()
end

function update(timestamp)
    local result = act:Update()
    local signal = result ~= nil and result[0] or nil
    if signal == "play" then return Exit("play", nil) end
    if signal == "cancel" then return Exit("title", nil) end
end

function draw()
    act:Draw()
end

function deactivate()
    act:Deactivate()
end
```

### DEACTIVATE

Функция, которую движок регистрирует внутри скриптов Activity и ROActivity; она позволяет модулю деактивировать самого себя.

<div class="callout warn">
Её вызов помечает модуль неактивным (handle.IsActive становится false) и выполняет собственный обратный вызов deactivate модуля. Поставляемые диалоги вызывают её, когда игрок подтверждает или отменяет действие, а хост следит за IsActive, чтобы узнать, что диалог закрылся.
</div>

| Метод | Описание |
| --- | --- |
| `DEACTIVATE(...)` | Деактивирует текущий модуль и вызывает его обратный вызов deactivate с указанными аргументами. |

### ROActivity, размещаемые движком

Некоторые ROActivity движок ищет по фиксированному имени папки и управляет ими сам. Скин заменяет одну из них, поставляя папку Modules/ROActivities с таким именем; точки вызова движка, перечисленные ниже, задают обратные вызовы, которые она должна определять. Если какой-то из них отсутствует, движок не рисует соответствующую возможность.

| Имя | Что вызывает движок |
| --- | --- |
| `nameplate` | `activate(player, name, title, dan, data)` при изменении таблички игрока; `update()` раз в кадр; `draw(mode, ...)`, где mode 0 = полная табличка `(x, y, opacity, player, side)`, 1 = табличка дана `(x, y, opacity, danGrade, textTexture)`, 2 = табличка титула `(x, y, opacity, type, textTexture, rarity, nameplateId)`. |
| `modal` | `activate(player, rarity, modalType, ...)` для каждого модального окна разблокировки в очереди, затем `update()` и `draw()` каждый кадр. Скрипт вызывает DEACTIVATE(), чтобы закрыть окно; затем движок активирует следующее. |
| `modicons` | `activate()` один раз, затем `draw(x, y, player, layout, alpha)` с layout "menu" или "game". Глобальный объект MODICONS оборачивает эту ROActivity. |
| `danplate` | `draw(x, y, opacity, danTick, r, g, b, titleText)` на экране результатов и в дан-курсах. |
| `popup_menu` | `activate(title, items, fontSize, ...)`, где items — метки, соединённые переносами строк, за которыми следуют позиции PopupMenu из скина; `draw(selected)` каждый кадр; `deactivate()` при закрытии. |
| `config_ui` | `activate(model)` с моделью настроек; `update()` каждый кадр, возвращающий "exit" для выхода с экрана настроек; `draw()`; `reload(model)` через Call, когда движок перестраивает модель; `deactivate()`. |
| `song_enum` | `activate()`, затем `draw(isCommandSongDataGet, done, total)` каждый кадр, пока идёт сканирование песен; `deactivate()`. |

## Фоны

### Модуль фона

Script.lua, который рисует один фон экрана, слой игрового процесса, толпу, анимацию клира или эффект кусудамы и размещается собственными экранами движка.

<div class="callout warn">
Фоны живут вне папки Modules, в папке Graphics скина, в каталоге того экрана, который они украшают, например Graphics/0_Startup/Script.lua, Graphics/10_Heya/Script.lua, Graphics/6_Result/Script.lua, Graphics/5_Game/5_Background/Normal/Up/{variant}/Script.lua, Graphics/5_Game/5_Background/Normal/Down/{variant}/Script.lua, Graphics/5_Game/3_Mob/{variant}/Script.lua, Graphics/5_Game/9_End/{result}/Script.lua и Graphics/5_Game/11_Balloon/Kusudama/Script.lua. Если папка содержит несколько вариантов, движок при каждой игре выбирает один из них случайно (или из пресета сцены в чарте). Экран-хост создаёт экземпляр фона (игровые фоны — при каждом входе движка на игровой экран) и уничтожает его вместе с экраном, поэтому во время игры одновременно живут несколько экземпляров. Скрипт фона получает те же глобальные объекты, что и ROActivity (CONFIG, DATABASE и GetSaveFile только для чтения; без ACTIVITY). Обработчики событий ниже необязательны, и движок вызывает каждый из них один раз, когда происходит его событие.
</div>

| Метод | Описание |
| --- | --- |
| `clearIn(player)` | Игровые фоны Up и Down: шкала игрока вошла в зону клира. |
| `clearOut(player)` | Игровые фоны Up и Down: шкала игрока вышла из зоны клира. |
| `playEndAnime(player)` | Анимации клира (Graphics/5_Game/9_End): для игрока начинается финальная анимация. |
| `kusuIn()` / `kusuBroke()` / `kusuMiss()` | Кусудама: шар появился, игрок разбил его или игрок его пропустил. |
| `skipAnime()` | Фон результатов: игрок пропустил анимацию результатов. |

### Состояние фона

Объект, который хост передаёт в activate, update и draw фона.

<div class="callout warn">
Один экземпляр на хост, который хост обновляет на месте каждый кадр. Поля-массивы разделяют массивы движка по игрокам и индексируются от 0 (`state.gauge[0]` — игрок 1). Игровые поля обновляют только игровые хосты; остальные хосты оставляют их со значениями по умолчанию, а timeStamp вне игрового процесса остаётся равным -1. Состояние не несёт тайминга кадров: читайте глобальный объект fps.
</div>

| Метод | Описание |
| --- | --- |
| `state.playerCount  -> number` | Число игроков. |
| `state.p1IsBlue  -> boolean` | Истина, когда игрок 1 использует синюю сторону. |
| `state.lang  -> string` | Текущий код языка. |
| `state.simplemode  -> boolean` | Истина, когда включён Simple Mode. |
| `state.puchicharaRarities  -> string[]` | Редкость пучичары каждого игрока. |
| `state.characterRarities  -> string[]` | Редкость персонажа каждого игрока. |
| `state.isClear  -> boolean[]` | Находится ли каждый игрок сейчас в зоне клира. |
| `state.gauge  -> number[]` | Значение шкалы каждого игрока. |
| `state.bpm  -> number[]` | Текущий BPM каждого игрока. |
| `state.gogo  -> boolean[]` | Находится ли каждый игрок в гоу-гоу-тайме. |
| `state.towerNightNum  -> number` | Коэффициент перехода от дня к ночи в башне, от 0 до 1. |
| `state.battleState  -> number` | Код состояния битвы с ИИ. |
| `state.battleWin  -> boolean` | Истина, когда игрок выигрывает битву с ИИ. |
| `state.timeStamp  -> number` | Время, синхронизированное с чартом, в секундах; -1 вне игрового процесса. |
| `state.paused  -> boolean` | Истина, пока игровой процесс на паузе. |
| `state.player  -> number` | Игрок, для которого рисует хост с привязкой к игроку (анимации клира). |

## Переходы

### Модуль перехода

Modules/Transitions/{name}/Script.lua, который рисует фазы затемнения, загрузки и появления между двумя сценами.

<div class="callout warn">
Третий аргумент Exit выбирает переход; движок использует "default", когда вызов не указал имя или движок не может найти указанное. Загрузка в игровой процесс после Exit("play") всегда использует переход с именем "song_loading" или "default", если его в скине нет. Движок проводит фазы по порядку: вызывает fadeOut(t) каждый кадр поверх уходящей сцены, пока t не достигнет 1, затем размонтирует уходящую сцену и загружает новую, вызывая каждый кадр loading(progress, elapsed), затем вызывает fadeIn(t) поверх новой сцены, пока t не достигнет 1. Каждая фаза затемнения длится 0,5 секунды, если скрипт не задал FADE_OUT_SECONDS или FADE_IN_SECONDS; значение, не являющееся положительным числом, движок игнорирует. При переключении сцен движок вызывает loading только тогда, когда загрузка длится дольше 0,5 секунды; до этого он вызывает fadeOut(1), чтобы короткие загрузки не мигали экраном загрузки. Путь загрузки песни показывает фазу загрузки сразу.
</div>

| Метод | Описание |
| --- | --- |
| `FADE_OUT_SECONDS  -> number` | Необязательная глобальная переменная верхнего уровня: длительность затемнения в секундах. |
| `FADE_IN_SECONDS  -> number` | Необязательная глобальная переменная верхнего уровня: длительность появления в секундах. |

```lua
FADE_OUT_SECONDS = 0.3
FADE_IN_SECONDS = 0.3

local pixel = nil

local function cover(alpha)
    pixel:SetColor(0, 0, 0)
    pixel:SetOpacity(alpha)
    pixel:SetScale(8000, 8000)
    pixel:Draw(0, 0)
end

function onStart()
    pixel = TEXTURE:CreateTexture("pixel.png")
end

function fadeOut(t) cover(t) end
function fadeIn(t) cover(1.0 - t) end
function loading(progress, elapsed) cover(1.0) end

function onDestroy()
    if pixel ~= nil then pixel:Dispose() end
end
```

## Тайминг и камера

### COUNTER

Фабрика счётчиков анимации, которые перемещают значение от начального к конечному за время.

<div class="callout warn">
Регистрируется как глобальный объект COUNTER. Счётчик продвигается только при вызове Tick — на дельту кадра, делённую на interval, где interval — число секунд на единицу значения. Знак interval должен соответствовать направлению: положительный, когда end больше begin, отрицательный, когда меньше. Если знаки не совпадают, счётчик меняет концы местами и завершается на первом же тике. CreateCounterDuration принимает общую длительность и выбирает знак сам. Нулевой interval или равные begin и end завершают счётчик на первом тике. Счётчик вызывает необязательную функцию ended, когда значение достигает конца, и по одному разу на каждый завершённый цикл при зацикливании или отскоке.
</div>

| Метод | Описание |
| --- | --- |
| `COUNTER:CreateCounter(begin, end, interval, ended?)  -> counter` | Создаёт счётчик, движущийся от begin к end со скоростью interval секунд на единицу и вызывающий ended по завершении. |
| `COUNTER:CreateCounterDuration(begin, end, seconds, ended?)  -> counter` | Создаёт счётчик, движущийся от begin к end за указанное число секунд; возвращает пустой счётчик, если seconds не положительно или begin равен end. |
| `COUNTER:EmptyCounter()  -> counter` | Создаёт инертный счётчик, значение которого остаётся 0; пригоден как заглушка. |

### Дескриптор счётчика

Счётчик, созданный через COUNTER.

<div class="callout warn">
Читайте Value каждый кадр и вызывайте Tick каждый кадр, чтобы продвигать счётчик; счётчик, который вы не запустили или который остановился, игнорирует Tick. Begin, End и Interval — поля, доступные для чтения и записи. SetLoop и SetBounce исключают друг друга. SetEasing только формирует сообщаемое Value; внутри счётчик по-прежнему продвигается линейно. Слушатели получают текущее значение на каждом тике, включая последний.
</div>

| Метод | Описание |
| --- | --- |
| `counter.Value  -> number` | Текущее значение с применённой функцией сглаживания, если она задана; присваивание переводит счётчик на это значение. |
| `counter.Begin  -> number` | Начальное значение (чтение и запись). |
| `counter.End  -> number` | Конечное значение (чтение и запись). |
| `counter.Interval  -> number` | Секунд на единицу значения (чтение и запись). |
| `counter:Start()  -> nil` | Сбрасывает значение в Begin и начинает тикать. |
| `counter:Resume()  -> nil` | Начинает тикать без сброса значения. |
| `counter:Stop()  -> nil` | Останавливает тики. |
| `counter:Pause()  -> nil` | То же, что Stop. |
| `counter:Reset()  -> nil` | Возвращает значение в Begin, не меняя того, тикает ли счётчик. |
| `counter:Tick()  -> nil` | Продвигает значение на один кадр, вызывая слушателей и функцию ended при необходимости. |
| `counter:SetLoop(loop)  -> nil` | Возвращает к Begin, когда значение достигает конца; выключает отскок. |
| `counter:SetBounce(bounce)  -> nil` | Меняет направление, когда значение достигает любого из концов; выключает зацикливание. |
| `counter:GetLoop()  -> boolean` | Включено ли зацикливание. |
| `counter:GetBounce()  -> boolean` | Включён ли отскок. |
| `counter:SetEasing(type, function)  -> nil` | Применяет кривую сглаживания к сообщаемому значению; type — IN, OUT, INOUT или OUTIN, function — LINEAR, SINE, QUAD, CUBIC, QUART, QUINT, EXPO, CIRC, ELASTIC, BACK или BOUNCE (без учёта регистра; неизвестное имя счётчик игнорирует). |
| `counter:ClearEasing()  -> nil` | Убирает сглаживание. |
| `counter:Listen(listener)  -> nil` | Регистрирует функцию, вызываемую с текущим значением на каждом тике. |
| `counter:ClearListeners()  -> nil` | Удаляет всех слушателей. |

```lua
local fade = nil

function activate()
    fade = COUNTER:CreateCounterDuration(0, 1, 0.5, function() debugLog("fade done") end)
    fade:SetEasing("OUT", "QUAD")
    fade:Start()
end

function update(timestamp)
    fade:Tick()
end

function draw()
    background:SetOpacity(fade.Value)
    background:Draw(0, 0)
end
```

### GLOBALCAMERA

2D-камера всего экрана: она сдвигает, масштабирует и поворачивает весь отрисованный кадр и добавляет затухающую тряску экрана.

<div class="callout warn">
Регистрируется как глобальный объект GLOBALCAMERA. Управляет тем же преобразованием экрана, что и команды #CAMERA в TJA, и влияет на всё нарисованное, включая выведенные 3D-сцены. Смещения задаются в опорных пикселях 1280x720, поворот — в градусах, а зум 1 означает отсутствие масштабирования. Базовое преобразование сохраняется, пока вы его не измените: вызывайте Update(dt) каждый кадр, чтобы применить его и продвинуть тряску, и Reset() при выходе из сцены, чтобы оно не переносилось в следующую. Собственную камеру 3D-сцены вы задаёте на объекте сцены.
</div>

| Метод | Описание |
| --- | --- |
| `GLOBALCAMERA:SetOffset(x, y)  -> nil` | Сдвигает экран на (x, y) пикселей. |
| `GLOBALCAMERA:SetZoom(sx, sy)  -> nil` | Масштабирует экран с раздельными коэффициентами по X и Y. |
| `GLOBALCAMERA:SetUniformZoom(s)  -> nil` | Масштабирует экран равномерно. |
| `GLOBALCAMERA:SetRotation(deg)  -> nil` | Поворачивает экран вокруг его центра. |
| `GLOBALCAMERA:GetOffsetX()  -> number` | Базовое смещение по X. |
| `GLOBALCAMERA:GetOffsetY()  -> number` | Базовое смещение по Y. |
| `GLOBALCAMERA:GetZoomX()  -> number` | Коэффициент зума по X. |
| `GLOBALCAMERA:GetZoomY()  -> number` | Коэффициент зума по Y. |
| `GLOBALCAMERA:GetRotation()  -> number` | Базовый поворот в градусах. |
| `GLOBALCAMERA:Shake(amplitudePx, seconds, rotAmpDeg?)  -> nil` | Запускает тряску, линейно затухающую от указанной амплитуды в пикселях за указанное число секунд, с необязательным вращательным покачиванием в градусах. Вызов с seconds, равным 0 или меньше, камера игнорирует; новая тряска заменяет текущую, только когда её амплитуда равна или больше. |
| `GLOBALCAMERA.IsShaking  -> boolean` | Истина, пока тряска ещё затухает. |
| `GLOBALCAMERA:Update(dt)  -> nil` | Продвигает тряску на dt секунд (ограничено 0,25) и применяет к экрану базовое преобразование плюс тряску. |
| `GLOBALCAMERA:Reset()  -> nil` | Возвращает камеру в центр, сбрасывает зум и поворот и останавливает тряску. |

```lua
function update(timestamp)
    if INPUT:Pressed("LRed") or INPUT:Pressed("RRed") then GLOBALCAMERA:Shake(18, 0.35) end
    GLOBALCAMERA:Update(fps.deltaTime)
end

function deactivate()
    GLOBALCAMERA:Reset()
end
```

## Перечисление песен

Две глобальные функции сообщают состояние сканирования песен. Используйте их вместе с обратным вызовом afterSongEnum.

| Метод | Описание |
| --- | --- |
| `IsSongsEnumerating()  -> boolean` | Истина, пока выполняется проход перечисления песен. |
| `IsSongsEnumDone()  -> boolean` | Истина после завершения сканирования песен. Ложна до начала сканирования и во время него; IsSongsEnumerating ложна и в незапущенном, и в завершённом состоянии, поэтому, чтобы узнать, что список готов, проверяйте эту функцию. |
