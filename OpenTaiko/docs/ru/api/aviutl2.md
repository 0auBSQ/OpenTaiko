# Проекты AviUtl2

Глобальный объект `AVIUTL2` воспроизводит файлы проектов, сохранённые видеоредактором AviUtl2 (`.aup2`). Игра читает проект и рисует его объекты, движения и эффекты на лету, поэтому скин может поставлять анимацию в виде проекта с его изображениями вместо отрендеренного видео.

Дескриптором проекта владеет загрузивший его скрипт, и игра освобождает дескриптор при выгрузке этого скрипта. Вызовите `Dispose()` сами, чтобы освободить его раньше.

<div class="callout warn">
Игра рисует проект собственным рендерером. Позиции, размеры, повороты, кривые движения, управление камерой и распространённые эффекты соответствуют редактору. Случайные движения и тряска используют другие случайные значения, а некоторые эффекты приближённые. После загрузки проекта прочитайте GetUnsupported и GetApproximated, чтобы узнать, что игра пропустила или упростила.
</div>

## Загрузка

### AVIUTL2

| Метод | Описание |
| --- | --- |
| `AVIUTL2:LoadProject(path)  -> project` | Открывает файл проекта и возвращает его дескриптор. Путь задаётся относительно каталога скрипта. |
| `AVIUTL2:LoadProjectFromAbsolutePath(path)  -> project` | Открывает файл проекта по полному пути. |

<div class="callout warn">
Проект хранит полные пути того компьютера, на котором его сохранили. Игра ищет каждое изображение, видео, звук и модель рядом с файлом проекта: сначала по папкам, общим у сохранённого пути и пути самого проекта, затем по имени файла. Храните файлы проекта в его папке или в её подпапках. Отсутствующий или нечитаемый проект возвращает дескриптор, у которого Loaded равно false.
</div>

## Дескриптор проекта

Проект, возвращаемый `AVIUTL2:LoadProject`. Его методы воспроизведения называются так же, как у дескриптора видео.

### Воспроизведение

| Метод | Описание |
| --- | --- |
| `project:Start()  -> nil` | Запускает воспроизведение с начала. |
| `project:Resume()  -> nil` | Возобновляет воспроизведение после Pause. |
| `project:Pause()  -> nil` | Приостанавливает воспроизведение вместе со звуками. |
| `project:Stop()  -> nil` | Останавливает воспроизведение. |
| `project:Reset()  -> nil` | Перематывает на начало. |
| `project.IsPlaying  -> bool` | True, пока проект воспроизводится и не дошёл до конца. |
| `project:IsFinished()  -> bool` | True после того, как проект без повтора дошёл до конца. |
| `project:GetTimestampMs()  -> number` | Текущая позиция в миллисекундах. |
| `project:SetTimestampMs(ms)  -> nil` | Перематывает на позицию в миллисекундах. |
| `project:GetFrame()  -> number` | Текущая позиция в кадрах проекта. |
| `project:SetFrame(frame)  -> nil` | Перематывает на кадр. |
| `project:GetSpeed()  -> number` | Текущий множитель скорости воспроизведения (1 = обычная). |
| `project:SetSpeed(speed)  -> nil` | Задаёт множитель скорости воспроизведения. |
| `project:GetLoop()  -> bool` | True, если проект в конце начинается заново. |
| `project:SetLoop(loop)  -> nil` | Заставляет проект в конце начинаться заново. |
| `project:GetVolumePercent()  -> number` | Громкость звуков проекта в процентах. |
| `project:SetVolumePercent(vol)  -> nil` | Задаёт громкость звуков проекта в процентах. |
| `project:Dispose()  -> nil` | Освобождает проект, его изображения, видео и звуки. |

### Рисование

| Метод | Описание |
| --- | --- |
| `project:Draw(x, y)  -> nil` | Рисует текущий кадр с левым верхним углом в (x, y) в масштабе, заданном через SetScale. |
| `project:DrawFit(x, y, w, h)  -> nil` | Рисует текущий кадр настолько крупно, насколько позволяет рамка, с сохранением пропорций и по центру рамки. |
| `project:SetScale(scaleX, scaleY)  -> nil` | Задаёт масштаб, который использует Draw (1 = собственный размер проекта). |
| `project:SetOpacity(opacity)  -> nil` | Задаёт непрозрачность всего кадра от 0 до 1. |
| `project:SetBackground(r, g, b, a)  -> nil` | Заливает кадр позади объектов цветом, каждое значение от 0 до 255. При альфе 0 кадр остаётся прозрачным. |
| `project:ClearBackground()  -> nil` | Возвращает фон, заданный в файле проекта. |
| `project.HasProjectBackground  -> bool` | True, если у сцены есть собственный цвет фона. |
| `project.ProjectBackground  -> int` | Цвет фона сцены в виде 0xRRGGBB или -1, если его нет. |

<div class="callout warn">
Сцена без цвета фона прозрачна там, где не нарисован ни один объект, поэтому проект рисуется поверх всего, что скрипт нарисовал до него. Редактор показывает такую сцену на чёрном. Чтобы получить ту же картинку, сначала нарисуйте чёрный прямоугольник или вызовите SetBackground(0, 0, 0, 255).
</div>

### Изображения, которые рисует скрипт

Скрипт может заменить изображение проекта собственным рисунком, например чтобы показать табличку имени игрока внутри анимированной рамки.

| Метод | Описание |
| --- | --- |
| `project:SetImageDrawer(fileName, width, height, draw)  -> nil` | Каждый объект, показывающий файл изображения `fileName`, показывает то, что рисует функция `draw`. Игра вызывает `draw` каждый кадр с областью рисования `width` на `height`, левый верхний угол которой находится в (0, 0). |
| `project:ClearImageDrawer(fileName)  -> nil` | Объекты снова показывают файл изображения. |

Игра вызывает `draw(rank, layer)` один раз для каждого слоя, содержащего такой объект. `rank` считает эти слои с 0, начиная с самого верхнего, а `layer` равен номеру слоя в проекте. Внутри `draw` используйте обычные вызовы рисования: игра перенаправляет их в изображение, которое затем движется, масштабируется и затухает вместе с объектом.

<div class="callout warn">
Функция должна принадлежать скрипту, который вызывает SetImageDrawer. Мягкие края, нарисованные внутри `draw`, получаются чуть тоньше, чем на экране.
</div>

### Чтение проекта

| Метод | Описание |
| --- | --- |
| `project.Loaded  -> bool` | True, если файл прочитан. |
| `project.Width  -> int` | Ширина сцены в пикселях или -1, если ничего не загружено. |
| `project.Height  -> int` | Высота сцены в пикселях или -1, если ничего не загружено. |
| `project.FrameRate  -> number` | Число кадров в секунду у сцены. |
| `project.FrameCount  -> int` | Длина сцены в кадрах. |
| `project.DurationMs  -> number` | Длина сцены в миллисекундах. |
| `project.SceneCount  -> int` | Количество сцен в проекте. |
| `project:GetScene()  -> int` | Индекс воспроизводимой сцены. |
| `project:SetScene(index)  -> nil` | Воспроизводит другую сцену проекта с её начала. |
| `project:GetSceneName(index)  -> string` | Имя сцены. |
| `project.ObjectCount  -> int` | Количество объектов в сцене. |
| `project:GetProjectValue(key)  -> string` | Настройка проекта в том виде, в каком она записана в файле. |
| `project:GetSceneValue(key)  -> string` | Настройка воспроизводимой сцены. |
| `project:GetValue(section, key)  -> string` | Настройка любого раздела файла по имени раздела (`"12"` для объекта, `"12.1"` для его второго эффекта). |
| `project:GetValueAtFrame(objectId, effect, key, frame)  -> number` | Числовая настройка эффекта объекта на заданном кадре с учётом её движения. |

### Проверка того, что рисуется

| Метод | Описание |
| --- | --- |
| `project.UnsupportedCount  -> int` | Количество вещей, которые проект использует, а игра не рисует, включая отсутствующие файлы. |
| `project:GetUnsupported()  -> string` | Эти вещи, по одной на строку. |
| `project.ApproximatedCount  -> int` | Количество вещей, которые игра рисует упрощённо. |
| `project:GetApproximated()  -> string` | Эти вещи, по одной на строку. |
| `project:AddScriptFolder(path)  -> nil` | Добавляет папку с файлами скриптов AviUtl, на которые могут ссылаться эффекты проекта. Папку `Script` рядом с файлом проекта игра читает сама. |
| `project.ScriptErrorCount  -> int` | Количество файлов скриптов, завершившихся ошибкой. |
| `project:GetScriptErrors()  -> string` | Первая ошибка каждого такого скрипта, по одной на строку. |
| `project.GraphicsMemoryMB  -> number` | Графическая память, которую проект сейчас занимает под собственное рисование, в мегабайтах. |
| `project:SetSurfaceBudgetMB(mb)  -> nil` | Задаёт, сколько графической памяти проект сохраняет для повторного использования между кадрами. |

<div class="callout warn">
Файлы скриптов, поставляемые с проектом, выполняются в закрытой среде: они не могут читать и записывать файлы, запускать программы и загружать нативные модули.
</div>

```lua
local intro
local box

function onStart()
    intro = AVIUTL2:LoadProject("Intro/intro.aup2")
    box = TEXTURE:CreateTexture("Intro/player_box.png")
    -- табличка имени каждого игрока, нарисованная в рамках игроков проекта
    intro:SetImageDrawer("player_box.png", 520, 216, function(rank)
        box:Draw(0, 0)
        NAMEPLATE:DrawPlayerNameplate(170, 88, 255, rank)
    end)
end

function activate()
    intro:SetBackground(0, 0, 0, 255)
    intro:Start()
end

function draw()
    intro:DrawFit(0, 0, 1920, 1080)
    if intro:IsFinished() then Exit("title", nil) end
end

function deactivate()
    intro:Stop()
end

function onDestroy()
    intro:Dispose()
    box:Dispose()
end
```
