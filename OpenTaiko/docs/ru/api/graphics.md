# Графика и текст

Текстуры, холсты, отсечение, текст, видео, цвета, карты градиентов и размеры. Все позиции и размеры задаются в логических пикселях экрана — системе координат, в которой рисуют скрипты (см. `INPUT:GetSurfaceWidth()` / `GetSurfaceHeight()`).

Дескриптором текстуры, холста, текста, видео или градиента владеет создавший его скрипт, и игра освобождает дескриптор при выгрузке этого скрипта. Вызовите `Dispose()` сами, чтобы освободить дескриптор раньше.

## Текстуры

### TEXTURE

Загружает файлы изображений в дескрипторы текстур.

<div class="callout warn">
Относительные пути разрешаются относительно каталога скрипта; варианты FromAbsolutePath принимают полный путь. Отсутствующий файл возвращает пустой дескриптор, который ничего не рисует. CreateTexture загружает асинхронно: дескриптор ничего не рисует и сообщает Width и Height равными 0, пока не завершатся фоновое декодирование и загрузка на GPU. Используйте CreateTextureSync, когда размер или пиксели нужны вам сразу. Таблица параметров принимает { maxSize = N }, чтобы уменьшить изображение при декодировании так, чтобы его длинная сторона не превышала N пикселей.
</div>

| Метод | Описание |
| --- | --- |
| `TEXTURE:CreateTexture()  -> texture` | Создаёт пустой дескриптор без изображения. |
| `TEXTURE:CreateTexture(path)  -> texture` | Асинхронно загружает изображение по пути относительно каталога скрипта. |
| `TEXTURE:CreateTexture(path, options)  -> texture` | То же, с таблицей параметров (`{ maxSize = N }`). |
| `TEXTURE:CreateTextureSync(path)  -> texture` | Загружает изображение синхронно; размер и пиксели доступны сразу после возврата. |
| `TEXTURE:CreateTextureFromAbsolutePath(path)  -> texture` | Загружает изображение по полному пути в файловой системе. |
| `TEXTURE:CreateTextureFromAbsolutePath(path, options)  -> texture` | То же, с таблицей параметров (`{ maxSize = N }`). |
| `TEXTURE:Exists(path)  -> bool` | Возвращает, существует ли файл по пути относительно каталога скрипта. |

```lua
local logo, jacket

function onStart()
    logo = TEXTURE:CreateTexture("Textures/Logo.png")
    jacket = TEXTURE:CreateTexture("Textures/Jacket.png", { maxSize = 512 })
end

function draw()
    logo:DrawAtAnchor(960, 540, "center")
end

function onDestroy()
    logo:Dispose()
    jacket:Dispose()
end
```

### Дескриптор текстуры

Рисуемое 2D-изображение, возвращаемое фабрикой `TEXTURE`, методами `text:GetText` / `GetVerticalText` и полем `video.Texture`.

<div class="callout warn">
Имена якорей: topleft, top, topright, left, center, right, bottomleft, bottom, bottomright (без учёта регистра; неизвестное имя откатывается к topleft). Отрисовка по якорю учитывает текущий масштаб. Имена режимов смешивания: Normal, Add, Multi, Sub, Screen. Имена режимов адресации: Edge, Border, Repeat, Mirror; новые дескрипторы по умолчанию используют Repeat. На пустом дескрипторе каждый метод является пустой операцией, а геттеры возвращают значения по умолчанию, перечисленные ниже.
</div>

| Метод | Описание |
| --- | --- |
| `texture:Draw(x, y)  -> nil` | Рисует всю текстуру с левым верхним углом в (x, y). |
| `texture:DrawRect(x, y, rect_x, rect_y, rect_width, rect_height)  -> nil` | Рисует исходный подпрямоугольник (в пикселях текстуры) с левым верхним углом в (x, y). |
| `texture:DrawAtAnchor(x, y, anchor)  -> nil` | Рисует всю текстуру так, чтобы именованная точка якоря попала в (x, y). |
| `texture:DrawRectAtAnchor(x, y, rect_x, rect_y, rect_width, rect_height, anchor)  -> nil` | Рисует исходный подпрямоугольник так, чтобы именованная точка якоря попала в (x, y). |
| `texture.Loaded  -> bool` | Истина, когда дескриптор оборачивает текстуру. Игра устанавливает его, как только находит файл, ещё до завершения асинхронной загрузки. |
| `texture.Width  -> int` | Ширина в пикселях; -1 у пустого дескриптора, 0 пока идёт асинхронная загрузка. |
| `texture.Height  -> int` | Высота в пикселях; -1 у пустого дескриптора, 0 пока идёт асинхронная загрузка. |
| `texture.Pointer  -> int` | Нативный идентификатор GL-текстуры или 0, если её нет. |
| `texture:GetScale()  -> vector2` | Текущий масштаб отрисовки в виде vector2 (`X`, `Y`). |
| `texture:GetOpacity()  -> number` | Текущая непрозрачность, 0..1; -1 у пустого дескриптора. |
| `texture:GetColor()  -> number, number, number` | Текущий оттенок в виде трёх значений 0..1 (красный, зелёный, синий). |
| `texture:GetRotation()  -> number` | Текущий поворот в градусах. |
| `texture:GetBlendMode()  -> string` | Имя текущего режима смешивания. |
| `texture:GetWrapMode()  -> string` | Имя текущего режима адресации. |
| `texture:SetScale(scale_x, scale_y)  -> nil` | Задаёт горизонтальный и вертикальный масштаб отрисовки (1 = исходный размер). |
| `texture:SetOpacity(opacity)  -> nil` | Задаёт непрозрачность, 0..1. |
| `texture:SetColor(color)  -> nil` | Задаёт оттенок из значения `COLOR`. Альфу цвета дескриптор игнорирует; прозрачность задавайте через SetOpacity. |
| `texture:SetColor(red, green, blue)  -> nil` | Задаёт оттенок из трёх значений 0..1. |
| `texture:SetRotation(angle)  -> nil` | Задаёт поворот вокруг центра текстуры, в градусах. |
| `texture:SetBlendMode(mode)  -> nil` | Задаёт режим смешивания по имени (без учёта регистра). Неизвестные имена дескриптор игнорирует. |
| `texture:SetWrapMode(mode)  -> nil` | Задаёт режим адресации по имени (без учёта регистра). Неизвестные имена дескриптор игнорирует. |
| `texture:SetUseNoiseEffect(enabled)  -> nil` | При включении каждая отрисовка заменяет цвет текстуры анимированным случайным шумом в оттенках серого и сохраняет её альфу. |
| `texture:SetGradientMap(gradient)  -> nil` | Применяет карту градиента `GRADIENT` к каждой отрисовке этой текстуры (см. GRADIENT). |
| `texture:ClearGradientMap()  -> nil` | Убирает карту градиента с этой текстуры. |
| `texture:Dispose()  -> nil` | Освобождает текстуру. |

## Холст и отсечение

### CANVAS

Создаёт пиксельные поверхности с возможностью записи, которые Lua редактирует на CPU и загружает как одну текстуру.

<div class="callout warn">
Холст — это текстура, пиксели которой задаёт Lua (SetPixel, FillRect, ...) и затем отправляет на GPU вызовом Upload. Он подходит для программной отрисовки и запечённых фигур интерфейса, когда скрипт рисует и загружает один раз, а затем рисует результат каждый кадр. Новые холсты изначально полностью прозрачны.
</div>

| Метод | Описание |
| --- | --- |
| `CANVAS:CreateCanvas(width, height)  -> canvas` | Создаёт прозрачный холст указанного размера (минимум 1x1). |

```lua
local panel

function onStart()
    panel = CANVAS:CreateCanvas(300, 80)
    panel:FillRect(0, 0, 300, 80, 20, 20, 40, 220)
    panel:FillCircle(40, 40, 24, 255, 200, 0, 255)
    panel:Upload()
end

function draw()
    panel:Draw(100, 100)
end

function onDestroy()
    panel:Dispose()
end
```

### Дескриптор холста

Пиксельный буфер RGBA с возможностью записи, возвращаемый `CANVAS:CreateCanvas` и рисуемый как текстура.

<div class="callout warn">
Аргументы цвета r, g, b, a — целые числа 0-255. Правки пикселей накапливаются в «грязном» прямоугольнике и попадают на GPU только при вызове Upload (BlitPacked загружает сам). Координаты отрисовки целочисленные. Имена якорей те же, что у дескриптора текстуры.
</div>

| Метод | Описание |
| --- | --- |
| `canvas.Width  -> int` | Ширина в пикселях. |
| `canvas.Height  -> int` | Высота в пикселях. |
| `canvas.Pointer  -> int` | Нативный идентификатор GL-текстуры или 0, если её нет. |
| `canvas:SetPixel(x, y, r, g, b, a)  -> nil` | Задаёт один пиксель. Координаты вне диапазона холст игнорирует. |
| `canvas:FillRect(x, y, w, h, r, g, b, a)  -> nil` | Заливает прямоугольник, выровненный по осям, с отсечением по холсту. |
| `canvas:FillCircle(cx, cy, radius, r, g, b, a)  -> nil` | Заливает круг указанного радиуса в пикселях. |
| `canvas:StrokeLine(x0, y0, x1, y1, radius, r, g, b, a)  -> nil` | Рисует толстую линию как перекрывающиеся круги указанного радиуса. |
| `canvas:PasteTexture(texture, x, y)  -> nil` | Накладывает текстуру на холст с альфа-смешиванием, левый верхний угол в (x, y). Холст считывает пиксели текстуры с GPU один раз на дескриптор текстуры; это медленная операция, которой место в коде инициализации. |
| `canvas:PasteTextureTransformed(texture, x, y, scale, rotationDeg, anchor)  -> nil` | Накладывает текстуру с альфа-смешиванием, масштабированную на `scale` и повёрнутую по часовой стрелке на `rotationDeg`, с выборкой по ближайшему соседу. При anchor "center" центр текстуры попадает в (x, y); любое другое значение помещает туда левый верхний угол. |
| `canvas:Clear(r, g, b, a)  -> nil` | Заливает весь холст одним цветом. |
| `canvas:ClearTransparent()  -> nil` | Сбрасывает весь холст в полностью прозрачное состояние. |
| `canvas:CopyFrom(other)  -> nil` | Копирует пиксели другого холста того же размера в этот. Если размеры различаются, вызов ничего не делает. |
| `canvas:BlitPacked(data, count)  -> nil` | Заполняет поверхность из Lua-массива с индексацией от 1 упакованных целых `0xRRGGBB` в построчном порядке (пиксели становятся непрозрачными; отрицательное значение становится прозрачным пикселем), затем загружает. |
| `canvas:Upload()  -> nil` | Отправляет отложенные правки (только изменённую область) на GPU. Пустая операция, если ничего не изменилось. |
| `canvas:Draw(x, y)  -> nil` | Рисует холст с левым верхним углом в (x, y). |
| `canvas:DrawRect(x, y, rect_x, rect_y, rect_width, rect_height)  -> nil` | Рисует исходный подпрямоугольник (в пикселях холста) с левым верхним углом в (x, y). |
| `canvas:DrawAtAnchor(x, y, anchor)  -> nil` | Рисует холст так, чтобы именованная точка якоря попала в (x, y). |
| `canvas:SetScale(scale_x, scale_y)  -> nil` | Задаёт горизонтальный и вертикальный масштаб отрисовки. |
| `canvas:SetOpacity(opacity)  -> nil` | Задаёт непрозрачность, 0..1. |
| `canvas:SetColor(red, green, blue)  -> nil` | Задаёт оттенок из трёх значений 0..1. |
| `canvas:Dispose()  -> nil` | Освобождает GPU-текстуру и CPU-буфер холста. |

### GRAPHICS

Scissor-отсечение для прокручиваемых панелей.

<div class="callout warn">
SetClip принимает логические координаты экрана и отображает их на текущий вьюпорт, поэтому отсечение одинаково при масштабировании рендера и леттербоксинге. GPU отбрасывает каждый пиксель, нарисованный вне прямоугольника между SetClip и ClearClip. SetClip заменяет предыдущий прямоугольник (стека нет); держите SetClip и ClearClip парными. Игра отключает scissor в начале каждого кадра.
</div>

| Метод | Описание |
| --- | --- |
| `GRAPHICS:SetClip(x, y, w, h)  -> nil` | Включает отсечение по указанному прямоугольнику. |
| `GRAPHICS:ClearClip()  -> nil` | Отключает отсечение. |

```lua
GRAPHICS:SetClip(100, 200, 600, 400)
for i, row in ipairs(rows) do
    row.tex:Draw(100, 200 + (i - 1) * 48 - scrollY)
end
GRAPHICS:ClearClip()
```

## Текст

### TEXT

Создаёт рендереры шрифта для основного шрифта скина.

<div class="callout warn">
Create возвращает текстовый дескриптор, который рендерит целые строки в кэшированные текстуры; используйте его для редко меняющихся надписей. CreateGlyphCached возвращает глифовый текстовый дескриптор, который кэширует по одной текстуре на символ и собирает строки при отрисовке; используйте его для часто меняющегося текста (таймеры, счёт, вводимый текст) и для блоков с переносом по словам. Аргументы стиля — любые из bold, italic, underline, strikeout (без учёта регистра; другие значения означают обычный). В пределах одного скрипта поставляемая версия NLua даёт сбой, если скрипт вызывает один и тот же фабричный метод сначала без аргумента стиля, а затем ровно с одним аргументом стиля. Либо никогда не передавайте стиль, либо всегда передавайте его с первого вызова, либо передавайте два токена стиля (например "bold", "regular").
</div>

| Метод | Описание |
| --- | --- |
| `TEXT:Create(size, ...style)  -> text` | Создаёт рендерер целых строк с указанным размером в пикселях. |
| `TEXT:CreateGlyphCached(size, ...style)  -> glyphText` | Создаёт рендерер текста, собираемого из глифов, с указанным размером в пикселях. |

#### Встроенные теги цвета

Оба рендерера поддерживают эти теги внутри строки. Теги вкладываются; незакрытый тег действует до конца строки. Функции измерения их игнорируют.

| Тег | Эффект |
| --- | --- |
| `<c.#rrggbb>` ... `</c>` | Цвет заливки. |
| `<c.#rrggbb.#rrggbb>` ... `</c>` | Цвет заливки и цвет обводки. |
| `<g.#rrggbb.#rrggbb>` ... `</g>` | Вертикальная градиентная заливка (верхний цвет, нижний цвет). |

### Текстовый дескриптор

Рендерер целых строк, возвращаемый `TEXT:Create`.

<div class="callout warn">
GetText и GetVerticalText кэшируют по одной текстуре на каждую уникальную комбинацию строки, цвета заливки, цвета обводки и ограничения размера и хранят её, пока вы не освободите дескриптор. Поэтому строка, меняющаяся каждый кадр, добавляет по текстуре каждый кадр и утекает память GPU; такой текст рисуйте через DrawDirect или глифовый текстовый дескриптор. forecolor и backcolor — значения COLOR; по умолчанию белая заливка и непрозрачная чёрная обводка. Флаг centered центрирует каждую строку многострочного текста; в ключ кэша он не входит, поэтому его определяет первый вызов для данной строки.
</div>

| Метод | Описание |
| --- | --- |
| `text:GetText(text, centered, max_width, forecolor, backcolor)  -> texture` | Рендерит горизонтальную строку в кэшированную текстуру. Все аргументы после `text` необязательны. Если отрисованная текстура шире `max_width`, она рисуется сжатой по горизонтали, чтобы уместиться. |
| `text:GetVerticalText(text, centered, max_height, forecolor, backcolor)  -> texture` | Рендерит вертикально расположенную строку в кэшированную текстуру. Если отрисованная текстура выше `max_height`, она рисуется сжатой по вертикали, чтобы уместиться. |
| `text:DrawDirect(text, x, y, r, g, b, opacity, spacing)  -> number` | Рисует строку глиф за глифом из посимвольного кэша и возвращает позицию x после последнего глифа. `r`, `g`, `b` — 0-255 (по умолчанию 255), `opacity` — 0..1 (по умолчанию 1), `spacing` — промежуток между глифами в пикселях (по умолчанию -6). |
| `text:Dispose()  -> nil` | Освобождает шрифт и все кэшированные текстуры. |

```lua
local font, title

function onStart()
    font = TEXT:Create(28)
    title = font:GetText("Song select", true, 600)
end

function draw()
    title:DrawAtAnchor(960, 80, "center")
    font:DrawDirect(tostring(score), 40, 40, 255, 255, 0)
end

function onDestroy()
    font:Dispose()
end
```

### Глифовый текстовый дескриптор

Рендерер, собирающий текст из глифов, возвращаемый `TEXT:CreateGlyphCached`.

<div class="callout warn">
forecolor и backcolor — значения COLOR; по умолчанию белая заливка и чёрная обводка. Каждый аргумент после позиции необязателен. maxWidth (0 = без ограничения) сжимает каждый глиф по горизонтали, чтобы вся строка уместилась. anchor использует те же девять имён, что и дескриптор текстуры. '\n' начинает новую строку; Draw располагает строки с выравниванием по левому краю. Draw возвращает координату x правого края нарисованного прямоугольника. Геометрия прямоугольника совпадает с текстурами GetText (отступ 25 px с каждой стороны и снизу от букв), поэтому глифовый текст и текстура GetText, нарисованные в одной точке, совпадают.
</div>

| Метод | Описание |
| --- | --- |
| `glyphText.LineHeight  -> number` | Шаг строк многострочного текста, в пикселях. |
| `glyphText.BoxHeight  -> number` | Высота однострочного прямоугольника (буквы плюс отступы), совпадающая с однострочной текстурой GetText. |
| `glyphText:Measure(text, scale)  -> number` | Ширина букв самой широкой строки, умноженная на `scale` (по умолчанию 1). |
| `glyphText:Draw(text, x, y, forecolor, backcolor, opacity, scale, maxWidth, anchor, scaleY, rotationDeg)  -> number` | Рисует текст. `opacity` 0..1 (по умолчанию 1); `scale` (по умолчанию 1); `scaleY` при значении > 0 переопределяет вертикальный масштаб; `rotationDeg` поворачивает весь блок вокруг (x, y). Возвращает x правого края прямоугольника. |
| `glyphText:SetClipY(y0, y1)  -> nil` | Ограничивает последующие вызовы Draw без поворота вертикальной полосой y0..y1 в экранных координатах; Draw пропускает глифы вне полосы и обрезает глифы на её границах. Передайте y1 <= y0, чтобы снять ограничение. Отрисовка с поворотом игнорирует полосу. |
| `glyphText:WrapToLines(text, wrapWidth, scale)  -> string[]` | Переносит по словам до ширины `wrapWidth` и возвращает строки как простые строки (теги удалены). |
| `glyphText:MeasureWrapped(text, wrapWidth, scale, lineSpacing)  -> number` | Высота, которую занял бы DrawWrapped, без отрисовки. `lineSpacing` умножает шаг строк (по умолчанию 1). |
| `glyphText:DrawWrapped(text, x, y, wrapWidth, forecolor, backcolor, opacity, scale, lineSpacing)  -> number` | Переносит по словам до ширины `wrapWidth` и рисует с выравниванием по левому краю от (x, y). Возвращает нарисованную высоту. |
| `glyphText:Dispose()  -> nil` | Освобождает шрифт и все кэшированные глифы. |

Перенос по словам выполняется по пробелам, между символами CJK и внутри слова, которое шире ширины переноса.

```lua
local font, white

function onStart()
    font = TEXT:CreateGlyphCached(24)
    white = COLOR:CreateColorFromRGBA(255, 255, 255)
end

function draw()
    font:Draw("Time " .. string.format("%.1f", t), 960, 40, white, nil, 1, 1, 0, "center")
    font:DrawWrapped(description, 200, 300, 800, white)
end

function onDestroy()
    font:Dispose()
end
```

## Видео

### VIDEO

Загружает видеофайлы в воспроизводимые дескрипторы декодера.

<div class="callout warn">
Пути задаются относительно каталога скрипта. Декодер открывается в фоновом потоке; пока он не готов, дескриптор ничего не рисует, ставит в очередь вызовы Start, перемотки и скорости и применяет их после подключения декодера. Отсутствующий файл возвращает пустой дескриптор.
</div>

| Метод | Описание |
| --- | --- |
| `VIDEO:CreateVideo(path)  -> video` | Открывает видеофайл и возвращает его дескриптор. |

### Дескриптор видео

Видеодекодер, возвращаемый `VIDEO:CreateVideo`.

<div class="callout warn">
Позиции задаются в миллисекундах; Duration — в секундах. Читайте Texture каждый кадр, чтобы получить текущий кадр как дескриптор текстуры. Этот дескриптор оборачивает собственную текстуру кадра видео: рисуйте его, а освобождение оставьте дескриптору видео. SetSpeed игнорирует значения 0 и ниже.
</div>

| Метод | Описание |
| --- | --- |
| `video:Start()  -> nil` | Запускает воспроизведение. |
| `video:Resume()  -> nil` | Возобновляет воспроизведение после Pause. |
| `video:Pause()  -> nil` | Приостанавливает воспроизведение. |
| `video:Stop()  -> nil` | Останавливает воспроизведение. |
| `video:Reset()  -> nil` | Перематывает на начало. |
| `video.Width  -> int` | Ширина кадра в пикселях или -1, пока декодер не готов. |
| `video.Height  -> int` | Высота кадра в пикселях или -1, пока декодер не готов. |
| `video.Duration  -> number` | Общая длительность в секундах (1, пока декодер не готов). |
| `video.DurationMs  -> number` | Общая длительность в миллисекундах. |
| `video.Texture  -> texture` | Текущий декодированный кадр. |
| `video:IsFinished()  -> bool` | Истина после окончания потока, когда кадров не осталось. |
| `video:GetTimestampMs()  -> number` | Текущая позиция воспроизведения в миллисекундах. |
| `video:SetTimestampMs(ms)  -> nil` | Перематывает на позицию в миллисекундах. |
| `video:GetSpeed()  -> number` | Текущий множитель скорости воспроизведения (1 = обычная). |
| `video:SetSpeed(speed)  -> nil` | Задаёт множитель скорости воспроизведения. |
| `video:GetPlayPosition()  -> number` | Текущая позиция в секундах (старое имя для GetTimestampMs / 1000). |
| `video:SetPlayPosition(seconds)  -> nil` | Перематывает на позицию в секундах (старое имя для SetTimestampMs). |
| `video:GetPlaySpeed()  -> number` | Старое имя для GetSpeed. |
| `video:SetPlaySpeed(speed)  -> nil` | Старое имя для SetSpeed. |
| `video:Dispose()  -> nil` | Освобождает декодер и его текстуру кадра. |

```lua
local intro

function onStart()
    intro = VIDEO:CreateVideo("Videos/intro.mp4")
end

function activate()
    intro:Start()
end

function draw()
    intro.Texture:Draw(0, 0)
    if intro:IsFinished() then Exit("title", nil) end
end

function deactivate()
    intro:Stop()
end

function onDestroy()
    intro:Dispose()
end
```

## Цвет, градиент и размер

### COLOR

Создаёт значения цвета.

<div class="callout warn">
Каналы задаются в диапазоне 0-255. Методы текстур, холстов и текста, которые получают цвет, принимают эти значения.
</div>

| Метод | Описание |
| --- | --- |
| `COLOR:CreateColorFromRGBA(r, g, b, a)  -> color` | Создаёт цвет из красного, зелёного, синего и необязательной альфы (по умолчанию 255). |
| `COLOR:CreateColorFromARGB(a, r, g, b)  -> color` | Создаёт цвет из альфы, красного, зелёного и синего. |
| `COLOR:CreateColorFromHex(value)  -> color` | Разбирает шестнадцатеричную строку `AARRGGBB` без префикса (например `"ff2080ff"`). Шестизначная строка даёт альфу 0. Неразбираемая строка даёт непрозрачный белый. |

| Метод | Описание |

| `color.R  -> int` | Красный канал, 0-255 (чтение/запись). |
| `color.G  -> int` | Зелёный канал, 0-255 (чтение/запись). |
| `color.B  -> int` | Синий канал, 0-255 (чтение/запись). |

### GRADIENT

Карты градиентов перекрашивают отрисовку текстур, отображая яркость каждого пикселя на цветовую шкалу, либо для одной текстуры, либо для каждой отрисовки.

<div class="callout warn">
Create принимает таблицу как минимум из двух опорных точек, каждая из которых — массив { позиция 0-1, r 0-255, g 0-255, b 0-255 [, a 0-255] }, и степень смешивания (0 = без эффекта, 1 = полная замена, промежуточные значения смешивают; по умолчанию 1). Меньше двух опорных точек возбуждает ошибку. Одинаковые опорные точки и степень смешивания переиспользуют одну кэшированную GPU-текстуру на всю программу. Применяйте к одной текстуре через texture:SetGradientMap или к каждой отрисовке текстур через SetActive.
</div>

| Метод | Описание |
| --- | --- |
| `GRADIENT:Create(stops, blend)  -> gradient` | Строит (или переиспользует) карту градиента из опорных цветов и степени смешивания. |
| `GRADIENT:SetActive(gradient)  -> nil` | Применяет градиент к каждой отрисовке текстур до вызова ClearActive. |
| `GRADIENT:ClearActive()  -> nil` | Убирает глобальную карту градиента. |

```lua
local sepia

function onStart()
    sepia = GRADIENT:Create({
        { 0.0,  40,  20,   0 },
        { 1.0, 255, 230, 180 },
    }, 0.8)
end

function draw()
    GRADIENT:SetActive(sepia)
    background:Draw(0, 0)
    GRADIENT:ClearActive()
end

function onDestroy()
    sepia:Dispose()
end
```

### Дескриптор градиента

Карта градиента, возвращаемая `GRADIENT:Create`.

| Метод | Описание |
| --- | --- |
| `gradient.BlendStrength  -> number` | Степень смешивания, 0..1 (только чтение). |
| `gradient:Dispose()  -> nil` | Освобождает дескриптор. Общая GPU-текстура остаётся в кэше. |

### Дескриптор размера

| Метод | Описание |
