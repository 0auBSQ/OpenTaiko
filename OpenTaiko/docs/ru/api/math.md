# Математика

Векторы, матрицы и кватернионы.

Каждый тип представлен глобальной фабрикой (VECTOR2, MATRIX4, QUATERNION, ...), которая создаёт значения, и типом дескриптора с операциями. Соглашения, общие для всех типов на этой странице:

- Читайте и записывайте поля компонентов (X, Y, Z, W) напрямую. Индексный доступ (`Get`, `Set`) начинается с 1.
- Арифметические методы возвращают новое значение и не трогают операнды. Только `Set` изменяет значение на месте.
- Углы задаются в радианах.
- Методы, возвращающие несколько чисел (`Unpack`, `RotateVec`), возвращают их как несколько значений Lua.

```lua
local a = VECTOR2:CreateVector2(3, 4)
local b = a:Normalized():Scale(10)   -- (6, 8)
local x, y = b:Unpack()

local q = QUATERNION:FromAxisAngle(0, 1, 0, math.pi / 2)
local rx, ry, rz = q:RotateVec(1, 0, 0)
```

## Векторы

### VECTOR

Фабрика векторов произвольной длины.

<div class="callout warn">
Доступен как глобальный объект VECTOR. Операции между двумя векторами требуют одинаковых размеров; несовпадение размеров возвращает вектор нулевой длины (или 0 для скалярных результатов) и не возбуждает ошибку.
</div>

| Метод | Описание |
| --- | --- |
| `VECTOR:CreateVector(n)  -> vector` | Создаёт заполненный нулями вектор длины n. |

### Дескриптор вектора

Вектор произвольной длины с компонентами, индексируемыми от 1.

| Метод | Описание |
| --- | --- |
| `vector:Size()  -> number` | Возвращает число компонентов. |
| `vector:Get(i)  -> number` | Возвращает i-й компонент или 0, если i вне диапазона. |
| `vector:Set(i, value)  -> nil` | Задаёт i-й компонент; индексы вне диапазона метод игнорирует. |
| `vector:Add(o)  -> vector` | Возвращает покомпонентную сумму. |
| `vector:Sub(o)  -> vector` | Возвращает покомпонентную разность. |
| `vector:Mul(o)  -> vector` | Возвращает покомпонентное произведение. |
| `vector:Scale(s)  -> vector` | Возвращает вектор, каждый компонент которого умножен на s. |
| `vector:Dot(o)  -> number` | Возвращает скалярное произведение. |
| `vector:Length()  -> number` | Возвращает евклидову длину. |
| `vector:LengthSq()  -> number` | Возвращает квадрат длины. |
| `vector:Distance(o)  -> number` | Возвращает евклидово расстояние до o. |
| `vector:Normalized()  -> vector` | Возвращает копию единичной длины или нулевой вектор, если длина близка к нулю. |
| `vector:Lerp(o, t)  -> vector` | Возвращает линейную интерполяцию к o на долю t. |
| `vector:Clone()  -> vector` | Возвращает независимую копию. |

## Матрицы

Все матрицы хранятся построчно: `Get(r, c)` читает строку r, столбец c, оба от 1. `MulVec` рассматривает вектор как вектор-столбец (результат = M * v).

### MATRIX

Фабрика матриц произвольного размера.

<div class="callout warn">
Доступен как глобальный объект MATRIX. Операции с несовместимыми размерами возвращают пустую матрицу 0 на 0 (или вектор нулевой длины) и не возбуждают ошибку.
</div>

| Метод | Описание |
| --- | --- |
| `MATRIX:CreateMatrix(rows, cols)  -> matrix` | Создаёт заполненную нулями матрицу. |
| `MATRIX:Identity(n)  -> matrix` | Создаёт единичную матрицу n на n. |

### Дескриптор матрицы

Матрица произвольного размера.

<div class="callout warn">
Add и Sub требуют совпадающих размерностей; Mul требует, чтобы число столбцов этой матрицы равнялось числу строк другой; MulVec требует, чтобы размер вектора равнялся числу столбцов.
</div>

| Метод | Описание |
| --- | --- |
| `matrix:RowCount()  -> number` | Возвращает число строк. |
| `matrix:ColCount()  -> number` | Возвращает число столбцов. |
| `matrix:Get(r, c)  -> number` | Возвращает элемент в строке r, столбце c или 0, если индексы вне диапазона. |
| `matrix:Set(r, c, v)  -> nil` | Задаёт элемент в строке r, столбце c; индексы вне диапазона метод игнорирует. |
| `matrix:Add(o)  -> matrix` | Возвращает поэлементную сумму. |
| `matrix:Sub(o)  -> matrix` | Возвращает поэлементную разность. |
| `matrix:Scale(s)  -> matrix` | Возвращает матрицу, каждый элемент которой умножен на s. |
| `matrix:Mul(o)  -> matrix` | Возвращает произведение матриц. |
| `matrix:MulVec(v)  -> vector` | Возвращает произведение на вектор (см. VECTOR). |
| `matrix:Transpose()  -> matrix` | Возвращает транспонированную матрицу. |
| `matrix:Clone()  -> matrix` | Возвращает независимую копию. |

## Кватернионы

### QUATERNION

Фабрика кватернионов.

<div class="callout warn">
Доступен как глобальный объект QUATERNION. Единичный кватернион — (0, 0, 0, 1). Методы поворота предполагают единичные кватернионы; вызывайте Normalized после построения кватерниона вручную.
</div>

| Метод | Описание |
| --- | --- |
| `QUATERNION:Identity()  -> quaternion` | Возвращает единичный кватернион. |
| `QUATERNION:Create(x, y, z, w)  -> quaternion` | Создаёт кватернион из четырёх компонентов. |
| `QUATERNION:FromAxisAngle(ax, ay, az, angle)  -> quaternion` | Возвращает поворот на `angle` радиан вокруг оси (ax, ay, az). Метод нормализует ось; нулевая ось даёт единичный кватернион. |

### Дескриптор кватерниона

Кватернион с полями X, Y, Z и W.

| Метод | Описание |
| --- | --- |
| `quaternion.X  -> number` | Компонент x (поле для чтения и записи). |
| `quaternion.Y  -> number` | Компонент y (поле для чтения и записи). |
| `quaternion.Z  -> number` | Компонент z (поле для чтения и записи). |
| `quaternion.W  -> number` | Компонент w (поле для чтения и записи). |
| `quaternion:Mul(o)  -> quaternion` | Возвращает произведение Гамильтона this * o. Применение результата поворачивает сначала на o, затем на this. |
| `quaternion:Dot(o)  -> number` | Возвращает скалярное произведение. |
| `quaternion:Length()  -> number` | Возвращает длину. |
| `quaternion:Normalized()  -> quaternion` | Возвращает копию единичной длины или единичный кватернион, если длина близка к нулю. |
| `quaternion:Conjugate()  -> quaternion` | Возвращает (-X, -Y, -Z, W), обратный поворот единичного кватерниона. |
| `quaternion:RotateVec(vx, vy, vz)  -> number, number, number` | Поворачивает вектор (vx, vy, vz) и возвращает результирующие x, y и z. |
| `quaternion:Slerp(o, t)  -> quaternion` | Возвращает сферическую линейную интерполяцию к o на долю t по кратчайшей дуге. |
| `quaternion:Clone()  -> quaternion` | Возвращает независимую копию. |
| `quaternion:Unpack()  -> number, number, number, number` | Возвращает X, Y, Z и W как четыре значения. |
