# Сетевая игра <span class="badge-exp">Экспериментально</span>

Глобальный объект `NET` — это клиент OpenTaiko Online, однорангового протокола, на котором работают онлайн-лобби и многопользовательские сцены. Один игрок создаёт комнату и получает код комнаты; другие игроки присоединяются по этому коду. Сервер (создатель комнаты, если только комната не мигрировала) ретранслирует весь трафик, и каждый игрок хранит список участников комнаты.

Как Lua его использует:

- Все данные пересекают границу Lua в виде строк. Сцены передают структурированные данные как JSON.
- Сеть работает в фоновых потоках и складывает события в очередь. Сцена опустошает очередь каждый кадр, вызывая `NET:Poll()` в цикле, пока он не вернёт nil.
- Сеть по умолчанию выключена. Её включает настройка «Allow LuaNetworking connections»; пока она выключена, CreateRoom возвращает nil, JoinRoom возвращает false, а клиент ставит в очередь событие "error".
- Идентификаторы в комнате: создатель комнаты имеет идентификатор 1. Каждый присоединившийся получает следующий идентификатор в порядке присоединения. `NET:SelfId()` вне комнаты равен 0.
- Роль хоста отделена от владения соединением. Она отмечает игрока, который в данный момент управляет лобби (выбирает песню, запускает игру). Изначально она у создателя; RotateHost или SetHostRole передаёт её другому игроку.
- Если создатель комнаты уходит, оставшиеся игроки автоматически мигрируют на новый сервер; комната закрывается, только если никто не может её принять.

```lua
function update(ts)
    while true do
        local e = NET:Poll()
        if e == nil then break end
        if e.Type == "message" and e.Channel == "chat" then
            addChatLine(e.Peer, e.Data)
        elseif e.Type == "left" then
            removePlayer(e.Peer)
        elseif e.Type == "roomclosed" then
            return Exit("title")
        end
    end
end
```

## NET

### Жизненный цикл комнаты

<div class="callout warn">
Доступен как глобальный объект NET. Вызовите SetLocalPlayer перед CreateRoom или JoinRoom, чтобы другие игроки получили ваши сведения при присоединении. JoinRoom асинхронен: результат приходит позже как событие "connected" или "error". Создание или присоединение к комнате сначала покидает текущую комнату.
</div>

| Метод | Описание |
| --- | --- |
| `NET:SetLocalPlayer(infoJson)  -> void` | Задаёт строку сведений о локальном игроке (обычно JSON с табличкой имени, персонажем и так далее). Клиент отправляет её другим игрокам при вашем присоединении, и она появляется в их событиях "joined" и в PeersJson. Пустая строка становится "{}"; строку длиннее 16384 символов сервер заменяет на "{}". |
| `NET:CreateRoom(stageId, payload, maxPlayers)  -> string` | Создаёт комнату для указанного идентификатора сцены с необязательной строкой полезной нагрузки и возвращает её код комнаты или nil, если сеть выключена или создание комнаты не удалось. maxPlayers ограничивает список участников (по умолчанию 8). |
| `NET:CreateRoom(stageId, payload)  -> string` | То же с ограничением по умолчанию в 8 игроков. |
| `NET:PeekStageId(roomCode)  -> string` | Возвращает идентификатор сцены, хранящийся в коде комнаты, без подключения, или nil, если код недействителен. Позволяет экрану присоединения направить игрока в нужную сцену. |
| `NET:JoinRoom(roomCode)  -> bool` | Начинает присоединение к комнате. Немедленно возвращает false, если сеть выключена или код некорректен; иначе результат приходит как событие "connected" или "error". |
| `NET:Leave()  -> void` | Покидает комнату и очищает очередь событий. Если создатель комнаты уходит, а остальные остаются, комнату принимает другой игрок; иначе она закрывается для всех. |
| `NET.PortOverride  (int, settable)` | Если больше 0, комнаты используют этот TCP-порт; 0 выбирает порт по умолчанию 41234. В обычной работе оставляйте 0. |

### Обмен сообщениями

<div class="callout warn">
Сцена выбирает имена каналов свободно. Механизм игровых раундов резервирует имена каналов "ps", "ld" и "fn", которые никогда не доходят до Poll().
</div>

| Метод | Описание |
| --- | --- |
| `NET:Broadcast(channel, data)  -> void` | Отправляет сообщение по указанному каналу всем остальным игрокам в комнате. |
| `NET:SendTo(peerId, channel, data)  -> void` | Отправляет сообщение по указанному каналу одному игроку по идентификатору. -1 отправляет всем остальным, как Broadcast. |
| `NET:Poll()  -> NetEvent` | Извлекает и возвращает следующее ожидающее событие или nil, если очередь пуста. |

### Состояние комнаты и роль хоста

| Метод | Описание |
| --- | --- |
| `NET:SelfId()  -> int` | Идентификатор этого игрока (1 для создателя комнаты) или 0 вне комнаты. |
| `NET:Connected()  -> bool` | Истина в комнате: у этого игрока есть собственный идентификатор, и он либо является сервером, либо подключён к нему. |
| `NET:IsHost()  -> bool` | Истина, если этот игрок владеет соединением комнаты (создатель комнаты или игрок, принявший её после миграции). |
| `NET:HasHostRole()  -> bool` | Истина, если этот игрок в данный момент держит роль хоста. |
| `NET:HostRoleId()  -> int` | Идентификатор игрока, держащего роль хоста. |
| `NET:PeerCount()  -> int` | Число игроков в списке участников, включая себя. |
| `NET:PeersJson()  -> string` | Список участников как JSON-массив в порядке присоединения. Каждая запись — {id, info, isHost, hostRole}: info — строка, которую этот игрок передал в SetLocalPlayer, isHost истинно для идентификатора 1, hostRole истинно для текущего держателя роли хоста. |
| `NET:RotateHost()  -> void` | Передаёт роль хоста следующему игроку в порядке присоединения. Работает только на сервере; вызовы других игроков он игнорирует. |
| `NET:SetHostRole(peerId)  -> void` | Отдаёт роль хоста указанному игроку и объявляет об этом комнате. Работает только на сервере и только для идентификаторов из списка участников. |

### Игровые раунды

Во время онлайн-песни игра приостанавливает сцену лобби, и игровой экран сам ведёт обмен: рассылает текущий счёт локального игрока, заполняет удалённые позиции данными из сети и ждёт на барьерах загрузки и завершения. Лобби нужно лишь объявить, кто играет на какой позиции, и открыть и закрыть раунд.

<div class="callout warn">
Позиции (spots) — это места игроков на игровом экране: позиция 0 всегда локальный игрок, позиции 1 и выше — удалённые игроки. Задайте соответствие через SetPlaySpots, затем вызовите BeginPlaySync непосредственно перед входом в игру и EndPlaySync, как только лобби вернёт себе управление. Методы барьеров, отправки счёта и шансов вызывает игровой экран; они перечислены здесь, потому что их предоставляет тот же объект.
</div>

| Метод | Описание |
| --- | --- |
| `NET:SetPlaySpots(json)  -> void` | Задаёт соответствие позиций игрокам для предстоящей игры из JSON-массива идентификаторов, где индекс 0 — это вы (например "[1,3,2]"). Неразбираемая строка очищает соответствие. |
| `NET:PlaySpotCount()  -> int` | Число записей в текущем соответствии позиций (0, если оно не задано). |
| `NET:BeginPlaySync(selfName)  -> void` | Открывает игровой раунд: очищает предыдущие счета и запоминает отображаемое имя локального игрока для сообщений с текущим счётом. |
| `NET:EndPlaySync()  -> void` | Закрывает игровой раунд и очищает барьеры и результаты по позициям. |
| `NET:IsRemoteSpot(spot)  -> bool` | Истина, если позиция соответствует удалённому игроку во время открытого игрового раунда. |
| `NET:IsSpotActive(spot)  -> bool` | Истина, если игрок, соответствующий позиции, всё ещё в списке участников (позиция 0 всегда истинна). Ложь означает, что игрок отключился посреди игры. |
| `NET:GetSpotPlayJson(spot)  -> string` | Последний JSON текущего счёта, который прислала удалённая позиция, или пустая строка. Ключи: n (имя), s (очки), g (шкала), a (точность), gr (great), gd (good), ms (bad), co (комбо). |
| `NET:GetSelfPlayScore()  -> string` | Последний JSON текущего счёта, разосланный этим клиентом. |
| `NET:LivePlayScoresJson()  -> string` | Последний JSON текущего счёта каждого игрока как JSON-массив {id, d}, где d — строка JSON счёта. Массив включает вас, как только этот клиент разослал счёт хотя бы один раз. |
| `NET:GetSpotResultJson(spot)  -> string` | JSON итогового результата, который удалённая позиция сообщила в конце песни, или пустая строка. Ключи: cl (клир), fc (фулл-комбо), pf (перфект), mx (радужная шкала) как логические значения; gr, gd, ms, rl (дроби), bl (шары), ad (ad-lib), hc (наибольшее комбо), sc (очки) как целые числа. |
| `NET:GetSpotClearLevel(spot)  -> int` | Уровень клира из итогового результата удалённой позиции: 2 радужный, 1 клир, 0 провал, -1 если результат ещё не пришёл. |
| `NET:GetSpotJudge(spot, key)  -> int` | Одно целочисленное поле итогового результата удалённой позиции по ключу (см. GetSpotResultJson) или -1, если результат ещё не пришёл. |
| `NET:GetSpotBadOdds(spot)  -> int` | Шанс в промилле (0-1000), что игра оценит следующий автоудар удалённой позиции как bad, выведенный из разосланных ею счётчиков оценок. |
| `NET:GetSpotGoodOdds(spot)  -> int` | Шанс в промилле (0-1000), что игра оценит следующий автоудар удалённой позиции как good. |
| `NET:PushPlayScore(json)  -> void` | Рассылает JSON текущего счёта локального игрока. Игровой экран вызывает его несколько раз в секунду. |
| `NET:ReportLoaded()  -> void` | Однократно сообщает, что этот клиент закончил загрузку песни. |
| `NET:LoadBarrierReady(timeoutMs)  -> bool` | Истина, когда каждый игрок из списка участников сообщил о загрузке или когда истёк тайм-аут с момента сообщения этого клиента (сервер затем исключает игроков, которые так и не сообщили). |
| `NET:ReportFinished(resultJson)  -> void` | Однократно сообщает, что этот клиент закончил песню, вместе с JSON его итогового результата. |
| `NET:FinishBarrierReady(timeoutMs)  -> bool` | Истина, когда каждый игрок из списка участников сообщил о завершении или когда истёк тайм-аут. |
| `NET:BarrierReset()  -> void` | Очищает барьеры загрузки и завершения и результаты по позициям. |

## NetEvent

Объект, возвращаемый NET:Poll() и описывающий одно сетевое событие.

<div class="callout warn">
Читайте его поля напрямую; методов у него нет. Peer равен 0, если у события нет связанного игрока.
</div>

| Метод | Описание |
| --- | --- |
| `event.Type  -> string` | Вид события, одно из значений, перечисленных ниже. |
| `event.Peer  -> int` | Идентификатор связанного игрока: ваш собственный для "connected", отправитель для "message", затронутый игрок для "joined", "left" и "hostrole"; иначе 0. |
| `event.Channel  -> string` | Канал события "message"; пустой для других видов. |
| `event.Data  -> string` | Полезная нагрузка события; см. ниже. |

| Тип | Значение |
| --- | --- |
| `connected` | Вы присоединились к комнате. Data — JSON-объект {selfId, stageId, payload, hostRoleId}. Создатель комнаты никогда его не получает. Игроки, уже находящиеся в комнате, появляются в PeersJson и не возбуждают событий "joined". |
| `joined` | Игрок присоединился после вас. Peer — его идентификатор, Data — его строка сведений. |
| `left` | Игрок ушёл, или сервер его отключил. Peer — его идентификатор. |
| `message` | Сообщение от другого игрока. Peer — отправитель, Channel и Data — сообщение. |
| `hostrole` | Роль хоста перешла к другому игроку. Peer — идентификатор нового держателя. |
| `roomclosed` | Комната закрылась, или восстановление соединения не удалось. |
| `error` | Сообщение о состоянии для показа игроку. Data — текст. Клиент возбуждает его, когда сеть выключена, когда создание или присоединение не удалось, когда комната заполнена, а также как уведомления о ходе миграции хоста. |
