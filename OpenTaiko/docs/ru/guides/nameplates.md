# Добавление табличек имени

Титулом таблички имени называется текстовая табличка, которую игра показывает на табличке имени игрока рядом с его именем и титулом дана. Игроки разблокируют титулы, играя, покупая их или получая от скрипта, и экипируют один из них в «Моей комнате». Вы можете добавить собственные титулы с помощью пакета табличек имени: папки с файлом `Nameplates.json`, которую вы помещаете в `Global/Nameplates/`. Скин может поставлять собственный пакет. На каждом экране, где показываются таблички имени, игра выводит таблички всех пакетов рядом с поставляемыми.

## Прежде чем начать

- Текстовый редактор, сохраняющий в UTF-8.
- Идентификатор пакета: короткое имя из строчных букв, цифр и `_`, которое не использует ни один другой пакет, например ваше имя или название вашего пакета чартов. Из него игра строит идентификатор каждой таблички имени в пакете.
- Игра читает пакеты при запуске и при загрузке скина. Чтобы увидеть изменение, перезапускайте игру после каждой правки.

## Шаг 1: создайте папку пакета

Создайте папку внутри `Global/Nameplates/` (папка `Global` находится рядом с игрой). Имя папки может быть любым. Пакет содержит один обязательный файл и необязательную папку `Lang/` для переводов (шаг 3):

```
Global/
  Nameplates/
    Example Pack/
      Nameplates.json
      Lang/
        fr.json
        ja.json
```

Скин поставляет свой пакет так же, в виде папки `Nameplates/` в корне скина (`System/<skin>/Nameplates/Nameplates.json`). Игра загружает только пакет активного скина, поэтому таблички из пакета скина пропадают, пока активен другой скин.

## Шаг 2: напишите Nameplates.json

`Nameplates.json` содержит идентификатор пакета и список табличек имени:

- `pack` (string, обязательно): идентификатор пакета.
- `name` (object, необязательно): название пакета, которое показывается на ленте пакетов компьютера в «Моей комнате», в виде `{ "strings": { "default": "...", "<code>": "..." } }`: лента показывает название для текущего языка, иначе `default`. Без него лента пакетов показывает идентификатор пакета.
- `nameplates` (array, обязательно): по одному объекту на табличку, со следующими полями:
  - `key` (string, обязательно): имя таблички, уникальное внутри пакета. Полный идентификатор таблички: `<pack>:<key>`, например `example_pack:night_sky`. Файлы сохранений хранят этот идентификатор, поэтому не меняйте ключ, как только игроки могут получить табличку, и никогда не отдавайте его другой табличке.
  - `title` (string, обязательно): текст титула. Его показывает каждый язык, для которого нет перевода.
  - `type` (int, по умолчанию 0): графика таблички, номер папки в текстурах табличек имени скина. В поставляемом скине это папки от `Modules/ROActivities/nameplate/Textures/Title/0` до `45`, а номер без папки не рисует табличку. В таблице ниже перечислены таблички поставляемого скина.
  - `rarity` (string, по умолчанию `Common`): название редкости (см. таблицу ниже). Неизвестное название становится `Common`.
  - `unlock` (object, необязательно): условие разблокировки с теми же полями, что и в `Unlock.json`: `condition`, `values`, `type` и `references` (идентификаторы условий см. на странице [Справочник по разблокировке](unlockables-reference.md)). Без `unlock` табличка с самого начала есть у каждого игрока.

Игра проверяет условия разблокировки на экране результатов после каждой игры. Когда игрок выполняет условие, игра разблокирует табличку и показывает уведомление. Условия с монетами (`ch`, `cs`, `cm`) разблокируются только покупкой: в поставляемом скине игрок покупает табличку на компьютере в «Моей комнате». Кроме того, компьютер в «Моей комнате» не показывает в своём списке заблокированные таблички Mythical, пока игрок ими не владеет.

```json
{
  "pack": "example_pack",
  "name": { "strings": { "default": "Example Pack", "fr": "Pack d'exemple" } },
  "nameplates": [
    {
      "key": "night_sky",
      "title": "Night Sky Walker",
      "type": 8,
      "rarity": "Rare",
      "unlock": { "condition": "tp", "values": [50] }
    },
    {
      "key": "hello",
      "title": "Hello There"
    }
  ]
}
```

## Шаг 3: добавьте переводы

Переводы необязательны. Каждый файл в папке `Lang/` пакета содержит титулы на одном языке, по одной строке на табличку, с ключами пакета (без идентификатора пакета). Имя файла соответствует коду языка:

| Файл | Язык |
| --- | --- |
| `de.json` | Немецкий |
| `en.json` | Английский |
| `es.json` | Испанский |
| `fr.json` | Французский |
| `ja.json` | Японский |
| `ko.json` | Корейский |
| `nl.json` | Нидерландский |
| `ru.json` | Русский |
| `zh.json` | Китайский |

```json
{
  "night_sky": "Promeneur du ciel nocturne",
  "hello": "Bonjour"
}
```

Табличка, которой нет в файле языка, показывает на этом языке свой `title`.

## Шаг 4: проверьте в игре

Запустите игру и откройте компьютер в «Моей комнате». На вкладке «Таблички» выберите свой пакет на ленте пакетов над списком: список показывает таблички пакета, заблокированные с подсказкой о разблокировке. Экипируйте одну и проверьте её титул, табличку и звёзды на табличке имени игрока. Переключите язык игры, чтобы проверить переводы.

Пакет, который не удаётся прочитать, игра пропускает и показывает уведомление об ошибке с его названием. Пакет без допустимого идентификатора `pack` или с идентификатором уже загруженного пакета считается нечитаемым. Отдельную табличку без `key` или `title` либо с ключом, который уже есть в пакете, игра пропускает и записывает причину в `OpenTaiko.log`.

## Таблички имени из скрипта

Lua-скрипты работают с теми же идентификаторами. Каждый метод, принимающий идентификатор таблички, принимает полный идентификатор строкой; для поставляемых табличек подходит и их номер. Скрипт может выдать табличку с условием `ig`, которая в игре никогда не разблокируется:

```lua
local save = GetSaveFile(0)
local id = "example_pack:night_sky"
if not save:IsNameplateUnlocked(id) then
    save:UnlockNameplate(id)
end
save:ChangeNameplate(id)
```

UnlockNameplate не показывает уведомление, поэтому скрипт, которому оно нужно, показывает его сам. Методы табличек имени описаны в разделе [Игроки и профили](../api/players.md).

## Примеры

Эти пакеты показывают типичные схемы. Замените идентификаторы, титулы и числа своими.

**Бесплатная табличка.** Без `unlock` табличка есть у каждого игрока, и он может сразу её экипировать.

```json
{
  "pack": "example_pack",
  "nameplates": [
    { "key": "welcome", "title": "Welcome Aboard", "type": 0, "rarity": "Common" }
  ]
}
```

**Разблокировка игрой (`tp`).** Табличка разблокируется после 100 игр. `ap` (игры в битвах с ИИ), `aw` (победы в битвах с ИИ) и `ce` (всего заработано монет) используют ту же схему с одним значением.

```json
{
  "pack": "example_pack",
  "nameplates": [
    { "key": "regular", "title": "Regular Drummer", "type": 3, "rarity": "Uncommon",
      "unlock": { "condition": "tp", "values": [100] } }
  ]
}
```

**Клир песни из вашего пакета чартов (`sp`).** Пакет чартов может награждать за собственные песни. В качестве ссылки указывается поле `id` из `uniqueID.json` песни, а `[3, 3]` требует фулл-комбо (3) на Extreme (3).

```json
{
  "pack": "example_charts",
  "nameplates": [
    { "key": "storm_fc", "title": "Storm Chaser", "type": 33, "rarity": "Epic",
      "unlock": { "condition": "sp", "values": [3, 3],
                  "references": ["4xtDLgcLGqMLaXd7mq344TtjhhR4dopA4ykf5wTCfFq8UOdHFBlwpW2lSJ9ndcVU"] } }
  ]
}
```

**Покупка за монеты (`ch`).** Цена является единственным значением. В поставляемом скине игрок покупает табличку на компьютере в «Моей комнате».

```json
{
  "pack": "example_pack",
  "nameplates": [
    { "key": "golden", "title": "Golden Touch", "type": 11, "rarity": "Rare",
      "unlock": { "condition": "ch", "values": [800] } }
  ]
}
```

**Награда, которую выдаёт только скрипт (`ig`).** Табличка с `ig` никогда не разблокируется в игре, поэтому её выдаёт скрипт через UnlockNameplate (см. «Таблички имени из скрипта»). До этого компьютер в «Моей комнате» показывает для неё общую подсказку о недействительном условии.

```json
{
  "pack": "example_story",
  "nameplates": [
    { "key": "finale", "title": "Curtain Call", "type": 19, "rarity": "Legendary",
      "unlock": { "condition": "ig", "values": [] } }
  ]
}
```

**Пакет скина с переводами.** Скин хранит свой пакет в `System/<skin>/Nameplates/`, а переводы в `System/<skin>/Nameplates/Lang/`.

```json
{
  "pack": "example_skin",
  "nameplates": [
    { "key": "visitor", "title": "First Visit", "type": 22, "rarity": "Common",
      "unlock": { "condition": "tp", "values": [1] } }
  ]
}
```

```json
{
  "visitor": "初めての訪問"
}
```

## Устранение неполадок и примечания

- Пакет не появляется: папка лежит не прямо в `Global/Nameplates/`, файл называется не `Nameplates.json`, идентификатор `pack` отсутствует или содержит символы помимо строчных букв, цифр и `_`, либо другой пакет уже использует тот же идентификатор. Уведомление об ошибке называет пакет.
- Табличка отсутствует в списке: у неё нет `key` или `title`, либо её ключ повторяет более ранний. `OpenTaiko.log` называет эту запись.
- Перевод не показывается: ключ в файле `Lang` должен быть ключом пакета без идентификатора пакета (`night_sky` для `example_pack:night_sky`), а имя файла должно быть кодом языка.
- На табличке нет графики: у скина нет папки для этого `type`.
- В сетевой игре другие игроки видят титул таблички из пакета, только если у них есть тот же пакет. Иначе они видят табличку имени игрока без титула.
- Если вы удалите пакет, у игроков, носивших одну из его табличек, титул не показывается, пока пакет не вернётся. Их разблокировки остаются в файле сохранения.
- JSON-парсер игры принимает комментарии и завершающие запятые; строгие валидаторы их отклоняют.
