# Добавление пучичары

Пучичара — маленький спутник, который подпрыгивает рядом со шкалой во время игры. Каждая пучичара — это одна папка в `Global/PuchiChara/` в папке установки игры, содержащая двухкадровый спрайт-лист и несколько необязательных JSON-файлов. Код писать не нужно: создайте папку с правильными именами файлов, и игра подхватит её при следующем запуске.

Совместимость: OpenTaiko 0.6.1 по-прежнему загружает пучичар, созданных для 0.6.0, без изменений.

## Прежде чем начать

- Установленный OpenTaiko 0.6.1. Игра читает пучичар из `Global/PuchiChara/` рядом с исполняемым файлом игры, и все скины используют эту папку совместно.
- Графический редактор, экспортирующий PNG с прозрачностью.
- Текстовый редактор для JSON-файлов.
- Необязательно: короткий `.ogg`-клип для `Welcome.ogg`.

## Шаг 1: создайте папку

При запуске игра перечисляет подпапки `Global/PuchiChara/` и считает каждую из них пучичарой. Имя папки — это идентичность: игра записывает его в файл сохранения, когда игрок выбирает пучичару, и под ним же записывает разблокировку. Выберите устойчивое имя: после переименования существующий выбор откатывается к первой папке, а записанная разблокировка больше не совпадает. Поставляемые папки используют префикс для сортировки, например `00 - None`, `01a - OpenTaiko-Kun` и `02 - Bol`. Игра список не сортирует, поэтому префикс делает порядок файловой системы предсказуемым. Первая папка — запасной вариант, когда сохранение ссылается на папку, которой больше нет, поэтому держите `00 - None` первой.

```
Global/PuchiChara/
    00 - None/
    01a - OpenTaiko-Kun/
    02 - Bol/
    99 - MyMascot/          <-- ваша новая папка
```

## Шаг 2: нарисуйте спрайт-лист (Chara.png)

Игра рисует спутника из `Chara.png`, горизонтального спрайт-листа. Раскладка кадров берётся из значения скина `Game_PuchiChara`, которое по умолчанию равно `256,256,2` (ширина кадра, высота кадра, число кадров), поэтому поставляемые листы имеют размер 512x256 пикселей: два кадра 256x256 рядом, кадр 0 слева. Во время игры игра перебирает кадры и добавляет вертикальное подпрыгивание (спокойное в меню, синхронизированное с битом в игре), поэтому два кадра должны быть двумя позами одного персонажа. Используйте прозрачный фон. Если `Chara.png` отсутствует, запись всё равно загружается, но ничего не рисует.

Поставляемые папки также содержат `Chara.xcf` (исходник GIMP) и `PuchiConfig.txt`. Игра не читает ни тот, ни другой.

```ini
Chara.png : 512 x 256 PNG, transparency
  +-----------------+-----------------+
  |    frame 0      |    frame 1      |
  |   256 x 256     |   256 x 256     |
  +-----------------+-----------------+
```

## Шаг 3: напишите Metadata.json

Создайте `Metadata.json` со следующими полями:

- `name`, `author`, `description`: каждое — простая строка или локализованный объект `{ "strings": { "default": "...", "ja": "...", ... } }`, где `default` — запасное значение, а остальные ключи — коды языков игры.
- `rarity`: одно из `Poor`, `Common`, `Uncommon`, `Rare`, `Epic`, `Legendary`, `Mythical`. Редкость задаёт цвет и уровень уведомления о разблокировке. У каждой редкости множитель монет равен 1, поэтому на заработок она не влияет. Неизвестное значение ведёт себя как `Common`.

Если файл отсутствует, запись загружается с именем `(None)`, редкостью `Common` и автором `(None)`.

```json
{
    "name": {
        "strings": {
            "default": "MyMascot",
            "ja": "マイマスコット"
        }
    },
    "rarity": "Rare",
    "description": {
        "strings": {
            "default": "A friendly companion.\nWaves during play."
        }
    },
    "author": "YourName"
}
```

## Шаг 4 (необязательно): добавьте Effects.json

`Effects.json` даёт пучичаре игровые эффекты. При отсутствии файла все поля по умолчанию выключены:

- `allpurple` (bool): большие ноты дон и ка становятся фиолетовыми нотами, принимающими удар по любому барабану.
- `autoroll` (int): автоматических ударов в секунду по дробям и шарам. Любое значение выше 0 обнуляет множитель монет.
- `showadlib` (bool): показывает скрытые ноты ADLIB. Умножает монеты на 0.9.
- `splitlane` (bool): рисует ноты дон и ка на отдельных дорожках.

Для чисто косметического спутника файл не создавайте.

```json
{
    "allpurple": false,
    "autoroll": 0,
    "showadlib": false,
    "splitlane": false
}
```

## Шаг 5 (необязательно): добавьте Welcome.ogg и Render.png

- `Welcome.ogg`: голосовая реплика, которую игра загружает в группу звуков Voice. Встроенный экран комнаты игры проигрывает её, когда игрок выбирает пучичару; Lua-сценам она недоступна, поэтому скин с собственным экраном комнаты её не проигрывает.
- `Render.png`: полноразмерное статичное изображение, которое Lua-сцены могут рисовать как портрет (текстура `render` записи `PUCHICHARALIST`). Это одиночное изображение любого размера. Ни одна из поставляемых пучичар его не содержит.

Оба файла необязательны.

```
MyMascot/
    Chara.png       (обязателен, анимированный спрайт-лист)
    Metadata.json   (имя, редкость, автор, описание)
    Effects.json    (необязательные игровые эффекты)
    Unlock.json     (необязательное условие разблокировки)
    Welcome.ogg     (необязательная голосовая реплика)
    Render.png      (необязательный портрет)
```

## Шаг 6 (необязательно): добавьте условие разблокировки (Unlock.json)

Без `Unlock.json` пучичара доступна сразу. Чтобы заблокировать её, добавьте `Unlock.json` с полями `condition`, `type`, `values` и `references`; формат и идентификаторы условий те же, что у песен и персонажей (см. руководство по разблокировке). Пример ниже разблокирует, как только игрок заработает в сумме 500 монет. Поставляемые примеры: OpenTaiko-Kun стоит 100 монет (`"condition": "ch"`), Bol требует 20 пройденных чартов автора `bol` (`"condition": "sc"`), а Tinyfox требует одну сыгранную песню жанра `Project Outfox Serenity` (`"condition": "sg"`).

Условия с монетами игрок покупает на экране комнаты. Остальные условия игра проверяет на экране результатов после каждой игры; когда игрок выполняет условие, она добавляет пучичару в список разблокированных в файле сохранения и показывает уведомление.

```json
{
    "condition": "ce",
    "type": "me",
    "values": [
        500
    ]
}
```

## Шаг 7: перезапустите игру и выберите пучичару

Перезапустите игру (или перезагрузите скин из настроек), чтобы игра перестроила список. Откройте экран комнаты и выберите новую запись в списке пучичар. После выбора она появляется во время игры рядом со шкалой. Если во время игры спутник не появляется, проверьте, что в системных настройках включена опция `Draw PuchiChara`.

## Устранение неполадок и примечания

- Имена файлов точные: `Chara.png`, `Metadata.json`, `Effects.json`, `Unlock.json`, `Welcome.ogg`, `Render.png`. Файл с неверным именем игра игнорирует и применяет значение по умолчанию.
- Файлы сохранений и записи разблокировки хранят имя папки дословно. Переименование папки заставляет существующий выбор откатиться к первой папке.
- Игра нарезает спрайт-лист по размеру кадра `Game_PuchiChara` из скина (по умолчанию `256,256,2`). Лист другого размера она нарезает по тем же числам, поэтому кадры получаются обрезанными или смещёнными. Если скин переопределяет `Game_PuchiChara`, подстраивайтесь под это значение. Поставляемый скин его не переопределяет.
- `autoroll` выше 0 обнуляет получение монет, а `showadlib` снижает его до 0.9, поэтому косметический спутник, задающий любой из них, уменьшает заработок своего игрока.
- Поставляемые JSON-файлы содержат завершающие запятые. JSON-парсер игры их принимает; строгие валидаторы их отклоняют.
- Игра строит список один раз при запуске и при перезагрузке скина. Папка, добавленная во время работы игры, появляется после следующего запуска или перезагрузки скина.
