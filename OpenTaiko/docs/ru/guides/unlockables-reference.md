# Справочник по разблокировке

Песни, персонажи, пучичары и таблички имени используют один формат условий разблокировки. Песни, персонажи и пучичары хранят его в файле `Unlock.json`, а таблички имени хранят его в объекте `unlock` своей записи в `Nameplates.json`. Куда помещать каждый файл, объясняют руководства [Разблокировка чартов](unlockables.md), [Добавление персонажей](characters.md), [Добавление пучичар](puchicharas.md) и [Добавление табличек имени](nameplates.md). Эта страница перечисляет поля, идентификаторы условий и числа, которые они используют.

## Поля условия

| Поле | Тип | Значение |
| --- | --- | --- |
| `condition` | string | Идентификатор условия (см. «Идентификаторы условий»). |
| `values` | int array | Числовые параметры условия. |
| `type` | string | Сравнение, которое используют условия по значению (см. «Типы сравнения»). |
| `references` | string array | Идентификаторы песен, имена жанров, имена авторов чартов или имена флагов, в зависимости от условия. |

`Unlock.json` песни добавляет собственные поля (`hidden_index`, `rarity`, `custom_unlock_text`), которые описывает руководство [Разблокировка чартов](unlockables.md).

## Идентификаторы условий

| Идентификатор | Значение | `values` | `references` |
|----|---------|----------|--------------|
| `ch`, `cs`, `cm` | Покупка за монеты. Три идентификатора игра вычисляет одинаково (цена в монетах, `type` принудительно `me`, никогда не выдаётся автоматически). Идентификатор `cm` предназначен для песен; скрипты скина могут читать идентификатор и использовать его, чтобы решить, где предлагать покупку. | `[price]` | не используется |
| `ce` | Всего заработано монет с момента создания файла сохранения | `[coins]` | не используется |
| `tp` | Общее число игр | `[plays]` | не используется |
| `ap` | Число игр в битвах с ИИ | `[plays]` | не используется |
| `aw` | Число побед в битвах с ИИ | `[wins]` | не используется |
| `sd` | Различных чартов, достигших статуса клира | `[chart count, clear status]` | не используется |
| `dp` | Чартов одной сложности, достигших статуса клира | `[difficulty, clear status, chart count]` | не используется |
| `lp` | Чартов одного уровня звёзд, достигших статуса клира | `[level, clear status, chart count]` | не используется |
| `sp` | Конкретные песни, достигшие статуса клира | `[difficulty, clear status]` на песню (`-1` = любая сложность) | по одному идентификатору песни на пару |
| `sg` | Песни в названных жанрах, достигшие статуса клира | `[song count, clear status]` на жанр | по одному имени жанра на пару |
| `sc` | Чарты названных авторов, достигшие статуса клира | `[chart count, clear status]` на автора | по одному имени автора на пару |
| `gt` | Глобальный триггер (именованный флаг вкл/выкл в файле сохранения, который устанавливают скрипты) | `[1]` для ВКЛ, `[0]` для ВЫКЛ | `[trigger name]` |
| `gc` | Глобальный счётчик (именованное число в файле сохранения, которое устанавливают скрипты) | `[value]`, сравнивается через `type` | `[counter name]` |
| `ig` | Невозможно получить: никогда не разблокируется | нет | нет |
| `andcomb` | Игрок должен выполнить все дочерние условия (см. примеры комбинаций в руководстве [Разблокировка чартов](unlockables.md)) | `[]` | по одному дочернему условию на запись, в виде JSON-строки |
| `orcomb` | Игрок должен выполнить хотя бы одно дочернее условие (см. примеры комбинаций в руководстве [Разблокировка чартов](unlockables.md)) | `[]` | по одному дочернему условию на запись, в виде JSON-строки |

Игра проверяет число значений: `ch`/`cs`/`cm`/`ce`/`tp`/`ap`/`aw`/`gt`/`gc` требуют ровно 1 значение, `sd` ровно 2, `dp`/`lp` ровно 3, а `sp`/`sg`/`sc` требуют 2 значения на ссылку и столько ссылок, сколько пар. Неверное число делает условие невыполнимым с сообщением об ошибке в игре.

Условие с монетами разблокирует только явная покупка на экране, который её предлагает. Все остальные условия игра проверяет на экране результатов после каждой игры; когда игрок выполняет условие, игра разблокирует предмет и показывает уведомление.

## Типы сравнения

| `type` | Сравнение |
| --- | --- |
| `l` | меньше |
| `le` | меньше или равно |
| `e` | равно |
| `me` | больше или равно (по умолчанию) |
| `m` | больше |
| `d` | не равно |

Условия с монетами всегда используют `me`, что бы ни указывал `type`.

## Значения статуса клира

Требование статуса означает этот статус или лучше.

| Значение | Статус клира |
| --- | --- |
| 0 | сыграно |
| 1 | клир с помощью |
| 2 | клир |
| 3 | фулл-комбо |
| 4 | олл-перфект |

## Значения сложности

| Значение | Сложность |
| --- | --- |
| 0 | Easy |
| 1 | Normal |
| 2 | Hard |
| 3 | Extreme |
| 4 | Extra Extreme |

Для `dp` сложность 3 также учитывает чарты Extra Extreme. `dp` и `lp` учитывают только обычные чарты и пропускают чарты Dan и Tower. `sp` принимает `-1` в значении «любая сложность».

## Значение модов прохождения

Файл сохранения хранит лучшие прохождения игрока по каждому чарту, сложности и набору модов. Значение модов прохождения упаковывает моды одного прохождения в 8 байт, начиная с младшего байта: прохождение без модов даёт 8925478921.

| Байт | Мод | Значения |
| --- | --- | --- |
| 1 (младший) | Скорость прокрутки | от 0 до 99: 9 соответствует 1.0x, каждый шаг равен 0.1x |
| 2 | Stealth | 0 Off, 1 Doron, 2 Stealth, 3 Hidden, 4 Flashlight |
| 3 | Random | 0 Off, 1 Random, 2 Mirror, 3 SuperRandom, 4 MirrorRandom |
| 4 | Скорость песни | от 2 до 200: 20 соответствует 1.0x, каждый шаг равен 0.05x |
| 5 | Окно тайминга | 0 Loose, 1 Lenient, 2 Normal, 3 Strict, 4 Rigorous |
| 6 | Мод оценки | 0 выключен, 1 Just, 2 Safe |
| 7 | Не используется | 0 |
| 8 (старший) | Фан-мод | 0 None, 1 Avalanche, 2 Minesweeper, 3 Dynamic Beat |

Особые моды (Flawless, Timed) не входят в это значение.
