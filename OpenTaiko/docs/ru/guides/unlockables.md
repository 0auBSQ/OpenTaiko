# Условия разблокировки чартов

Вы можете закрыть пользовательскую песню условием (цена в монетах, клир других песен, общее число игр, сюжетный флаг и так далее), поместив файл `Unlock.json` в папку песни рядом с её `.tja` и `uniqueID.json`. Когда игра строит список песен, она читает этот файл и держит песню заблокированной, пока игрок не выполнит условие. Условия привязываются к отдельным песням: у `box.def` нет ключа разблокировки, поэтому папку жанра таким способом закрыть нельзя.

## Прежде чем начать

- Пользовательский чарт, который уже появляется в списке песен: папка в `Songs/` с `.tja` и, после того как игра её просканировала, `uniqueID.json`.
- Текстовый редактор, сохраняющий в UTF-8.
- Для условий, ссылающихся на другие песни: значение `id` из `uniqueID.json` каждой упоминаемой песни.
- Игра хранит прогресс разблокировки в каждом файле сохранения отдельно, поэтому, чтобы увидеть, как песня открывается, вы должны выполнить условие в игре. Опция `Ignore Song Unlockables` в настройках Game считает каждую песню разблокированной, пока вы тестируете.

## Шаг 1: создайте файл Unlock.json

Создайте `Unlock.json` в папке песни. Каждое поле необязательно и имеет значение по умолчанию:

- `hidden_index` (int, по умолчанию 0): как список песен показывает заблокированную песню (см. таблицу ниже). Игра ограничивает значения диапазоном 0-3.
- `rarity` (string, по умолчанию `Common`): название редкости (см. таблицу ниже). Она задаёт цвет отображения редкости и уровень уведомления о разблокировке. Пустое значение становится `Common`.
- `condition` (string, по умолчанию `ch`): идентификатор условия (шаг 2).
- `values` (int array, по умолчанию `[100]`): числовые параметры условия.
- `type` (string, по умолчанию `me`): сравнение, которое используют условия по значению: `l` меньше, `le` меньше или равно, `e` равно, `me` больше или равно, `m` больше, `d` не равно. Условия с монетами всегда используют `me`.
- `references` (string array, по умолчанию `[""]`): идентификаторы песен, имена жанров, имена авторов чартов или имена флагов, в зависимости от условия.
- `custom_unlock_text` (object, необязательно): заменяет сгенерированный текст подсказки. Локализованный объект `{ "strings": { "default": "...", "ja": "..." } }`; игра использует ключ активного языка, затем `default` и показывает сгенерированный текст, если нет ни того, ни другого.

Ключи пишутся в нижнем регистре с подчёркиваниями, ровно как перечислено.

Значения hidden_index:

| Значение | В списке песен |
| --- | --- |
| 0 | Показана со значком замка; превью аудио проигрывается |
| 1 | Затенена; без превью |
| 2 | Затенена, со скрытыми названием и превью-изображением |
| 3 | Скрыта до разблокировки |

Значения редкости:

| Редкость | Уровень уведомления |
| --- | --- |
| <span class="rarity rarity-poor">Poor</span> | 0 |
| <span class="rarity rarity-common">Common</span> | 0 |
| <span class="rarity rarity-uncommon">Uncommon</span> | 1 |
| <span class="rarity rarity-rare">Rare</span> | 2 |
| <span class="rarity rarity-epic">Epic</span> | 3 |
| <span class="rarity rarity-legendary">Legendary</span> | 4 |
| <span class="rarity rarity-mythical">Mythical</span> | 4 |

```json
{
  "hidden_index": 0,
  "rarity": "Common",
  "condition": "cm",
  "values": [500],
  "type": "me",
  "references": [""],
  "custom_unlock_text": {
    "strings": {
      "default": "Buy this song for 500 coins.",
      "ja": "500コインで解放できます。"
    }
  }
}
```

## Шаг 2: выберите условие

| Идентификатор | Значение | `values` | `references` |
|----|---------|----------|--------------|
| `ch`, `cs`, `cm` | Покупка за монеты. Три идентификатора игра вычисляет одинаково (цена в монетах, `type` принудительно `me`, никогда не выдаётся автоматически). `cm` — идентификатор, предназначенный для песен; скрипты скина могут читать идентификатор и использовать его, чтобы решить, где предлагать покупку. | `[price]` | не используется |
| `ce` | Всего заработано монет с момента создания файла сохранения | `[coins]` | не используется |
| `tp` | Общее число игр | `[plays]` | не используется |
| `ap` | Число игр в битвах с ИИ | `[plays]` | не используется |
| `aw` | Число побед в битвах с ИИ | `[wins]` | не используется |
| `sd` | Различных чартов, достигших статуса клира | `[chart count, clear status]` | не используется |
| `dp` | Чартов одной сложности, достигших статуса клира | `[difficulty, clear status, chart count]` | не используется |
| `lp` | Чартов одного уровня звёзд, достигших статуса клира | `[level, clear status, chart count]` | не используется |
| `sp` | Конкретные песни, достигшие статуса клира | `[difficulty, clear status]` на песню (`-1` = любая сложность) | по одному идентификатору песни на пару |
| `sg` | Песни в названных жанрах, достигшие статуса клира | `[song count, clear status]` на жанр | по одному имени жанра на пару |
| `sc` | Чарты названных авторов, достигшие статуса клира | `[chart count, clear status]` на автора | по одному имени автора на пару |
| `gt` | Глобальный триггер (именованный флаг вкл/выкл в файле сохранения, который устанавливают скрипты) | `[1]` для ВКЛ, `[0]` для ВЫКЛ | `[trigger name]` |
| `gc` | Глобальный счётчик (именованное число в файле сохранения, которое устанавливают скрипты) | `[value]`, сравнивается через `type` | `[counter name]` |
| `ig` | Невозможно получить: никогда не разблокируется | нет | нет |
| `andcomb` | Игрок должен выполнить все дочерние условия (см. примеры комбинаций) | `[]` | по одному дочернему условию на запись, в виде JSON-строки |
| `orcomb` | Игрок должен выполнить хотя бы одно дочернее условие (см. примеры комбинаций) | `[]` | по одному дочернему условию на запись, в виде JSON-строки |

Значения статуса клира (требование статуса означает этот статус или лучше):

| Значение | Статус клира |
| --- | --- |
| 0 | сыграно |
| 1 | клир с помощью |
| 2 | клир |
| 3 | фулл-комбо |
| 4 | олл-перфект |

Значения сложности:

| Значение | Сложность |
| --- | --- |
| 0 | Easy |
| 1 | Normal |
| 2 | Hard |
| 3 | Extreme |
| 4 | Extra Extreme |

Для `dp` сложность 3 также учитывает чарты Extra Extreme. `dp` и `lp` учитывают только обычные чарты и пропускают чарты Dan и Tower. `sp` принимает `-1` в значении «любая сложность».

Игра проверяет число значений: `ch`/`cs`/`cm`/`ce`/`tp`/`ap`/`aw`/`gt`/`gc` требуют ровно 1 значение, `sd` ровно 2, `dp`/`lp` ровно 3, а `sp`/`sg`/`sc` требуют 2 значения на ссылку и столько ссылок, сколько пар. Неверное число делает условие невыполнимым с сообщением об ошибке в игре.

Условие с монетами разблокирует только явная покупка на экране, который её предлагает (поставляемый скин предлагает купить заблокированные песни из выбора песни, какой бы идентификатор монет вы ни использовали). Все остальные условия игра проверяет на экране результатов после каждой игры; когда игрок выполняет условие, игра добавляет идентификатор песни в файл сохранения и показывает уведомление.

## Шаг 3: проверьте в игре

Запустите игру и откройте выбор песни. В зависимости от `hidden_index` песня показывает замок, затенена, скрыта частично или отсутствует. Купите её или выполните условие, затем убедитесь, что она остаётся разблокированной после перезапуска. Включите `Ignore Song Unlockables` в настройках Game, чтобы обходить все блокировки, пока вы итерируете.

## Примеры

Это схемы условий, которыми пользуются поставляемые песни, в виде файлов `Unlock.json`. Замените идентификаторы, имена и числа своими.

**Покупка песни за монеты (`cm`).** Самый частый случай. Цена — единственное значение, а `type` игра игнорирует. `hidden_index` 0 оставляет песню видимой, чтобы игрок мог найти и купить её. Сгенерированная подсказка уже указывает цену, поэтому `custom_unlock_text` вам не нужен.

```json
{
  "hidden_index": 0,
  "rarity": "Uncommon",
  "condition": "cm",
  "values": [500]
}
```

**Общее число игр (`tp`).** Поставляемые главы открывают свои песни одну за другой с растущим числом игр (10, 15, 20 и так далее), чтобы у игрока всегда была следующая песня в пределах досягаемости. `ap` (игры в битвах с ИИ), `aw` (победы в битвах с ИИ) и `ce` (всего заработано монет) используют ту же схему с одним значением.

```json
{
  "hidden_index": 1,
  "rarity": "Common",
  "condition": "tp",
  "values": [50]
}
```

**Клир конкретной песни (`sp`).** Схема, которую большинство поставляемых песен используют для сиквела или ремикса. `-1` в качестве сложности принимает клир на любой сложности; идентификатор — это поле `id` из `uniqueID.json` упоминаемой песни (игра генерирует 64-символьный идентификатор при первом сканировании песни без него, а поставляемые песни могут содержать идентификатор, написанный вручную). Пример разблокирует после того, как игрок пройдёт упоминаемую песню.

```json
{
  "hidden_index": 1,
  "rarity": "Common",
  "condition": "sp",
  "values": [-1, 2],
  "references": ["4xtDLgcLGqMLaXd7mq344TtjhhR4dopA4ykf5wTCfFq8UOdHFBlwpW2lSJ9ndcVU"]
}
```

**Фулл-комбо нескольких песен (`sp`).** Каждая дополнительная песня добавляет пару значений и ссылку, и игрок должен выполнить требование для каждой упоминаемой песни. Пример требует фулл-комбо (3) на двух песнях.

```json
{
  "hidden_index": 2,
  "rarity": "Rare",
  "condition": "sp",
  "values": [-1, 3, -1, 3],
  "references": ["4xtDLgcLGqMLaXd7mq344TtjhhR4dopA4ykf5wTCfFq8UOdHFBlwpW2lSJ9ndcVU", "4aJ2I19XyEG2cEA9tlmdnZSz2H43OKsVBPLi52UfRhSjDGNgTGGqhmqkbWfPDoyw"]
}
```

**Клир песен жанра (`sg`).** Каждая запись — `[song count, clear status]` с именем жанра в `references`. Жанр — тот, который игра записывает, когда игрок играет песню: `#GENRE` из `box.def` содержащей папки или собственный `#GENRE` чарта, когда у папки его нет. Поставляемые главы используют это для своих медли. Пример разблокирует после того, как игрок пройдёт 10 различных песен этого жанра.

```json
{
  "hidden_index": 1,
  "rarity": "Uncommon",
  "condition": "sg",
  "values": [10, 2],
  "references": ["OpenTaiko Chapter II"]
}
```

**Клир чартов одного автора (`sc`).** Та же схема с именами `#NOTESDESIGNER` в качестве ссылок. Пример требует 5 пройденных чартов одного автора; второй автор добавляет ещё одну пару значений и ссылку.

```json
{
  "hidden_index": 1,
  "rarity": "Uncommon",
  "condition": "sc",
  "values": [5, 2],
  "references": ["bol"]
}
```

**Клир заданного числа различных чартов (`sd`).** Учитывает каждый чарт, который в файле сохранения имеет указанный статус или лучше. Пример требует 10 фулл-комбо.

```json
{
  "hidden_index": 2,
  "rarity": "Rare",
  "condition": "sd",
  "values": [10, 3]
}
```

**Клир чартов одной сложности или одного уровня звёзд (`dp` / `lp`).** `dp` учитывает чарты одной сложности, `lp` — чарты одного уровня звёзд. Первый пример требует 20 пройденных чартов Extreme, второй — один пройденный чарт на 7 звёзд.

```json
{
  "hidden_index": 1,
  "rarity": "Uncommon",
  "condition": "dp",
  "values": [3, 2, 20]
}
```

```json
{
  "hidden_index": 1,
  "rarity": "Common",
  "condition": "lp",
  "values": [7, 2, 1]
}
```

**Любое из двух условий (`orcomb`).** `values` пуст, а каждая запись `references` — полное дочернее условие (`condition`, `type`, `values`, `references`), записанное как JSON-строка. Поставляемые песни используют это, чтобы предложить короткий путь: сыграть достаточно песен или заплатить. `orcomb` использует самую дешёвую выполненную ветвь, когда вычисляет цену покупки.

```json
{
  "hidden_index": 0,
  "rarity": "Common",
  "condition": "orcomb",
  "values": [],
  "references": [
    "{\"condition\": \"tp\", \"type\": \"me\", \"values\": [100]}",
    "{\"condition\": \"cm\", \"type\": \"me\", \"values\": [200]}"
  ]
}
```

**Все из нескольких условий (`andcomb`).** Та же схема; игрок должен выполнить каждое дочернее условие. Дочерние условия сами могут быть комбинациями, а `andcomb` складывает цены в монетах внутри комбинации. Пример требует клир одной песни и клир любого чарта на 7 звёзд.

```json
{
  "hidden_index": 1,
  "rarity": "Uncommon",
  "condition": "andcomb",
  "values": [],
  "references": [
    "{\"condition\": \"sp\", \"type\": \"me\", \"values\": [-1, 2], \"references\": [\"4xtDLgcLGqMLaXd7mq344TtjhhR4dopA4ykf5wTCfFq8UOdHFBlwpW2lSJ9ndcVU\"]}",
    "{\"condition\": \"lp\", \"type\": \"me\", \"values\": [7, 2, 1], \"references\": [\"\"]}"
  ]
}
```

**Сюжетный флаг с собственной подсказкой (`gt`).** `gt` читает именованный флаг вкл/выкл из файла сохранения. Флаги устанавливают Lua-скрипты (сюжетные сцены, катсцены), поэтому используйте `gt` только тогда, когда флаг устанавливает скрипт, который вы контролируете. `values` — `[1]` для ВКЛ или `[0]` для ВЫКЛ; `references` содержит имя флага. У сюжетной разблокировки нет самоочевидной сгенерированной подсказки, поэтому здесь полезен `custom_unlock_text`. Вы можете указать любой ключ языка; `default` — запасное значение.

```json
{
  "hidden_index": 3,
  "rarity": "Legendary",
  "condition": "gt",
  "values": [1],
  "references": ["story_done"],
  "custom_unlock_text": {
    "strings": {
      "default": "Finish the story to unlock this song.",
      "ja": "ストーリーをクリアするとこの曲が解放されます。"
    }
  }
}
```

**Секретная песня с загадкой.** Поставляемые секретные песни сочетают высокий `hidden_index` (название и превью остаются скрытыми, или песня отсутствует до разблокировки) с `custom_unlock_text`, который намекает на условие вместо того, чтобы называть его. Под ним работает любое условие; пример прячет требование фулл-комбо за загадкой.

```json
{
  "hidden_index": 2,
  "rarity": "Epic",
  "condition": "sp",
  "values": [-1, 3],
  "references": ["4xtDLgcLGqMLaXd7mq344TtjhhR4dopA4ykf5wTCfFq8UOdHFBlwpW2lSJ9ndcVU"],
  "custom_unlock_text": {
    "strings": {
      "default": "Perfect the storm that came before this one."
    }
  }
}
```

## Устранение неполадок и примечания

- Песня не заблокирована: файл называется не `Unlock.json`, он лежит не в той папке, где находятся `.tja` и `uniqueID.json`, или включена опция `Ignore Song Unlockables`.
- Подсказка сообщает, что условие недействительно: число значений не соответствует условию (см. шаг 2) или у `sp`/`sg`/`sc` число ссылок не совпадает с числом пар значений.
- Ключ не действует: ключи — это `hidden_index`, `rarity`, `condition`, `values`, `type`, `references`, `custom_unlock_text`, все в нижнем регистре. Всё остальное игра игнорирует и применяет значение по умолчанию.
- `sp` никогда не разблокируется: ссылка должна быть идентификатором из `uniqueID.json` целевой песни (название или имя файла никогда не совпадает), и игрок должен быть в состоянии достичь сложности и статуса (статус 3 — это фулл-комбо, поэтому чарт, который игрок только прошёл, не считается).
- `sg` никогда не разблокируется: имя жанра должно совпадать с жанром, который игра записывает для сыгранных песен (`#GENRE` из `box.def` папки или `#GENRE` чарта, когда у папки жанра нет).
- `gt`/`gc` никогда не разблокируются: ничто не устанавливает названный флаг. Чарт не может установить его сам.
- Ничто не разблокирует `ig` в игре. Используйте его только для контента, который выдаёт какая-то другая система.
- `custom_unlock_text` должен быть объектом `{ "strings": { ... } }`; голая строка не работает.
- Поставляемые файлы `Unlock.json` содержат завершающие запятые. JSON-парсер игры их принимает; строгие валидаторы их отклоняют.
