# Calendar

## Calendar.almanac

Шаблоны дат для событий, которые приходят и уходят вместе с календарём: избранный товар магазина на Рождество, первоапрельская сцена, ежемесячный бонус. Дни считаются по японскому стандартному времени (UTC+9), что бы ни показывали часы игрока, поэтому все игроки видят один и тот же день. Шаблон можно записать непрозрачным токеном `enc:`, чтобы сюрприз не был виден в исходном коде.

| Шаблон | Соответствует |
| --- | --- |
| `"2026-06-15"` | Этому дню. |
| `"2026-06-15+30"` | Этому дню и 29 дням после него. |
| `"2026-06-15..2026-07-31"` | Диапазону, включая оба конца (оба записаны полностью). |
| `"*-06-15"`, `"*-06-15+7"` | Этому дню или этой неделе каждый год. |
| `"*-*-01"`, `"2026-*-13"` | 1-му числу каждого месяца; каждому 13-му числу 2026 года. |
| `"*-06-*"`, `"2026-12-*"` | Целому месяцу каждый год; одному месяцу. |
| `{ "...", "..." }` | Любому из нескольких шаблонов. |

Запись — это таблица `{ code, when, priority, sticky }`: она активна, пока `when` совпадает. `sticky = true` оставляет её активной для файла сохранения, как только она однажды совпала в нём, через триггер `.almanac_<code>` этого сохранения. `code` тоже может быть токеном `enc:`.

| Функция | Описание |
| --- | --- |
| `Almanac.matches(spec)  -> bool` | Совпадает ли сегодняшний день с шаблоном, токеном или их списком. |
| `Almanac.active(entry, save?)  -> bool` | Активна ли запись сегодня; с файлом сохранения запись sticky, однажды совпавшая, остаётся активной, а совпадение устанавливает её триггер. |
| `Almanac.pick(entries, save?, skip?)  -> entry` | Активная запись с наибольшим `priority` (при равенстве — первая) или nil. Если `skip(entry)` возвращает true, запись исключается (например, то, что у игрока уже есть). |
| `Almanac.encrypt(pattern)  -> string` | Токен `enc:` для шаблона или кода. |
| `Almanac.decrypt(token)  -> string` | Текст токена или nil, если токен недействителен. |
| `Almanac.plain(s)  -> string` | Расшифрованный токен или `s` как есть. |
| `Almanac.parse(spec)  -> table` | Один разобранный шаблон (nil, если он записан неверно) для `matchesPattern`. |
| `Almanac.matchesPattern(p)  -> bool` | Совпадает ли сегодняшний день с разобранным шаблоном. |

```lua
local Almanac = require("Calendar.almanac")
local EVENTS = {
    { code = "winter", when = "*-12-20+12", priority = 80 },
    { code = "spring", when = "*-03-20+14", priority = 50, sticky = true },
}
local now = Almanac.pick(EVENTS, GetSaveFile(0))
if now ~= nil then banner = now.code end
```
