# Characters

## Characters.Student

Сюжетный студент, которым ходит игрок, A или B, и цветовая палитра этого студента, чтобы все сюжетные сцены рисовали одного и того же студента в одних и тех же цветах. Студенты — это персонажи `02v2 - Student (A)` и `03v2 - Student (B)` из `Global/Characters/`.

Всё хранится в файле сохранения:

| Ключ сохранения | Тип | Содержимое |
| --- | --- | --- |
| `story_student` | счётчик | Выбранный студент: 1 — это B; любое другое значение, включая отсутствующее, читается как A. |
| `.character_palette_<folder>` | счётчик | Индекс палитры персонажа студента, считая с 0, — тот же счётчик, который записывает экран настройки персонажа, так что они не расходятся. У A и B он свой. |
| `.character_playcount_<folder>` | счётчик | Число игр этим персонажем, которые открывают палитры. |

Палитры студента — это `Palettes.json` персонажа, за которыми следуют палитры из собственной копии модуля (`Global/Modules/Lib/Characters/Student/<id>/Palettes.json`), которых нет в файле персонажа, сопоставленные по `name`. У персонажа без палитр или не установленного персонажа всё равно есть палитры копии. Индекс за пределами списка читается как палитра по умолчанию, 0.

| Функция | Описание |
| --- | --- |
| `Student.current(save)  -> "a" or "b"` | Студент, выбранный в сохранении. |
| `Student.ensure(save)  -> "a" or "b"` | То же, но записывает A в счётчик, если в нём нет студента. |
| `Student.set(save, id)  -> id` | Выбирает студента. |
| `Student.folder(id)  -> string` | Имя папки персонажа студента. |
| `Student.index(save, id)  -> number` | Индекс палитры студента, всегда допустимый. |
| `Student.setIndex(save, id, idx)  -> number` | Сохраняет индекс палитры; если этот персонаж надет в сохранении, его текущая палитра тоже меняется. |
| `Student.palettes(id)  -> table` | Список палитр: записи `{ name, plays, blend, stops }`, запись `i` для индекса `i - 1`; `name` дан на языке игры, если файл его содержит. |
| `Student.count(id)`, `Student.entry(id, idx)`, `Student.clamp(id, idx)` | Число палитр, одна запись, индекс, приведённый к допустимому. |
| `Student.unlocked(save, id, idx)  -> bool` | Открыта ли палитра: требования по играм нет или игр этим персонажем достаточно. |
| `Student.gradient(id, idx)  -> gradient` | Палитра в виде карты `GRADIENT` или nil для палитры без цветов. |
| `Student.withPalette(id, idx, fn, ...)` | Выполняет `fn` (2D-отрисовку) с активной палитрой. Возвращает результаты pcall. |
| `Student.registerSprite(scene, spriteId, tex, id, idx)  -> bool` | Регистрирует `tex` как спрайт-билборд 3D-сцены, перекрашенный в палитру. |
| `Student.reload()` | Забывает разобранные файлы палитр; при следующем запросе они читаются заново. |

`palettes`, `count`, `entry`, `clamp`, `gradient` и `registerSprite` принимают необязательный последний аргумент `visitor`: true — для списка студента другого игрока (сетевого гостя), который кэшируется отдельно от списка самого игрока.

```lua
local Student = require("Characters.Student")
local save = GetSaveFile(0)
local id  = Student.current(save)
local idx = Student.index(save, id)
Student.withPalette(id, idx, function() tex:Draw(x, y) end)
```
