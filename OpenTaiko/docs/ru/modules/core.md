# Core

Небольшие вспомогательные модули без собственного экрана: кривые сглаживания, работа с цветом, утилиты для таблиц, кодировщик и декодер JSON и папка текущего файла. При загрузке они не трогают состояние движка, поэтому их может подключить любой модуль, в том числе модуль только для чтения.

## Core.Easing

Кривые сглаживания на отношении от 0 до 1 для анимаций, которые идут по вашим собственным часам (временная шкала, возраст частицы). Для анимации по часам движка другой вариант — глобальный объект `COUNTER` с SetEasing. Каждая кривая ограничивает вход диапазоном 0..1 и переводит 0 в 0, а 1 в 1, кроме `hump`.

| Функция | Описание |
| --- | --- |
| `Easing.linear(t)  -> number` | Само ограниченное отношение. |
| `Easing.inQuad(t)`, `outQuad`, `inOutQuad`, `inCubic`, `outCubic`, `inOutCubic`, `inSine`, `outSine`, `inOutSine`, `inExpo`, `outExpo`  `-> number` | Обычные кривые, по имени. |
| `Easing.inBack(t, s?)`, `Easing.outBack(t, s?)  -> number` | Кривые с перелётом; `s` — величина перелёта (по умолчанию 1.7). |
| `Easing.inBounce(t)`, `Easing.outBounce(t)`, `Easing.outElastic(t)  -> number` | Кривые с отскоком и упругие кривые. |
| `Easing.hump(t)  -> number` | 0, подъём до 1 в середине и обратно до 0: для сжатий и вспышек. |
| `Easing.span(t, t0, dur)  -> number` | Прогресс окна, которое начинается в `t0` и длится `dur`, ограниченный диапазоном 0..1. |
| `Easing.lerp(a, b, k)  -> number` | `a + (b - a) * k`. |
| `Easing.clamp01(t)  -> number` | `t`, ограниченное диапазоном 0..1. |
| `Easing.get(kind, fn)  -> function` | Кривая по именам сглаживания движка: `kind` — `"IN"`, `"OUT"` или `"INOUT"`, `fn` — `"LINEAR"`, `"SINE"`, `"QUAD"`, `"CUBIC"`, `"EXPO"`, `"BACK"`, `"BOUNCE"` или `"ELASTIC"`. Пара без кривой даёт кривую QUAD. |

```lua
local Easing = require("Core.Easing")
local k = Easing.outBack(Easing.span(t, startTime, 0.4))
x = Easing.lerp(x0, x1, k)
```

## Core.Color

Преобразования и коррекция цвета. Каждый канал — число с плавающей точкой от 0 до 1, включая тон (от 0 до 1 по цветовому кругу); функции принимают и возвращают отдельные значения `r, g, b`.

| Функция | Описание |
| --- | --- |
| `Color.rgbToHsv(r, g, b)  -> h, s, v` | Из RGB в HSV. |
| `Color.hsvToRgb(h, s, v)  -> r, g, b` | Из HSV в RGB. |
| `Color.rgbToHsl(r, g, b)  -> h, s, l` | Из RGB в HSL. |
| `Color.hslToRgb(h, s, l)  -> r, g, b` | Из HSL в RGB. |
| `Color.mix(r, g, b, r2, g2, b2, t)  -> r, g, b` | Линейное смешивание: `t` = 0 оставляет первый цвет, 1 даёт второй. |
| `Color.lighten(r, g, b, amount)  -> r, g, b` | Сдвигает светлоту HSL к белому на долю `amount` оставшегося диапазона (1 = белый); тон и насыщенность сохраняются. |
| `Color.darken(r, g, b, amount)  -> r, g, b` | Сдвигает светлоту HSL к чёрному на `amount` (1 = чёрный). |
| `Color.saturate(r, g, b, factor, add?)  -> r, g, b` | Умножает насыщенность HSV на `factor`, прибавляет `add` и ограничивает результат единицей. |
| `Color.brighten(r, g, b, factor)  -> r, g, b` | Умножает значение HSV на `factor`, с ограничением единицей. |
| `Color.ramp(from, to, n)  -> table` | `n` цветов, ступенчато идущих от `{r, g, b}` к `{r, g, b}`, в виде списка `{r, g, b}`. |
| `Color.fromEngine(col)  -> r, g, b, a` | Каналы объекта `COLOR` в виде чисел с плавающей точкой. |
| `Color.toEngine(r, g, b, a?)  -> color` | Объект `COLOR` из чисел с плавающей точкой (альфа по умолчанию 1). |
| `Color.rampEngine(fromCol, toCol, n)  -> table` | Градиент из `n` объектов `COLOR` между двумя объектами `COLOR`. |
| `Color.clamp01(v)  -> number` | `v`, ограниченное диапазоном 0..1. |

## Core.Json

Текст JSON из значений Lua и обратно, на чистом Lua. В отличие от `JSONLOADER`, который разбирает файлы в словари .NET, он работает с таблицами Lua, поэтому подходит для данных, которые вы храните в строке сохранения (`sf:SetGlobalString`) или в значении базы данных.

| Функция | Описание |
| --- | --- |
| `Json.encode(value)  -> string` | Таблица с ключами 1..n записывается как массив, любая другая — как объект с отсортированными ключами, поэтому одно и то же значение всегда даёт один и тот же текст. Функции и userdata в объекты не попадают; целые числа записываются без десятичной точки. Таблица, содержащая саму себя, вызывает ошибку. |
| `Json.decode(text)  -> value` или `nil, message` | Разбирает текст JSON. JSON `null` становится `Json.null`; при синтаксической ошибке возвращает nil и сообщение с позицией. |
| `Json.null` | Значение, обозначающее JSON `null`; при кодировании снова превращается в `null`. |

```lua
local Json = require("Core.Json")
local sf = GetSaveFile(0)
local data = Json.decode(sf:GetGlobalString("my_feature")) or { v = 1, items = {} }
data.items[#data.items + 1] = "lamp"
sf:SetGlobalString("my_feature", Json.encode(data))
```

## Core.Here

Функция, которая возвращает папку вызвавшего её файла по аргументам, которые `require` передаёт этому файлу. Так файл Lib находит собственные ресурсы (см. [Ресурсы разрешаются относительно вызывающего модуля](README.md)).

| Функция | Описание |
| --- | --- |
| `require("Core.Here")(...)  -> string` | Абсолютная папка файла, с прямыми косыми чертами и завершающим `/`; nil, если файл загружен не через `require`. Вызывайте её на верхнем уровне файла, где `...` содержит имя модуля и путь к файлу. |
