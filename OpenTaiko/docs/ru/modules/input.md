# Input

## Input.NavInput

Навигация по меню сразу со всех устройств: стрелки клавиатуры, Return и Escape, универсальные действия настройки клавиш (`RightChange`, `LeftChange`, `Decide`, `Cancel`) и барабан каждого игрока (синие ободы для перемещения, красные центры для подтверждения). Экран спрашивает «нажал ли игрок подтверждение?», не перечисляя клавиш, и при этом действует собственная настройка клавиш игрока.

Каждая привязка — функция, которая возвращает true в этом кадре. Добавьте к имени `Pressed` (то же, что без суффикса), `Pressing` или `Released` для других событий ввода: `decide()`, `decidePressing()`, `leftReleased()`.

| Привязка | Реагирует на |
| --- | --- |
| `right`, `left` | Стрелку вправо или влево, `RightChange` / `LeftChange`, синий обод. |
| `rightKeyboard`, `leftKeyboard` | Только клавишу со стрелкой. |
| `up`, `down` | Стрелку вверх или вниз (у барабанов нет вертикального ввода). |
| `upOrPadLeft`, `downOrPadRight` | Стрелку вверх (вниз) или то, на что реагирует `left` (`right`) на геймпаде или барабане: вертикальный список, который можно прокручивать барабаном. |
| `decide` | Return, `Decide`, красный центр. |
| `cancel` | Escape, `Cancel`. |
| `rightOtherPlayer`, `leftOtherPlayer` | Только в наборах отдельных игроков: стрелку или синий обод другого игрока. |

| Функция или поле | Описание |
| --- | --- |
| `NavInput.decide()`, `NavInput.left()`, ...  `-> bool` | Привязки сразу для всех игроков: клавиатура, универсальные действия и барабан любого игрока. |
| `NavInput.getPn(player)  -> table` | Привязки одного игрока: от 1 до 5 — барабан этого игрока плюс клавиатура и универсальные действия, 0 — только клавиатура и универсальные действия, `""` или nil — все игроки (то же, что сокращения выше). |
| `NavInput.p[player]` | Таблицы `getPn` для значений от 0 до 5 и `""`, построенные один раз. |
| `NavInput.bindingNames(binding, player?)  -> string[]` | То, на что реагирует привязка, в виде отображаемых имён для подсказки: сначала клавиша клавиатуры, затем привязки из настройки клавиш (`"Pad 3"`, `"MIDI 38"`, `"Mouse Left"`), без повторов. |
| `NavInput.keyName(key)  -> string` | Отображаемое имя клавиши клавиатуры (`"Return"` даёт `"Enter"`, `"D1"` даёт `"1"`); nil, если клавиши нет. |

```lua
local NavInput = require("Input.NavInput")
local p1 = NavInput.getPn(1)

function update(ts)
    if p1.right() then cursor = cursor + 1 end
    if p1.left() then cursor = cursor - 1 end
    if NavInput.cancel() then return Exit("stage", "_title") end
end
```
