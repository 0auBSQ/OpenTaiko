# Locale

## Locale.i18n

Собственные переводы модуля, которые хранятся рядом с ним, а не в `Locales/` скина. Тексты лежат в `lang/<code>/<name>.json`, по одному файлу на функцию, с ключами в виде стабильных идентификаторов; `lang/en/` содержит английский текст и служит запасным вариантом для всех остальных языков. Коды — это идентификаторы языков игры: `en`, `de`, `es`, `fr`, `ja`, `ko`, `nl`, `ru`, `zh`.

```
Global/Modules/Stages/my_stage/
  Script.lua
  lang/
    en/menu.json      { "title": "Settings", "count": "%d items", "tips": ["One", "Two"] }
    ja/menu.json      { "title": "設定", "count": "%d 件" }
```

| Функция или поле | Описание |
| --- | --- |
| `I18N.texts(name, dir?)  -> texts` | Тексты из `lang/<code>/<name>.json`. `dir` — папка, в которой лежит `lang/`: в сцене или Activity опустите его (или передайте `""`), чтобы использовать их собственную папку, а в файле Lib передайте папку из `Core.Here`. Файлы читаются при первом обращении и сохраняются. |
| `I18N.detect()` | Читает текущий язык игры и делает его языком всех поисков. Вызывайте в `activate`, который выполняется при каждом входе, чтобы язык, изменённый в настройках, применялся при следующем посещении. |
| `I18N.load(code)` | Использует язык `code` (для тестового стенда или предпросмотра языка). |
| `I18N.currentCode()  -> string` | Идентификатор текущего языка игры, `"en"`, если движок его не сообщает. |
| `I18N.code` | Язык, который сейчас используют поиски. |
| `I18N.localizedPath(path, code?)  -> string` | `<name>_<code>.<ext>`, если рядом с `path` есть текстура с таким именем, иначе `path`: для картинок со встроенным текстом. |

| Метод | Описание |
| --- | --- |
| `texts:tr(id)  -> string` | Текст для `id`; сам id, если его нет ни в одном языке, так что пробел виден на экране. |
| `texts:trf(id, ...)  -> string` | Текст для `id`, использованный как шаблон `string.format` с аргументами. |
| `texts:get(...)  -> string` | Строка по пути ключей (`texts:get("menu", "title")` для вложенных объектов), nil, если её нет или она пуста. |
| `texts:list(...)  -> table` | Массив строк по пути ключей; каждый элемент по отдельности откатывается к английскому. |
| `texts:loc(...)  -> handle` | Дескриптор, чей `GetString(fallback)` читает путь ключей в момент вызова, так что имя, закэшированное при загрузке, следует за последующей сменой языка. |
| `texts:node(...)  -> value` | Необработанный узел JSON по пути ключей (на текущем языке, иначе на английском). |

```lua
local I18N = require("Locale.i18n")
local T = I18N.texts("menu")
local title, count

function activate()
    I18N.detect()
    title = T:tr("title")
    count = T:trf("count", #items)
end
```

<div class="callout warn">
Поиски следуют `I18N.code`, который меняется только при вызове `detect` или `load`. Модуль, который остаётся на экране, пока игрок меняет язык, может определить глобальную функцию `reloadLanguage(lang)` и вызвать в ней `detect`. Текстовые модули Pagoda, Vault и Shop сами проверяют язык при каждом поиске.
</div>

Старые модули вместо этого используют словарь с точным английским текстом: `lang/<code>.lua` возвращает таблицу, сопоставляющую каждой английской строке её перевод, `detect` загружает таблицу для текущего языка, а функции `I18N.tr(s)` и `I18N.trf(fmt, ...)` ищут в ней строки. Эта форма по-прежнему работает; новые модули должны использовать `texts`.
