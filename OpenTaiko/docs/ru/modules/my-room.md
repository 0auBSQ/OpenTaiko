# Моя комната

Моя комната — глобальная сцена `my_room` в `Global/Modules/Stages/`: комната игрока, по которой он ходит, которую обставляет тем, что дают пагода, хранилище и магазин за монеты, и которую открывает для сетевых гостей. Её может открыть любой скин, и все скины показывают одну и ту же комнату, потому что её данные хранятся в файле сохранения.

## Вход и выход

Задайте в общей строке `my_room_return` сцену, в которую Моя комната должна вернуться, затем выйдите в `my_room`:

```lua
SHARED:SetSharedString("my_room_return", "my_menu")               -- back to my_menu
-- or, with the transition to play on the way back:
SHARED:SetSharedString("my_room_return", "my_menu|my_transition")
return Exit("stage", "my_room")
```

Моя комната читает строку и очищает её при входе. Если строка пуста, возврат идёт на титульный экран (`_title`).

Общая строка `my_room_place` запоминает, чья это была комната и где стоял игрок, на время выходов из комнаты и возвращения: из комнаты ведут и матрица-заглушка (предмет мебели со списком сцен, которые можно посетить), и капсула (предмет, который открывает другую сцену). Титульный экран может очистить её (задать `""`), чтобы следующее посещение начиналось у двери.

Open-World Memories сохраняет сцену-переадресацию `myroom` для старых вызовов `Exit("stage", "myroom")` и выхода движка `"heya"`; она будет удалена к официальному релизу, поэтому новый код должен выходить в `my_room`.

## Её данные

| Ключ | Тип | Содержимое |
| --- | --- | --- |
| `my_room` | строка сохранения | Комната в виде JSON `{ v, room, jukebox }` (`sf:GetGlobalString("my_room")`). Записывается только для собственного слота сохранения: никогда для сетевого гостя или пустого слота. |
| `.myroom_<id>` | счётчик | Мебель, которую выдаёт другая сцена: Моя комната один раз добавляет её в запас комнаты при следующем посещении и ведёт учёт того, что уже забрала. |
| `.myroom_held_<id>` | счётчик | Сколько таких предметов есть в сохранении. Моя комната поддерживает его в актуальном состоянии; сцена, которая выдаёт предмет, тоже сразу его увеличивает. |
| `.myroom_iw`, `.myroom_ih`, `.myroom_items` | счётчики | Ширина и высота комнаты и число расставленных предметов, которые записывает Моя комната, чтобы их мог показать список сохранений (только читайте их). |
| `myroom_thumb_<id>` | общая текстура | Картинка предмета мебели из магазина или из наград, создаваемая при запуске Моей комнаты; её показывают всплывающие окна покупки и наград. |

Чтобы выдать предмет мебели из своей сцены, прибавьте 1 к обоим счётчикам, как это делают [Pagoda.Rewards](pagoda.md) и [Vault.Chests](vault.md). Пока строка `my_room` не задана, временная миграция читает комнату из старого хранилища Open-World Memories; она будет удалена к официальному релизу.

## На чём она построена

- Её меню и диалоги используют библиотеку интерфейса скина через [UI.Pick](ui.md), выбираемую при первом использовании (PopUI в Open-World Memories, SimpleUI в скине, который никакую не указал), а её индикатор монет — виджет монет этой библиотеки.
- Её строки, включая названия мебели (`lang/<code>/items.json`, с id мебели в качестве ключа), лежат в её собственной папке `lang/`, на девяти языках.
- Каталог мебели — `data/furniture.json` в папке сцены.
- Матрица-заглушка показывает только отладочные сцены, которые есть в `Global/Modules/Stages/`. Эти отладочные сцены и ROActivity `video_player`, которую использует телевизор, тоже глобальные модули.
- Капсула открывает сцену `mysterypod`, если она есть в `Global/Modules/Stages/`, или если собственная сцена `mysterypod` скина задаёт общей строке `mysterypod_installed` значение `"1"` в своём `onStart`.
- Сетевые посещения используют id комнаты `"myroom"` с версией 2 его полезной нагрузки, как и до переноса.
