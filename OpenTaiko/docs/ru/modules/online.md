# Online

Логика онлайн-лобби: комнаты, которые открывают и в которые входят по коду, список игроков, сложность, моды и готовность каждого игрока, песня комнаты, начало раунда, результаты и следующий раунд. Модули `Online` ничего не рисуют; скин рисует свои экраны лобби и подключает к ним свой выбор песен. Лобби любого скина говорит на одних и тех же сообщениях, поэтому игроки с разными скинами встречаются в одной комнате. Стейдж `onlinelobby` из Open-World Memories — один из таких клиентов. Модули работают поверх [глобального NET](../api/networking.md), который экспериментальный.

## Модули

| Модуль | Что содержит |
| --- | --- |
| `Online.Lobby` | Сеанс: его состояние, каждое действие экрана, подключение выбора песен и обработку событий. |
| `Online.Protocol` | Сообщения: имена каналов и JSON каждой нагрузки. |
| `Online.Identity` | То, что игрок отправляет о себе (имя, персонаж, пучичара, именная табличка, табличка дана, палитра). |
| `Online.Media` | Песню комнаты на этой машине: её уровни, обложку в общей текстуре `preimage`, превью в общем звуке `presound`. |
| `Online.Texts` | Собственные строки модулей (`lang/<code>/online.json`). |

Скину нужен только `Online.Lobby`, который реэкспортирует то, что он использует из остальных. На одно состояние Lua приходится один сеанс: модуль хранит своё состояние в `Lobby.net`.

## Состояние сеанса

Скин читает `Lobby.net` каждый кадр, чтобы рисовать свои экраны:

| Поле | Описание |
| --- | --- |
| `online`, `connecting` | В комнате; ждёт ответа на вход. |
| `isHost`, `code` | Эта машина ведёт комнату (она её создала); код комнаты. |
| `roomGone` | Комната закрылась: выйти и вернуться в меню скина. |
| `msg`, `msgCode`, `msgArg` | Последнее сообщение, уже на языке игры, его постоянный код и аргумент (см. Сообщения). |
| `notice` | Сообщение, пришедшее во время пребывания в комнате; показать один раз и очистить. |
| `nameByPeer`, `infoByPeer` | Игроки по id: имена и данные `Online.Identity` (`name`, `char`, `puchi`, `dan`, `npk`, `dgold`, `dtype`, `palStops`, `palBlend`). |
| `diffByPeer`, `modByPeer`, `readyByPeer` | Сложность (от 0 до 4), моды и готовность каждого игрока. |
| `lackByPeer`, `watchByPeer` | Игроки без песни комнаты; игроки, которые ещё на результатах. |
| `song` | Песня комнаты `{ uid, title, diff, speed, dyn }`, nil, пока роль хоста её не выберет. |
| `songLevels`, `songPlus`, `songSubtitle`, `songBpm`, `iLackSong` | Песня на этой машине: уровень и знак плюс каждой её сложности, подзаголовок и BPM; `iLackSong`, когда на этой машине её нет. |
| `resultByPeer` | Результаты раунда: `{ name, sc, gr, gd, ms, co, cl, fc, pf, ac, ab }` (счёт, great, good, bad, комбо, пройдено, фулл-комбо, идеально, точность, прервано). |
| `resultsT`, `resultsReadyT` | Секунды на результатах; задаётся, когда они собраны. |

## Online.Lobby

| Функция | Описание |
| --- | --- |
| `Lobby.host()  -> bool` | Открывает комнату (не больше `Lobby.MAXP` = 5 игроков) и сохраняет её код через `STORAGE:WriteLobbyCode`; false с `net.msg`, когда NET отказал. |
| `Lobby.join(code)  -> bool` | Начинает вход в комнату по коду (пробелы игнорируются); ответ приходит через `drain`. False с `net.msg`, когда код пустой, неверный или от комнаты другого вида. |
| `Lobby.leave()` | Завершает сеанс (и после неудачного входа) и возвращает места игроков файлам сохранений. |
| `Lobby.drain()` | Обрабатывает каждое ожидающее событие NET; вызывайте каждый кадр, пока `online` или `connecting` истинно. |
| `Lobby.amController()  -> bool` | У этого игрока роль хоста: он выбирает песню и начинает раунд. |
| `Lobby.peerIds()`, `Lobby.count()` | Id игроков по порядку; их число. |
| `Lobby.spotOf[id]` | Локальное место каждого игрока (0 для себя), для `NAMEPLATE:DrawPlayerNameplate`. |
| `Lobby.myDiff()`, `Lobby.setDiff(d)`, `Lobby.stepDiff(dir)  -> bool` | Моя сложность; задать её; перейти к следующей, которая есть у песни (false в конце ряда). |
| `Lobby.availDiffs()`, `Lobby.diffAvailable(d)`, `Lobby.fixDiff()` | Сложности песни; удерживать мою на одной из них (вызывайте каждый кадр лобби). |
| `Lobby.myReady()`, `Lobby.setReady(b)` | Моя готовность. |
| `Lobby.broadcastMods()` | Читает моды игрока 0 из `CONFIG` и отправляет их; вызывайте, когда закрывается выбор модов скина. |
| `Lobby.applyModsToSlot(slot, mods)` | Ставит моды игрока на место игрока в `CONFIG`, чтобы нарисовать их значки через ROActivity `modicons`. |
| `Lobby.adjustSpeed(delta)`, `Lobby.setSpeed(sp)` | Скорость песни комнаты (только роль хоста). |
| `Lobby.startProblem()  -> "need_song", "need_players" or nil` | Почему раунд пока не может начаться. Готовность не обязательна. |
| `Lobby.hostStart()  -> bool` | Начинает раунд (только роль хоста). |
| `Lobby.takeGo()  -> bool` | Один раз true, когда раунд начался; затем вызовите `launchPlay`. |
| `Lobby.launchPlay()  -> true, "eject" or false` | Монтирует песню для каждого игрока и открывает игровой раунд: при true скин выходит в `"play"`; `"eject"` значит, что у этой машины нет песни и нужно покинуть комнату; false приходит с `net.msg`. |
| `Lobby.returnedFromPlay()` | Вызывайте, когда в стейдж снова входят после той игры: отправляет мой результат и запускает результаты. |
| `Lobby.tickResults(dt)  -> bool` | Каждый кадр на результатах: true, как только пришли все результаты или прошло `Lobby.RESULTS_WAIT` (20) секунд. |
| `Lobby.standings()  -> rows` | Результаты, лучший счёт первым: `{ id, name, r }`, `r` равно nil, пока этот игрок ещё играет. |
| `Lobby.nextRound()` | Назад в лобби: роль хоста переходит к следующему игроку. |
| `Lobby.tickPreview(dt)`, `Lobby.stopPreview()` | Зацикливает превью песни на экранах лобби и результатов; останавливает его. |
| `Lobby.onEvent` | Необязательная функция `(kind, peer, data)`, вызываемая для каждого события, которое обрабатывает `drain` (`"joined"`, `"left"`, `"song"`, `"ready"`, `"go"`, `"result"`, ...). |

Онлайн-игра выглядит как офлайн-игра с тем же числом игроков: остальные игроки занимают локальные места 2–5 как виртуальные слоты, со своими персонажами и табличками, а игровой экран ведёт их по данным из сети.

## Подключение выбора песен

Игрок с ролью хоста выбирает песню комнаты в выборе песен скина. Выбор песен должен выбирать только песню (без шага сложности, без Auto); его клавиши скорости меняют `CONFIG.SongSpeed`. Его подключают три вызова:

1. `Lobby.openSongSelect(open)` вместо прямой активации: `open` — функция, которая активирует выбор песен. Сначала скорость комнаты кладётся в `CONFIG.SongSpeed`.
2. Когда песня подтверждена: деактивируйте выбор песен, затем `Lobby.songPicked(uid?)`. По умолчанию `uid` — это `SONGMOUNT:ChosenUniqueId()`.
3. Когда выбор песен покинули без песни: деактивируйте его, затем `Lobby.songPickCancelled()`, который сохраняет изменённую там скорость и возвращает обложку и превью комнаты.

Общая строка `presound_path` называет звук в `presound`: выбор песен, который оставляет в нём играть песню комнаты, передаёт превью обратно, и лобби продолжает его, а не запускает заново.

## Сообщения

`net.msg` готово к показу. Скин, который сам формулирует сообщения, читает вместо него `net.msgCode`:

| Код | Когда |
| --- | --- |
| `open_failed`, `join_failed` | NET отказал, не назвав причину. |
| `room_open` | Комната открыта, её код сохранён. |
| `connecting` | Начался вход. |
| `no_code`, `code_invalid` | Код пустой или не является кодом комнаты. |
| `code_other` | Код от комнаты другого вида; `msgArg` — id её стейджа. |
| `chart_failed` | `launchPlay` не смог смонтировать чарт. |
| `net` | Текст самого NET (сеть выключена, соединение потеряно, ...) на английском. |

Сеть выключена, пока игрок не разрешит её в настройках. Скину стоит проверять `CONFIG.AreLuaNetworkingConnectionsAllowed` перед открытием лобби; NET тоже отказывает с сообщением `net`.

## Online.Protocol

Каждое сообщение — строка JSON на одном канале NET. Id комнаты в коде — `"onlinelobby"` (`Protocol.ROOM_ID`), какой бы стейдж её ни открыл.

| Канал | Нагрузка | Отправляется |
| --- | --- | --- |
| `song` | `{"u":uid,"t":title,"d":0,"s":speed,"b":dyn}` | Ролью хоста, когда меняется песня или её скорость, и каждому новичку. |
| `diff`, `mod`, `ready` | `{"d":n}`, `{"r","st","ju","tz","ss","sm"}`, `{"r":bool}` | Когда игрок их меняет, и каждому новичку. |
| `have`, `watch` | `{"h":bool}`, `{"w":bool}` | Есть ли у игрока песня; на результатах ли он. |
| `go` | `{}` | Раунд начинается. |
| `result` | `{"n","sc","gr","gd","ms","co","cl","fc","pf","ac","ab"}` | Результат игрока после песни. |

## Минимальное лобби

```lua
local Lobby = require("Online.Lobby")
local net = Lobby.net
local screen, back = "menu", false

function activate()
    if back then back = false; Lobby.returnedFromPlay(); screen = "results" end
end

function update(ts)
    local dt = 1 / 60
    if net.online or net.connecting then
        Lobby.drain()
        if net.roomGone then Lobby.leave(); screen = "menu" end
    end
    if screen == "lobby" then
        Lobby.tickPreview(dt)
        Lobby.fixDiff()
        if Lobby.takeGo() then
            local r = Lobby.launchPlay()
            if r == true then back = true; return Exit("play", nil) end
            if r == "eject" then Lobby.leave(); screen = "menu" end
        end
    elseif screen == "results" then
        if Lobby.tickResults(dt) and decidePressed() then Lobby.nextRound(); screen = "lobby" end
    end
end

function onDestroy() Lobby.leave() end
```

`Lobby.host()` или `Lobby.join(code)` из меню скина переводят `screen` в `"lobby"`; песню задаёт описанное выше подключение выбора песен.
