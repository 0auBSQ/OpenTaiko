# Pagoda

Пагода Неизвестного — это восхождение по этажам-данам: каждый этаж разыгрывает три песни (а иногда и четвёртую, фиолетовую) из своих пулов, с тремя экзаменами, которые ужесточаются по мере подъёма. Модули `Pagoda` содержат правила, данные и ключи сохранения; сами они ничего не рисуют. Скин рисует поверх них собственные экраны пагоды, и все скины разделяют один прогресс, потому что прогресс хранится в файле сохранения. Сцена `pagoda` в Open-World Memories — один из таких клиентов.

Этажи с 1 по 10 называются от 道一 до 道十, с 11 по 20 — от 扉一 до 扉十, а начиная с 21-го — крыши 穹天1, 穹天2 и так далее. Эти названия — титул дана, одинаковый на всех языках.

## Модули

| Модуль | Что содержит |
| --- | --- |
| `Pagoda.Levels` | Всё, что выводится из номера этажа: пулы песен, название, рамку и цвет таблички дана, пороги экзаменов, шанс фиолетовой песни. Чистые вычисления. |
| `Pagoda.Floor` | Песни этажа (розыгрыш) и его дан: передаёт розыгрыш в `DANBUILDER` вместе с табличкой и экзаменами. |
| `Pagoda.Rewards` | Что даёт клир: табличку имени, монеты, мебель для Моей комнаты, ключи хранилища; сохраняет их и показывает всплывающие окна через ROActivity `modal`. |
| `Pagoda.Progress` | Постоянные данные сохранения (ниже). |
| `Pagoda.Songs` | Список песен, из которого берёт пагода, и проверка того, что саундтрек покрывает каждую запись пулов. |
| `Pagoda.Run` | Необязательно: ход забега-испытания и тренировки, без экрана. |
| `Pagoda.Texts` | Собственные строки модулей (`lang/<code>/pagoda.json`). |

## Pagoda.Levels

| Функция | Описание |
| --- | --- |
| `Levels.get_pool(level)  -> pool` | Пул этажа: списки `{ blue, green, red, purple }` из `{ id, diff }` (уникальный id песни и сложность от 0 до 4). Этаж без собственной записи использует ближайшую ниже. |
| `Levels.load_pools()`, `Levels.clear_pools()` | Читает `pools.json` (один раз); забывает его после повторного перечисления песен. |
| `Levels.level_name(level)  -> string` | Название этажа. |
| `Levels.level_tick(level)`, `Levels.level_tick_color(level)` | Рамка таблички дана (от 0 до 4) и цвет `{ r, g, b }`. |
| `Levels.exam1_gauge(level)  -> red, gold` | Экзамен по шкале. |
| `Levels.exam2(level)  -> type, red, gold, lessThan` | Экзамен на точность (этажи с 1 по 20) или на число Ok (с 21-го). |
| `Levels.exam3_base(level)  -> red, gold` | Экзамен на число Bad до послабления за фиолетовую песню. |
| `Levels.purple_prob(level)  -> number` | Шанс четвёртой, фиолетовой песни (на 20-м этаже она есть всегда). |
| `Levels.pick_entry(entries, used)`, `Levels.shuffle(t)` | Вспомогательные функции, которые используют розыгрыши. |

`pools.json` рядом с модулями сопоставляет каждому номеру этажа его пул:

```json
{
  "1": {
    "comment": "一題",
    "blue":   [ { "id": "<song unique id>", "diff": 0 } ],
    "green":  [ { "id": "<song unique id>", "diff": 0 } ],
    "red":    [ { "id": "<song unique id>", "diff": 0 } ],
    "purple": [ { "id": "<song unique id>", "diff": 0 } ]
  }
}
```

Пулы называют песни саундтрека OpenTaiko. `Songs.count_missing_songs()` записывает в журнал и подсчитывает записи, которых нет среди установленных песен (песни или её сложности), чтобы экран мог предупредить игрока.

## Pagoda.Floor

| Функция | Описание |
| --- | --- |
| `Floor.rollFloor(level, avoid?, songList?)  -> roll` | Одна синяя, одна зелёная и одна красная песня в случайном порядке, затем фиолетовая с шансом этажа, без повторов песен. `avoid` — набор id песен, которые не выбираются, пока в пулах есть другие. Розыгрыш — это `{ songs = { { color, node, entry }, ... }, purple = { node, entry } or nil, speed }`. |
| `Floor.rerollFloor(level, roll, keepMystery, songList?)  -> roll` | Разыгрывает заново, с другими песнями там, где позволяют пулы; `keepMystery` сохраняет фиолетовую песню. |
| `Floor.exams(level, hadPurple)  -> table` | Три экзамена в виде `{ type, red, gold, lessThan }`. |
| `Floor.buildDan(level, roll?, opts?)  -> bool` | Настраивает `DANBUILDER` для этажа: название, табличку, жанр (`opts.genre`, `opts.genreColor`), песни и экзамены. False, если не удалось добавить ни одной песни; иначе смонтируйте его через `DANBUILDER:Mount()` и играйте. |
| `Floor.speed(level)  -> number` | Скорость песен этажа (значение `CONFIG.SONGSPEED`): x1 ниже 穹天18 и выше начиная с него. |

## Pagoda.Run

Забег-испытание начинается на одном из открытых стартовых этажей, поднимается на этаж за каждый клир и заканчивается на первом поражении. Тренировка играет любой этаж вплоть до самого высокого, которого достиг забег (не ниже 11-го), и ничего не сохраняет.

| Функция | Описание |
| --- | --- |
| `Run.startOptions()  -> table` | Стартовые этажи, открытые в этом сохранении: 1, 6 и 11 всегда, 16 после клира 15-го, 21 после клира 20-го. |
| `Run.new(start, songList?)  -> run` | Забег с этого этажа. Его поля: `level` (текущий этаж), `tower` (самый высокий этаж, показанный пройденным), `roll`, `over`. |
| `run:rollFloor(avoid?)`, `run:reroll(keepMystery)  -> roll` | Песни текущего этажа, чтобы показать их перед игрой. |
| `run:enter()` | Забег достиг своего этажа: с этого момента тренировка его предлагает. |
| `run:buildDan(opts?)  -> bool` | `DANBUILDER`, настроенный для текущего этажа; смонтируйте его и играйте. |
| `run:clear()  -> result` | После клира: выдаёт и сохраняет награды, поднимает самый высокий этаж, переходит выше. Возвращает `{ level, rewards, shrouded }`: `rewards` — список, который возвращает `Rewards.grant`, `shrouded` — был ли этаж выше башни. |
| `run:fail()` | После поражения: запоминает этаж, засчитывает игру, завершает забег. |
| `Run.practiceLevels()  -> table`, `Run.practiceDan(level, opts?)  -> bool` | Этажи, которые предлагает тренировка; `DANBUILDER`, настроенный для тренировочной игры с новым розыгрышем. |

## Pagoda.Rewards

| Функция | Описание |
| --- | --- |
| `Rewards.grant(level)  -> table` | Выдаёт и сохраняет награды клира в сохранении игрока 1 и возвращает всплывающие окна, которые нужно показать по порядку: `{ kind = "nameplate", id }`, `{ kind = "furniture", id }`, `{ kind = "key", key, count }`, `{ kind = "coins", amount }`. |
| `Rewards.KEY_PICTURE` | Префикс общих текстур, которые показывают окна ключей (`pagoda_reward_key_<id>`). Модули не содержат картинок ключей: скин делает общей по одной на ключ перед показом окна ключа. |
| `Rewards.show(r)  -> bool` | Запускает всплывающее окно одной награды через ROActivity `modal`. |
| `Rewards.update()  -> bool`, `Rewards.draw()`, `Rewards.stop()` | Обрабатывает всплывающее окно (true, пока оно идёт; ввод оно читает само), рисует его, убирает его. |
| `Rewards.poolOf(level)`, `Rewards.nameplateOf(level)` | Пул наград этажа и табличка имени, которую даёт его первый клир. |

Первый клир этажа даёт его табличку имени (id с 381 по 397, на этажах из `Rewards.NAMEPLATES`). Затем монеты (диапазон, с шансом 50 %) и каждая запись пула этажа разыгрываются со своим шансом (`Rewards.POOLS`, `Rewards.ROOF_POOLS`), так что один клир может дать несколько вещей. Пока секретное хранилище закрыто, ключи хранилища превращаются в монеты, а все монеты одного клира показываются в одном всплывающем окне. Окно мебели показывает общую текстуру `myroom_thumb_<id>`, которую предоставляет [Моя комната](my-room.md).

## Ключи сохранения

Всё хранится в сохранении игрока 1 (`GetSaveFile(0)`):

| Ключ | Тип | Содержимое |
| --- | --- | --- |
| `pagoda_highest_level` | счётчик | Самый высокий этаж, пройденный в забеге-испытании. |
| `pagoda_highest_reached` | счётчик | Самый высокий этаж, которого достиг забег; до него предлагает этажи тренировка. |
| `pagoda_plays` | счётчик | Сыгранные забеги-испытания (засчитываются при поражении). |
| `pagoda_lost_<level>` | триггер | Забег был проигран на этом этаже. |
| `pagoda_story_first_seen` | триггер | Вступительная история уже показана (в старом сохранении вместо этого может быть счётчик `pagoda_story_seen`). |
| `pagoda_held_mods`, `pagoda_held_mods_lo`, `pagoda_held_mods_hi` | триггер, счётчики | Флаги модов игрока 1, удерживаемые во время игры в пагоде, в двух 32-битных половинах (`Progress.hold_mods(flags)`, `held_mods()`, `drop_held_mods()`). |
| `pagoda_structure_version` | счётчик | Однократная перенумерация старых сохранений (`Progress.migrate_save()`) уже выполнена. |
| `.myroom_<id>`, `.myroom_held_<id>` | счётчики | Выигранная мебель: передана в Мою комнату и имеется в наличии. |
| `.vault_key_count_<key>` | счётчики | Выигранные ключи хранилища, через [Vault.Keys](vault.md). |

Таблички имени и монеты проходят через собственные методы сохранения (`UnlockNameplate`, `EarnCoins`).

```lua
local Run     = require("Pagoda.Run")
local Rewards = require("Pagoda.Rewards")
local run = Run.new(Run.startOptions()[1])

run:rollFloor()                  -- show run.roll's songs
run:enter()
if run:buildDan() and DANBUILDER:Mount() then return Exit("play") end

-- back from the play
local r = run:clear()            -- or run:fail()
for id in pairs(Rewards.KEYS) do SHARED:SetSharedTexture(Rewards.KEY_PICTURE .. id, "Textures/key_" .. id .. ".png") end
for _, reward in ipairs(r.rewards) do queue[#queue + 1] = reward end   -- then Rewards.show / update / draw
```
