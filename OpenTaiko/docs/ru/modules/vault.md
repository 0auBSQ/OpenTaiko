# Vault

В секретном хранилище стоят три сундука, которые открываются ключами, выигранными игроком в другом месте (клиры пагоды, магазин за монеты). Модули `Vault` содержат ключи, пулы наград сундуков и ключи сохранения; сами они ничего не рисуют. Скин рисует поверх них собственный экран хранилища, и все скины разделяют одно хранилище, потому что его состояние хранится в файле сохранения. Сцена `secret_vault_rw` в Open-World Memories — один из таких клиентов.

## Модули

| Модуль | Что содержит |
| --- | --- |
| `Vault.Keys` | Три ключа: их количество и названия, а также открыто ли хранилище. |
| `Vault.Chests` | Три сундука, их взвешенные пулы наград и всплывающие окна наград. |
| `Vault.Texts` | Собственные строки модулей (`lang/<code>/vault.json`). |

## Vault.Keys

Ключ обозначается номером или id: 1 `"simple"`, 2 `"gold"`, 3 `"optk"`. Каждый открывает сундук с тем же номером.

| Функция | Описание |
| --- | --- |
| `Keys.count(key)  -> number` | Сколько таких ключей у игрока 1. |
| `Keys.set(key, n)`, `Keys.add(key, n?)` | Задаёт количество; прибавляет `n` (по умолчанию 1). |
| `Keys.name(key)  -> string` | Название ключа на языке игры. |
| `Keys.vaultOpen()  -> bool` | Открыто ли хранилище: триггер `.vault_opened`, который устанавливает собственный путь скина в хранилище. Пока оно закрыто, другие модули дают монеты вместо ключей. |
| `Keys.index(key)  -> number` | Номер ключа. |

## Vault.Chests

Сундуки: 1 — деревянный, 2 — золотой, 3 — платиновый. Открытие сундука тратит один из его ключей и разыгрывает одну награду из его взвешенного пула: ничего (ключ ломается), монеты, ключ от следующего сундука, табличку имени, которой у игрока нет (id с 361 по 368, с 369 по 375 и с 376 по 380 в зависимости от сундука), предмет мебели для Моей комнаты (у предмета, который уже есть, остаётся пятая часть шанса) или ещё не выигранную песню из папки `Secret Vault` саундтрека, распределённую по сундукам по самому высокому уровню её чарта.

| Функция | Описание |
| --- | --- |
| `Chests.enter()  -> bool` | Один раз за посещение, прежде всего остального: выдаёт бесплатный простой ключ первого посещения (тогда возвращает true) и строит пулы песен. |
| `Chests.roll(i)  -> reward` | Открывает сундук `i` одним из его ключей (сначала проверьте `keyCount`), сразу сохраняет награду и возвращает её. |
| `Chests.showReward(reward)  -> bool` | Запускает всплывающее окно награды через ROActivity `modal`; false для сломанного ключа или ключа, у которых окна нет. |
| `Chests.keyCount(i)  -> number` | Ключи, имеющиеся для сундука `i`. |
| `Chests.name(i)  -> string` | Название сундука на языке игры. |
| `Chests.stock(i)  -> left, total` | Сколько ещё можно выиграть в сундуке (песни, таблички имени, мебель) и общее число. |
| `Chests.chestPool(i)  -> table` | Взвешенный пул сундука в его текущем состоянии для этого сохранения: записи `{ w, type, ... }`. |
| `Chests.songPool(i)`, `Chests.maxChartLevel(node)` | Песни сундука; самый высокий уровень чарта песни. |

Награда — это `{ type, openedChest, ... }`, где `type` — `"snap"`, `"coins"` (`amount`), `"key"` (`target`, номер сундука), `"nameplate"` (`id`, `info`), `"furniture"` (`id`, `rarity`) или `"song"` (`node`). Всплывающее окно работает так же, как ROActivity `modal`: вызывайте его `Update` и `Draw`, пока `IsActive`, как это делают `Pagoda.Rewards.update` и `draw`. Окно мебели показывает общую текстуру `myroom_thumb_<id>`, которую предоставляет [Моя комната](my-room.md).

## Ключи сохранения

Всё хранится в сохранении игрока 1 (`GetSaveFile(0)`):

| Ключ | Тип | Содержимое |
| --- | --- | --- |
| `.vault_key_count_simple`, `.vault_key_count_gold`, `.vault_key_count_optk` | счётчики | Имеющиеся ключи. |
| `.vault_opened` | триггер | Хранилище открыто (устанавливает скин). |
| `.vault_first_key_given` | триггер | Ключ первого посещения выдан. |
| `.vault_song_unlocked_<unique id>` | триггер | Эта песня из `Secret Vault` выиграна. |
| `.myroom_<id>`, `.myroom_held_<id>` | счётчики | Выигранная мебель: передана в Мою комнату и имеется в наличии. |

Таблички имени и монеты проходят через собственные методы сохранения (`UnlockNameplate`, `EarnCoins`).

```lua
local Chests = require("Vault.Chests")

function activate()
    if Chests.enter() then showFreeKeyNotice = true end
end

local function open(i)
    if Chests.keyCount(i) < 1 then return end
    local reward = Chests.roll(i)
    if not Chests.showReward(reward) then playSnap(reward) end
end
```
