# VN

Составные части сцены визуальной новеллы: окно диалога, исполнитель сценариев и проигрыватель сцен. `VN.Scene` объединяет два других; используйте исполнитель и окно по отдельности, когда ваша сцена сама рисует происходящее.

## VN.Dialogue

Окно диалога с эффектом пишущей машинки: имя говорящего, область портрета, текст с переносом по словам, появляющийся буква за буквой, и варианты выбора. Оно работает само: вызывайте `dlg:update(dt)` и `dlg:draw()` каждый кадр и прочитайте `dlg.result`, когда оно сообщит `"done"`. Окно рисуется фигурами и звуками библиотеки интерфейса, в собственном оформлении (параметр `theme`), какую бы библиотеку ни выбрал скин.

Сценарий — это список узлов `{ name, text, portrait, choices }`. Узел с `choices` (списком `{ label, value }`) показывает их, когда его текст выведен целиком; выбор варианта присваивает `dlg.result` его `value` и завершает диалог. Сценарий, закончившийся без выбора, присваивает `dlg.result` значение true.

Теги внутри `text` срабатывают, когда до них доходит пишущая машинка:

| Тег | Действие |
| --- | --- |
| `{pause:sec}` | Задерживает вывод (по умолчанию 0.4 с). |
| `{speed:cps}` | Меняет скорость вывода, в символах в секунду. |
| `{shake:amp,dur}` | Трясёт экран: `onShake(amp, dur)` или 3D-камеру, если обработчик `onShake` не задан. |
| `{sfx:name}`, `{voice:name}`, `{expr:name}` | Вызывают `onSfx(name)`, `onVoice(name)` или `onExpr(name)` (смена выражения посреди реплики). |

| Поле `opts` | Описание |
| --- | --- |
| `gfont`, `gfontName` | Глифовые шрифты (`TEXT:CreateGlyphCached`) для текста и имени: текст UTF-8 с переносом по словам. Для имени по умолчанию берётся `gfont`. |
| `fonts` | Текстовые шрифты `{ name, text }` вместо них, старый путь (ASCII). |
| `ui` | `"popui"` (по умолчанию: скруглённое окно с тенью и плашкой имени) или `"plain"` (плоская панель). |
| `theme` | Цвета окна: `face`, `face2`, `outline`, `namePill`, `namePill2`, `nameText`, `text`, `choiceRow`, `choiceSel`, `choiceText`, `caret`, `shadow`, `textEdge`. |
| `box` | `{ x, y, w, h }`: положение окна (по умолчанию вдоль нижнего края экрана). |
| `portraitSize`, `portraits` | Квадрат портрета (0 скрывает его — для крупных спрайтов, которые рисует сцена); `{ name = texture }` по имени говорящего. |
| `cps` | Скорость вывода, с которой начинается каждый узел (по умолчанию 42). |
| `mouse` | true: щелчок левой кнопкой тоже продвигает и подтверждает. |
| `advanceInput` | Функция, возвращающая true для дополнительного ввода продвижения (пэд барабана). |
| `drawBox` | false рисует только текст, варианты и маркер поверх вашего собственного рисунка окна. |
| `onBlip`, `blipEvery` | Звук печати: `onBlip()` через каждые `blipEvery` выведенных символов (3). |
| `onSfx`, `onVoice`, `onExpr`, `onShake` | Обработчики тегов. |
| `sfx` | Звуки по имени для продвижения и выбора, как в [интерфейсе](ui.md). |
| `opacity`, `caret` | Непрозрачность всего окна и false, чтобы скрыть маркер продвижения; оба можно менять в любом кадре. |

| Метод | Описание |
| --- | --- |
| `Dialogue.new(opts)  -> dlg` | Создаёт окно. |
| `dlg:start(script)` | Запускает сценарий с первого узла. |
| `dlg:update(dt)  -> "running" or "done"` | Обрабатывает один кадр: Decide, пробел (или щелчок, или `advanceInput`) выводит реплику целиком, затем продвигает; «вверх» и «вниз» выбирают вариант. |
| `dlg:draw()` | Рисует окно. |
| `dlg:active()  -> bool` | Выполняется ли сценарий. |
| `dlg.result` | Выбранное значение или true после завершения. |
| `dlg:dispose()` | Освобождает запечённые холсты окна. |

```lua
local Dialogue = require("VN.Dialogue")
local dlg, answer, last = nil, nil, 0

function activate()
    dlg = Dialogue.new{ gfont = TEXT:CreateGlyphCached(30), portraitSize = 0 }
    dlg:start{
        { name = "Nokon", text = "Welcome back.{pause:0.5} Ready?" },
        { name = "Nokon", text = "Pick one.", choices = { { label = "Yes", value = 1 }, { label = "Later", value = 2 } } },
    }
end

function update(ts)
    local dt = (ts - last) / 1000; last = ts
    if dlg:update(dt) == "done" then answer = dlg.result end
end

function draw() dlg:draw() end
```

## VN.Runner

Проходит по сценарию из строк: условия, случайный выбор, варианты, которые вставляют свою ветку, и ремарки, которые регистрирует вызывающий код. Сам он ничего не рисует: `VN.Scene` (ниже) или ваша собственная сцена продвигает его и выводит его строки текста в окно `VN.Dialogue`.

Строка — это таблица, все поля которой необязательны:

| Поле | Описание |
| --- | --- |
| `text` | Текст со встроенными тегами окна. Строка с `choices` и без `text` (или с `""`) оставляет на экране предыдущую строку текста, уже прочитанную, под своими вариантами. |
| `who`, `name` | Id говорящего; показываемое имя, которое важнее собственного имени говорящего (`"???"`). |
| `expr` | Выражение лица говорящего. |
| `choices`, `branch` | `{ { label, value }, ... }`; `branch = { [value] = { lines } }` вставляется после выбора. Выбранное значение попадает в `ctx.choice` и `ctx.choices[value]`. |
| `when` | `function(ctx)`, возвращающая true, когда строка проигрывается; условие, вызвавшее ошибку, считается false. |
| `pick` | `{ { lines = { ... }, weight = n }, ... }`: один вариант, выбранный по весу (по умолчанию 1), никогда не один и тот же дважды подряд, вставляется после строки. |
| любой другой ключ | Ремарка (`enter`, `bg`, `fade`, `sfx`, `flag`, ...), которую выполняет зарегистрированная для неё функция. |

| Поле `opts` | Описание |
| --- | --- |
| `lines`, `ctx` | Сценарий (исполнитель проходит по его копии) и таблица, которую читают условия. |
| `tr` | `fn(s)`: переводит тексты, имена и подписи вариантов; без неё они показываются так, как написаны. |
| `speakerName` | Имя, которое показывает строка с `who` и без `name`: строка, таблица `{ [who] = name }` или `fn(who, line, ctx)`. |
| `playerTag`, `playerName` | Тег, который в текстах заменяется именем игрока (`"<player name>"`), и само это имя: строка или `fn(ctx)`, по умолчанию `ctx.playerName`. |
| `directions`, `order` | `{ [key] = fn(line, runner) }` и порядок, в котором они пробуются (`Runner.ORDER`, затем остальные ключи по алфавиту). |
| `onLine`, `onChoose` | `fn(line, runner)` для каждой проигрываемой строки, перед её ремарками; `fn(line, value, runner)`, когда выбран вариант, в том числе при восстановлении. |
| `random` | `fn()`, возвращающая число из [0, 1), для случайного выбора (по умолчанию `math.random`). |

Ремарка возвращает `false`, если не обрабатывает строку (пробуется следующая по порядку), nil или true, чтобы перейти к следующей строке, `"hold"`, чтобы остановить проход до следующего шага вызывающего кода, или `"end"`, чтобы завершить сценарий. Если вызывающий код не зарегистрировал собственную ремарку `text`, строка с текстом или вариантами останавливает проход как `"line"`.

| Метод | Описание |
| --- | --- |
| `Runner.new(opts)  -> runner` | Создаёт исполнитель для `opts.lines`. |
| `runner:step()  -> verdict, line` | Проходит до следующей остановки: `"line"` (строка текста для показа), `"hold"` или `"end"`. |
| `runner:present(dlg, line?)  -> node, carried` | Запускает текущую строку в окне `VN.Dialogue`; строка только с вариантами переносит предыдущую строку текста, полностью выведенную. |
| `runner:choose(value)  -> bool` | Сообщает результат окна: значение варианта записывается, а его ветка вставляется. |
| `runner:current()  -> line`, `runner:load(lines)` | Текущая строка; начинает заново с другим сценарием. |
| `runner:ahead(fn, otherwise)  -> value` | Первый ответ (true или false), который `fn(line)` даёт для строк после текущей; `otherwise`, если сценарий закончится раньше. |
| `runner:bookmark()  -> mark` | `{ idx, picks, rolls }`: строка на экране, сделанные выборы и выпавшие случайные варианты. |
| `runner:resume(mark, replay?)` | Молча возвращается к строке из закладки, делая те же выборы и выбирая те же случайные варианты; `replay = { [key] = fn(line, runner) }` повторно применяет ремарки, которые оставляют после себя состояние (фон, флаг). Следующий `step` показывает строку из закладки. |

Вспомогательные функции `Runner.passes(line, ctx)`, `Runner.node(line, ctx, o, carry)`, `Runner.start(dlg, line, ctx, o, carry)`, `Runner.resolveChoice(lines, idx, ctx, value)` и `Runner.resolvePick(lines, idx, random, forced)` работают без исполнителя, для сцены, которая сама проходит по своему сценарию.

## VN.Scene

Проигрыватель сцен, построенный на исполнителе и окне: слои фона, которые появляются после загрузки, набор спрайтов персонажей, затемнения и тряска экрана, а также окно диалога со своим звуком печати для каждого говорящего. Сам он ничего не загружает: фоны, текстуры персонажей, музыка, звуки и сохранённая закладка — всё приходит от вызывающего кода.

Сцена — это `{ bg, music, lines }`: первый фон, музыка (иначе музыка фона) и строки в форме исполнителя со следующими встроенными ремарками:

| Строка | Действие |
| --- | --- |
| `{ enter = who, expr, side }` | Персонаж появляется с проявлением (и сдвигом); сцена ждёт, пока он не появится. Если он уже на экране, меняется только его лицо. |
| `{ leave = who }` | Персонаж уходит; сцена ждёт, пока он не уйдёт. |
| `{ expr = name }` | Лицо `who` или персонажа в фокусе. |
| `{ bg = key }` | Фон, показываемый после загрузки его слоёв (или через `backgrounds.wait` секунд). |
| `{ fade = "out" or "in", keepSprite }` | Затемнение поверх сцены; `keepSprite = true` оставляет персонажей освещёнными. |
| `{ shake = true }`, `{ sfx = name }` | Тряска экрана (`shake` может быть и амплитудой или `{ amp, dur }`); звук. |
| `{ flag = name, value }` | Задаёт `ctx.flags[name]` (true, если `value` не указано). |
| `{ outcome = value }` | Сцена затемняется и сообщает `value`. |

Строка персонажа, который ещё не появился, сначала проявляет его. Ремарка вызывающего кода, вернувшая `"hold"`, удерживает сцену до `scene:continue()` или пока функция, переданная в `scene:waitFor(fn)`, не вернёт true (`fn(dt)` вызывается каждый кадр).

| Поле `opts` | Описание |
| --- | --- |
| `box` | Параметры `VN.Dialogue.new`; сцена заполняет `onBlip`, `onShake`, `onExpr` и `onSfx`, если они не заданы. Или `dialogue` — ваше собственное окно. |
| `cast` | `{ [who] = member }`. Персонаж: `body` (текстура или `fn(expr)` для отдельной картинки на каждое выражение), `face` (`fn(expr)`, рисуется поверх тела в точке `faceX`, `faceY`), `name`, `expr` (выражение, с которым он появляется), `side` (`"left"`, `"center"`, `"right"`) или `x`, `y` и `anchor` (`"top"` или `"bottom"`), `scale` или `height` (масштаб, при котором тело занимает столько пикселей), `fade` (0.35 с), `slide` (пикс.), `bounce` (0.36 с, 0 — без отскока) и `squash` для отскока при смене лица. |
| `sides`, `focus`, `dim` | Координата x каждой стороны; чьё лицо меняет `expr` без говорящего; цвет `{ r, g, b }` персонажей, которые не говорят (если не задан, они никогда не затемняются). |
| `backgrounds` | `defs` (`{ [key] = def }`) и `path` (`"Textures/bg/%s.png"` для ключа без def) или `resolve(key)`; `open(layer)` для текстур, которыми владеет вызывающий код (заимствованная текстура открывается снова, если владелец её освобождает); `wait` (2 с); хуки `prepare`, `show`, `update`, `drawBehind`, `drawOver`, `close`. Def — это слой или `{ layers = { ... } }`, слой — `{ path, x, y, scale, scroll }`, а `music` из def играет, пока он показан. |
| `music` | `{ play(key), fadeOut(sec), playing(), update(dt), stop() }`, все необязательны. |
| `sound`, `blip`, `clickSound` | `fn(name)` проигрывает звук по имени; `blip(node)` возвращает звук печати узла окна (`node.speaker`), nil — тишина; щелчок продвижения. |
| `cover` или `drawCover` | Текстура затемнения (или `fn()`, возвращающая её), растянутая на весь экран; или `fn(alpha)`, рисующая затемнение. |
| `drawBox`, `fadeSec`, `outcome` | `fn(dlg, scene)`, рисующая окно вместо `dlg:draw()`; длительность затемнения (0.45 с); результат, когда строки просто заканчиваются (`"done"`). |
| `tr`, `speakerName`, `playerTag`, `playerName`, `random`, `onLine`, `order` | Передаются исполнителю. |
| `directions`, `replay` | Дополнительные ремарки или замены встроенных; как их повторно применяет восстановленная закладка. |
| `onBookmark`, `hooks` | `fn(mark)` на каждой начинающейся строке, с закладкой для сохранения; `hooks = { prose, start, expr, choose, update, draw, dispose }`. |

| Метод | Описание |
| --- | --- |
| `Scene.new(opts)  -> scene` | Создаёт проигрыватель. |
| `scene:play(scene, ctx, onDone, resume?)` | Запускает сцену. `ctx` читают условия, и в него записываются выборы; `onDone(result)` получает исход; `resume` — закладка, с которой нужно продолжить. |
| `scene:update(dt)  -> "running" or "done"`, `scene:draw()` | Вызывайте каждый кадр. |
| `scene:continue()`, `scene:waitFor(fn)` | Завершает удержание; удерживает, пока `fn(dt)` не вернёт true. |
| `scene:setBackground(key)`, `scene:setExpr(who, expr)`, `scene:shake(amp, dur)`, `scene:sound(name)` | Встроенные эффекты, для ваших собственных ремарок. |
| `scene:bookmark()  -> mark`, `scene:active()  -> bool` | Закладка исполнителя; проигрывается ли сцена. |
| `scene:reset()`, `scene:dispose()` | Останавливает сцену; освобождает то, что открыла сцена (и окно, если оно не ваше). |

```lua
local Scene = require("VN.Scene")
local vn = Scene.new{
    box = { gfont = font30, gfontName = font34 },
    cast = { aoi = { name = "Aoi", body = aoiTex, face = function(e) return faces[e] end,
                     faceX = 210, faceY = 140, side = "right", anchor = "bottom", expr = "normal" } },
    backgrounds = { path = "Textures/bg/%s.png" }, cover = blackTex,
    sound = function(n) sfx[n]:Play() end,
    blip = function(node) return node and node.speaker and "blip" end,
    onBookmark = function(mark) save.vn = mark end,
}
vn:play({ bg = "park", lines = {
    { text = "A quiet afternoon." },
    { who = "aoi", expr = "smile", text = "Hi, <player name>!" },
    { text = "", choices = { { label = "Hi!", value = "hi" }, { label = "...", value = "shy" } },
      branch = { shy = { { who = "aoi", expr = "sad", text = "Not talkative today?" } } } },
    { bg = "street", sfx = "door" }, { fade = "out" }, { fade = "in" }, { outcome = "met" },
} }, { playerName = name }, function(result) met = result end, save.vn)
-- then vn:update(dt) and vn:draw() every frame
```

Окно рисуется через `VN.Dialogue`, поэтому его оформление следует библиотеке интерфейса, которую выдаёт [UI.Pick](ui.md).
