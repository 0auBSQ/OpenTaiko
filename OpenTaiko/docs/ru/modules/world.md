# World <span class="badge-exp">Экспериментально</span>

## World.OWM3d

Движок 3D-мира, на котором работают Моя комната и сюжетные сцены поставляемого скина; он построен на [мире растеризатора](../api/3d.md) и [физике](../api/3d-physics.md) движка. Он превращает данные карты в место, где можно играть: сеточный ландшафт или ландшафт по карте высот с соответствующей коллизией, модели glTF, персонажи, которые сталкиваются и скользят, камера, которая не проходит сквозь стены, триггеры, смена дня и ночи, погода и вода.

<div class="callout">
OWM3d экспериментален, как и 3D-движок, на котором он построен: его функции, формат карт и значения по умолчанию могут меняться между версиями без периода устаревания. Проверяйте скин, который его использует, заново после каждого обновления.
</div>

`require("World.OWM3d")` возвращает фасад с частями, которые сцена создаёт сама:

| Поле | Что это |
| --- | --- |
| `World` | Мир (`World.OWM3d.core`): `World.new{ rw, rh, screenW, screenH, gridW, gridH, lit, hour, yaw, pitch, fov, dist }` создаёт сцену и все подсистемы. |
| `Camera` | Схемы камеры (`iso`, `interior`, `orbit` или таблица из `yaw`, `pitch`, `fov`, `dist`), следование, облёт и масштаб, а также штанга с коллизией. |
| `Json` | Чтение файлов карт: `Json.loadMap(dir)` читает `<dir>/map.json` в простые таблицы Lua с применёнными значениями по умолчанию. |
| `IsoMap` | Сеточные карты: полы, пандусы, стены и здания сетки ячеек с теми же треугольниками в качестве коллизии. |
| `Terrain` | Карты высот: сетка из поля высот, текстурирование по маске смешивания (splat) и трава. |
| `NPC` | Персонажи, которые бродят, стоят или патрулируют вокруг исходной точки и поворачиваются к игроку во время разговора. |
| `ModelIcon` | Миниатюра 3D-модели, один раз отрисованная в маленькой сцене и затем рисуемая как текстура (значки каталога и магазина). |
| `version` | Номер версии фасада (1). |

Мир, созданный через `World.new`, несёт остальное в виде полей: `world.phys` (именованные группы коллайдеров, контроллеры персонажей, лучевые проверки), `world.models` (экземпляры моделей), `world.triggers` (объёмы, которые переключают группы, меняют схему камеры, телепортируют, меняют карту или запускают функцию), `world.particles`, `world.weather` (`clear`, `rain`, `storm`, `snow`, `sakura`, `embers`), `world.water`, `world.daynight` и `world.cam`. Каждая часть — также отдельный модуль, `World.OWM3d.<part>`.

```lua
local OWM = require("World.OWM3d")
local world, last = nil, 0

function onStart()
    world = OWM.World.new{ rw = 1280, rh = 720, screenW = 1920, screenH = 1080, lit = true }
    world:registerMap("plaza", { type = "folder", dir = "maps/plaza" })
    world:loadMap("plaza", "default")
end

function update(ts)
    local dt = (ts - last) / 1000; last = ts
    world:update(dt, px, py, pz)   -- the player's position drives the triggers and the camera
end

function draw()
    world:render()
    world:blit()
end
```

Папки карт, модели и текстуры — это файлы сцены: относительные пути разрешаются относительно папки вызывающей сцены. Вызовите `world:dispose()`, когда мир сцене больше не нужен.
