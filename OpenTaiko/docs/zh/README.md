# OpenTaiko 文档

<span class="badge-new">游戏版本 0.6.1</span>

<div class="callout warn">本文档仍在审阅中，在发布之前可能会有所变动。</div>

OpenTaiko 中除核心演奏之外的几乎每一个界面都由随皮肤一起发布的 Lua 脚本绘制：菜单、选曲界面、房间与剧情场景、背景，以及结算界面。本站记录这些脚本所使用的 Lua API，并逐步讲解皮肤作者最常见的需求。

## 从哪里开始

- 如果你还没有写过模块，请阅读[模块的工作原理](getting-started.md)：皮肤的文件夹布局、模块类型，以及脚本会收到的生命周期回调。
- 要查找某个函数，请打开 [API 参考](api/)，从侧边栏中选择一个分类。
- 对于明确的目标，各篇指南会一步一步地讲解[角色](guides/characters.md)、[小角色](guides/puchicharas.md)、[皮肤与主题](guides/skins.md)以及[谱面解锁条件](guides/unlockables.md)。

## 你可以构建的内容

| 类别 | 所在位置 | 说明 |
| --- | --- | --- |
| 模块 | 皮肤的 `Modules/` 文件夹 | 舞台（拥有自己的输入、绘制和状态的完整界面：选曲界面、房间、剧情场景）、活动（对话框和名牌等子界面与覆盖层）以及过渡（舞台之间的淡入淡出和加载界面）。 |
| 背景 | 皮肤的 `Graphics/` 文件夹 | 装饰某个界面的脚本：启动界面、房间、演奏背景与观众、结算界面。 |
| 皮肤与主题 | 游戏安装目录下的 `System/` | 玩家安装并切换到的完整视觉套件，以及它在选项界面中提供的主题设置。 |
| 角色与小角色 | `Global/Characters/` 和 `Global/PuchiChara/`，由所有皮肤共享 | 演奏时随之起舞的角色，以及会做出反应的小吉祥物。 |
| 谱面解锁条件 | 歌曲文件夹中，谱面旁边 | 在玩家达成条件之前让歌曲保持锁定的 `Unlock.json`。 |

## 实验性章节

部分页面在侧边栏中带有 <span class="badge-exp">实验性</span> 徽章。它们描述的功能在当前版本中可以正常使用，但其 API 仍可能在版本之间变动且没有弃用过渡期。依赖这些功能的皮肤应注明所针对的游戏版本，并且你应在每次更新后重新测试。
