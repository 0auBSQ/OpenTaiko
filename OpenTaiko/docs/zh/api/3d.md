# 3D 引擎：光栅化世界 <span class="badge-exp">实验性</span>

场景、模型、光源、相机、物理、碰撞体、寻路、粒子、渲染目标和地形高度图。

3D 引擎属于实验性功能。按计划，它将在 1.0 版本中去掉实验性标记。

<div class="callout">
本页的每个全局对象和每个方法都可能在版本之间变动且没有弃用过渡期。如果你的皮肤依赖它，请在每次更新后重新测试，并注明所针对的游戏版本。
</div>

本页使用的约定：

- 位置和尺寸以世界单位计；+Y 向上。对象、纹理、精灵、材质和图元的 id 都是整数。
- 除非某一行注明为弧度（物理载具的朝向和倾斜、车轮旋转、草叶摆动相位），角度均以度为单位。
- `Clear`、`FillRect`、`DrawLine`、`SetFog`、`ObjSetPass`、`PsEmit` 和 `PsBurst` 接受 0-255 的颜色。光源、太阳、环境光、材质、着色和 `ObjSetColor` 接受线性 0-1 的颜色。
- 三种渲染器共享同一份场景数据：GPU 光栅化渲染器（有 GLES 3.1 计算着色器时为默认）、CPU 光栅化渲染器（回退方案，或用 `SetMode("raster_cpu")` 强制启用）和路径追踪器（`SetMode("raytrace")`）。其他渲染器会忽略标记为*仅 GPU 光栅化渲染器*或*仅路径追踪器*的行。

光线追踪器和物理世界各有专门页面：[光线追踪世界](3d-raytrace.md) 与 [物理](3d-physics.md)。

## 场景

### SCENE3D

<span class="badge-exp">实验性</span>

3D 场景的工厂。场景是一个渲染目标，拥有相机、保留对象、纹理、精灵、光源和粒子系统；你像绘制 2D 纹理一样绘制它。

| 方法 | 说明 |
| --- | --- |
| `SCENE3D:CreateScene(width, height)  -> scene` | 创建给定逻辑像素尺寸的场景并返回其句柄。游戏在拆除脚本所属舞台时释放场景。 |

### 场景句柄

<span class="badge-exp">实验性</span>

<div class="callout warn">
每帧流程：绘制背景（FillRect 或 ClearTransparent），更新相机和所有每帧变化的几何体，调用 Render，然后 Upload，然后 Draw。Render 不会清除颜色缓冲区，因此请先绘制天空或背景。
</div>

```lua
local scene, floor

function onStart()
    scene = SCENE3D:CreateScene(1280, 720)
    scene:SetLighting(true)
    scene:SetAmbient(0.4, 0.4, 0.46)
    scene:SetSun(0.3, 0.8, 0.5, 0.85, 0.82, 0.72)

    scene:RegisterTexture(1, pixels, 16, 16)          -- pixels：以 1 起始的 0xRRGGBB 整数数组
    floor = scene:NewObject()
    scene:ObjAddQuadTex(floor, 0,0,0,  0,0,8,  8,0,8,  8,0,0,  1, 8, 8, 1.0)
    scene:ObjSetBounds(floor, 0, 0, 0, 8, 0, 8)
end

function draw()
    scene:SetCameraPosition(4, 3, -6)
    scene:SetCameraAngles(0, -20)
    scene:FillRect(0, 0, 1280, 720, 90, 140, 220, 255)
    scene:Render()
    scene:Upload()
    scene:Draw(0, 0)
end

function onDestroy()
    scene:Dispose()
end
```

#### 渲染器

| 方法 | 说明 |
| --- | --- |
| `scene:SetMode(mode)  -> nil` | 选择渲染器：`"raster"`（默认；可用时为 GPU，否则为 CPU）、`"raster_cpu"`、`"raytrace"` 或 `"rt"`（GPU 路径追踪器，带 CPU 回退）、`"raytrace_cpu"` 或 `"rt_cpu"`。切换会丢弃缓存和累积的状态。 |
| `scene:GetMode()  -> string` | 当前渲染器：`"raster"`、`"raster_cpu"` 或 `"raytrace"`。 |
| `scene:SetThreads(n)  -> nil` | CPU 光栅化渲染器的线程数，它把屏幕分成这么多行带（默认 1）。 |
| `scene:SetRenderDistance(d)  -> nil` | 跳过包围盒（见 ObjSetBounds）完全位于此距相机距离之外的对象；0 = 不限制。仅光栅化渲染器。 |
| `scene:SetAntialias(on)  -> nil` | 对最终颜色缓冲区启用后处理边缘平滑（默认关闭）。 |
| `scene:GetSampleCount()  -> number` | 自上次相机或场景变化以来路径追踪器每像素累积的采样数；光栅模式下为 0。 |
| `scene:GetMemoryStats()  -> texCount, texBytes, spriteCount, objCount, grassBlades, liveParticles` | 供调试叠加层使用的资源计数。 |
| `scene:GetRendererStats()  -> string` | GPU 光栅化渲染器侧的缓存计数，或 `"cpu"`。 |
| `scene:ClearRenderCaches()  -> nil` | 丢弃可重建的渲染缓存（渲染到纹理目标、按对象的顶点缓冲区、合并的静态缓冲区）。已注册的纹理和精灵保留；在卸载地图时调用它。 |
| `scene:Dispose()  -> nil` | 立即释放场景；否则它会一直存在到舞台拆除。 |

如果 GPU 渲染器在渲染时失败（例如驱动拒绝了某个着色器），场景会在其余生命周期内切换到 CPU 光栅化渲染器，舞台继续运行。

#### 纹理与精灵

纹理是不透明的 RGB 图像，由四边形和三角形按 UV 采样。精灵是 ARGB 图像，供广告牌精灵、精灵四边形、粒子、草叶和地形混合权重使用。纹理 id 和精灵 id 是各自独立的命名空间，注册一个已存在的 id 会替换其像素。

| 方法 | 说明 |
| --- | --- |
| `scene:RegisterTexture(id, pixels, w, h)  -> nil` | 从一个以 1 起始、打包为 `0xRRGGBB` 整数的 Lua 数组（行主序，原点在左上）注册一张纹理。负值标记透明（镂空）纹素。场景会忽略超过 4,194,304 像素的图像。 |
| `scene:RegisterTextureFromImage(id, tex)  -> nil` | 通过回读一个已加载纹理句柄的像素来注册一张纹理。回读会丢弃 alpha，并且每次调用都访问一次 GPU，速度太慢，不适合每帧使用。 |
| `scene:SetTextureFilter(id, mode)  -> nil` | 纹理的采样过滤：`"nearest"`（默认）、`"linear"` 或 `"mipmap"`。仅 GPU 光栅化渲染器。 |
| `scene:UnregisterTexture(id)  -> nil` | 忘记一张纹理，包括其 GPU 上传和绑定到该 id 的任何渲染到纹理目标。 |
| `scene:SetSpriteRGBA(spriteId, pixels, w, h)  -> nil` | 从一个以 1 起始的 ARGB 整数 Lua 数组（`a << 24 | r << 16 | g << 8 | b`，行主序，原点在左上）注册一个精灵。 |
| `scene:RegisterSpriteFromTexture(spriteId, tex)  -> nil` | 通过回读一个已加载纹理句柄的像素来注册一个精灵。回读每次调用都访问一次 GPU，速度太慢，不适合每帧使用。 |
| `scene:MakeSoftCircle(spriteId, res, edge)  -> nil` | 生成一个 `res` x `res` 像素的白色圆形精灵，中心不透明，向边缘淡出为零；`edge` 决定衰减形状（1 为线性，2-3 为柔和辉光）。 |
| `scene:MakeCrystal(spriteId, res)  -> nil` | 生成一个 `res` x `res` 像素的六臂白蓝色雪花精灵。 |
| `scene:SetSpriteFilter(spriteId, mode)  -> nil` | 精灵的采样过滤：`"nearest"`（默认）或 `"linear"`。注册后立即调用。仅 GPU 光栅化渲染器。 |
| `scene:UnregisterSprite(spriteId)  -> nil` | 忘记一个精灵，包括其 GPU 上传。 |

模型的 Register 调用会把其材质注册为 id 从 4000 起（glTF）和 6000 起（OBJ）的纹理，因此当场景同时绘制模型时，请把你自己的纹理 id 保持在 4000 以下。

#### 对象

对象是一组保留的图元。同一对象中的所有图元必须是同一种类（带纹理四边形、纯色四边形、带纹理三角形、广告牌精灵或精灵四边形）；用不同种类重新填充对象前请先调用 ObjBegin。对象 id 从 1 起。

| 方法 | 说明 |
| --- | --- |
| `scene:NewObject()  -> id` | 在不透明通道中创建一个空的可见对象。 |
| `scene:DeleteObject(id)  -> nil` | 移除一个对象及其几何体。 |
| `scene:ClearObjects()  -> nil` | 移除所有对象和所有粒子系统，并丢弃渲染缓存。纹理、精灵、光源和相机保留；对象 id 从 1 重新开始。 |
| `scene:ObjBegin(id)  -> nil` | 清除一个对象的图元以便你重新填充。 |
| `scene:ObjAddQuadTex(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, texId, uMax, vMax, shade)  -> nil` | 追加一个带纹理的四边形。四个角映射到 UV (0, vMax)、(uMax, vMax)、(uMax, 0)、(0, 0)；`shade`（0-1）与纹素相乘，并在启用光照时控制太阳光的作用。 |
| `scene:ObjAddQuadFlat(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3)  -> nil` | 追加一个纯色四边形；颜色和 alpha 来自 ObjSetPass。 |
| `scene:ObjAddTriTex(id, x0, y0, z0, u0, v0, x1, y1, z1, u1, v1, x2, y2, z2, u2, v2, texId, shade)  -> nil` | 追加一个带显式 UV 的带纹理三角形。模型句柄用此图元填充对象。 |
| `scene:ObjAddSprite(id, x, y, z, w, h, spriteId, billboard, cutout)  -> nil` | 追加一个世界尺寸 `w` x `h`、底部中心位于 (x, y, z) 的精灵四边形。`billboard`：0 固定在 XY 平面，1 面向相机但保持直立，2 始终面向相机，3 平贴地面并沿 SetGroundSpriteLight 方向拉伸。`cutout` 非零时做 alpha 测试并写入深度（不透明通道）；0 时做 alpha 混合（请把对象放到透明通道）。 |
| `scene:ObjAddSpriteQuad(id, x0, y0, z0, x1, y1, z1, x2, y2, z2, x3, y3, z3, spriteId, cutout)  -> nil` | 在显式给出的世界四边形上追加一个精灵（四个角映射到 UV (0, 1)、(1, 1)、(1, 0)、(0, 0)）；不做广告牌处理。 |
| `scene:ObjSetTransform(id, m)  -> nil` | 从一张 16 个行主序数字的 Lua 表设置对象的模型矩阵（平移在 m[4]、m[8]、m[12]）；nil 恢复单位矩阵。 |
| `scene:ObjSetTransform16(id, m0, m1, m2, m3, m4, m5, m6, m7, m8, m9, m10, m11, m12, m13, m14, m15)  -> nil` | 与 ObjSetTransform 相同，但用 16 个普通参数；每帧更新时请用此方法。 |
| `scene:ObjClearTransform(id)  -> nil` | 恢复单位模型矩阵。 |
| `scene:ObjSetBounds(id, minX, minY, minZ, maxX, maxY, maxZ)  -> nil` | 用于相机后方剔除、SetRenderDistance 和 ObjSetNormal 的世界空间包围盒。 |
| `scene:ObjSetNormal(id, nx, ny, nz)  -> nil` | 把对象视为面向 (nx, ny, nz) 的平面组，并在相机位于该平面后方时跳过它（需要 ObjSetBounds）；0, 0, 0 禁用。 |
| `scene:ObjSetVisible(id, v)  -> nil` | 显示或隐藏一个对象。 |
| `scene:ObjSetPass(id, pass, r, g, b, a)  -> nil` | 渲染通道（0 不透明，从前往后绘制；1 透明，从后往前绘制），以及作用于纯色四边形和精灵的纯色颜色（0-255）和 alpha（0-255）。 |
| `scene:ObjSetTint(id, r, g, b)  -> nil` | 对带纹理表面和精灵的逐通道颜色相乘（0-1）；1, 1, 1 = 无。 |
| `scene:ObjSetColor(id, r, g, b)  -> nil` | 在光照之前替换纹理或材质颜色的纯色反照率覆盖（0-1）；r < 0 清除。仅 GPU 光栅化渲染器。 |
| `scene:ObjSetEmissive(id, r, g, b)  -> nil` | 自发光叠加（颜色 += 基色 x rgb）；大于 1 的值会进入 SetDiorama 的泛光。0, 0, 0 = 关闭。仅 GPU 光栅化渲染器。 |
| `scene:ObjSetLit(id, lit)  -> nil` | 前向光照是否作用于该对象（默认 true）；false 时只按其烘焙的 shade 渲染。 |
| `scene:ObjSetCastShadow(id, on)  -> nil` | 该对象的精灵是否投射到太阳阴影贴图中（默认 true）。仅 GPU 光栅化渲染器。 |
| `scene:ObjSetDepthBias(id, bias)  -> nil` | 多边形偏移的深度偏移：负值把对象拉向相机（共面表面上的贴花），正值推离；0 = 关闭。仅 GPU 光栅化渲染器。 |
| `scene:ObjSetOverlay(id, on)  -> nil` | 在清除深度缓冲区后最后绘制该对象，使其始终显示在最上层（第一人称视角模型）。 |
| `scene:ObjSetXray(id, alpha)  -> nil` | 在世界几何体遮挡处以此 alpha（0-1）把对象的精灵重绘为幽灵；0 = 关闭。仅 GPU 光栅化渲染器。 |
| `scene:ObjSetMaterial(id, matId)  -> nil` | 路径追踪器为该对象使用的材质（-1 = 默认）。仅路径追踪器。 |
| `scene:ObjSetTerrainSplat(id, splatSpriteId, tex1, tex2, tex3, tex4, worldW, worldH, uvScale)  -> nil` | 按一个 ARGB 权重精灵逐像素混合四层纹理（见“混合权重图句柄”）；`worldW`/`worldH` 是权重图的世界覆盖范围，`uvScale` 是每世界单位的纹理重复次数。`splatSpriteId` < 0 禁用。仅 GPU 光栅化渲染器。 |

#### 光源与阴影

前向光照默认关闭。启用后，环境光项、太阳和点光源会照亮每个面。

| 方法 | 说明 |
| --- | --- |
| `scene:SetLighting(on)  -> nil` | 在光栅化渲染器上启用前向光照。 |
| `scene:SetAmbient(r, g, b)  -> nil` | 加到每个受光面上的环境光。 |
| `scene:SetSun(dx, dy, dz, r, g, b)  -> nil` | 方向性太阳光：(dx, dy, dz) 是朝向太阳的方向（自动归一化）；(r, g, b) 是颜色乘以亮度，因此大于 1 的值也有效。零颜色禁用它。 |
| `scene:AddLight(x, y, z, r, g, b, intensity)  -> nil` | 添加一个平方反比衰减的点光源；颜色乘以强度。 |
| `scene:AddLightRanged(x, y, z, r, g, b, intensity, range)  -> nil` | 添加一个在光栅化渲染器上于 `range` 处衰减到零的点光源；路径追踪器忽略范围。 |
| `scene:ClearLights()  -> nil` | 移除所有点光源。 |
| `scene:SetShadows(on)  -> nil` | 启用太阳阴影贴图。需要 SetLighting 和非零的 SetSun。仅 GPU 光栅化渲染器。 |
| `scene:SetShadowFocus(x, y, z)  -> nil` | 每帧把太阳阴影贴图的中心置于此世界点（通常是玩家）。仅 GPU 光栅化渲染器。 |
| `scene:SetShadowArea(half)  -> nil` | 围绕焦点的阴影贴图盒子的半边长（世界单位，默认 60，最小 4）。仅 GPU 光栅化渲染器。 |
| `scene:SetGroundSpriteLight(dx, dz, lenScale)  -> nil` | 广告牌模式 3 的精灵（平贴地面的投影）的水平方向和长度比例。 |

#### 雾、天空与后处理

| 方法 | 说明 |
| --- | --- |
| `scene:SetFog(on, r, g, b, start, end)  -> nil` | 距离雾：像素在相机深度 `start` 和 `end` 之间淡入 (r, g, b)（0-255）。仅光栅化渲染器。 |
| `scene:SetDiorama(on, tilt, sat, vig, bloom)  -> nil` | 后期调色：移轴模糊（像素，0 = 无）、饱和度（1 = 无）、暗角强度和泛光强度（0 = 关闭）。仅 GPU 光栅化渲染器。 |
| `scene:SetColorGrade(exposure, r, g, b)  -> nil` | 由 SetDiorama 通道应用的曝光乘数和逐通道着色；1, 1, 1, 1 为中性。仅 GPU 光栅化渲染器。 |
| `scene:SetWetness(w)  -> nil` | 表面湿润度 0-1：压暗受光漫反射并添加太阳高光。仅 GPU 光栅化渲染器。 |
| `scene:SetOutline(r, g, b, thicknessPx)  -> nil` | 围绕渲染形状、给定颜色（0-255）和像素粗细的轮廓描边；0 禁用。 |
| `scene:ApplyOutline(r, g, b, thickness)  -> nil` | 直接在 CPU 颜色缓冲区上运行描边通道。设置了 SetOutline 时，CPU 光栅化渲染器的 Render 已经会这样做。 |
| `scene:SetTime(t)  -> nil` | 供涟漪、天空、表面和后处理着色器使用的着色器时钟（秒，`uTime`）；每帧提供一次。 |
| `scene:SetSkyShader(fragSrc)  -> nil` | 附加一个渲染器在 3D 通道之前绘制的全屏 GLSL ES 3.00 片段着色器。可传入完整源码，或只传入 `main()` 主体，场景会加上前导部分（`uRes`、`uTime`、`uUser[8]`、`out vec4 frag`）。nil 或 "" 分离。仅 GPU 光栅化渲染器。 |
| `scene:SetSkyUniform(slot, x, y, z, w)  -> nil` | 为天空着色器设置 `uUser[slot]`（0..7）。 |
| `scene:SkyShaderActive()  -> boolean` | GPU 光栅化渲染器本帧将绘制已附加的天空着色器时为 true，舞台可据此跳过自己的天空填充。 |
| `scene:SetPostShader(fragSrc)  -> nil` | 附加一个在 SetDiorama 通道之后运行的全屏后处理片段着色器。源码规则与 SetSkyShader 相同；前导部分提供 `uTex`（渲染出的帧）、`uRes`、`uTime`、`uUser[4]` 和 `out vec4 frag`。nil 或 "" 分离。仅 GPU 光栅化渲染器。 |
| `scene:SetPostUniform(slot, x, y, z, w)  -> nil` | 为后处理着色器设置 `uUser[slot]`（0..3）。 |
| `scene:GetShaderError()  -> string` | 最近一次天空、后处理或表面着色器的编译错误；正常时为 ""。渲染器会跳过失败的着色器，舞台继续运行。 |
| `scene:SetDistanceBlur(on, near, far)  -> nil` | 已弃用的空操作，为让旧脚本继续运行而保留；请使用 SetDiorama。 |

| `scene:GrassRemoveRect(x0, z0, x1, z1)  -> nil` | 移除根部位于该 XZ 矩形内的草叶（道路、水池、建筑地基）。 |

#### 粒子

粒子系统是一个面向相机的广告牌池。向其中发射粒子，每帧调用 PsUpdate，光栅化渲染器会在透明通道中绘制存活的粒子。系统 id 从 0 起；ClearObjects 会使它们失效。

| 方法 | 说明 |
| --- | --- |
| `scene:NewParticleSystem()  -> id` | 创建一个粒子系统并返回其 id。 |
| `scene:PsUpdate(id, dt)  -> nil` | 把系统推进 `dt` 秒（老化、重力、阻力、运动）。 |
| `scene:PsEmit(id, x, y, z, vx, vy, vz, r, g, b, a0, size0, size1, life, gravity, drag, additive)  -> nil` | 发射一个粒子：颜色 0-255，起始不透明度 `a0` 0-1，广告牌尺寸在 `life` 秒内从 `size0` 变到 `size1`（世界单位），向下的重力，每秒阻力；`additive` 非零时把粒子以叠加方式混合到画面上，为 0 时以 alpha 混合。 |
| `scene:PsBurst(id, x, y, z, count, dirX, dirY, dirZ, spread, speed, r, g, b, colorJitter, a0, size0, size1, life, lifeVar, gravity, drag, additive)  -> nil` | 发射 `count` 个粒子，方向随机但按 `spread` 偏向 (dirX, dirY, dirZ)（0 = 严格沿该方向，1 = 完全随机），速度最高为 `speed`，带颜色抖动，以及每粒子寿命变化 `lifeVar`（`life` 的比例）。 |
| `scene:PsSetSprite(id, spriteId)  -> nil` | 印在之后发射的粒子上的精灵（-1 = 纯色方块）。 |
| `scene:PsSetNextRotation(id, rotDeg, rotVelDegPerSec)  -> nil` | 之后发射的粒子的广告牌旋转：起始角度（度，负值 = 每粒子随机）和旋转速率（度/秒，每个粒子获得随机的大小和方向）。0, 0 = 关闭。 |
| `scene:PsSetNextCurves(id, sizeCurve, fadeCurve)  -> nil` | 之后发射的粒子的曲线。尺寸：0 线性，1 缓出，2 先长后缩。淡出：0 线性，1 平滑淡入淡出，2 亮闪加长尾。 |
| `scene:PsSetCap(id, cap)  -> nil` | 最大存活粒子数（默认 4000）；系统会丢弃超过上限的发射。 |
| `scene:PsCount(id)  -> number` | 存活粒子数。 |
| `scene:PsClear(id)  -> nil` | 移除系统中所有存活的粒子。 |

#### 渲染到纹理视图

这些方法从另一个相机把场景重新渲染到一张已注册的纹理中，然后由一个四边形按屏幕位置采样它（ObjSetScreenTex），以显示镜子、水面反射、传送门和显示器。重新渲染会跳过标记了 ObjSetScreenTex 或 ObjSetOverlay 的对象，以免反射递归。

| 方法 | 说明 |
| --- | --- |
| `scene:SetReflectionScale(shift)  -> nil` | 重新渲染相对于主视图的分辨率：0 全分辨率，1 一半（默认），2 四分之一，3 八分之一。 |
| `scene:SetReflectionGpu(on)  -> nil` | 让 RenderView 和 RenderViewReflect 通过 GPU 离屏通道运行。默认关闭，此时由 CPU 光栅化渲染器渲染这些视图；GPU 通道失败时，场景回退到 CPU 路径。 |
| `scene:RenderView(texId, cx, cy, cz, yawDeg, pitchDeg, fovDeg, clr, clg, clb, flipX)  -> nil` | 从给定相机把场景渲染到纹理 `texId`，先把它清除为 (clr, clg, clb)（0-255）。`flipX` 非零时镜像图像（平面镜）。 |
| `scene:RenderViewReflect(texId, px, py, pz, nx, ny, nz, clr, clg, clb)  -> nil` | 把关于经过 (px, py, pz)、法线为 (nx, ny, nz) 的平面的平面反射渲染到纹理 `texId`。GPU 路径会裁掉平面以下的几何体。 |
| `scene:ObjSetScreenTex(id, on)  -> nil` | 把对象的纹理采样方式从 UV 切换为屏幕位置，使贴有 RenderView 结果的四边形显示与屏幕对齐的该视图。 |
| `scene:ObjSetScreenTexRipple(id, amp, freq, speed)  -> nil` | 屏幕纹理表面的动态扭曲：`amp` 以渲染目标像素计（0 = 关闭），世界空间波频率和动画速度（由 SetTime 驱动）。仅 GPU 光栅化渲染器。 |
| `scene:ObjSetFresnel(id, f0)  -> nil` | 屏幕纹理表面的逐像素 Schlick 菲涅尔反射率（水约为 0.04）；负值禁用。仅 GPU 光栅化渲染器。 |

| `scene:ObjSetSurfaceShader(id, fragSrc)  -> nil` | 为屏幕纹理表面附加一个自定义 GLSL ES 3.00 片段着色器，替换内置的涟漪和菲涅尔外观。完整源码或 `main()` 主体；前导部分提供 `vUV`、`vShade`、`vCamZ`、`vWorld`、`vNormal`、`uTex`（反射）、`uRsh`、`uRttFlip`、`uCam`、`uTint`、`uFlat`、`uTime`、`uAlpha`、`uUser[4]` 和 `out vec4 frag`。nil 或 "" 分离；编译失败时回退到内置着色器。仅 GPU 光栅化渲染器。 |

## 模型

### MODEL

<span class="badge-exp">实验性</span>

把 glTF/GLB（蒙皮、带动画）和 OBJ（静态）文件加载为可摆姿势的模型句柄。

<div class="callout warn">
路径相对于脚本目录；加载器也接受绝对路径。加载器每个进程只解析一次每个 glTF 文件，并在场景和舞台之间共享，因此用 SetPartObject 设置的部件路由会一直保留，直到 ClearPartObjects 或 PurgeCache。glTF 支持涵盖带位置、一组 UV、可选关节和权重、一个蒙皮、节点层级、线性 TRS 动画、材质基色以及内嵌基色纹理（长边缩小到 512 像素）的索引三角形图元。OBJ 支持涵盖位置、纹理坐标、多边形面以及来自 .mtl 文件的漫反射颜色；加载器跳过图像纹理。
</div>

| 方法 | 说明 |
| --- | --- |
| `MODEL:Load(path)  -> model` | 加载一个 .glb、.gltf 或 .obj 文件并返回模型句柄；失败时返回 nil。 |
| `MODEL:PurgeCache()  -> nil` | 丢弃进程范围的 glTF 缓存（舞台退出时）。之后请重新加载仍在使用的模型。 |

### 模型句柄

<span class="badge-exp">实验性</span>

<div class="callout warn">
每个场景调用一次 Register，然后每帧调用 Pose，把摆好姿势（对 glTF 还包括蒙皮）的三角形写入一个场景对象。动画索引从 0 起；-1 摆出绑定姿势。Pose 会把动画时间限制在片段范围内，请自行用 Duration 循环。Duration 以下的方法仅限 glTF；OBJ 句柄公开 Register、Pose、AnimCount（0）、AnimName 和 Duration。
</div>

```lua
local model, obj
local clip = 0

function onStart()
    model = MODEL:Load("models/lantern.glb")
    if model then
        model:Register(scene)
        obj = scene:NewObject()
    end
end

function draw()
    if model then
        local t = elapsed % model:Duration(clip)
        model:Pose(scene, obj, clip, t, x, y, z, yawDeg, 1.0)
    end
end

function onDestroy()
    MODEL:PurgeCache()
end
```

| 方法 | 说明 |
| --- | --- |
| `model:Register(scene)  -> nil` | 把模型的材质和纹理注册到一个场景中（每个场景一次）。 |
| `model:Pose(scene, objId, anim, time, x, y, z, yawDeg, scale)  -> nil` | 清除对象 `objId`，并用模型在动画 `anim`、`time` 秒时的三角形填充它，平移到 (x, y, z)，绕 Y 旋转 `yawDeg`，并等比缩放。 |
| `model:AnimCount()  -> number` | 动画片段的数量（OBJ 为 0）。 |
| `model:AnimName(i)  -> string` | 片段 `i` 的名称；超出范围时为 ""。 |
| `model:Duration(i)  -> number` | 片段 `i` 的时长（秒）；超出范围时为 0。 |
| `model:PartCount()  -> number` | 部件（图元实例）的数量。 |
| `model:PartMaterial(part)  -> number` | 某个部件的材质索引（从 0 起）；超出范围时为 -1。 |
| `model:MaterialCount()  -> number` | glTF 材质的数量。 |
| `model:MaterialName(mat)  -> string` | 某个 glTF 材质的名称；超出范围时为 ""。 |
| `model:MaterialEmissive(mat)  -> r, g, b` | 该材质的 glTF `emissiveFactor`；没有时为 0, 0, 0。 |
| `model:SetPartObject(part, objId)  -> nil` | 在 Pose 时把某个部件的三角形路由到它自己的场景对象，使该部件可以拥有自己的透明、自发光或镜面标志；-1 清除该部件的路由。 |
| `model:ClearPartObjects()  -> nil` | 丢弃所有部件路由。在世界卸载时调用它，因为模型实例是共享的，而对象 id 在 ClearObjects 后会重新开始。 |
| `model:GetBounds()  -> minX, minY, minZ, maxX, maxY, maxZ` | 模型空间的绑定姿势包围盒。 |
| `model:BuildCollider(mc, x, y, z, yawDeg, scale)  -> nil` | 把按给定变换放置的绑定姿势三角形追加到一个 MeshCollider。负的缩放按其绝对值生效。 |

## 高度图

### HEIGHTMAP

<span class="badge-exp">实验性</span>

为地形加载原始 16 位高度场和 RGBA 混合权重图像，并一次性构建整个地形。

<div class="callout warn">
路径相对于脚本目录。高度场文件包含 w x h 个按行主序排列的小端无符号 16 位采样；混合权重图像是一张 RGBA PNG，其 R、G、B、A 通道分别是第 1 到第 4 层的权重。读取出错时，两个加载器都返回平坦的回退值。
</div>

| 方法 | 说明 |
| --- | --- |
| `HEIGHTMAP:Load(path, w, h)  -> heightfield` | 加载一个 w x h 采样的高度场；出错时返回平坦的零场。 |
| `HEIGHTMAP:LoadSplat(path)  -> splatmap` | 加载一张混合权重图像；出错时返回全为第 1 层的图。完全不透明的 alpha 通道表示该图没有第 4 层。 |
| `HEIGHTMAP:BuildTerrain(scene, floorObj, world, hf, splat, w, h, minY, maxY, cellSize, tex1, tex2, tex3, tex4, grassDensity, grassClump)  -> number` | 一次性生成地形：向 `floorObj` 中每个单元写入一个带纹理四边形（采样 (ix, iz) 位于世界 x = ix x cellSize、z = iz x cellSize、y = minY + 采样 x (maxY - minY)；每层纹理每单元重复一次），向 `world` 中写入匹配的碰撞四边形和不可见的边界墙（在 BeginStatic 和 EndStatic 之间调用），并在 `grassDensity` > 0 时于远离陡坡和地图边缘的第 1 层地面种草（`grassClump` > 0 时把草聚成丛）。没有混合权重图时，陡峭单元使用 `tex2`，其余使用 `tex1`。返回种下的草叶数量。 |
