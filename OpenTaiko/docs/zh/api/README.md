# API 参考

<span class="badge-new">游戏版本 0.6.1</span>

OpenTaiko Lua 运行时向皮肤公开的每一个全局对象的参考。从侧边栏中选择一个分类；如果你还没有写过模块，请先从[模块与生命周期](activities.md)开始。

## 如何阅读函数签名

每个条目都按你在 Lua 中调用它的方式展示函数。

- 冒号表示你在某个值上调用该函数，Lua 会把该值作为隐藏的 `self` 传入：你在先前加载的纹理上调用 `tex:Draw(x, y)`。
- 点或裸名称表示普通调用，例如 `GetSaveFile(0)`。
- 箭头后面的类型是调用的返回值：`TEXTURE:CreateTexture(path) -> texture` 返回一个你保留并在之后绘制的句柄。

全局对象的名称为大写（`TEXTURE`、`SOUND`、`INPUT`）。运行时在每个模块脚本中提供它们；你永远不需要自己创建它们。

## “实验性”标记

标记为<span class="badge-exp">实验性</span>的函数目前可以正常工作，但可能在版本之间变动且没有弃用过渡期。3D 引擎和在线联机目前都带有此标记；按计划，3D 引擎将在 1.0 版本中脱离实验性状态。如果皮肤依赖实验性函数，请在每次更新后重新测试，并注明所针对的游戏版本。
